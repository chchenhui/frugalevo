<DESCRIPTION>
The dynamic program reconstructs a minimum-cost shared edge union, but the final per-destination routes are currently extracted with an unweighted shortest-path search. If reconstruction produces multiple source-to-destination routes within the shared union, NetworkX selects the route with the fewest hops rather than the cheapest transfer route. This can materialize unnecessarily expensive cloud egress links and can prevent redundant expensive branches from being omitted by the topology consumer.

Use cost-weighted path extraction when materializing destination routes. The selected path remains entirely inside the optimized shared broadcast union, preserves source reachability, and minimizes each destination's transfer cost among the available shared routes.
</DESCRIPTION>
