<DESCRIPTION>
Replace the purely greedy multicast expansion with an exact directed Steiner-tree dynamic program for small destination sets. The current Prim-like strategy commits early to the nearest terminal, which can prevent discovery of a slightly more expensive relay branch that substantially reduces total shared-link cost for later destinations.

The replacement computes the minimum-cost shared directed subgraph connecting the source to every reachable destination when there are at most nine terminals. It combines terminal subsets at relay nodes and relaxes those shared subtrees backward across the network, thereby explicitly valuing overlapping transfers. For larger terminal sets, it preserves the existing scalable greedy behavior. This hybrid keeps runtime bounded while improving the cases where exact shared branching is most beneficial.
</DESCRIPTION>
