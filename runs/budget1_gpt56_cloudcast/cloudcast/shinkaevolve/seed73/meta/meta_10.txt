# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- **Exact directed Steiner optimization produced the best observed cost.** The current best program, **Exact Shared Broadcast Steiner Planner** (Generation 9), achieved **total cost 618.10 / average 123.62**, substantially improving on greedy multicast trees at approximately **741.09–741.10 / 148.22**. Its Dreyfus-Wagner-style subset DP explicitly optimizes a shared directed relay tree rather than choosing each destination attachment independently.

- **The same exact-Steiner result was reproduced across several implementations**, strengthening the evidence that shared-tree optimization is beneficial: **Exact Steiner Broadcast with Greedy Fallback** (Generation 4), **Directed Steiner Broadcast Planner** (Generation 6), and **Exact Directed Steiner Broadcast Tree** (Generation 8) all reached **618.10 total cost** with full validation success. This is a **16.6% cost reduction** versus the 741.09 greedy shared-tree baseline.

- **Sanitizing the graph before optimization was consistently compatible with successful execution.** The current best removes self-loops, edges entering the source, and invalid/negative/non-finite cost edges. The exact planners all maintained **5/5 successful configurations** and **100% success rate**, showing that defensive graph cleanup did not compromise feasibility.

- **Shared-edge materialization is materially better than independent per-destination routing.** The initial **Per-Destination Shortest-Path Broadcast** cost **1035.14**, while the current exact shared-tree solution cost **618.10**—a **40.3% reduction**. This strongly indicates that the evaluator rewards at least some degree of shared relay/link usage in the constructed topology.

## Ineffective Approaches

- **Independent shortest paths were the weakest routing strategy.** Generation 0 replicated each destination’s individually cheapest source-to-destination path into every partition and incurred **1035.14 total cost**, the highest result. It fails to exploit common prefixes or shared relay links among destinations.

- **Nearest-destination greedy expansion improved over independent paths but remained significantly suboptimal.** Generations 1, 2, 3, and 5 used multi-source Dijkstra to attach the nearest pending terminal into a shared tree. Costs improved from **795.06** in Generation 1 to **741.09–741.10** in later greedy variants, but remained about **123.0 higher** than the exact planners. The evaluation feedback consistently attributes this to local connector decisions producing expensive global tree structures.

- **More sophisticated greedy marginal-cost search did not surpass exact DP.** **Marginal-Cost Broadcast Tree Search** (Generation 7) compared shortest-path unions and several zero-cost-for-existing-edge growth variants, reaching **627.13 total cost**. This was better than basic greedy expansion but still **9.03 cost units (1.46%) worse** than the 618.10 exact-Steiner result. Reusing selected edges in the path weight helps, but does not fully capture globally beneficial future branching choices.

- **All approaches received a 0.00 cost score despite cost differences.** Therefore, the evaluator’s score threshold or cost model is stricter than the best observed implementation. Nevertheless, the raw-cost ordering is clear: independent paths were worst, greedy sharing was intermediate, marginal-cost search was close, and exact Steiner DP was best.

## Implementation Insights

- **The current best program’s core strength is its exact state-space formulation.** `_ExactSteinerPlanner` stores the optimal cost of connecting each terminal subset from every graph node. For a mask, it:
  1. combines two previously solved submasks at a shared node; then
  2. runs reverse multi-source Dijkstra to propagate that subtree cost upstream.
  
  This is precisely the mechanism absent from the greedy implementations: it can choose a relay/branch point because it is globally useful for a subset, not merely because it gives the cheapest next destination connection.

- **The reverse-graph relaxation is particularly effective for directed routing.** In `_relax_reverse_edges`, a solved subtree rooted at a node is extended backward through predecessor edges using original forward edge costs. This allows the DP to compute the cheapest directed source-to-subtree construction while respecting edge directionality, unlike a simple undirected or prefix-only sharing model.

- **Tree reconstruction preserves shared links before topology conversion.** `_reconstruct` follows recorded `"split"` and `"edge"` decisions into one `nx.DiGraph`; `_TopologyMaterializer` then derives each destination’s source-to-destination route from that tree. This differs from Generation 0’s independent route construction and explains the large 1035.14-to-618.10 reduction.

- **Robustness-oriented details were successful but do not explain the cost gain alone.** The current best validates costs, filters source-incoming links and self-loops, deduplicates destinations for optimization, handles source-local destinations, and uses a scalable marginal-cost fallback above 15 terminals. These mechanisms support its perfect **5/5 validation** record, while the exact DP is the primary differentiator behind its lowest raw cost.

## Performance Analysis

- **The strongest observed cost progression is from no sharing to greedy sharing to exact sharing.**
  - Per-destination shortest paths: **1035.14**
  - Incremental shared multicast: **795.06**
  - Greedy shared multicast variants: **741.09–741.10**
  - Marginal-cost shared-tree search: **627.13**
  - Current best exact shared Steiner planners: **618.10**

  This progression correlates directly with increasing ability to optimize shared relay edges globally.

- **The current best is decisively better than conventional greedy multicast.** At **618.10**, it beats the 741.09 greedy shared-tree family by **122.99 total-cost units**, or about **16.6%**. The repeated equal result in Generations 4, 6, 8, and 9 indicates that the exact DP, rather than naming or minor fallback variation, drove this improvement.

- **Generation 7 narrowed the gap but did not eliminate it.** Its **627.13** total cost demonstrates that marginal-cost routing and multiple order/seed attempts capture much of the value of link reuse. However, its remaining gap to the current best confirms that choosing paths based only on presently selected edges is weaker than jointly optimizing terminal subsets and branch points.

- **Reliability was uniformly high, so raw cost is the meaningful differentiator.** Every listed program achieved **runs_successfully = 1.00**, **success_rate = 1.00**, and **5 successful configurations**. Since all combined and cost scores were still **0.00**, the benchmark’s scoring cutoff was not reached by any candidate, but the raw evaluator cost consistently ranks the current best exact-Steiner design first.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Extend the exact directed-Steiner DP beyond the fixed 15-terminal cutoff using terminal decomposition.** Partition large destination sets into geographically/cost-correlated clusters, solve an exact Steiner tree for each cluster plus representative relay terminals, then run a second exact or marginal optimization over the union of selected relay nodes. This preserves the proven subset-DP advantage while avoiding the full \(2^k\) state explosion that currently forces the weaker greedy fallback.

2. **Add incumbent-guided exact search and stronger pruning to the Dreyfus-Wagner solver.** First construct a high-quality feasible tree with the marginal-cost planner, use its cost as an upper bound, and skip DP states or merge candidates whose lower-bound cost cannot beat that incumbent. Since Generation 7’s marginal search was already close to optimum (627.13 versus 618.10), it is a strong source of upper bounds that may enable exact optimization for more terminals or reduce runtime enough to explore richer states.

3. **Optimize the selected Steiner tree with local directed exchange moves after reconstruction.** Starting from the exact DP tree, attempt to remove a relay edge/subtree and reconnect its affected terminal set through an alternative predecessor, alternate branch node, or cheaper directed path, accepting only changes that preserve source reachability for every destination and reduce unique-edge cost. The current DP is exact for its modeled state space, but a postprocessing phase can exploit graph details such as equivalent paths, redundant edges, or topology-materialization effects that may not be captured by the initial reconstruction choices.

4. **Implement a hybrid “core exact + marginal attachment” planner for terminal counts above the exact limit.** Select a small core subset of high-cost, distant, or structurally diverse terminals; solve it exactly, then attach remaining terminals using marginal shortest paths where already-selected edges have zero incremental cost. Repeatedly try several core selections—e.g., farthest terminals, highest individual source distance, and terminals with least path overlap—because the evidence shows exact shared branching is most valuable, while marginal attachment is a reliable scalable complement.

5. **Make tie-breaking in DP relaxation and reconstruction sharing-aware rather than arbitrary.** When equal-cost `"split"` or `"edge"` decisions occur, prefer decisions that reuse edges already likely to be present in sibling subtrees, reduce total tree edge count, favor existing branch nodes, or produce shorter source-to-terminal paths. The best planner already achieves optimal reported DP cost, but deterministic cost-only ties can yield different materialized topologies; explicit sharing-aware tie-breaking is a low-risk mutation that may uncover a lower evaluator-measured topology without sacrificing feasibility.
