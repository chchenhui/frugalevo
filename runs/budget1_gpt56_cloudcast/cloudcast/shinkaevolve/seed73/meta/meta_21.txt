# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- **Exact directed-Steiner subset DP remains the best observed cost pattern.** The current best exact-Steiner family, represented by **Hybrid Directed Steiner Broadcast Routing (Generation 18, `incumbent_pruned_steiner`)**, achieved **618.10 total cost / 123.62 average cost** with **5/5 successful configurations**. The current evaluated program, **Generation 20 (`incumbent_pruned_exact_extension`)**, also achieved the same **618.10 / 123.62** with perfect validation, confirming that the exact DP topology is still the strongest evaluated routing approach.

- **The current program’s DP correctly models shared multicast structure.** `_exact_steiner_tree` uses `dp[mask][node]`: a minimum-cost directed subtree rooted at `node` that reaches the terminal subset in `mask`. Its `"merge"` transition combines two terminal subsets at the same relay, while its reverse-edge Dijkstra relaxation extends a solved subtree upstream. This jointly chooses branch points and shared prefixes, explaining the large improvement over independent shortest paths (**1035.14**) and greedy shared-tree growth (**795.06**).

- **Reverse-graph shortest-path relaxation is a robust exact-solver implementation pattern.** For singleton masks, the current code starts each terminal at cost zero and relaxes through `h.predecessors(node)`, charging the original forward edge cost. For merged masks it repeats the same relaxation after evaluating subset partitions. This exact directed formulation was consistently successful across Generations 12, 13, 15, 16, 17, 18, 19, and 20, all reaching the observed best plateau of **618.10**.

- **Feasible greedy construction plus exact incumbent pruning retained reliability.** The current program first builds `_greedy_shared_tree`, computes the selected-edge incumbent cost, and supplies that as `upper_bound` to the exact DP. It remained fully valid on all five configurations while making exact search practical for up to 12 unique terminals. The fact that Generation 20 ties the prior best rather than regressing shows that this pruning safely preserved the strongest known solution quality on the evaluated cases.

## Ineffective Approaches

- **Greedy attachment alone remained substantially worse than global subset optimization.** **Greedy Shared Multicast Tree (Generation 10)** reached **795.06 total / 159.01 average**, which is **176.96 higher** than the exact-Steiner family’s **618.10**—a **28.6% higher raw cost**. Its local multi-source attachment rule accounts for already-built edges, but it cannot select relay branches whose benefit only becomes apparent when multiple future terminals are optimized jointly.

- **The fixed exact-core plus greedy-attachment decomposition performed especially poorly.** The earlier **Hybrid Directed Steiner Broadcast Planner (Generation 11)** had an **1065.12 total / 213.02 average** result, worse even than basic greedy expansion. Its distant-terminal core selection and greedy outer attachments evidently broke globally useful sharing relationships rather than preserving them.

- **Small exact-terminal cutoffs were insufficient.** **Generation 14**, which limited exact Steiner candidates to eight terminals and combined them with several heuristic candidates, produced **741.08 total / 148.22 average**. This is **122.98 cost units above** the current best. The result indicates that covering only a small terminal core failed to represent enough of the multicast branching decision space.

- **Generation 20’s hybrid/extension framing did not improve beyond the established exact-DP plateau.** Although it was correct and robust, its **618.10** total is identical to Generations 12, 13, 15, 16, 17, 18, and 19. Thus, on these five evaluated configurations, the additional hybrid fallback/core-selection ideas did not produce a lower-cost topology than the existing exact-DP approach.

## Implementation Insights

- **The current program retains sharing until after tree selection.** `_exact_steiner_tree` reconstructs one union of selected directed edges from DP decisions, then `_normalize_tree` derives source-to-terminal paths inside that common union. `search_algorithm` only replicates those final destination paths across partitions afterward. This is important because edge sharing is optimized at the topology level rather than lost through independent per-destination route construction.

- **`_normalize_tree` is a useful feasibility and cleanup layer.** Both greedy and exact trees are normalized by running source-rooted Dijkstra over the selected edge union and retaining only routes needed by reachable terminals. This removes residual cycles and redundant edges from heuristic or reconstruction artifacts without compromising route validity. The program maintained **100% success rate**, suggesting this cleanup was compatible with evaluator requirements.

- **Graph sanitization is conservative and reliability-preserving.** `_valid_cost_graph` removes source-incoming edges, self-loops, and edges with missing, negative, non-finite, or malformed costs. It also handles missing sources and unreachable destinations by returning empty paths rather than failing. This defensive behavior is consistent with the perfect **5/5 successful configurations** reported for the current program and the broader Generation 10–20 group.

- **Strict incumbent pruning explains runtime practicality but not the cost improvement plateau.** The DP discards candidates with `candidate >= upper_bound`, where the bound is the greedy tree’s summed edge cost. This avoids exploring exact states that cannot beat a deployable multicast solution. However, because Generation 20’s result exactly matches prior exact variants, the evaluation data indicates that the decisive factor is still the core DP state/transition formulation, not the particular pruning or normalization refinement.

## Performance Analysis

- **The current best raw-cost result is a tie, not a new improvement.** Generation 20 achieved **618.10 total cost / 123.62 average cost**, matching the previously best Generation 18 exact-Steiner implementation and several related exact variants. It is still the strongest observed cost level, but no evaluated modification after the core exact-DP design has reduced cost below **618.10**.

- **Exact shared-tree optimization materially dominates heuristic sharing.** Relative to the current best, Generation 10 greedy shared multicast was **28.6% more expensive** (**795.06 vs. 618.10**), while Generation 14’s limited-exact hybrid was **19.9% more expensive** (**741.08 vs. 618.10**). Independent per-destination shortest paths at **1035.14** were approximately **67.5% more expensive**, confirming that globally shared selected edges are central to cost reduction.

This shows that marginal edge-cost accounting captures much of the benefit of sharing, but exact subset merging recovers the remaining savings from globally coordinated terminal grouping and branch-node placement.

- **Reliability does not differentiate the evaluated solutions; cost does.** The current program and the listed comparison programs all had **success_rate 1.00**, with **5 successful configurations and zero failures**. Despite this, all received **combined_score 0.00** and **cost_score 0.00**, including the current best **618.10** result. # META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Remove the global strict `candidate < upper_bound` pruning inside DP state construction, and apply the incumbent only to complete source-rooted solutions.** A partial subtree can have cost equal to or above the greedy tree cost before edge sharing with another subset reduces the final union cost; pruning it early can eliminate valid equal-cost or better reconstructions. Keep a best complete `dp[full_mask][src]` bound, and prune states using an admissible completion lower bound such as `state_cost + dist_to_src[node]`, rather than raw subtree cost alone.

2. **Add cost-aware equal-cost tie-breaking and reconstruction metadata to maximize physical edge reuse.** When a merge or reverse relaxation has equal DP cost, compare the candidate’s selected-edge signature against the incumbent decision and prefer the one reusing edges/nodes already favored by sibling subsets, then use deterministic node/edge ordering as a final tie-break. The exact DP cost plateau may hide multiple equal-cost DP derivations whose reconstructed normalized unions differ in evaluator-visible edge cost or robustness; explicit ties are a low-risk mutation of the already successful solver.

3. **Use several deterministic greedy multicast constructions to obtain a stronger exact-search incumbent and better large-terminal fallback.** Extend `_greedy_shared_tree` with alternative terminal-selection policies: minimum marginal attachment cost (current), farthest source-distance first, maximum overlap with the current tree, and a few stable hashed destination orders. Normalize every candidate, select the cheapest feasible union as `upper_bound`, and retain it if exact search is skipped or times out; this directly builds on the near-best marginal-union behavior while preserving the proven exact DP topology.

4. **Extend exact coverage beyond 12 terminals through decomposition at articulation-like relay regions, not a fixed terminal cutoff.** Identify groups of terminals whose cheap reverse shortest-path regions converge through the same gateway/relay, solve each group exactly with the current subset DP, contract each solved group into a required relay attachment, and run a second exact DP over the group roots plus ungrouped terminals. This preserves global sharing where the graph structure supports it and is more promising than the previously unsuccessful fixed small-core approach, because grouping is driven by observed directed overlap rather than an arbitrary terminal count.

5. **Add a post-DP directed edge-exchange improvement over the normalized selected union.** For each branch/rooted subtree edge `(u, v)`, temporarily remove the affected downstream subtree, compute an alternate cheapest attachment from any still-retained tree node to the subtree root or its terminals using marginal edge cost, and accept only a strictly cheaper feasible union. The current exact formulation is strongest, but its DP is capped and normalization chooses shortest paths within a reconstructed union; a safe local exchange can improve topology materialization without replacing the validated exact-Steiner core.
