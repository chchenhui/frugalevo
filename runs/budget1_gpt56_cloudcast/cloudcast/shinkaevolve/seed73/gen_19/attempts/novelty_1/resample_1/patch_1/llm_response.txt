<DESCRIPTION>
Construct a feasible shared broadcast tree with a marginal-cost planner before running the exact Dreyfus-Wagner dynamic program. Its link-union cost is a valid upper bound on the optimal broadcast cost. Because all sanitized transfer costs are non-negative, any partial DP state whose cost is already at least this incumbent cannot contribute to a strictly cheaper complete topology, so it is safely discarded during subset merging and reverse shortest-path relaxation.

This preserves exactness whenever the DP finds an improvement, while avoiding exponential work on states that cannot beat the already feasible broadcast. If the incumbent is optimal, the solver directly returns it after proving no strictly cheaper state exists. This is especially valuable for larger multi-cloud fan-out sets where redundant state exploration otherwise dominates runtime.
</DESCRIPTION>

    # fallback, its union cost is an incumbent upper bound for exact search.
    # Existing tree edges have zero marginal cost because a relay receives a
    # partition once and can then fan that same partition out to more clouds.
    incumbent_tree = nx.DiGraph()
    incumbent_tree.add_node(src)
    remaining = set(terminals)

    while remaining:
        def marginal_cost(u, v, data):
            return 0.0 if incumbent_tree.has_edge(u, v) else float(data["cost"])

        best = None
        for dst in remaining:
            try:
                path = nx.dijkstra_path(h, src, dst, weight=marginal_cost)
            except nx.NetworkXNoPath:
                continue

            incremental = sum(
                0.0 if incumbent_tree.has_edge(u, v) else float(h[u][v]["cost"])
                for u, v in zip(path, path[1:])

            candidate = (incremental, len(path), str(dst), dst, path)

                best = candidate

                f"No broadcast path exists from {src} to {sorted(remaining)}"
