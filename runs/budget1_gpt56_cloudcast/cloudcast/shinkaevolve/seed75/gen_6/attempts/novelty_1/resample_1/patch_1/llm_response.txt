<DESCRIPTION>
Replace the single locally-greedy broadcast-tree construction with a multi-start directed-Steiner heuristic. The current greedy expansion always commits to the cheapest first destination extension, which can prevent selection of a slightly more expensive initial trunk that later serves many clouds at low incremental cost.

The revised logic evaluates the existing greedy solution plus one seeded solution for every reachable destination. Each seeded solution installs that destination’s least-cost source path first, then continues using zero-cost reuse of installed broadcast edges. The lowest total unique-edge-cost tree is selected. This retains valid source-rooted paths and shared-edge semantics while reducing sensitivity to destination ordering and improving opportunities for overlapping inter-cloud transfers.
</DESCRIPTION>
