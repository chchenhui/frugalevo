<DESCRIPTION>
Reduce the graph to terminal-aware low-cost source-to-destination corridors before invoking the exponential directed-Steiner DP, then increase the exact-DP limit from 14 to 16 terminals.

For fan-outs above 14 destinations, the existing implementation immediately falls back to greedy attachment, which can miss a low-cost shared trunk. The reduction computes shortest source distances and reverse shortest distances from every terminal, retaining edges that lie near at least one low-slack source-terminal route. This preserves inexpensive relay and backbone opportunities while removing unrelated cloud links from the DP state space. With fewer active relay nodes, exact optimization remains practical for moderately larger fan-outs and can select shared paths that greedy routing does not discover. Individual shortest-path corridors are always retained, so the reduced graph still has a feasible route for every reachable destination.
</DESCRIPTION>

    # For larger fan-outs, discard links that cannot participate in a
    # reasonably priced source-to-terminal corridor.  This keeps relay nodes
    # that can form a shared trunk while making the subset DP feasible for a
    # few more destinations than the unrestricted graph permits.
    if len(terminals) > 14:
        forward = nx.single_source_dijkstra_path_length(h, src, weight="cost")
        reverse = h.reverse(copy=False)
        terminal_distances = {
            dst: nx.single_source_dijkstra_path_length(reverse, dst, weight="cost")
            for dst in terminals
            if dst in forward
        }

        reduced = nx.DiGraph()
        reduced.add_nodes_from(h.nodes(data=True))
        for u, v, data in h.edges(data=True):
            if u not in forward:
                continue
            edge_cost = data["cost"]
            for dst, distances in terminal_distances.items():
                shortest = forward.get(dst, float("inf"))
                tail_distance = distances.get(v, float("inf"))
                # A modest slack admits alternate relay branches that can
                # become cheaper once their source-side links are shared.
                if forward[u] + edge_cost + tail_distance <= shortest * 1.35 + 1e-12:
                    reduced.add_edge(u, v, **dict(data))
                    break

            if dst not in forward:

            except nx.NetworkXNoPath:
                continue
            reduced.add_edges_from(
                (u, v, dict(h[u][v])) for u, v in zip(path, path[1:])
            )
