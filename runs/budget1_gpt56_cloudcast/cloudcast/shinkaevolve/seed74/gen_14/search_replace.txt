<DESCRIPTION>
Extend exact shared-transfer optimization to moderately larger destination sets by first reducing the network to low-slack source-to-terminal corridors. The reduction preserves every shortest route while retaining reasonably priced relay alternatives, which are where multicast trunks and cross-cloud reuse are most likely to occur. This makes the directed-Steiner DP practical for up to 14 destinations instead of falling immediately to the greedy attachment strategy at 12 destinations.

The reduction is applied only for fan-outs that previously used the greedy fallback, so existing exact behavior for smaller configurations is unchanged. A generous per-terminal slack retains alternative relay paths while avoiding DP work across unrelated network regions.
</DESCRIPTION>

    if not terminals:

    # For medium fan-outs, retain the useful relay corridors before running
    # the exponential Steiner DP.  Every shortest source-to-terminal path is
    # retained, together with substantially longer alternatives that can be
    # beneficial when their prefix is shared by several destinations.
    exact_terminal_limit = 14
    if 11 < len(terminals) <= exact_terminal_limit:
        source_distance = nx.single_source_dijkstra_path_length(
            h, src, weight="cost"
        )
        reverse_h = h.reverse(copy=False)
        terminal_distance = {
            dst: nx.single_source_dijkstra_path_length(
                reverse_h, dst, weight="cost"
            )
            for dst in terminals
        }
        max_edge_cost = max(
            (data["cost"] for _, _, data in h.edges(data=True)),
            default=0.0,
        )
        reduced = nx.DiGraph()
        reduced.add_nodes_from(h.nodes(data=True))
        for u, v, data in h.edges(data=True):
            from_source = source_distance.get(u, math.inf)
            if not math.isfinite(from_source):
                continue
            for dst in terminals:
                to_terminal = terminal_distance[dst].get(v, math.inf)
                shortest = source_distance.get(dst, math.inf)
                # The additive term also keeps useful alternatives when a
                # destination's direct shortest path is very inexpensive.
                allowance = shortest * 1.75 + max_edge_cost
                if (math.isfinite(to_terminal) and
                        from_source + data["cost"] + to_terminal <= allowance + 1e-12):
                    reduced.add_edge(u, v, **dict(data))
                    break

        # the original graph defensively if an unusual numeric edge case
        # removed a terminal route.
        if all(nx.has_path(reduced, src, dst) for dst in terminals):
