<DESCRIPTION>
Add a terminal-aware corridor reduction before the exponential directed-Steiner dynamic program. The reduction retains every shortest source-to-terminal corridor plus controlled near-shortest alternatives, which preserves useful shared relay opportunities while removing regions and links that cannot plausibly participate in an economical multicast tree. The slack is expanded automatically if the first reduction disconnects a terminal, ensuring feasibility is never sacrificed. This reduces DP state work on multi-cloud topologies and makes it practical to optimize larger fan-outs while still favoring shared broadcast trunks over redundant direct transfers.

    # slightly longer route can be amortized by serving several destinations.
    # This reduces the node dimension of the Steiner DP without prematurely
    # forcing independent direct transfers.
    if len(terminals) > 8 and h.number_of_edges():
        source_distances = nx.single_source_dijkstra_path_length(
            h, src, weight="cost"
        )
        reverse_h = h.reverse(copy=False)
        terminal_distances = {
            terminal: nx.single_source_dijkstra_path_length(
                reverse_h, terminal, weight="cost"
            )
            for terminal in terminals
        }
        max_cost = max(float(data["cost"]) for _, _, data in h.edges(data=True))

        # Retry with a wider corridor only when the tighter economical
        # corridor does not retain a route for every requested receiver.
        for multiplier in (1.5, 2.5, 4.0):
            reduced = nx.DiGraph()
            reduced.add_nodes_from(h.nodes(data=True))

            for u, v, data in h.edges(data=True):
                prefix_cost = source_distances.get(u, float("inf"))
                if prefix_cost == float("inf"):
                    continue

                edge_cost = float(data["cost"])

                    suffix_cost = terminal_distances[terminal].get(v, float("inf"))
                    direct_cost = source_distances.get(terminal, float("inf"))
                    allowance = direct_cost * multiplier + max_cost
                    if prefix_cost + edge_cost + suffix_cost <= allowance + 1e-12:
                        reduced.add_edge(u, v, **dict(data))
                        break

                for terminal in terminals
