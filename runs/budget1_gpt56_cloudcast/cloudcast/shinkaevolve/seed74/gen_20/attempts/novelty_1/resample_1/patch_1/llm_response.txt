<DESCRIPTION>
Add a source-dominator decomposition candidate for large fan-outs. Destination groups whose routes must leave the source through different dominator branches cannot share a paid prefix, so their directed-Steiner subproblems can be solved independently and their edge unions merged. This extends exact optimization beyond the global terminal cutoff without increasing the exponential DP state space to all destinations at once. The existing clustered and greedy candidates remain available as safeguards, and the final union-cost selection retains the lowest-cost valid topology.

def _dominator_component_tree(h, src, terminals, exact_terminal_limit):
    """
    Decompose a broadcast at mandatory source-side dominator branches.

    Terminals below different children of ``src`` in the dominator tree cannot
    share any source-reachable edge: a shared edge would itself dominate both
    terminals and would place them below the same branch.  Consequently, when
    every branch is small enough, solving each branch exactly is equivalent to
    applying the directed-Steiner DP after a safe component reduction.
    """
    try:
        dominators = nx.immediate_dominators(h, src)
    except (nx.NetworkXError, nx.NetworkXException):
        return None

    groups = {}
    for terminal in terminals:
        node = terminal
        parent = dominators.get(node)

        # Find the direct dominator-tree child through which this terminal is
        # reached from the source.  A terminal directly adjacent to the source
        # is its own branch.
        while parent is not None and parent != src:
            node = parent
            parent = dominators.get(node)

        if parent != src:
            return None
        groups.setdefault(node, []).append(terminal)

    if len(groups) < 2 or any(
        len(group) > exact_terminal_limit for group in groups.values()
    ):
        return None

    result = nx.DiGraph()
    result.add_node(src)
    for group in groups.values():
        local_tree = _exact_directed_steiner(h, src, group)
        if not all(
            terminal in local_tree and nx.has_path(local_tree, src, terminal)
            for terminal in group
        ):
            return None
        result.add_edges_from(local_tree.edges(data=True))

    return result
