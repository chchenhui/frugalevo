<DESCRIPTION>
Replace the naive concentric-ring layout with a near-optimal explicit construction: a 5x5 grid of circles of radius 0.1 (spacing 0.2, tangent horizontally/vertically, exactly fitting the unit square), plus a 26th small circle tucked into a cell-corner gap. Each grid circle has radius exactly 0.1 (border-limited, spacing exactly 2r), giving 2.5, and the extra circle at (0.2,0.2) has radius 0.2/sqrt(2) - 0.1 ≈ 0.0414 (limited by the diagonal neighbor), giving a total of ~2.5414 — a large improvement over the current 0.96. The radius computation is also fixed: the old pairwise proportional scaling incorrectly shrank already-valid circles (e.g. it would shrink the 0.1 grid circles when processing the small gap circle). Instead, radii are computed by iterative constraint propagation: start each radius at its border limit and repeatedly enforce r_i + r_j <= d_ij by shrinking only the violating circle, which converges to the intended maximal radii without degrading valid ones.

    # circles, this never needlessly shrinks circles that are already

        changed = False
        for i in range(n):
            for j in range(i + 1, n):
                dist = np.sqrt(np.sum((centers[i] - centers[j]) ** 2))
                if radii[i] + radii[j] > dist + 1e-12:
                    # Shrink only the violating side(s), respecting
                    # the other circle's current radius.

                    new_rj = dist - radii[i]
