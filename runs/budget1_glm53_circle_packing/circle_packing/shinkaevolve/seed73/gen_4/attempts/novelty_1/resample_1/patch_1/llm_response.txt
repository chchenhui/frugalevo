<DESCRIPTION>
Replace the ad-hoc concentric-ring layout (which only achieves sum ≈ 0.96) with a proper hexagonal lattice arrangement: rows of 5,4,5,4,5,3 circles with hexagonal vertical spacing (√3·r) and staggered columns — the classic densest local structure for circle packing. With 6 rows, the equal radius that fits the unit square is r ≈ 1/(2+5√3) ≈ 0.0939, giving sum ≈ 2.44 immediately. Then, because square corners leave extra space that a pure hex lattice wastes, I add a greedy expansion phase: repeatedly sweep over circles and grow each one to the maximum radius allowed by the walls and its current neighbors (min over wall distances and d_ij - r_j). This is always feasible (each step keeps the packing valid) and monotonically increases the sum, letting corner/edge circles bulge into the leftover corner space — moving the sum toward the 2.635 AlphaEvolve target.

    # Initialize arrays for 26 circles
    n = 26
    centers = np.zeros((n, 2))

    # Hexagonal lattice: rows of 5,4,5,4,5,3 circles.
    # Vertical spacing between rows is sqrt(3)*r (hex packing),
    # staggered rows are offset horizontally by r.
    r0 = 1.0 / (2.0 + 5.0 * np.sqrt(3.0))  # ~0.0939, fits 6 hex rows
    dy = np.sqrt(3.0) * r0

    row_counts = [5, 4, 5, 4, 5, 3]
    idx = 0
    for k, cnt in enumerate(row_counts):
        y = r0 + k * dy
        if cnt == 5:
            # Full row touching left/right walls
            xs = [r0 + 2.0 * r0 * j for j in range(5)]
        elif cnt == 4:
            # Staggered (offset) row
            xs = [2.0 * r0 + 2.0 * r0 * j for j in range(4)]
        else:
            # Top row of 3, centered horizontally
            xs = [0.5 - 2.0 * r0 + 2.0 * r0 * j for j in range(3)]
        for x in xs:
            centers[idx] = [x, y]
            idx += 1

    # Greedy expansion: sweep repeatedly, growing each circle to the
    # largest radius allowed by the walls and current neighbor radii.
    # This exploits leftover space near the square's corners that a
    # pure hex lattice leaves empty. Each step keeps the packing valid.
    radii = np.full(n, 0.5 * r0)
    d = np.sqrt(((centers[:, None, :] - centers[None, :, :]) ** 2).sum(-1))
    for _ in range(60):
        for i in range(n):
            # Wall limit
            x, y = centers[i]
            r_max = min(x, y, 1.0 - x, 1.0 - y)
            # Neighbor limits
            for j in range(n):
                if j != i:
                    r_max = min(r_max, d[i, j] - radii[j])
            radii[i] = max(0.5 * r0, r_max)

    # Calculate the sum of radii
    sum_radii = np.sum(radii)

    return centers, radii, sum_radii
