The current single hexagonal-lattice start confines the search to one basin. Add a set of four structurally diverse deterministic seeds (hex rows 5-4-5-4-5-3, hex rows 4-5-4-5-4-4, a dense 5-column square-like grid with 26 circles in 6 rows, and a corner-anchored layout with 4 large corner circles surrounding a 5-4-5-4 interior lattice). Each seed is LP-evaluated, then the hill-climb is run on the best seed(s) with a per-seed iteration budget, keeping the global best. This exploits the fact that n=26 optimal packings are known to be non-lattice arrangements (the AlphaEvolve solution is irregular), so diverse geometric starts (especially corner-heavy ones where corner circles can grow large due to three-sided slack) give the LP-driven hill-climb access to better basins. Time budget: ~450 LP solves total (~3s at observed 0.006s per LP), well within limits.

    def _hex_layout(counts):
        """Staggered-row hexagonal layout for the given row counts."""
        pts = np.zeros((sum(counts), 2))
        m = max(counts)
        s_loc = 1.0 / m
        h_loc = s_loc * np.sqrt(3.0) / 2.0
        # shrink slightly if too many rows
        if s_loc + (len(counts) - 1) * h_loc > 1.0:
            s_loc = 1.0 / (m + (len(counts) - 1) * np.sqrt(3.0) / 2.0)
            h_loc = s_loc * np.sqrt(3.0) / 2.0
        r_loc = s_loc / 2.0
        k = 0
        for row, count in enumerate(counts):
            y = r_loc + row * h_loc
            off = r_loc if row % 2 == 0 else r_loc + s_loc / 2.0
            # center rows with fewer circles horizontally
            off += (m - count) * s_loc / 2.0 if row % 2 == 0 else 0.0
            for j in range(count):
                pts[k] = [min(max(off + j * s_loc, 0.02), 0.98),
                          min(max(y, 0.02), 0.98)]
                k += 1
        return pts

    def _grid_layout():
        """Rectangular-grid seed: 6 rows of 5,4,5,4,5,3 aligned columns."""
        counts = [5, 4, 5, 4, 5, 3]
        pts = np.zeros((26, 2))
        sx = 1.0 / 5.0
        sy = 1.0 / 6.0
        k = 0
        for row, count in enumerate(counts):
            off = (5 - count) * sx / 2.0
            for j in range(count):
                pts[k] = [off + sx * (j + 0.5), sy * (row + 0.5)]
                k += 1
        return pts
