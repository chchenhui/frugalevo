<DESCRIPTION>
The current program uses a single staggered-lattice seed and achieves 2.48. The Generation-2 multi-seed version reached only 2.28 because its seeds were poorly designed, but the key insight remains: different layouts (row patterns, wall-anchored arrangements) lead to different local optima, and 26 circles likely benefit from a mixed-size arrangement (large corner/edge circles + smaller interior circles) rather than a near-uniform lattice. I propose two changes: (1) restore a small set of well-chosen structured seeds (staggered lattices with several row patterns, plus corner-anchored seeds where large circles sit in the corners and edges), run the full _refine + _local_shift_search pipeline on each, and keep the best; (2) add a pressure-based perturbation pass after refinement: after solving radii, push each center away from its tightest active constraint (nearest neighbor or wall) by a step proportional to its slack deficit, then re-run the radius solver — this "perturb-and-resolve" escapes the quasi-regular local optimum the relaxation converges to, which is exactly the headroom between 2.48 and the 2.635 reference. To keep runtime acceptable, the local shift search is only run on the best seed's result, and seed count is modest (5 seeds).

def _pressure_perturb(centers):
    """Move each center away from its tightest neighbor/wall by a step
    proportional to its 'pressure' (how compressed it is), then return
    the perturbed centers."""
    n = len(centers)
    radii = compute_max_radii(centers)
    out = centers.copy()
    for i in range(n):
        x, y = centers[i]
        ri = radii[i]
        # find tightest constraints (largest overlap deficit)
        worst_gap = -1e9
        fx = fy = 0.0
        active = 0
        for j in range(n):
            if j == i:
                continue
            dx = x - centers[j, 0]
            dy = y - centers[j, 1]
            dist = np.sqrt(dx * dx + dy * dy) + 1e-12
            gap = dist - (ri + radii[j])
            if gap < worst_gap + 1e-6:
                if gap < worst_gap - 1e-6:
                    fx = fy = 0.0
                    active = 0
                worst_gap = gap
                fx += dx / dist
                fy += dy / dist
                active += 1
        # walls
        for wall_gap, ddx, ddy in ((x - ri, -1.0, 0.0), (1.0 - x - ri, 1.0, 0.0),
                                   (y - ri, 0.0, -1.0), (1.0 - y - ri, 0.0, 1.0)):
            if wall_gap < worst_gap + 1e-6:
                if wall_gap < worst_gap - 1e-6:
                    fx = fy = 0.0
                    active = 0
                worst_gap = wall_gap
                fx += ddx
                fy += ddy
                active += 1
        if active > 0:
            norm = np.sqrt(fx * fx + fy * fy)
            if norm > 1e-9:
                step = 0.012 * max(0.0, -worst_gap)
                out[i, 0] = min(max(x + step * fx / norm, 1e-9), 1.0 - 1e-9)
                out[i, 1] = min(max(y + step * fy / norm, 1e-9), 1.0 - 1e-9)
    return out
