<DESCRIPTION>
The current best result (2.47) came from a pure hexagonal lattice; the headroom toward 2.635 lies in deliberately asymmetric corner circles. Corner positions have three-sided wall slack, so the LP/water-filling solver can give them much larger radii than interior circles. I modify the seed layout to anchor 4 circles exactly in the corners (at distance rc from both walls), fill the remaining 22 circles in staggered interior rows, keep the existing repulsion refinement (it will pull interior circles away from the oversized corners), and add a final exact LP solve (`solve_radii_lp`, already proven in Gen 1/2) to extract the optimal unequal radii at the refined centers — the water-filling heuristic is lossy, and the LP typically recovers a few percent of sum. This combines the identified corner-growth insight with the exact radii evaluation while staying fast (one LP, ~325 constraints).

def solve_radii_lp(centers, eps=1e-9):
    """
    Solve the linear program: maximize sum(r_i) subject to
      r_i + r_j <= dist(i, j)  for all pairs
      0 <= r_i <= min(x_i, y_i, 1-x_i, 1-y_i)
    Returns optimal radii array, or None if the LP fails.
    """
    try:
        from scipy.optimize import linprog
    except ImportError:
        return None

    n = centers.shape[0]
    c = -np.ones(n)

    rows = []
    rhs = []
    for i in range(n):
        for j in range(i + 1, n):
            d = np.sqrt(np.sum((centers[i] - centers[j]) ** 2))
            row = np.zeros(n)
            row[i] = 1.0
            row[j] = 1.0
            rows.append(row)
            rhs.append(d - 2.0 * eps)

    for i in range(n):
        x, y = centers[i]
        for lim in (x - eps, y - eps, 1.0 - x - eps, 1.0 - y - eps):
            row = np.zeros(n)
            row[i] = 1.0
            rows.append(row)
            rhs.append(max(lim, 0.0))

    A_ub = np.vstack(rows)
    b_ub = np.array(rhs)

    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=[(0.0, None)] * n,
                  method="highs")
    if not res.success:
        return None
    return np.maximum(res.x, 0.0)
