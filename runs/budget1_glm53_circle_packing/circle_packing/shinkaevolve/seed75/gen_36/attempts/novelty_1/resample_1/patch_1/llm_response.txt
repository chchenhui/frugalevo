</NAME>
<DESCRIPTION>
Run the identical optimize pipeline (LP water-filling + corner-aware hill-climb + greedy growth pass) on two different seeds — the original wall-aligned hex lattice and the corner-anchored variant — and return the better result. This diversifies the local optimum the hill-climb lands in: the corner-anchored seed favors large corner circles with a small interior, while the wall-aligned seed spreads radius more evenly. Since the hill-climb only accepts strict LP-sum improvements, neither variant can fall below its own LP seed value, and keeping the best of the two can only help. Iterations per run are halved to keep total runtime near the previous ~9s budget.

def _seed_corners(anchor_corner):
    """
    Build the hexagonal-lattice seed (5 staggered rows 6,5,6,5,6, with two
    adjacent middle-row circles dropped). If anchor_corner is True, pull
    the 4 circles nearest each corner diagonally INTO the corners; corner
    circles enjoy three-sided wall slack, so the LP water-filling grants
    them large radii while interior circles stay small.
    """
    centers_list = []
    y0 = 0.1
    dy = 0.1 * np.sqrt(3.0)
    counts = [6, 5, 6, 5, 6]
    skip = {(2, 2), (2, 3)}  # remove two adjacent circles in the middle row
    for row, cnt in enumerate(counts):

        for k in range(cnt):

                continue

                x = 0.2 * k  # touches walls at x=0 and x=1
            else:
                x = 0.1 + 0.2 * k  # staggered by half spacing
            centers_list.append([x, y])
    centers = np.array(centers_list)
    assert centers.shape == (26, 2)

    if anchor_corner:

            centers[i] = [
                anchor if cx == 0.0 else 1.0 - anchor,
                anchor if cy == 0.0 else 1.0 - anchor,
            ]
    return centers
