<DESCRIPTION>
Key insight: with circle centers fixed, maximizing the sum of radii is a *linear program*: maximize Σr_i subject to r_i + r_j ≤ d_ij (pairwise) and r_i ≤ min border distance. The previous uniform-radius assignment (r = min over all constraints) massively underuses space — border and corner circles can be much larger than lattice circles. So I: (1) keep the hexagonal lattice as a starting layout, (2) solve the exact LP for optimal radii at those positions (scipy `linprog` with HiGHS — fast for 26 variables / ~350 constraints), and (3) run a hill-climb over centers: random jitter perturbations with a decreasing step size, re-solving the LP after each move and accepting improvements. Wall-constrained circles also get directed pushes away from walls. A tiny safety epsilon (1e-9) on all constraints plus a final 1-1e-6 radius shrink guarantees strict feasibility. A greedy fallback keeps the program working if scipy is unavailable.

def solve_radii_lp(centers, eps=1e-9):
    """
    Solve the linear program: maximize sum(r_i) subject to
      r_i + r_j <= dist(i, j)  for all pairs
      0 <= r_i <= min(x_i, y_i, 1-x_i, 1-y_i)
    Returns optimal radii array, or None if the LP fails.
    """
    try:
        from scipy.optimize import linprog
    except ImportError:
        return None

    n = centers.shape[0]
    c = -np.ones(n)

    rows = []
    rhs = []
    for i in range(n):
        for j in range(i + 1, n):
            d = np.sqrt(np.sum((centers[i] - centers[j]) ** 2))
            row = np.zeros(n)
            row[i] = 1.0
            row[j] = 1.0
            rows.append(row)
            rhs.append(d - 2.0 * eps)

    for i in range(n):
        x, y = centers[i]
        for lim in (x - eps, y - eps, 1.0 - x - eps, 1.0 - y - eps):
            row = np.zeros(n)
            row[i] = 1.0
            rows.append(row)
            rhs.append(max(lim, 0.0))

    A_ub = np.vstack(rows)
    b_ub = np.array(rhs)

    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=[(0.0, None)] * n,
                  method="highs")
    if not res.success:
        return None
    return np.maximum(res.x, 0.0)
