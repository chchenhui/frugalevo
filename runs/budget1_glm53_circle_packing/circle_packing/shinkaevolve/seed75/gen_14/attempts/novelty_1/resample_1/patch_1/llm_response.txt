<DESCRIPTION>
The current best program (score 0.93, sum 2.44) used an LP-based radius solver plus a hill-climb over centers, starting from a suboptimal 5/4/5/4/5/3 lattice. The current program has a better initial lattice (6/5/6/5/6 with a growth hole) but no center optimization, capping it at 2.00. I propose combining both strengths: keep the denser lattice as the starting layout, solve radii exactly with the LP at every step, and add a hill-climb over center positions. Crucially, per the corner-aware recommendation, I add directed moves that push circles touching two walls (corner circles) diagonally toward the nearest corner, where three-sided wall slack lets the LP assign them larger radii, and push single-wall circles away from walls. Small interior circles get larger jitter since they have more freedom. This should recover the ~2.44+ regime and improve on it via the denser seed.

def solve_radii_lp(centers, eps=1e-9):
    """
    Solve the linear program: maximize sum(r_i) subject to
      r_i + r_j <= dist(i, j)  for all pairs
      0 <= r_i <= min(x_i, y_i, 1-x_i, 1-y_i)
    Returns optimal radii array, or None if scipy is unavailable or LP fails.
    """
    try:
        from scipy.optimize import linprog
    except ImportError:
        return None

    n = centers.shape[0]
    c = -np.ones(n)

    rows = []
    rhs = []
    for i in range(n):
        for j in range(i + 1, n):
            d = np.sqrt(np.sum((centers[i] - centers[j]) ** 2))
            row = np.zeros(n)
            row[i] = 1.0
            row[j] = 1.0
            rows.append(row)
            rhs.append(d - 2.0 * eps)

    for i in range(n):
        x, y = centers[i]
        for lim in (x - eps, y - eps, 1.0 - x - eps, 1.0 - y - eps):
            row = np.zeros(n)
            row[i] = 1.0
            rows.append(row)
            rhs.append(max(lim, 0.0))

    A_ub = np.vstack(rows)
    b_ub = np.array(rhs)

    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=[(0.0, None)] * n,
                  method="highs")
    if not res.success:
        return None
    return np.maximum(res.x, 0.0)
