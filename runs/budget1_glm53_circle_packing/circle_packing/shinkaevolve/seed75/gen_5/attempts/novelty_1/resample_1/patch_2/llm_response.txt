<DESCRIPTION>
Replace the naive concentric-ring layout (sum ≈ 0.96) with a near-optimal explicit hexagonal-lattice construction, and replace the greedy pairwise-scaling radius computation with an exact linear program. A triangular lattice with horizontal spacing 0.2 and row spacing 0.1·√3 supports 28 circles of radius 0.1 in rows of 6,5,6,5,6; dropping two adjacent circles from the middle row leaves a growth hole. For fixed centers, maximizing Σr subject to border and pairwise-distance constraints is a linear program, solvable exactly with scipy; a converged multi-pass scaler serves as fallback.

    # Hexagonal-lattice layout: 5 staggered rows with counts 6,5,6,5,6.
    # Horizontal spacing 0.2, vertical spacing 0.1*sqrt(3) ~ 0.1732.
    # This lattice supports 28 circles of radius 0.1; we drop 2 adjacent
    # circles from the middle row (n=26) to leave a growth hole.
    n = 26
    centers_list = []
    y0 = 0.1
    dy = 0.1 * np.sqrt(3.0)
    counts = [6, 5, 6, 5, 6]
    skip = {(2, 2), (2, 3)}  # remove two adjacent circles in the middle row
    for row, cnt in enumerate(counts):
        y = y0 + row * dy
        for k in range(cnt):
            if (row, k) in skip:
                continue
            if cnt == 6:
                x = 0.2 * k  # touches walls at x=0 and x=1
            else:
                x = 0.1 + 0.2 * k  # staggered by half spacing
            centers_list.append([x, y])
    centers = np.array(centers_list)
    assert centers.shape == (n, 2)
