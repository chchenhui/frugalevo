Replace the naive ring layout (which yields sum ≈ 0.96) with a hexagonal lattice arrangement of 26 circles — the near-optimal local structure for circle packing (density π/√12). Rows of 5,4,5,4,5,3 circles with horizontal spacing s and vertical spacing s·√3/2 use the square efficiently. Then replace the one-pass radius heuristic with an iterative relaxation solver: initialize each radius to its full distance to the nearest wall, then repeatedly rescale any overlapping pair proportionally and re-clip to the walls until convergence. This is a projection onto the feasible region (non-overlap + containment) and typically converges to radii near the equal-radius hexagonal optimum (r ≈ s/2), giving a sum of radii around 2.5–2.6, close to the AlphaEvolve target of 2.635.

    # Distance from each center to the nearest wall of the unit square
    wall_dist = np.minimum(
        np.minimum(centers[:, 0], 1.0 - centers[:, 0]),
        np.minimum(centers[:, 1], 1.0 - centers[:, 1]),

    # Precompute pairwise distances
    dist = np.zeros((n, n))
    for i in range(n):
        for j in range(i + 1, n):
            d = np.sqrt(np.sum((centers[i] - centers[j]) ** 2))
            dist[i, j] = d
            dist[j, i] = d

    # Start optimistic: each circle as large as its nearest wall allows
    radii = wall_dist.copy()

    # Iterative relaxation: repeatedly resolve overlaps by scaling the
    # offending pair proportionally, then re-clip to the walls.
    # This is a projection onto the feasible set and converges to a
    # valid packing that exploits the hexagonal lattice spacing
    # (interior radii approach s/2, the hex optimum).
    for _ in range(1000):
        max_violation = 0.0
        for i in range(n):
            for j in range(i + 1, n):
                d = dist[i, j]
                rsum = radii[i] + radii[j]
                if rsum > d and rsum > 1e-15:
                    scale = d / rsum
                    radii[i] *= scale
                    radii[j] *= scale
                    violation = 1.0 - scale
                    if violation > max_violation:
                        max_violation = violation
        # Re-clip to walls after pair relaxation
        radii = np.minimum(radii, wall_dist)
        if max_violation < 1e-9:
            break

    return radii
