<DESCRIPTION>
Two improvements:

1. **Layout**: The previous layout [4,5,4,5,4,4] had a flaw — the last two rows were both 4-circle rows with the *same* x-positions (no hex stagger), forcing the vertical spacing dy to be at least 0.2, which pushed the whole grid out of the walls and caused cascading radius shrinkage (sum only 1.59). New design: rows [4,5,4,5,4,4] where the top 4-row is *staggered* by half a spacing (x = 0.1,0.3,0.5,0.7), so every adjacent row pair has horizontal offset 0.1. Then every nearest-neighbor distance is sqrt(dy² + 0.1²), and we solve the fixed point r = sqrt(((1-2r)/5)² + 0.01)/2 ≈ 0.0954, placing the bottom/top rows exactly at distance r from the walls. This makes nearly all 26 circles touch their neighbors and the walls, giving sum ≈ 26 × 0.0954 ≈ 2.48.

2. **Radius solver**: Proportional pairwise shrinking is suboptimal (it over-shrinks both circles of a violating pair, causing cascades). Replace with a Gauss–Seidel pass: r_i = min(wall_i, min_j (d_ij − r_j)), iterated to convergence. This is still guaranteed feasible (each radius respects the current neighbor radii and walls) but assigns radii much more generously, and it naturally handles the asymmetric wall constraints at the boundary.

def build_hex_rows():
    """
    Build 26 circle centers arranged in 6 hexagonal rows.

    Row layout (from bottom to top): 4, 5, 4, 5, 4, 4 circles.
    Rows with 5 circles are inset by half a spacing (hex offset),
    giving the densest local triangular arrangement.

    Returns:
        np.array of shape (26, 2)
    """
    s = 0.2                       # horizontal lattice spacing
    dy = s * HEX_ASPECT           # vertical lattice spacing
    row_counts = [4, 5, 4, 5, 4, 4]
    centers = []

    # vertical placement: center the 6 rows in the square
    total_h = dy * (len(row_counts) - 1)
    y0 = (1.0 - total_h) / 2.0

    for r, count in enumerate(row_counts):
        y = y0 + r * dy
        # 5-circle rows are offset inward by s/2 (hex staggering)
        x0 = (1.0 - s * (count - 1)) / 2.0
        for c in range(count):
            centers.append([x0 + c * s, y])

    return np.array(centers)

def build_hex_rows():
    """
    Build 26 circle centers arranged in 6 staggered rows.

    Row layout (bottom to top): 4, 5, 4, 5, 4, 4 circles.
    Every adjacent row pair is offset by half the horizontal
    spacing (s/2 = 0.1), so all nearest-neighbor distances equal
    sqrt(dy^2 + 0.1^2). The vertical gap dy and the common radius r
    satisfy the fixed point r = sqrt(dy^2 + 0.1^2) / 2 with the
    bottom/top rows sitting exactly r away from the walls:
        2r + 5*dy = 1.

    Returns:
        np.array of shape (26, 2)
    """
    s = 0.2          # horizontal spacing within a row
    dx = s / 2.0     # stagger between adjacent rows

    # Solve fixed point: r = sqrt(((1-2r)/5)^2 + dx^2) / 2
    r = 0.095
    for _ in range(100):
        dy = (1.0 - 2.0 * r) / 5.0
        r = min(0.1, np.sqrt(dy * dy + dx * dx) / 2.0)

    # x-positions per row; every adjacent pair staggered by dx
    row_xs = [
        [0.2, 0.4, 0.6, 0.8],              # 4 circles
        [0.1, 0.3, 0.5, 0.7, 0.9],         # 5 circles
        [0.2, 0.4, 0.6, 0.8],              # 4 circles
        [0.1, 0.3, 0.5, 0.7, 0.9],         # 5 circles
        [0.2, 0.4, 0.6, 0.8],              # 4 circles
        [0.1, 0.3, 0.5, 0.7],              # 4 circles, staggered
    ]

    centers = []
    for k, xs in enumerate(row_xs):
        y = r + k * dy
        for x in xs:
            centers.append([x, y])

    return np.array(centers)
