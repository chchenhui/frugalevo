<DESCRIPTION>
The water-filling radius solver (`compute_max_radii`) is only a heuristic approximation of the optimal radii at fixed centers: it maximizes each circle greedily and then shrinks pairs to restore feasibility, which systematically loses total radius sum relative to the exact solution. For fixed centers, the maximum-sum radii problem is a linear program (maximize sum r_i subject to r_i + r_j <= d_ij and r_i <= wall distances), solvable exactly with scipy's `linprog` (HiGHS) in well under a second for n=26 (only 26 variables and ~350 constraints). A previous program that used this LP scored well; here we combine it with the much better center-position search already present. The key edit: after `_local_shift_search` finishes and the best centers are fixed, replace the heuristic `_greedy_enlarge` radii with the exact LP solution (falling back to the heuristic if scipy is unavailable or the LP fails), and keep a tiny safety shrink to guarantee strict validity. This should recover the radius sum lost to the heuristic repair step (typically 1-3% of total, i.e. ~0.03-0.08 in sum), pushing sum_radii from ~2.49 toward ~2.55+, while validity remains 1.0 and eval_time grows only marginally (one LP solve ≈ 0.01s).

def solve_radii_lp(centers, eps=1e-9):
    """
    Exact maximum-sum radii at fixed centers via LP:
      maximize sum(r_i) s.t. r_i + r_j <= dist(i,j),
                            r_i <= min(x_i, y_i, 1-x_i, 1-y_i), r_i >= 0.
    Returns the optimal radii array, or None on failure.
    """
    try:
        from scipy.optimize import linprog
    except Exception:
        return None
    n = centers.shape[0]
    diff = centers[:, None, :] - centers[None, :, :]
    D = np.sqrt((diff ** 2).sum(-1))
    iu = np.triu_indices(n, 1)
    m = len(iu[0])
    A_pairs = np.zeros((m, n))
    A_pairs[np.arange(m), iu[0]] = 1.0
    A_pairs[np.arange(m), iu[1]] = 1.0
    b_pairs = D[iu] - 2.0 * eps
    x, y = centers[:, 0], centers[:, 1]
    wall = np.minimum(np.minimum(x, y), np.minimum(1.0 - x, 1.0 - y))
    A_wall = np.zeros((n, n))
    A_wall[np.arange(n), np.arange(n)] = 1.0
    A_ub = np.vstack([A_pairs, A_wall])
    b_ub = np.concatenate([b_pairs, wall - eps])
    res = linprog(c=-np.ones(n), A_ub=A_ub, b_ub=b_ub,
                  bounds=[(0.0, None)] * n, method="highs")
    if not res.success:
        return None
    r = np.maximum(res.x, 0.0)
    # guarantee feasibility against exact pairwise distances
    r = np.minimum(r, np.maximum(wall, 0.0))
    for _ in range(4):
        s = r[iu[0]] + r[iu[1]]
        bad = s > D[iu] + 1e-12
        if not bad.any():
            break
        idx = np.nonzero(bad)[0]
        i, j = iu[0][idx], iu[1][idx]
        scale = D[iu][idx] / s[idx]
        r[i] *= scale
        r[j] *= scale
    return r
