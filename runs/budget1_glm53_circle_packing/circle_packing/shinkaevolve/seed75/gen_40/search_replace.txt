<DESCRIPTION>
Two targeted improvements to raise the sum of radii beyond the uniform-lattice value (~2.44):

1. **Exploit horizontal slack in short rows.** In the 6-row hexagonal layout, the staggered rows of 4 circles (and the row of 3) do not touch the side walls — there is 0.156–0.34 of unused horizontal space. Instead of clumping them at half-offsets, spread them evenly across the width (with margin = uniform radius r). This increases both their wall allowances and their distances to neighbors in adjacent rows, creating room for larger radii.

2. **Solve for radii with a linear program instead of forcing uniform radii.** For fixed centers, the feasibility conditions are exactly linear: r_i + r_j ≤ d_ij for every pair, and r_i ≤ min(x_i, y_i, 1−x_i, 1−y_i) for walls. Maximizing Σ r_i under these constraints is a small LP (26 variables, ~350 constraints) solvable instantly with scipy's HiGHS. Uniform radii are feasible, so the LP can only improve on 2.44 — and it will naturally favor low-degree circles (edge/corner circles and the sparse 3-circle row), which is precisely how irregular high-scoring packings beat uniform ones. A uniform-radius fallback keeps the program robust if scipy is unavailable.

def compute_max_radii(centers):
    """
    Compute the maximum possible radii for each circle position
    such that they don't overlap and stay within the unit square.

    Args:
        centers: np.array of shape (n, 2) with (x, y) coordinates

    Returns:
        np.array of shape (n) with radius of each circle
    """
    n = centers.shape[0]

    # Uniform radius: limited by border distance and half the minimum
    # pairwise center distance (valid for lattice-based layouts).
    r = np.inf
    for i in range(n):
        x, y = centers[i]
        r = min(r, x, y, 1.0 - x, 1.0 - y)
    for i in range(n):
        for j in range(i + 1, n):
            dist = np.sqrt(np.sum((centers[i] - centers[j]) ** 2))
            r = min(r, dist / 2.0)

    return np.full(n, r)

def compute_max_radii(centers):
    """
    Compute radii maximizing the sum of radii for fixed centers.

    Feasibility for fixed centers is exactly the set of linear constraints
        r_i + r_j <= d_ij   (non-overlap, for all pairs i < j)
        0 <= r_i <= b_i     (inside unit square, b_i = wall distance)
    so the maximum-sum radii are the solution of a small linear program.
    Uniform radii are feasible, so this can only improve on the uniform
    value; the LP favors low-degree circles (edges/corners, sparse rows),
    which is how irregular packings beat uniform ones.

    Args:
        centers: np.array of shape (n, 2) with (x, y) coordinates

    Returns:
        np.array of shape (n) with radius of each circle
    """
    n = centers.shape[0]

    # Wall-distance upper bounds
    b = np.minimum.reduce(
        [centers[:, 0], centers[:, 1], 1.0 - centers[:, 0], 1.0 - centers[:, 1]]
    )

    # Pairwise distance matrix
    diff = centers[:, None, :] - centers[None, :, :]
    dist = np.sqrt((diff ** 2).sum(-1))

    # Uniform-radius fallback (also used if scipy is unavailable)
    r_uniform = min(b.min(), dist[dist > 0].min() / 2.0 if n > 1 else b.min())

    try:
        from scipy.optimize import linprog

        # Constraints: r_i + r_j <= d_ij for all pairs
        rows, cols, vals = [], [], []
        k = 0
        for i in range(n):
            for j in range(i + 1, n):
                rows += [k, k]
                cols += [i, j]
                vals += [1.0, 1.0]
                k += 1
        from scipy.sparse import coo_matrix

        A = coo_matrix((vals, (rows, cols)), shape=(k, n))
        ub = np.array([dist[i, j] for i in range(n) for j in range(i + 1, n)])

        res = linprog(
            c=-np.ones(n),
            A_ub=A,
            b_ub=ub,
            bounds=[(0.0, bi) for bi in b],
            method="highs",
        )
        if res.success and np.sum(res.x) > n * r_uniform:
            radii = np.maximum(res.x, 0.0)
            # Safety: ensure strict feasibility (tiny global shrink if needed)
            worst = 0.0
            for i in range(n):
                for j in range(i + 1, n):
                    worst = max(worst, radii[i] + radii[j] - dist[i, j])
            worst = max(worst, (radii - b).max())
            if worst > 0:
                radii = np.maximum(radii - worst - 1e-12, 0.0)
            if np.sum(radii) > n * r_uniform:
                return radii
    except Exception:
        pass

    return np.full(n, r_uniform)
