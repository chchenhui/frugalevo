<DESCRIPTION>
Replace the poor concentric-ring layout (sum ≈ 0.96) with a hexagonal (staggered-row) lattice packing of 26 equal circles. Densest local structure for equal circles is hexagonal, so rows alternate between 5 circles (unstaggered) and 4 circles (staggered by half the horizontal spacing), giving counts 5+4+5+4+5+3 = 26. With horizontal spacing s and row spacing h = s*sqrt(3)/2, the binding constraints are width 5s ≤ 1 and height s + 5h ≤ 1, i.e. s ≤ 1/(1 + 5√3/2) ≈ 0.1876, yielding uniform radius r = s/2 ≈ 0.0938 and sum ≈ 2.44. The radius computation is also fixed: instead of the flawed sequential pairwise scaling, the radius is the minimum of each center's border distance and half the minimum pairwise distance (a correct uniform-radius computation for a lattice).

    # Initialize arrays for 26 circles
    n = 26
    centers = np.zeros((n, 2))

    # Hexagonal (staggered-row) lattice packing of 26 equal circles.
    # Rows (top to bottom) have counts 5, 4, 5, 4, 5, 3 = 26 circles.
    # Horizontal spacing s, vertical row spacing h = s*sqrt(3)/2.
    # Width constraint: 5s <= 1 ; Height constraint: s + 5h <= 1.
    s = 1.0 / (1.0 + 5.0 * np.sqrt(3.0) / 2.0)
    h = s * np.sqrt(3.0) / 2.0
    r = s / 2.0

    row_counts = [5, 4, 5, 4, 5, 3]
    idx = 0
    for row, count in enumerate(row_counts):
        y = r + row * h
        if row % 2 == 0:
            # Unstaggered rows touch both side walls
            for j in range(count):
                centers[idx] = [r + j * s, y]
                idx += 1
        else:
            # Staggered rows are shifted by half a spacing
            for j in range(count):
                centers[idx] = [r + s / 2.0 + j * s, y]
                idx += 1

    # Compute maximum valid radii for this configuration
    radii = compute_max_radii(centers)
