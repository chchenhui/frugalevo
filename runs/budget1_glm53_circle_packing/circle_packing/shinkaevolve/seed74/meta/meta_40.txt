# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

# Recommendations for Future Mutations

1. **Add row-shift and cluster-shift collective moves alongside single-circle moves.** The plateau at 2.36–2.41 across all single-circle perturbation variants strongly suggests lattice-aligned local optima that per-circle moves cannot escape. In the annealing loop, with ~10% probability translate an entire hex row (centers within 0.02 in y of a chosen row) by ±0.005–0.02 horizontally, and with ~10% probability shift a spatially coherent cluster (all centers within 0.25 of a chosen center) by a common delta — both preserve local triangular geometry while repositioning rigid groups, and each still evaluates via the existing sparse `lp_radii`.

2. **Jitter per-start seeds with ±0.01 Gaussian noise to decorrelate the 6 annealing basins.** Currently all starts begin from exact lattice positions so starts 2–6 often rediscover the same trajectory; apply `rng_s.normal(0, 0.01)` to each start's centers (after seeding `rng_s`, before the climb). This is a near-free change consistent with prior evidence that jittered variants of a strong base beat diverse layouts, and it directly extends the mechanism that broke 2.40.

3. **Expand the candidate screen with denser-edge and mirrored row patterns.** Gen-25's gain came from seed breadth, and the current 12 templates miss boundary-heavy structures that favor the AlphaEvolve 2.635 regime. Add [6,5,5,5,6], [6,5,6,5,4], [5,6,4,6,5], and vertical mirrors of the current top rows — each costs microseconds in the LP screen since the sparse assembly already handles any center configuration.

4. **Add a greedy geometric pre-screen to skip exact LP solves for clearly-bad trials.** Before each `lp_radii` call in the climb, run `compute_max_radii` (already implemented, ~microseconds for n=26); if its sum is below the current `tot − 0.01`, reject the trial immediately, since greedy rarely underestimates the LP by more than that margin for small perturbations. This roughly halves LP calls, freeing time for a 7th–8th start basin or annealing temperature restarts from `bc/br` on stalls.

5. **Escape the hex-template plateau entirely with free-form seeded layouts.** Every correct program this round optimizes centers within hex-row templates, capping the achievable configuration space; the ~0.22 gap to 2.635 likely requires non-lattice structures. Add 2–3 free-form seeds — e.g., boundary-clustering layouts (circles pushed toward walls at varied radii, denser corners), or the best-known 26-circle packing layout with per-circle jitter — score them with the same sparse LP, and include top scorers among the multi-start basins so the annealing can refine them identically.
