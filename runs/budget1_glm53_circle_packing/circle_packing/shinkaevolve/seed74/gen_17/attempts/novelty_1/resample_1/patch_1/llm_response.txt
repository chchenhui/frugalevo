<DESCRIPTION>
The current hill-climb only accepts strictly improving moves, so it gets stuck in local optima around 2.40. Replace it with simulated annealing: accept worse moves with probability exp((s_new - s_cur)/T), with T decaying geometrically. When no improvement occurs for ~50 accepted/evaluated steps, reheat by resetting T to its starting value (2–3 times), then let it cool again. This lets circles pass through high-energy (overlapping-ish, small-radius) configurations to escape local optima, which is the key gap to 2.635. Also keep track of the best-ever configuration separately so annealing moves never degrade the returned answer.</DESCRIPTION>
