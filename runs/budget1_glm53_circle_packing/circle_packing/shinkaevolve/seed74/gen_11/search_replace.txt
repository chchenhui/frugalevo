<DESCRIPTION>
Replace the naive ring layout with a hexagonal (triangular) lattice arrangement of 26 sites, which is the densest local arrangement for equal circles and yields near-uniform nearest-neighbor distances. Then, instead of the crude pairwise scaling (which shrinks radii far too aggressively and yields only ~0.96), compute the optimal radii for the fixed centers exactly via linear programming (scipy.optimize.linprog): maximize sum(r_i) subject to r_i + r_j <= d(i,j) for all pairs and r_i <= border distance. This LP is the exact optimum for fixed centers, so any improvement comes purely from better site placement. The hexagonal layers (rows of 5,4,5,4,5,3) fill the square efficiently and place many circles near the boundary where border constraints dominate, which is characteristic of best-known square packings around n=26.

    # Initialize arrays for 26 circles
    n = 26
    centers = np.zeros((n, 2))

    # Hexagonal (triangular) lattice layout: rows of 5,4,5,4,5,3 circles.
    # This is the densest local arrangement; alternating row offsets create
    # near-equilateral triangles between neighboring circles, which is the
    # hallmark of optimal equal-circle packings.
    rows = [5, 4, 5, 4, 5, 3]
    dy = 1.0 / (len(rows) + 1)  # vertical spacing between row centers
    idx = 0
    for r, count in enumerate(rows):
        y = (r + 1) * dy
        # Horizontal spacing scaled so each row's circles spread across square
        dx = 1.0 / (count + 1)
        offset = 0.0
        if count % 2 == 0:
            # Even rows are offset by half a spacing (staggered lattice)
            offset = 0.5 * (1.0 / 5) - 0.5 * dx
        for c in range(count):
            x = (c + 1) * dx + offset
            x = min(max(x, 0.02), 0.98)
            centers[idx] = [x, y]
            idx += 1
    assert idx == n

    # Compute optimal radii for the fixed centers exactly via linear
    # programming: maximize sum(r) s.t. r_i + r_j <= d_ij, r_i <= border dist.
    radii = compute_max_radii(centers)
    try:
        from scipy.optimize import linprog

        m = np.zeros((n, n))
        A_ub = []
        b_ub = []
        for i in range(n):
            for j in range(i + 1, n):
                d = np.sqrt(np.sum((centers[i] - centers[j]) ** 2))
                row = np.zeros(n)
                row[i] = 1.0
                row[j] = 1.0
                A_ub.append(row)
                b_ub.append(d)
        # Border constraints: r_i <= min(x, y, 1-x, 1-y)
        for i in range(n):
            x, y = centers[i]
            row = np.zeros(n)
            row[i] = 1.0
            A_ub.append(row)
            b_ub.append(min(x, y, 1 - x, 1 - y))
        res = linprog(c=-np.ones(n), A_ub=np.array(A_ub), b_ub=np.array(b_ub),
                      bounds=[(0, None)] * n, method="highs")
        if res.success:
            radii = res.x
    except Exception:
        pass
