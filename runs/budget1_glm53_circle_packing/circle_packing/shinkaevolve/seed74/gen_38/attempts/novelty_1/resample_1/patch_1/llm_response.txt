<DESCRIPTION>
Replace the single-trajectory simulated annealing (which regressed to 2.38 from the 2.40 greedy hill-climb) with a multi-start greedy hill-climb: each of 4 starts begins from the best lattice candidate perturbed with a distinct ±0.01 Gaussian jitter, and the time budget is split evenly with shrinking per-start deadlines ((deadline−now)/(n_starts−start)). The hill-climb itself keeps the LP re-solve and adaptive step-size shrink/grow schedule that previously broke 2.40. Jittered variants of a strong base have empirically beaten diverse layouts, and decorrelating the starts cheaply samples more basins within the same wall-clock time. Also expand the seed candidate list slightly so the base itself is stronger before jittering.</DESCRIPTION>

    # Each start begins from the best lattice candidate perturbed with a
    # distinct small +/-0.01 jitter, and gets a shrinking share of the
    # remaining time: (deadline - now) / (n_starts - start).
    try:
        import time
        deadline = time.time() + 2.2
        n_starts = 4

        for start in range(n_starts):
            rng = np.random.default_rng(1000 + start)
            cur = centers + rng.normal(0.0, 0.01, size=centers.shape)
            cur = np.clip(cur, 0.01, 0.99)
            cur_radii = lp_radii(cur)
            cur_score = np.sum(cur_radii)
            if cur_score > sum_radii:
                centers, radii, sum_radii = cur.copy(), cur_radii, cur_score

            start_deadline = time.time() + max(
                (deadline - time.time()) / (n_starts - start), 0.1)
            step = 0.02

            while time.time() < start_deadline:
                trial = cur.copy()
                k_move = rng.integers(1, 4)
                for idx in rng.choice(n, size=k_move, replace=False):
                    trial[idx] += rng.normal(0.0, step, size=2)
