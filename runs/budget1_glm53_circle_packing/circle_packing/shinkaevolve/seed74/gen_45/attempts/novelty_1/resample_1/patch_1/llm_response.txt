<DESCRIPTION>
All prior variants that perturb only 1–3 individual circles plateau at sum ≈ 2.36–2.41. This is characteristic of lattice-aligned local optima: the seed is a triangular lattice, and moving single circles off their lattice sites almost always decreases the LP total, so the hill-climb gets stuck even though sliding whole rigid rows/clusters to better global positions could gain. The fix is to add two collective move types to the hill-climb, alongside the existing single-circle moves:

1. **Row-shift (≈10% of moves):** pick an anchor circle, gather all centers within 0.02 in y (one hex row, since row spacing is ≈0.16), and translate that whole row horizontally by ±0.005–0.02. This slides a rigid triangular-lattice row against its neighbors without breaking the local equilateral geometry, letting rows redistribute slack from the square's vertical mirror symmetry.

2. **Cluster-shift (≈10% of moves):** pick an anchor, gather all centers within 0.25 of it, and translate that coherent cluster by a common small random delta. This moves rigid hex patches (e.g., the 5-4-5 core) as a unit toward the walls or into underused corners, which per-circle jitter can never accomplish.

Both move types preserve the local pairwise distances inside the moved group, so the LP (which is exact given centers) re-evaluates only the group's interaction with the rest of the square — collective moves explore a direction in configuration space that single-circle moves cannot reach. The remaining 80% of moves stay single-circle to fine-tune individual sites. I also extend the time budget from 0.9s to 1.8s (prior runs completed within 2.7s comfortably) and grow the step slightly on successful moves so accepted collective shifts can be amplified.

    # augmented with collective row-shift and cluster-shift moves.
    # Single-circle perturbations cannot escape lattice-aligned local
    # optima; sliding rigid hex rows / coherent clusters preserves the
    # local triangular geometry while repositioning whole groups.
    try:
        import time
        rng = np.random.default_rng(0)
        deadline = time.time() + 1.8
        step = 0.02
        while time.time() < deadline:
            trial = centers.copy()
            u = rng.random()
            if u < 0.10:
                # Row shift: translate one horizontal hex row together.
                # Row spacing is ~s*sqrt(3)/2 (~0.16), so a 0.02 y-band
                # captures exactly one row of centers.
                anchor = int(rng.integers(0, n))
                y_ref = centers[anchor, 1]
                row_mask = np.abs(centers[:, 1] - y_ref) < 0.02
                dx = rng.uniform(0.005, 0.02) * rng.choice([-1.0, 1.0])
                trial[row_mask, 0] += dx
            elif u < 0.20:
                # Cluster shift: translate a spatially coherent group
                # (all centers within 0.25 of an anchor) by a common delta.
                anchor = int(rng.integers(0, n))
                d2 = np.sum((centers - centers[anchor]) ** 2, axis=1)
                cluster_mask = d2 < 0.25 ** 2
                delta = rng.normal(0.0, 0.012, size=2)
                trial[cluster_mask] += delta
            else:
                # Standard single-circle fine-tuning moves
                k_move = rng.integers(1, 4)
                for idx in rng.choice(n, size=k_move, replace=False):
                    trial[idx] += rng.normal(0.0, step, size=2)
            # Keep centers inside the square
            trial = np.clip(trial, 0.01, 0.99)
            radii_t = lp_radii(trial)
            total_t = np.sum(radii_t)
            if total_t > sum_radii + 1e-9:
                centers, radii, sum_radii = trial, radii_t, total_t
                # Amplify step after a success to ride improvement directions
                step = min(step * 1.1, 0.05)
            else:
                # Adaptive step size: shrink when stuck, grow occasionally
                if rng.random() < 0.7:
                    step = max(step * 0.92, 0.002)
                else:
                    step = min(step * 1.4, 0.05)
    except Exception:
        pass
