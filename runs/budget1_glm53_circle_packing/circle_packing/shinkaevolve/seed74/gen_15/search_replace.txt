<DESCRIPTION>
The current program regressed badly (2.37 → 1.69) for two reasons: (1) `fast_radii` is a monotone shrinking heuristic that systematically *underestimates* the optimal radii, so the hill-climb accepts/rejects moves based on a biased objective, wasting the whole search budget on noise; (2) the search spreads 4000 steps over 5 layouts with an isotropic random walk that has low acceptance probability. The earlier LP-based version proved the LP objective is what makes the search work (2.37 in only 250 steps).

The fix: restore the exact LP as the objective inside the loop, cut the step count to fit the time budget, and — following the targeted-move recommendation — replace isotropic Gaussian jitter with *slack-directed* moves: for each circle compute its slack (distance to nearest wall minus radius, and gaps to touching neighbors) and perturb preferentially along the direction of maximum slack, so a large fraction of the step lies in directions that are feasible by construction and thus more likely to be accepted. Random jitter is kept at a small fraction to preserve exploration. Fewer, more informative steps (each with exact LP evaluation) plus fewer layouts keeps runtime around the earlier ~1.5–3 s range while improving the attained sum.

def slack_direction(centers, radii, i):
    """Direction of maximum available slack for circle i.

    Slack = how much extra room circle i has: to walls and to the nearest
    non-touching neighbors. Moving along this direction is much more
    likely to be accepted than an isotropic random step.
    """
    n = len(centers)
    x, y = centers[i]
    cands = []
    # wall slacks (move away from walls with room to spare)
    walls = [(x - radii[i], [-1.0, 0.0]), (1 - x - radii[i], [1.0, 0.0]),
             (y - radii[i], [0.0, -1.0]), (1 - y - radii[i], [0.0, 1.0])]
    for slack, vec in walls:
        if slack > 0:
            cands.append((slack, np.array(vec, dtype=float)))
    # neighbor gaps: direction away from each neighbor, weighted by gap
    for j in range(n):
        if j == i:
            continue
        diff = centers[i] - centers[j]
        dist = np.hypot(*diff)
        if dist < 1e-12:
            continue
        gap = dist - (radii[i] + radii[j])
        if gap > 0:
            cands.append((gap, diff / dist))
    if not cands:
        return np.zeros(2)
    # pick the direction with the largest slack, with a tie-break toward
    # the average of all slack directions
    avg = sum(v for _, v in cands)
    best_dir = max(cands, key=lambda t: t[0])[1]
    d = 0.7 * best_dir + 0.3 * (avg / max(np.linalg.norm(avg), 1e-12))
    nn = np.linalg.norm(d)
    return d / nn if nn > 1e-12 else np.zeros(2)
