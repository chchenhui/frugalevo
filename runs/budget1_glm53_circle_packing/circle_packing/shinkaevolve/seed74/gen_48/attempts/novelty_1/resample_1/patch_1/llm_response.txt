<DESCRIPTION>
The current seed screen only tests 8 row patterns, and the hill-climb then commits all of its 1.6s budget to a single basin of attraction — the best seed by initial LP score. Two targeted improvements:

1. **Denser-edge and mirrored row templates.** Gen-25's gain came from seed breadth, but the current candidate list misses boundary-heavy structures (rows of 6 at the edges with 5s inside) and vertical mirrors of the top performers. Since `hex_layout` builds rows top-down with stagger alignment tied to row order, a vertically mirrored pattern is geometrically distinct and can land in a different (better) LP basin. Each new template costs microseconds in the LP screen. All new row counts sum to exactly 26.

2. **Multi-start hill climb.** Instead of climbing only from the single best seed, run the slack-directed climb from the top 3 seeds, splitting the time budget evenly, and keep the global best. The seed with the best *initial* LP value is not necessarily the seed with the best *nearby local optimum* — edge-heavy templates in particular often start lower but have more room to expand against the walls. Tracking `gbest` also guarantees we never return a configuration worse than any seed's post-climb result.
