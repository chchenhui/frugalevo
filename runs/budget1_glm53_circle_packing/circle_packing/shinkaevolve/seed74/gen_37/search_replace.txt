The current program regressed (2.38) because it uses the slow dense-matrix LP assembly (O(n²) Python loops building a dense A_ub) and only a single-start hill climb that tracks only the current state, so a temporarily bad accepted move can erase progress. The best prior program (2.41, score 0.92) combined the vectorized sparse-CSR LP with a multi-start slack-directed climb and best-ever tracking. I restore that combination and add the recommended cheap geometric pre-screen: before each exact LP call, evaluate the greedy `compute_max_radii` sum (microseconds for n=26); if it falls more than 0.01 below the current basin's sum, reject the trial without solving the LP, since greedy rarely underestimates the LP optimum by more than that margin for small perturbations. This roughly halves the LP calls per iteration, letting each start basin perform many more moves within the same ~1.9s budget, while the row-shift/block-shift collective moves are retained for better exploration of lattice-type packings.

    def lp_radii(centers):
        """Exact optimal radii at fixed centers via vectorized sparse LP:
        maximize sum(r) s.t. r_i + r_j <= d_ij, r_i <= border distance.
        Sparse CSR assembly avoids O(n^2) Python loops and dense matrices,
        so each LP solve is much faster during the search."""
        radii = compute_max_radii(centers)
        try:
            from scipy.optimize import linprog
            from scipy.sparse import csr_matrix

            ii, jj = np.triu_indices(n, 1)
            d = np.linalg.norm(centers[ii] - centers[jj], axis=1)
            keep = d > 1e-9
            ii, jj, d = ii[keep], jj[keep], d[keep]
            m = len(d)
            data = np.ones(2 * m + n)
            rows_ = np.concatenate([np.arange(m), np.arange(m), m + np.arange(n)])
            cols_ = np.concatenate([ii, jj, np.arange(n)])
            A_ub = csr_matrix((data, (rows_, cols_)), shape=(m + n, n))
            bd = np.minimum.reduce([centers[:, 0], centers[:, 1],
                                    1.0 - centers[:, 0], 1.0 - centers[:, 1]])
            b_ub = np.concatenate([d, bd])
            res = linprog(c=-np.ones(n), A_ub=A_ub, b_ub=b_ub,
                          bounds=[(0, None)] * n, method="highs")
            if res.success and np.sum(res.x) > np.sum(radii):
                radii = res.x
        except Exception:
            pass
        return radii
