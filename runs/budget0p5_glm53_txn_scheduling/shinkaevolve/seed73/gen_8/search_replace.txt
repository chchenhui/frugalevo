<DESCRIPTION>
The current version only runs a single greedy pass (the outer restart loop was removed, sample_rate=1.0). The prior best program showed that multiple randomized greedy restarts significantly improve makespan (2832 vs a single run's 2801 baseline). I propose restoring multi-restart randomized greedy (30 restarts), but adding a 2-opt style local search: after each greedy solution, repeatedly try swapping adjacent pairs and moving a transaction to a different position; if makespan improves, keep it. This refines each greedy solution beyond its myopic construction, typically shaving several units of makespan per workload. We also sample more candidates when few remain (cheap evaluations), and keep the best overall.

    best_cost = None
    best_seq = None
    num_restarts = 30
    for _ in range(num_restarts):
        cost, seq = get_greedy_cost_sampled(10, 0.9)
        # local search: adjacent swaps + reinsertion moves
        improved = True
        while improved:
            improved = False
            # try swapping adjacent pairs
            for i in range(len(seq) - 1):
                cand = seq.copy()
                cand[i], cand[i + 1] = cand[i + 1], cand[i]
                c = workload.get_opt_seq_cost(cand)
                if c < cost:
                    seq, cost = cand, c
                    improved = True
            # try moving a transaction to another position
            for i in range(len(seq)):
                for j in range(len(seq)):
                    if i == j:
                        continue
                    cand = seq.copy()
                    t = cand.pop(i)
                    cand.insert(j, t)
                    c = workload.get_opt_seq_cost(cand)
                    if c < cost:
                        seq, cost = cand, c
                        improved = True
                        break
                if improved:
                    break
        if best_cost is None or cost < best_cost:
            best_cost = cost
            best_seq = seq
    return best_cost, best_seq
