<DESCRIPTION>
Instead of a single greedy run with a random start, run many randomized greedy restarts and keep the best schedule found. Greedy construction quality varies heavily with the starting transaction and random sampling, so multiple restarts substantially improve expected makespan. We also increase the number of candidate samples per step and lower the random "skip" rate so the greedy choice is evaluated more thoroughly.</DESCRIPTION>

    # Multi-start randomized greedy: many restarts, keep the best schedule.
    best_cost = None
    best_seq = None
    num_restarts = 60
    for _ in range(num_restarts):
        cost, seq = get_greedy_cost_sampled(20, 0.85)
        if best_cost is None or cost < best_cost:
            best_cost = cost
            best_seq = seq
    return best_cost, best_seq
