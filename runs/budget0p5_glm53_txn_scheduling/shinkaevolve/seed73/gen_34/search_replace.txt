<DESCRIPTION>
Prior generations showed that simulated-annealing refinement (current Phase 2) and iterated local search (ILS) both plateau at makespan 275, while plain insertion/swap neighborhoods are too weak to escape local optima. The literature on sequencing problems (e.g., Job-Shop / TSP local search) consistently shows that adding **or-opt block moves (segment reinsertion of 2–3 consecutive transactions)** and **2-opt segment reversals** dramatically enriches the neighborhood: a single or-opt move changes the relative order of many transaction pairs at once, which pure insertion/swap cannot reach in one step.

Plan:
1. Replace the Phase-2 SA loop with an ILS framework: a deterministic first-improvement local search over four neighborhoods (insertion, swap, or-opt blocks of size 2–3, 2-opt reversal), each with per-candidate deadline checks so the time budget is respected.
2. After each local-search convergence, apply a random segment-shuffle perturbation and re-optimize, keeping improvements (classic ILS "restart from perturbed incumbent" scheme, which outperforms pure SA because it never wanders away from good basins).
3. Keep beam-search construction and greedy candidates from Phase 1 unchanged, but also add cheap randomized greedy constructions to diversify the seed pool for ILS.

This merges the proven ILS framework with the richer move set, which should push makespan below the current 275 plateau.
</DESCRIPTION>
