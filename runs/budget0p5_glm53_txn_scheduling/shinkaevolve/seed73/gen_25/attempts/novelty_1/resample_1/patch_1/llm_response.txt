<DESCRIPTION>
Replace the single-sample greedy with a beam search over transaction orderings. Each beam state holds a partial sequence and its cost; at each step we expand every state with all remaining transactions, evaluate with `get_opt_seq_cost`, and keep the best `beam_width` states. Beam search directly optimizes actual makespan (not proxies like length/write-count), corrects greedy mistakes by keeping several candidates alive, and is far more sample-efficient than random restarts of a 1-sample greedy. Depth-adaptive width: wide (e.g. 10-12) early where branching error compounds most, narrowing (3-4) later to keep runtime bounded. We also run a few restarts with different initial transactions to add diversity, keeping the best overall schedule.

    def get_beam_schedule(start_txn, beam_width_early, beam_width_late, taper_frac=0.25):
        n = workload.num_txns
        beam = [([start_txn], workload.get_opt_seq_cost([start_txn]))]
        all_txns = set(range(n))
        taper_start = max(1, int(taper_frac * n))
        for depth in range(1, n):
            width = beam_width_early if depth <= taper_start else beam_width_late
            candidates = []
            for seq, cost in beam:
                placed = set(seq)
                remaining = all_txns - placed
                for t in remaining:
                    new_seq = seq + [t]
                    new_cost = workload.get_opt_seq_cost(new_seq)
                    candidates.append((new_cost, new_seq))
            candidates.sort(key=lambda x: x[0])
            beam = [(seq, cost) for cost, seq in candidates[:width]]
        best_seq, best_cost = beam[0][0], beam[0][1]
        return best_cost, best_seq
