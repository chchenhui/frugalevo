<DESCRIPTION>
Replace the returned single-sample greedy with a beam search over transaction orderings. Each beam state holds a partial sequence and its makespan cost; at each step we expand every state with all remaining transactions, evaluate via `get_opt_seq_cost`, and keep the best `beam_width` states. Beam search directly optimizes actual makespan (not proxies like length/write-count), corrects greedy mistakes by keeping several candidates alive, and is far more sample-efficient than random restarts of a 1-sample greedy. We use a depth-adaptive width (wide early, e.g. 6–12, where pruning error compounds most; narrow late, e.g. 3) and run a few restarts with different initial transactions for diversity, keeping the best overall schedule.</DESCRIPTION>

    def get_beam_schedule(start_txn, beam_width_early, beam_width_late, taper_frac=0.25):
        beam = [([start_txn], workload.get_opt_seq_cost([start_txn]))]
        all_txns = set(range(n))
        taper_start = max(1, int(taper_frac * n))
        for depth in range(1, n):
            width = beam_width_early if depth <= taper_start else beam_width_late
            candidates = []
            for seq, cost in beam:
                placed = set(seq)
                remaining = all_txns - placed
                for t in remaining:
                    new_seq = seq + [t]
                    new_cost = workload.get_opt_seq_cost(new_seq)
                    candidates.append((new_cost, new_seq))
            candidates.sort(key=lambda x: x[0])
            beam = [(seq, c) for c, seq in candidates[:width]]
        return beam[0][1], beam[0][0]
