<DESCRIPTION>
The current solution is a full-lookahead greedy with random restarts. Greedy alone gets stuck in local optima. I propose two improvements:

1. Keep the multistart greedy (it's effective), but with a time budget per greedy run.
2. After each greedy solution, apply a local search (insertion + adjacent swap moves): repeatedly try moving a transaction to a different position in the sequence (an effective neighborhood for sequencing problems, like insertion neighborhoods in TSP), and accept any move that reduces makespan. This directly optimizes the actual objective (makespan from `get_opt_seq_cost`) rather than heuristics, and can escape greedy's local optima since a bad greedy choice can be relocated later.

The local search runs within a global time budget and keeps the best overall solution. Insertion moves are O(n²) candidates per pass, and since makespan is monotone in prefix conflicts, moving conflicting transactions earlier/later often yields real gains. This should push makespan below the current 299.

    def local_search(seq, cost, deadline):
        """Insertion-move local search: relocate a transaction to another
        position whenever it reduces the makespan."""
        n = len(seq)
        improved = True
        while improved and time.time() < deadline:
            improved = False
            for i in range(n):
                txn = seq[i]
                rest = seq[:i] + seq[i+1:]
                for j in range(n):
                    cand = rest[:j] + [txn] + rest[j:]
                    c = workload.get_opt_seq_cost(cand)
                    if c < cost:
                        seq, cost = cand, c
                        improved = True
                        break
                if improved:
                    break
        return seq, cost

    start_time = time.time()
    total_budget = 25
    best_cost = None
    best_seq = None
    order = list(range(workload.num_txns))
    random.shuffle(order)
    for idx, start_txn in enumerate(order):
        elapsed = time.time() - start_time
        remaining = total_budget - elapsed
        if best_seq is not None and remaining <= 0.5:
            break
        # split remaining time across remaining restarts
        per_run = max(remaining / max(1, (len(order) - idx)), 0.5)
        deadline = time.time() + per_run
        cost, seq = greedy_from(start_txn)
        if time.time() < deadline:
            seq, cost = local_search(seq, cost, deadline)
        if best_cost is None or cost < best_cost:
            best_cost = cost
            best_seq = seq

    return best_cost, best_seq
