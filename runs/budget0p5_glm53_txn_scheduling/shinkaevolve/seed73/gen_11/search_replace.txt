<DESCRIPTION>
The current version runs only a single greedy pass with a fixed sample rate. The prior best version used 60 random restarts, which scored 355 vs current 352 — showing variance across runs. My improvement: restore multi-start randomized greedy (with increasing sample rate as the sequence grows, since decisions near the end matter less for sampling overhead but correctness matters) and add a cheap 2-opt style local search: repeatedly try swapping adjacent transactions or moving a transaction to a different position, and accept improvements. This hill-climbing on top of greedy typically reduces makespan further since pure greedy gets stuck in local orderings that adjacent swaps can fix. I keep total work bounded by a restart budget so runtime stays reasonable.

    def local_search(seq, best_cost, rounds=60):
        # 2-opt style local search: adjacent swaps and single-txn reinsertion
        improved = True
        while improved and rounds > 0:
            improved = False
            n = len(seq)
            # try adjacent swaps
            for i in range(n - 1):
                rounds -= 1
                if rounds <= 0:
                    return seq, best_cost
                cand = seq.copy()
                cand[i], cand[i + 1] = cand[i + 1], cand[i]
                c = workload.get_opt_seq_cost(cand)
                if c < best_cost:
                    best_cost = c
                    seq = cand
                    improved = True
            # try moving one txn to another position
            for i in range(n):
                rounds -= 1
                if rounds <= 0:
                    return seq, best_cost
                t = seq.pop(i)
                for j in range(len(seq) + 1):
                    if j == i:
                        continue
                    cand = seq[:j] + [t] + seq[j:]
                    c = workload.get_opt_seq_cost(cand)
                    if c < best_cost:
                        best_cost = c
                        seq = cand
                        improved = True
                        break
                else:
                    seq.insert(i, t)
        return seq, best_cost

    # Multi-start randomized greedy followed by local search
    best_cost = None
    best_seq = None
    num_restarts = 30
    for i in range(num_restarts):
        # increase exploitation (sample_rate) in later restarts
        rate = 0.7 if i < num_restarts // 2 else 0.95
        cost, seq = get_greedy_cost_sampled(15, rate)
        if best_cost is None or cost < best_cost:
            best_cost = cost
            best_seq = seq
        # apply local search only to promising candidates
        if cost <= best_cost * 1.15:
            seq, cost = local_search(seq, cost)
            if cost < best_cost:
                best_cost = cost
                best_seq = seq
    return best_cost, best_seq
