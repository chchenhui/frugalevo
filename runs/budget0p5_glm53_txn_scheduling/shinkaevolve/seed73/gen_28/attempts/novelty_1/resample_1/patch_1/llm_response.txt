<DESCRIPTION>
The current local search only uses single-insertion and pairwise-swap neighborhoods, which can get stuck in local optima that segment-based moves (Or-opt: move blocks of 2-3 consecutive transactions; 2-opt: reverse a segment) can escape. Transaction makespan is highly sensitive to the *relative order* of conflicting transactions, and reversing a segment changes many pairwise orders at once — a powerful move for this cost landscape. Additionally, the current implementation is best-improvement per pass, which wastes time re-evaluating; switching insertion/swap to first-improvement with a wrap-around restart of the scan speeds up each pass so more perturbation restarts fit in the time budget. I add these moves to `local_search` while keeping the existing perturbation restart loop unchanged, so the overall hybrid structure (beam search + GRASP + ILS) and its proven score are preserved, only the descent neighborhood is enriched.

Step-by-step reasoning:
1. Insertion/swap moves explore a small neighborhood; Or-opt (moving short contiguous blocks) and 2-opt (segment reversal) are standard, complementary moves for sequencing problems and escape different local optima.
2. First-improvement (accept immediately on gain, continue scanning from the next index) reduces cost-function evaluations per pass, giving more perturbation restarts within the same 20s budget.
3. All moves preserve permutation validity (each txn appears exactly once), so schedule validity (validity: 1.00) is maintained.

    def local_search(seq, cur_cost, deadline):
        improved = True
        while improved and time.time() < deadline:
            improved = False
            # insertion moves (first-improvement)
            for i in range(n):
                if time.time() >= deadline:
                    return seq, cur_cost
                t = seq[i]
                base = seq[:i] + seq[i+1:]
                for j in range(n):
                    if j == i:
                        continue
                    cand = base[:j] + [t] + base[j:]
                    c = workload.get_opt_seq_cost(cand)
                    if c < cur_cost:
                        seq, cur_cost, improved = cand, c, True
                        break
            # swap moves (first-improvement)
            for i in range(n):
                if time.time() >= deadline:
                    return seq, cur_cost
                for j in range(i + 1, n):
                    cand = seq[:]
                    cand[i], cand[j] = cand[j], cand[i]
                    c = workload.get_opt_seq_cost(cand)
                    if c < cur_cost:
                        seq, cur_cost, improved = cand, c, True
                        break
            # or-opt: move short contiguous blocks (size 2-3) elsewhere
            for blk in (2, 3):
                for i in range(n - blk + 1):
                    if time.time() >= deadline:
                        return seq, cur_cost
                    block = seq[i:i + blk]
                    rest = seq[:i] + seq[i + blk:]
                    for j in range(len(rest) + 1):
                        cand = rest[:j] + block + rest[j:]
                        if cand == seq:
                            continue
                        c = workload.get_opt_seq_cost(cand)
                        if c < cur_cost:
                            seq, cur_cost, improved = cand, c, True
                            break
                    else:
                        continue
                    break
            # 2-opt: reverse a segment (changes many pairwise orders at once)
            for i in range(n - 1):

                    return seq, cur_cost

                    c = workload.get_opt_seq_cost(cand)
                    if c < cur_cost:
                        seq, cur_cost, improved = cand, c, True
                        break
                else:

                break
        return seq, cur_cost
