<DESCRIPTION>
The previous best program (combined_score 3521.13, makespan 283) used an adaptive beam width that starts wide early in the schedule (where branching errors compound most) and narrows toward the end. The current program regressed to a constant beam width (score dropped to 3412.97, makespan 292). This edit restores the adaptive width schedule: full width for the first 20% of placements, reduced width for the middle, and a narrow beam near the end. Concentrating search effort early is justified because beam-pruning errors made on early placements propagate through the entire prefix, while late placements affect only a short suffix. This recovers the previously demonstrated gain without changing the time budget or phase-2 annealing behavior.
