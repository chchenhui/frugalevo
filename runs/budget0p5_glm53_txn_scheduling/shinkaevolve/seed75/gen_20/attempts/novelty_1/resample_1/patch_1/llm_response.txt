<DESCRIPTION>
Replace the best-improvement insertion local search with a first-improvement variant using a shuffled transaction order each round. This dramatically reduces per-round cost (stop scanning as soon as one improving relocation is found) while retaining the full insertion neighborhood. The savings allow many more restarts within the same time budget. Also move `import time` to the top of the function (before any use) to avoid crash risk, and raise the restart cap since each restart is now much cheaper.
</DESCRIPTION>
