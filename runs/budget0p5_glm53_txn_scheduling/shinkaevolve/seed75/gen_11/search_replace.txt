<DESCRIPTION>
The current local search only swaps nearby pairs (window of 5, 3 rounds). Scheduling research shows that for sequencing problems, "insertion" moves (remove a transaction and re-insert it at another position) often find improvements that swaps miss, especially when a long transaction should move far back. I propose: (1) add an insertion-move pass to the local search, alternating with the swap pass; (2) widen the swap window slightly; (3) increase restarts so the randomized greedy produces more diverse starting points. Each candidate is evaluated with the actual makespan function `get_opt_seq_cost`, so improvements are guaranteed to be real makespan reductions. This should strictly lower makespan relative to the current swap-only search since every existing move is still available and new improving moves can be accepted.
</DESCRIPTION>

    def swap_local_search(seq, max_rounds=4):
        seq = list(seq)
        best_cost = workload.get_opt_seq_cost(seq)
        improved = True
        rounds = 0
        while improved and rounds < max_rounds:
            improved = False
            rounds += 1
            # swap pass (wider window)
            for i in range(n - 1):
                for j in range(i + 1, min(n, i + 8)):
                    seq[i], seq[j] = seq[j], seq[i]
                    c = workload.get_opt_seq_cost(seq)
                    if c < best_cost:
                        best_cost = c
                        improved = True
                    else:
                        seq[i], seq[j] = seq[j], seq[i]
            # insertion pass: remove txn and reinsert elsewhere
            for i in range(n):
                t = seq.pop(i)
                for j in range(n):
                    if j == i:
                        continue
                    seq.insert(j, t)
                    c = workload.get_opt_seq_cost(seq)
                    if c < best_cost:
                        best_cost = c
                        improved = True
                        break
                    else:
                        seq.pop(j)
                else:
                    seq.insert(i, t)
        return best_cost, seq
