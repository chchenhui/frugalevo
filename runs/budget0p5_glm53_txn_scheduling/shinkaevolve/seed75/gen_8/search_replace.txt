<DESCRIPTION>
The current code runs a single randomized greedy pass. Since the greedy construction is randomized (random sampling of candidate transactions), running many restarts and keeping the best schedule found substantially improves expected makespan at little cost. Additionally, using a lower sampling rate occasionally injects random picks (exploration), avoiding local minima. We wrap the greedy in a multi-restart loop with both a fully-greedy mode and an exploratory mode, returning the best schedule over all restarts. This exploits the stochastic nature of the construction: best-of-N restarts monotonically improves the expected result.

    best_cost = None
    best_seq = None
    # Multi-restart: run greedy many times with varying sample rates,
    # keep the best (lowest makespan) schedule found.
    num_restarts = 200
    for i in range(num_restarts):
        if i < num_restarts // 2:
            # fully greedy phase
            cost, seq = get_greedy_cost_sampled(10, 1.0)
        else:
            # exploratory phase: allow random picks to escape local minima
            cost, seq = get_greedy_cost_sampled(10, 0.9)
        if best_cost is None or cost < best_cost:
            best_cost = cost
            best_seq = seq
    return best_cost, best_seq
