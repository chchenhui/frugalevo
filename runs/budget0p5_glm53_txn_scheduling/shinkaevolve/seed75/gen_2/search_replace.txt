<DESCRIPTION>
The current greedy only runs once and evaluates at most `num_samples` random candidate transactions per step, so quality is highly dependent on luck. Improvement: (1) at each greedy step, evaluate ALL remaining transactions using exact `get_opt_seq_cost` (not random sampling), (2) run many restarts from different starting transactions, and (3) return the best schedule found across all restarts. This systematically reduces makespan because the greedy step picks the locally optimal next transaction, and multiple restarts escape bad local minima caused by the first choice.

        txn_seq = [start_txn]
        remaining_txns = [x for x in range(0, workload.num_txns)]
        remaining_txns.remove(start_txn)

        while remaining_txns:
            min_cost = float("inf")
            min_txn = -1
            for t in remaining_txns:
                test_seq = txn_seq + [t]
                cost = workload.get_opt_seq_cost(test_seq)

        assert len(set(txn_seq)) == workload.num_txns
