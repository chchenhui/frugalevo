<DESCRIPTION>
The current local search only considers adjacent swaps, which limits its ability to escape local optima — a transaction that would be much better placed far earlier or later in the sequence is never moved more than one position at a time, and single-pass swaps converge quickly to a poor local minimum. My edit extends the local search with (1) insertion moves (remove a transaction from its position and try reinserting it at every other position), which are strictly more powerful than adjacent swaps and known to be effective for sequencing problems, and (2) an occasional random-restart perturbation (ruin-and-recreate style): if a GRASP run fails to improve the best solution, perturb the best sequence by shuffling a random contiguous segment and re-optimizing with local search. This diversifies the search without extra greedy-construction cost (which is the expensive part since each candidate evaluation calls get_opt_seq_cost). Since all moves are evaluated on the true makespan, any accepted move is guaranteed to improve or maintain the real objective. This combination of stronger local moves plus perturbation restarts should reliably lower makespan relative to the current adjacent-swap-only scheme.

</DESCRIPTION>

    def local_search(seq, cost, max_passes=30):
        """Adjacent swap + insertion local search on true makespan."""
        improved = True
        passes = 0
        while improved and passes < max_passes:
            improved = False
            passes += 1
            # adjacent swaps
            for i in range(len(seq) - 1):
                cand = seq.copy()
                cand[i], cand[i + 1] = cand[i + 1], cand[i]
                c = seq_cost(cand)
                if c < cost:
                    seq, cost = cand, c
                    improved = True
            # insertion moves: pull txn i out, try every other position
            for i in range(len(seq)):
                t = seq[i]
                rest = seq[:i] + seq[i + 1:]
                for j in range(len(rest) + 1):
                    if j == i:
                        continue
                    cand = rest[:j] + [t] + rest[j:]
                    c = seq_cost(cand)
                    if c < cost:
                        seq, cost = cand, c
                        improved = True
                        # re-extract from updated seq position
                        break
        return cost, seq
