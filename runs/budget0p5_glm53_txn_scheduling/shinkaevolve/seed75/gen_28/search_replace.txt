<DESCRIPTION>
The recommendation suggests interleaving a full pairwise-swap sweep with the insertion-based local search. Insertion moves (relocating a transaction to a different position) and adjacent/arbitrary swap moves (exchanging two transactions' positions) explore different neighborhoods of the schedule space; combining them within the proven restart/time-budget structure covers both move classes. Step-by-step reasoning: (1) the greedy construction gives a decent starting schedule; (2) insertion sweeps already improve it; (3) some local optima of the insertion neighborhood can only be escaped by swap moves (and vice versa), so alternating sweeps within each local search round converges to better minima; (4) the cost cache via get_opt_seq_cost ensures the same safe API is used, no new API risk. We modify local_search_insertion to perform one insertion pass followed by one full pairwise-swap pass per round, keeping the existing 20-restart/100-second outer structure intact.</DESCRIPTION>

    def local_search_insertion(seq, best_cost, max_rounds=30):
        # hybrid local search: each round does one insertion sweep
        # followed by one full pairwise-swap sweep, covering both
        # move classes to escape single-neighborhood local optima.
        improved = True
        rounds = 0
        while improved and rounds < max_rounds:
            improved = False
            rounds += 1
            # --- insertion sweep ---
            for i in range(len(seq)):
                for j in range(len(seq)):
                    if i == j:
                        continue
                    cand = seq.copy()
                    t = cand.pop(i)
                    cand.insert(j, t)
                    c = workload.get_opt_seq_cost(cand)
                    if c < best_cost:
                        best_cost = c
                        seq = cand
                        improved = True
            # --- pairwise swap sweep ---
            for i in range(len(seq)):
                for j in range(i + 1, len(seq)):
                    cand = seq.copy()
                    cand[i], cand[j] = cand[j], cand[i]
                    c = workload.get_opt_seq_cost(cand)
                    if c < best_cost:
                        best_cost = c
                        seq = cand
                        improved = True
        return best_cost, seq
