<DESCRIPTION>
The current program builds a greedy randomized solution and then applies strict-descent swap/insertion local search, which gets trapped in local optima. To escape these local optima, I add simulated-annealing-style acceptance on the insertion neighborhood: each round, we try a random insertion move (remove a transaction from position i and reinsert at position j) and accept it if it improves cost OR with a small probability if it is only slightly worse (within a temperature-controlled threshold). The temperature decays over the rounds. We track and return the best-so-far schedule, never letting an accepted worsening move destroy the best solution found. This extends the proven insertion neighborhood (which achieved makespan 292) with a stronger metaheuristic search strategy, typically yielding better makespans on such sequencing problems. I keep the greedy restarts for diversification and reduce the pure best-improvement descent to a quick warm-start, spending the remaining budget on annealed moves evaluated with the true makespan cost function.</DESCRIPTION>
