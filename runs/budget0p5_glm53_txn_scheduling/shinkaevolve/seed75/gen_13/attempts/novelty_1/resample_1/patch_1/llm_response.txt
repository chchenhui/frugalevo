greedy_plus_2opt_swap_local_search</NAME>
<DESCRIPTION>
The current program builds a greedy schedule from each starting transaction. Greedy construction alone is myopic — it cannot repair ordering mistakes made early. A classic improvement is to follow each greedy construction with a local search: repeatedly try swapping pairs of transactions in the sequence (prioritizing swaps of nearby positions and swaps involving conflicting transactions, since makespan only changes when dependency order of conflicting txns changes), accepting any swap that reduces makespan. Iterating this until no improving swap exists typically shaves significant makespan off greedy solutions. We keep multiple restarts (one per starting transaction plus randomized restarts) and apply local search to each, returning the best. This directly minimizes the true objective (evaluated via get_opt_seq_cost) rather than heuristics, which the prompt warns against.</DESCRIPTION>

    def local_search(seq, cost, max_iters=30):
        # 2-opt style swap local search: try swapping pairs of transactions
        # (with emphasis on nearby positions, which most often matter since
        # cost changes come from reordering conflicting transactions) and
        # accept any swap that lowers makespan. Repeat until no improvement.
        n = len(seq)
        for _ in range(max_iters):
            improved = False
            best_pair = None
            best_pair_cost = cost
            for i in range(n - 1):
                for span in (1, 2, 3, 5, 8, 13):
                    j = i + span
                    if j >= n:
                        break
                    trial = seq[:]
                    trial[i], trial[j] = trial[j], trial[i]
                    c = workload.get_opt_seq_cost(trial)
                    if c < best_pair_cost:
                        best_pair_cost = c
                        best_pair = (i, j)
            if best_pair is None:
                break
            i, j = best_pair
            seq[i], seq[j] = seq[j], seq[i]
            cost = best_pair_cost
            improved = True
        return cost, seq

    best_cost = float("inf")
    best_seq = None
    num_restarts = max(1, num_seqs)
    for i in range(num_restarts):
        if i < workload.num_txns:
            start_txn = i
        else:
            start_txn = random.randint(0, workload.num_txns - 1)
        cost, seq = greedy_from(start_txn)
        cost, seq = local_search(seq, cost)
        if cost < best_cost:
            best_cost = cost
            best_seq = seq

    return best_cost, best_seq
