<DESCRIPTION>
The current implementation runs a single random greedy pass. Two improvements: (1) run many random restarts of the sampled greedy (each with different random decisions) and keep the best schedule found, since greedy is stochastic and variance across restarts is high; (2) apply a 2-opt style local search afterward — try moving each transaction to a different position (insertion neighborhood) and accept improvements — to fix greedy's ordering mistakes. Evaluating candidates with `get_opt_seq_cost` keeps decisions tied to actual makespan, not heuristics.

    def local_search_insertion(seq, best_cost, max_rounds=30):
        # insertion-based local search: try relocating each txn to a better position
        improved = True
        rounds = 0
        while improved and rounds < max_rounds:
            improved = False
            rounds += 1
            for i in range(len(seq)):
                for j in range(len(seq)):
                    if i == j:
                        continue
                    cand = seq.copy()
                    t = cand.pop(i)
                    cand.insert(j, t)
                    c = workload.get_opt_seq_cost(cand)
                    if c < best_cost:
                        best_cost = c
                        seq = cand
                        improved = True
                # keep best-so-far seq going forward
        return best_cost, seq
