# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Run ILS from all 3 pool members in round-robin, not just the diversity-weighted pick.** Gen 43's diversity-weighted selection is unproven (Gen 40 matched it without diversity), so instead cycle the perturb-descend loop across the full top-3 pool — every improvement replaces that pool entry. This preserves the validated deep-ILS budget while tripling basin coverage; cap each entry's ILS time at ~15s of the 45s reserve so all three get refined.

2. **Add Or-opt segment moves (length 2–3) to the perturbation operator.** Gen 42's Or-opt failed from a tuple-arity bug, not a bad neighborhood. Implement perturbation as popping segment `seq[i:i+k]` (k∈{2,3}) and reinserting at a random position via `cand = seq[:i] + seq[i+k:]`, then `cand[:j] + seg + cand[j:]` — the same slice-copy safety pattern that makes Gen 43 bug-free — occasionally mixed with the existing 2–5 single insertions to keep the classic perturbation available.

3. **Add an escape-kick when ILS stagnates: increase perturbation strength adaptively.** Gen 43's fixed strength 2–5 random insertions can stall in a deep local optimum. Track non-improving iterations; after ~50 consecutive failures, temporarily raise strength to 8–12 insertions (or apply a random 12-swap-window scramble), then revert to 2–5 once an improvement is found. Deterministic acceptance (keep only if improved) stays unchanged — annealing is confirmed dominated.

4. **Add best-improvement reinsertion sweeps to the descent's final pass.** The descent currently accepts the best target within a ±10 window plus 6 random targets per element; on the last descent round only, evaluate all n insertion positions per element and take the global minimum. This is a bounded O(n²) addition to a phase that already runs comfortably within budget, and mirrors the insight that fuller exploration in the final round is cost-effective.

5. **Tune the pool/refinement time split: try 35s pool / 65s ILS.** Gen 43's greedy construction parameters (10 samples, 0.9 rate) are validated and converge quickly; the deep ILS is the decisive phase (Gen 41's ablation: 287-point gap). Shave 10 seconds off pool building and give it to the perturb-descend loop, keeping the explicit `pool_deadline = deadline - 65` reservation so pool progress never starves refinement.
