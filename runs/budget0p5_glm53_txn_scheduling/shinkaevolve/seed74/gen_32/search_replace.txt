<DESCRIPTION>
Add a ruin-and-recreate perturbation phase between the greedy restarts and the local search. After greedy construction produces a good base sequence, iteratively remove 3-8 random transactions, then greedily reinsert each removed transaction (in random order) at its best position evaluated with the true makespan cost. Accept only improvements and repeat until the time budget expires, keeping the best solution found. This combines the proven gain of ruin-and-recreate (23 makespan units at identical construction settings per Gen 20) with the existing descent, and effectively acts as a large-neighborhood search that escapes local optima that plain relocation/swap moves cannot.

    def ruin_and_recreate(seq, cost, deadline):
        # Remove k random transactions, greedily reinsert each at its
        # best position. Accept improvements only; repeat until budget.
        n = workload.num_txns
        while time.time() < deadline:
            k = random.randint(3, min(8, n - 1))
            removed_idx = random.sample(range(n), k)
            removed = [seq[i] for i in removed_idx]
            base = [seq[i] for i in range(n) if i not in set(removed_idx)]
            cur_cost = workload.get_opt_seq_cost(base)
            ok = True
            random.shuffle(removed)
            for t in removed:
                best_c = None
                best_pos = -1
                for pos in range(len(base) + 1):
                    cand = base[:pos] + [t] + base[pos:]
                    c = workload.get_opt_seq_cost(cand)
                    if best_c is None or c < best_c:
                        best_c = c
                        best_pos = pos
                if time.time() >= deadline:
                    ok = False
                    break
                base.insert(best_pos, t)
                cur_cost = best_c
            if not ok:
                break
            if cur_cost < cost:
                seq = base
                cost = cur_cost
            # else: keep original seq and perturb again
        return cost, seq
