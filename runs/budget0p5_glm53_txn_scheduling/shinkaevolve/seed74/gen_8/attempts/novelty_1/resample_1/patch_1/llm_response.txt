<DESCRIPTION>
The current approach relies on random sampling of candidates, which means at each greedy step many good candidate transactions are never evaluated. My improvement has two parts:

1. **Full greedy construction**: at each step, evaluate ALL remaining transactions (not a random sample of 6) and append the one that yields the lowest incremental makespan. This gives a much stronger deterministic baseline per restart. With multiple randomized restarts (random start txn + a small random perturbation rate), this combines the best of both worlds.

2. **Local search refinement (relocation + swap)**: greedy schedules are typically improvable. After each restart, apply a local search where we try (a) moving a transaction to a different position and (b) swapping pairs of transactions, accepting any move that reduces makespan, until no improvement. Since `get_opt_seq_cost` evaluates the whole sequence, we limit moves to a random subset per pass to keep runtime bounded, and we use a wall-clock time budget so the search keeps improving the best-known schedule across restarts instead of being cut off arbitrarily.

The reasoning: makespan is driven by conflict delays; the greedy step that measures the *actual* incremental cost (via `get_opt_seq_cost`) over all candidates is the most informed decision possible per step, and local search fixes the ordering mistakes greedy inevitably makes (e.g., a transaction placed early that creates long chains of conflict delays). Together with best-across-restarts, this should push makespan below the current 365–391 range.

    def get_full_greedy(perturb_rate):
        # Full greedy: at each step evaluate ALL remaining transactions
        # with the true makespan cost and append the cheapest one.
        start_txn = random.randint(0, workload.num_txns - 1)
        txn_seq = [start_txn]
        remaining_txns = [x for x in range(0, workload.num_txns)
                          if x != start_txn]
        while remaining_txns:
            min_cost = None
            min_txn = -1
            # occasionally accept a random (non-best) candidate to
            # diversify across restarts
            if random.random() < perturb_rate:
                idx = random.randint(0, len(remaining_txns) - 1)
                min_txn = remaining_txns[idx]
                test_seq = txn_seq + [min_txn]
                min_cost = workload.get_opt_seq_cost(test_seq)
            else:
                for t in remaining_txns:
                    test_seq = txn_seq + [t]
                    cost = workload.get_opt_seq_cost(test_seq)
                    if min_cost is None or cost < min_cost:
                        min_cost = cost
                        min_txn = t
            txn_seq.append(min_txn)
            remaining_txns.remove(min_txn)
        assert len(set(txn_seq)) == workload.num_txns
        return workload.get_opt_seq_cost(txn_seq), txn_seq

    def local_search(seq, cost, deadline, max_moves_per_pass=200):
        # Relocation + swap local search on the full-sequence cost.
        n = workload.num_txns
        improved = True
        while improved and time.time() < deadline:
            improved = False
            moves = []
            for _ in range(min(max_moves_per_pass, n * 2)):
                i = random.randint(0, n - 1)
                j = random.randint(0, n - 1)
                if i != j:
                    moves.append((i, j))
            for i, j in moves:
                if time.time() >= deadline:
                    break
                cand = seq[:]
                if random.random() < 0.5:
                    # relocation: move txn at i to position j
                    t = cand.pop(i)
                    cand.insert(j, t)
                else:
                    # swap positions i and j
                    cand[i], cand[j] = cand[j], cand[i]
                c = workload.get_opt_seq_cost(cand)
                if c < cost:
                    seq = cand
                    cost = c
                    improved = True
        return cost, seq

    time_budget = 20.0  # seconds per workload
    deadline = time.time() + time_budget
    best_cost = None
    best_seq = None
    # Greedy construction followed by local search, repeated with
    # randomized restarts under a time budget.
    while time.time() < deadline:
        cost, seq = get_full_greedy(0.05)
        cost, seq = local_search(seq, cost, deadline)
        if best_cost is None or cost < best_cost:
            best_cost = cost
            best_seq = seq
    return best_cost, best_seq
