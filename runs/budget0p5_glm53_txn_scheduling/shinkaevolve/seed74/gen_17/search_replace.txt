<DESCRIPTION>
The current local search only performs adjacent swaps, which gets stuck in poor local minima quickly. A 2-opt style local search with in-place apply/undo of segment reversals explores a much larger neighborhood of orderings at low constant overhead (no full candidate list copies), enabling more improvement rounds within the same time budget. We replace the adjacent-swap local search with an in-place pairwise-swap (2-opt) search and apply it to every greedy restart's result (keeping the best), rather than only the single best greedy schedule. This combines stronger local optimization with more diverse starting points, directly lowering makespan.

    def local_search(schedule, max_rounds=40):
        # In-place 2-opt style local search: try pairwise swaps (segment
        # reversals reduced to swaps) applied directly on one mutable list,
        # undoing non-improving moves to avoid candidate list copies.
        n = len(schedule)
        seq = list(schedule)
        best_cost = workload.get_opt_seq_cost(seq)
        rounds = 0
        improved_any = True
        while improved_any and rounds < max_rounds:
            improved_any = False
            rounds += 1
            for i in range(n - 1):
                for j in range(i + 1, n):
                    # apply move in place
                    seq[i], seq[j] = seq[j], seq[i]
                    c = workload.get_opt_seq_cost(seq)
                    if c < best_cost:
                        best_cost = c
                        improved_any = True
                        # keep move
                    else:
                        # undo move
                        seq[i], seq[j] = seq[j], seq[i]
        return best_cost, seq

    best_cost = None
    best_sched = None

        cost, sched = local_search(sched, max_rounds=25)
        if best_cost is None or cost < best_cost:
            best_cost = cost
            best_sched = sched

    return best_cost, best_sched
