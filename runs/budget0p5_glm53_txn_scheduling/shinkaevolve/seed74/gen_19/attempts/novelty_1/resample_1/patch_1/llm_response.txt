<DESCRIPTION>
The current multi-restart greedy plus 2-opt reaches a strong local optimum but can get stuck since 2-opt only accepts strictly improving moves. I add a simulated annealing refinement stage with a low initial temperature and fast decay, so it stays mostly cost-guided (accepting worsening swaps only rarely via math.exp(-Δ/T)) but can escape local optima that 2-opt cannot. All imports (math, time for a time budget) are verified at the top. The SA operates on adjacent-pair and random swaps, keeping the best-found schedule, so it never returns something worse than the 2-opt result. Step-by-step: (1) start from the 2-opt solution; (2) repeatedly propose random swaps/pair-moves; (3) accept with Metropolis criterion at low temperature T that decays geometrically; (4) track global best; (5) time-bounded so it terminates within budget. This yields schedules with makespan at or below the current 276 total.</DESCRIPTION>
