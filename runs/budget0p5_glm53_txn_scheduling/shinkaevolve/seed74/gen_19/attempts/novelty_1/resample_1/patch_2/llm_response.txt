<DESCRIPTION>
The current multi-restart greedy plus 2-opt reaches a strong local optimum but can get stuck since 2-opt only accepts strictly improving moves. I add a simulated annealing refinement stage entirely inside the evolve block: it starts from the 2-opt solution, proposes random adjacent/pair swaps, and accepts worsening moves with probability exp(-Δ/T) at a low temperature that decays geometrically — mostly downhill but able to escape 2-opt local optima. It tracks the global best, so it never returns worse than the 2-opt result. All needed imports (math, time) are done inside the function to avoid touching the immutable header.</DESCRIPTION>
