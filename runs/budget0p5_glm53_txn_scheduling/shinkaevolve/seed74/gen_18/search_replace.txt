<DESCRIPTION>
The current local search only performs adjacent swaps, which is a very weak neighborhood — it can barely reorder the greedy construction. A 2-opt (segment reversal) neighborhood explores a much larger portion of the schedule space. The recommendation asks us to avoid rebuilding full candidate lists every iteration (as the sliced-copy approach does) and instead apply/undo reversals in place on a single mutable sequence, which cuts constant overhead and allows more improvement rounds within the same time budget.

Step-by-step reasoning:
1. Replace `local_search` with a 2-opt routine operating on a single list: reverse `seq[i:j+1]` in place, evaluate with `workload.get_opt_seq_cost`, and if the move does not improve, reverse it back to undo the change — no list copies at all.
2. First-improvement strategy: accept the first improving reversal, restart the scan from that position (don't need a full restart), and keep iterating until no improving move exists.
3. Wrap the 2-opt around the multi-restart greedy: run 30 greedy restarts, 2-opt improve each candidate briefly, keep the global best, then run a deeper 2-opt pass on the global best. Since 2-opt on in-place reversals is cheap, we can afford to improve every restart rather than only the final winner, giving better basins for the final deep polish.
4. Because the schedule is a permutation of transaction indices, any reversal is still a valid permutation, so validity is preserved and makespan evaluation via `get_opt_seq_cost` is unchanged.

This should reduce makespan below the current 343 because adjacent swaps are a strict subset of 2-opt moves; the larger neighborhood escapes local optima the swap-only search gets stuck in, and the in-place apply/undo lets us run many more evaluations within the time budget.

    def local_search(schedule, max_rounds=200):
        # 2-opt local search with in-place apply/undo reversals.
        seq = list(schedule)
        n = len(seq)
        best_cost = workload.get_opt_seq_cost(seq)
        rounds = 0
        improved_any = True
        while improved_any and rounds < max_rounds:
            improved_any = False
            rounds += 1
            i = 0
            while i < n - 1:
                j = i + 1
                while j < n:
                    # apply reversal in place
                    seq[i:j + 1] = reversed(seq[i:j + 1])
                    c = workload.get_opt_seq_cost(seq)

                        best_cost = c
                        improved_any = True

                        # undo reversal in place
