<DESCRIPTION>
The current algorithm runs independent greedy restarts, each polished by local search. Independent restarts waste time: each greedy construction lands in a different region and the local search must re-polish from scratch. A better strategy is Iterated Local Search (ILS): keep the current best solution as the anchor, generate each new candidate by perturbing it (remove a random contiguous segment of transactions and greedily reinsert them at the best positions), then apply the local search to the perturbed candidate. This concentrates the search effort around the best-so-far basin while still providing enough diversification via the random segment removal. Over a fixed time budget, ILS reliably outperforms independent restarts for permutation problems like this one.

Reasoning step by step:
1. Greedy construction from scratch gives quality but with high variance; local search alone gets stuck in local optima.
2. Perturbing the best solution (ruin a random window of 3–8 transactions, recreate greedily) creates a candidate close to the incumbent, so the local search only needs a few improving moves rather than dozens.
3. Accepting only improvements to the incumbent (strict ILS) means search effort accumulates monotonically around the best region found.
4. Keeping the local search with a per-candidate time slice ensures we don't spend the whole budget on one candidate.

    def perturb_best(seq):
        # Ruin-and-recreate: remove a random contiguous segment of
        # transactions from the incumbent and greedily reinsert each
        # at the position that minimizes the true makespan. This keeps
        # the candidate close to the best solution while providing
        # enough diversification for the local search to escape optima.
        n = workload.num_txns
        k = random.randint(3, min(8, n - 1))
        start = random.randint(0, n - k)
        removed = seq[start:start + k]
        cand = seq[:start] + seq[start + k:]
        for t in removed:
            best_c = None
            best_pos = 0
            for pos in range(len(cand) + 1):
                trial = cand[:pos] + [t] + cand[pos:]
                c = workload.get_opt_seq_cost(trial)
                if best_c is None or c < best_c:
                    best_c = c
                    best_pos = pos
                if time.time() >= deadline:
                    best_pos = pos
                    break
            cand = cand[:best_pos] + [t] + cand[best_pos:]
        return cand

    time_budget = 20.0  # seconds per workload
    deadline = time.time() + time_budget
    # Initial construction: greedy + local search.
    best_cost, best_seq = get_full_greedy(0.05)
    best_cost, best_seq = local_search(best_seq, best_cost, deadline)
    # Iterated local search: perturb the incumbent and re-polish,
    # accepting only improvements, under the time budget.
    while time.time() < deadline:
        cand = perturb_best(best_seq)
        cost = workload.get_opt_seq_cost(cand)
        # give each candidate a bounded slice of the remaining budget
        slice_deadline = min(deadline, time.time() + 2.0)

        if cost < best_cost:
            best_cost = cost
            best_seq = cand
    return best_cost, best_seq
