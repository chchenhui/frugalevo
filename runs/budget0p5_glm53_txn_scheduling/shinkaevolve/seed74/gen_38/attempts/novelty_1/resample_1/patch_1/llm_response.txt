<DESCRIPTION>
The second prior program (score 3344) showed that combining greedy construction with simulated annealing over insertion/swap moves substantially outperforms pure greedy+local search. The current program already improved on that with better local search (285 makespan). The recommendation is to add a time-bounded simulated annealing phase after the local search, dominated by single-transaction insertion moves (Gen 14's proven winner), with occasional Or-opt segment reinsertions, cost-scaled temperature, and reheat from best. Key details: (1) use a time deadline (~20s) so we use the full budget rather than a fixed iteration count; (2) accept moves with probability exp(-delta/T) where T is scaled to the current cost (makespans here are hundreds, so T should start at a few percent of cost); (3) reheat from best incumbent on stagnation to keep exploring; (4) strictly avoid reversal moves, which were proven to break validity. This SA phase can escape local optima that swap_pass/or_opt_pass get stuck in.

Step-by-step reasoning:
- Greedy sampling gives diverse good starting points; local search polishes to a local optimum.
- Local optima differ in quality; SA with insertion moves (remove one txn, reinsert elsewhere) explores neighborhoods that Or-opt already covers but with acceptance of worsening moves, allowing escape.
- Cost-scaled temperature (T0 = max(1, 0.05*cost)) is important because deltas here are on the order of units to tens — a fixed T=2.0 may accept too many bad moves late or too few early.
- Reheating from the best solution after stagnation intensifies search around the incumbent, a standard iterated-local-search trick that reliably improves results.

    import time
    import math

    deadline = time.time() + 18.0

    best_cost = None
    best_sched = None
    while time.time() < deadline - 8.0:
        cost, sched = get_greedy_cost_sampled(8, 0.9)
        if best_cost is None or cost < best_cost:
            best_cost = cost
            best_sched = sched
        best_cost, best_sched = local_search(best_sched)

    # simulated annealing over incumbent: insertion-dominated moves,
    # occasional Or-opt segment relocation; reheat from best on stagnation.
    n = workload.num_txns
    cur_cost, cur_seq = best_cost, best_sched[:]
    T = max(1.0, 0.05 * best_cost)
    since_best = 0
    while time.time() < deadline:
        cand = cur_seq[:]
        r = random.random()
        i = random.randint(0, n - 1)
        if r < 0.65:
            # single-transaction insertion (dominant move)
            t = cand.pop(i)
            j = random.randint(0, len(cand))
            cand.insert(j, t)
        elif r < 0.85:
            # adjacent swap
            j = min(i, n - 2)
            cand[j], cand[j + 1] = cand[j + 1], cand[j]
        else:
            # Or-opt segment (1-3 txns) relocation
            seg_len = random.randint(1, 3)
            if n > seg_len:
                i = random.randint(0, n - seg_len)
                seg = cand[i:i + seg_len]
                rest = cand[:i] + cand[i + seg_len:]
                j = random.randint(0, len(rest))
                cand = rest[:j] + seg + rest[j:]
        c = workload.get_opt_seq_cost(cand)
        if c < cur_cost or random.random() < math.exp(-(c - cur_cost) / max(T, 1e-9)):
            cur_seq, cur_cost = cand, c
            if c < best_cost:
                best_cost, best_sched = c, cand[:]
                since_best = 0
            else:
                since_best += 1
        else:
            since_best += 1
        T *= 0.997
        if T < 0.05 or since_best > 500:
            # reheat from best incumbent
            T = max(0.5, 0.02 * best_cost)
            cur_cost, cur_seq = best_cost, best_sched[:]
            since_best = 0

    return best_cost, best_sched
