<DESCRIPTION>
The current SLSQP-only approach scores poorly (0.16) because it starts from random points on the sphere, which are bad starting configurations for this nonconvex problem. The prior hill-climbing program scored 0.74. The best strategy is to combine both: (1) run the fast stochastic hill climber from multiple structured and random seeds to get near a good local optimum, then (2) polish each result with SLSQP solving the exact max-min formulation: maximize t subject to t <= |x_i - x_j|^2 for all pairs (pushing the minimum squared distance up) and |x_i - x_j|^2 <= 1 for all pairs (capping the diameter). This smooth nonlinear program, warm-started near a good configuration, refines the point set precisely. Structured seeds (antipodal pairs, icosahedron-based, cube-lattice-based) provide diverse basins. A final global comparison by the true (dmin/dmax)^2 metric selects the best output.

    from scipy.optimize import minimize

    iu = np.triu_indices(n, 1)

    def score_sq(pts):
        dm = np.linalg.norm(pts[:, None, :] - pts[None, :, :], axis=-1)
        dists = dm[iu]
        dmax = dists.max()
        if dmax <= 0:
            return 0.0
        return (dists.min() / dmax) ** 2

    def ratio_of(pts):
        return float(np.sqrt(score_sq(pts)))
