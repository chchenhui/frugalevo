The current program reaches combined_score ≈ 0.96 using only a stochastic
gradient-style annealing (`_local_search`). The reported metric is
min_max_ratio = (dmin/dmax)^2 ≈ 0.23 (i.e. dmin/dmax ≈ 0.48), close to the
reference ratio 1/4.1658 ≈ 0.24 but still below 1.0 combined score.

The known-best approach from the top prior generation (score 1.00 in 1.60s)
was a two-stage pipeline: (1) smooth log-sum-exp Adam ascent on the ratio
with analytic gradients, then (2) a **constrained SLSQP polish** that
maximizes dmin² subject to hard constraints d²ᵢⱼ ≤ 1. The constrained
formulation is exactly the right geometry: normalizing diameter to 1 and
maximizing the minimum squared distance is the exact optimal-control
form of the problem, and SLSQP with per-pair analytic constraint Jacobians
converges to the boundary of the feasible set far more precisely than
stochastic annealing (which plateaus around 0.48 because jitter keeps
kicking points off the active constraints).

The current program lost that constrained polish stage. I add it back,
applied to the top candidates found by annealing:

1. Keep `_local_search` for global exploration (it produces diverse
   candidate basins), but track the top-3 distinct candidates instead of
   only the single best, since the annealing landscape has many near-tied
   basins and the constrained polish may lift any of them past the best.
2. For each of the top-3 candidates, apply σ=0.05–0.3 symmetry-breaking
   perturbations and run SLSQP maximizing t = dmin² with constraints
   d²ᵢⱼ - t ≥ 0 and 1 - d²ᵢⱼ ≥ 0. Constraints are built in a plain Python
   loop with per-pair closures (the vectorized Jacobian fill from an
   earlier generation crashed on a shape mismatch, so it is deliberately
   avoided here).
3. Accept the SLSQP result if it improves the raw ratio; also fall back to
   the annealing best if SLSQP fails.

4. Trim the annealing budget slightly (the seeds sweep was the dominant
   runtime cost at 5.79s and the SLSQP stage is fast); the final polish
   iteration count is reduced and the polish stage after selection is
   replaced by the SLSQP stage, keeping total runtime well within the
   previous 5.79s while adding the exact constrained refinement that
   pushed the prior best generation to score 1.00.

The SLSQP stage directly attacks the KKT structure of the optimal
configuration: at the optimum, the points realizing the minimum distance
are pushed against the diameter constraints, which is exactly what
constrained optimization handles and stochastic jitter cannot.

        n = points.shape[0]
        iu = np.triu_indices(n, 1)
        diff = points[:, None, :] - points[None, :, :]
        d2 = (diff ** 2).sum(-1)
        u = d2[iu]
        mx = u.max()
        if mx <= 0:
            return 0.0
