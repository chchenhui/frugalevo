Two targeted improvements: (1) per the recommendation, random Gaussian starts cluster and waste optimization trials. Preprocess the 16 random starts with ~150 iterations of projected gradient descent minimizing sum of inverse-square distances (Coulomb-like repulsion), recentering/rescaling each step — this spreads them quasi-uniformly into diverse new basins before annealing, at low cost. (2) Add a final intensive polish stage on the overall best configuration: several rounds of small random jitter followed by the exact-ratio L-BFGS-B, escaping kink stalls of the nonsmooth (dmin/dmax)^2 objective to squeeze out additional score beyond the reference ratio 1/4.1658.</DESCRIPTION>

    # random starts, preprocessed with Coulomb-like repulsion to spread
    # them quasi-uniformly (avoids clustered, wasted trials)
    def repulsion_preprocess(pts, iters=150, lr=0.05):
        for _ in range(iters):
            diff = pts[:, None, :] - pts[None, :, :]
            d2 = np.sum(diff * diff, axis=-1) + 1e-9
            np.fill_diagonal(d2, np.inf)
            inv = 1.0 / d2
            np.fill_diagonal(inv, 0.0)
            # grad of sum 1/|pi-pj|^2 w.r.t. points
            grad = -4.0 * np.einsum('ij,ijk->ik', inv, diff)
            # symmetric: each pair counted once via full matrices (factor ok
            # since both (i,j) and (j,i) appear with opposite diff signs)
            pts = pts + lr * grad / n
            pts = pts - pts.mean(axis=0)
            sc = np.linalg.norm(pts, axis=1).max()
            if sc > 0:
                pts = pts / sc
        return pts

    for _ in range(16):
        starts.append(repulsion_preprocess(rng.standard_normal((n, 3))))
