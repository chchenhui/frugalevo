The annealed soft-min/soft-max refinement is close to the reference optimum (0.24 vs ~0.2406 squared ratio) but the smooth surrogate saturates near the optimum: it can no longer "see" the exact binding constraints. Add a final exact-ratio hill-climb that directly targets the two constraints that define the score — the closest pair (must increase) and the farthest pair (must shrink). Single-coordinate moves get stuck, so we also move both endpoints of the min pair along their separating direction, and pull the max pair together along theirs, at a geometrically shrinking step schedule. Every candidate is evaluated with the exact nonsmooth ratio (dmin/dmax computed from real pairwise distances), so any strict improvement is a genuine gain in the reported metric, independent of the surrogate's temperature bias. This adds only a few milliseconds of work on top of the existing pipeline since each ratio evaluation is O(n²).

    def exact_ratio(p):
        D = dists(p)
        return D.min() / max(D.max(), 1e-12)

    def try_accept(cand):
        nonlocal best_pts, best_r
        if np.isfinite(cand).all():
            rc = exact_ratio(cand)
            if rc > best_r + 1e-12:
                best_r = rc
                best_pts = cand.copy()
                return True
        return False
