<DESCRIPTION>
The annealed soft-min/soft-max L-BFGS approach plateaus near 0.24 because gradient steps treat all pairwise distances nearly uniformly, while the true objective depends only on the min-distance pair and max-distance pair. Add a fast, targeted hill-climb that (a) pushes the closest pair of points directly apart along their separating direction, and (b) pulls the farthest pair inward along theirs, with adaptive step sizes and a shrinking geometric schedule. These moves act exactly on the binding constraints of dmin/dmax, so they can squeeze out extra ratio that coordinate-based optimizers miss. Insert it as Phase 4 before normalization, and trim Phase 2/3 trial counts slightly to offset added runtime (current eval_time 51.88s is high; keep under timeout). The hill-climb is cheap (O(n^2) per iteration, no gradients), and since every accepted move must strictly increase the true ratio, it can only improve the returned configuration.</DESCRIPTION>

    # --- Phase 4: targeted pair-move hill-climb on binding constraints ---
    # Push the closest pair apart and pull the farthest pair together,
    # along their connecting directions, with an adaptive shrinking step.
    def full_ratio(P):
        D = dists(P)
        return D.min() / D.max()

    def pair_moves(P, step):
        """Yield candidate configurations from targeted pair moves."""
        D = dists(P)
        iu2 = np.triu_indices(n, 1)
        idx = np.argmin(D)
        i, j = iu2[0][idx], iu2[1][idx]
        idx = np.argmax(D)
        k, l = iu2[0][idx], iu2[1][idx]
        cands = []
        # closest pair: separate along their connecting direction
        u = P[j] - P[i]
        nu = np.linalg.norm(u)
        if nu > 1e-12:
            u = u / nu
            Q = P.copy(); Q[i] -= step * u; Q[j] += step * u
            cands.append(Q)
        # farthest pair: pull together along their connecting direction
        v = P[l] - P[k]
        nv = np.linalg.norm(v)
        if nv > 1e-12:
            v = v / nv
            Q = P.copy(); Q[k] += step * v; Q[l] -= step * v
            cands.append(Q)
        # combined move
        if nu > 1e-12 and nv > 1e-12:
            Q = P.copy()
            Q[i] -= step * u; Q[j] += step * u
            Q[k] += step * v; Q[l] -= step * v
            cands.append(Q)
        return cands
