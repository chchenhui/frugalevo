perturb_reanneal_restarts</NAME>
<DESCRIPTION>
After the main seed loop and hill-climb, add a perturb-and-reanneal phase around the incumbent best: perturb best_pts by Gaussian noise, then run a full L-BFGS-B annealing chain (soft-min on sphere followed by the free-space soft-min/soft-max objective) on each perturbed start, keeping strict improvements. This is the highest-value compute identified: re-optimizing the incumbent with fresh annealing chains lets the configuration escape shallow local optima that greedy hill-climbing alone cannot, while the annealing schedule smooths the objective enough to find better basins. Each restart is cheap (~0.3s) so 8 restarts fit comfortably in the timeout.

    # runs a full annealing chain (soft-min on sphere, then free-space
    # soft-min/soft-max) from a perturbed copy of the best found so far,
    # which can escape basins that greedy climbing cannot.
    def anneal_chain(pts):
        for T in (0.06, 0.02, 0.01, 0.005, 0.002):
            def loss(x, T=T):
                p = unit(x)
                D = dists(p)
                return T * logsumexp(-D / T)

            res = minimize(loss, pts.ravel(), method="L-BFGS-B",
                           options={"maxiter": 500, "maxfun": 2000})
            pts = unit(res.x)

        def loss2(x):
            p = x.reshape(n, d)
            p = p - p.mean(0)
            D = dists(p)
            lo = 0.002 * logsumexp(-D / 0.002)
            hi = 0.005 * logsumexp(D / 0.005)
            return lo + hi

        res = minimize(loss2, pts.ravel(), method="L-BFGS-B",
                       options={"maxiter": 800, "maxfun": 3000})
        p2 = res.x.reshape(n, d)
        p2 -= p2.mean(0)
        return p2

    for rep in range(8):
        prng = np.random.default_rng(5000 + rep)

        p2 = anneal_chain(start)
        r = ratio(p2)
