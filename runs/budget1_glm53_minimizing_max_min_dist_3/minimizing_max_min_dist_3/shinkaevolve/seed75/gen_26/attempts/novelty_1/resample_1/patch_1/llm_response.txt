<DESCRIPTION>
The current program relies on a single symmetric family (two staggered hexagonal rings + two poles). Its optimum (~0.92 score) is likely a local optimum of that family, and the annealed soft-min/soft-max polish (L-BFGS-B) gets stuck at symmetric saddle points where the gradient vanishes. Two targeted improvements:

1. Add two more symmetric candidate families with grid search: (a) a 12-point ring + 2 poles (icosahedral-like D12 symmetry), and (b) a heptagonal antiprism (7+7 staggered rings, no poles). These are the other natural high-symmetry arrangements for 14 points, and different families can beat the D6 one.

2. Add a greedy hill-climb polish that, following the recommendation, moves pairs of points simultaneously: the pair realizing the current minimum distance is pushed apart along its separating direction (both endpoints displaced half a step each, as well as single-endpoint variants), and the pair realizing the maximum distance is pulled together. Single-coordinate moves are kept as fallback. This directly optimizes the exact ratio (not a soft surrogate) and can escape plateaus where smooth optimizers stall because the objective is only piecewise-smooth (only two distances matter at a time).

All candidates (best from each family grid + NM refinement + jittered restarts) are run through both the existing smooth polish and the new climb; the best result is kept. The climb is cheap (91 pairs, 14 points), so runtime stays well within budget.

def ring_poles_family(n_ring, h, z0, twist=0.0):
    """Single ring of n_ring points at z=h plus two poles at +-z0."""
    th = np.arange(n_ring) * (2 * np.pi / n_ring) + twist
    ring = np.stack([np.cos(th), np.sin(th), np.full(n_ring, h)], axis=1)
    poles = np.array([[0.0, 0.0, z0], [0.0, 0.0, -z0]])
    return np.vstack([ring, poles])


def hept_antiprism_family(R, h):
    """Heptagonal antiprism: two staggered 7-rings at z=+-h."""
    th = np.arange(7) * (2 * np.pi / 7)
    r1 = np.stack([R * np.cos(th), R * np.sin(th), np.full(7, h)], axis=1)
    r2 = np.stack([R * np.cos(th + np.pi / 7), R * np.sin(th + np.pi / 7),
                   np.full(7, -h)], axis=1)
    return np.vstack([r1, r2])


def climb(P, steps=(0.02, 0.006, 0.002, 6e-4, 2e-4, 8e-5, 3e-5)):
    """Exact greedy hill-climb on the true ratio with coordinated pair moves.

    Moves the min-distance pair apart along its separating direction

    P = P / pair_dists(P).max()
