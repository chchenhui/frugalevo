<DESCRIPTION>
Prior generations repeatedly converge "near" the D6-symmetric two-hexagonal-rings-plus-poles basin but the generic force-directed relaxation is too noisy to land exactly on the symmetric optimum. Instead of only adding the D6 rings as force-relaxation seeds, we should exploit the family's low-dimensional parametrization directly: sweep the ring height h and stagger twist finely on a grid, score each configuration exactly with the true objective, and then feed only the top few exact configurations into the free-space SLSQP maximin polish. Because the D6 family has only 2-3 effective parameters (h, twist, and implicitly the unit-sphere radius constraint), a dense grid scan plus polish essentially solves the symmetric subproblem exactly, guaranteeing the pipeline starts and ends inside the best-known basin rather than near it. We add a `_d6_direct_scan` helper that returns the best few (h, twist) configurations polished by SLSQP, and inject them as already-relaxed candidates at the top of the candidate list, so they compete directly with (and typically beat) the relaxed random starts. This costs little time (a few dozen cheap evaluations plus a couple of SLSQP calls) and directly targets the 0.21-0.22 ratio plateau where the best-known structures live.

def _d6_direct_scan(n: int, n_top: int = 3):
    """Exploit the 2-parameter D6 family directly: dense (h, twist) grid,
    exact objective scoring, then SLSQP polish of the top configurations.
    This solves the symmetric subproblem essentially exactly instead of
    relying on noisy force relaxation to find it."""
    results = []
    for h in np.linspace(0.15, 0.65, 26):
        for tw in np.linspace(-0.15, 0.15, 11):
            pts = _d6_rings_seed(float(h), float(tw))
            results.append((_score(pts), float(h), float(tw)))
    results.sort(reverse=True)
    out = []
    for s, h, tw in results[:n_top]:
        pts = _d6_rings_seed(h, tw)
        try:
            pol = _free_space_polish(pts)
            if np.isfinite(pol).all() and _score(pol) >= s:
                pts = pol
        except Exception:
            pass
        out.append(pts)
    return out
