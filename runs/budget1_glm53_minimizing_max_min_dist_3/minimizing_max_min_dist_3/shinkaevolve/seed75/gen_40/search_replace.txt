<DESCRIPTION>
The current pair-move hill-climb only moves the single closest and single farthest pair. Two upgrades inspired by the binding-constraint structure of the optimal Tammes-like configurations: (1) consider several near-minimal and near-maximal pairs (often the optimum has multiple simultaneously-binding constraints — e.g. several edges tied at dmin in the D6/ring family), moving each along its connecting direction; (2) after the hill-climb, re-anneal the result at low temperature with L-BFGS-B (the hill-climb point is generally not a local optimum of the smooth objective, and re-annealing lets all 14 coordinates relax), then hill-climb again — alternate for a few rounds. This closes the gap the coordinate moves cannot reach while keeping runtime bounded. I also slightly reduce Phase 2/3 work to compensate for the added time.

    def pair_moves(P, step):
        """Yield candidate configurations from targeted pair moves over
        all near-binding (near-min and near-max) pairs."""
        D = dists(P)
        iu2 = np.triu_indices(n, 1)
        ii, jj = iu2
        dmin, dmax = D.min(), D.max()
        # all pairs within 5% of the extremes are treated as binding
        near_min = np.where(D <= dmin * 1.05)[0]
        near_max = np.where(D >= dmax * 0.95)[0]
        cands = []
        for idx in near_min:
            i, j = ii[idx], jj[idx]
            u = P[j] - P[i]
            nu = np.linalg.norm(u)
            if nu > 1e-12:
                u = u / nu
                Q = P.copy(); Q[i] -= step * u; Q[j] += step * u
                cands.append(Q)
        for idx in near_max:
            k, l = ii[idx], jj[idx]
            v = P[l] - P[k]
            nv = np.linalg.norm(v)
            if nv > 1e-12:
                v = v / nv
                Q = P.copy(); Q[k] += step * v; Q[l] -= step * v
                cands.append(Q)
        # combined moves: separate a binding min pair AND pull in a
        # binding max pair simultaneously
        for a in range(min(len(near_min), 3)):
            i, j = ii[near_min[a]], jj[near_min[a]]
            u = P[j] - P[i]
            nu = np.linalg.norm(u)
            if nu <= 1e-12:
                continue
            u = u / nu
            for b in range(min(len(near_max), 3)):
                k, l = ii[near_max[b]], jj[near_max[b]]
                v = P[l] - P[k]
                nv = np.linalg.norm(v)
                if nv <= 1e-12:
                    continue
                v = v / nv
                Q = P.copy()
                Q[i] -= step * u; Q[j] += step * u
                Q[k] += step * v; Q[l] -= step * v
                cands.append(Q)
        return cands
