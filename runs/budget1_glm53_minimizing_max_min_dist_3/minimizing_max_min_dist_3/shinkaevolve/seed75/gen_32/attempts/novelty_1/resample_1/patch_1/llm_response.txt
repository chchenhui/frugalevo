<DESCRIPTION>
The recommendation is exactly right: single-coordinate moves cannot fix the ratio because improving it usually requires moving the two closest points apart along their separating direction (both must move) and pulling the two farthest points inward. I add a dedicated `_pair_hillclimb` polisher that, at each step, identifies the pair realizing dmin and pushes both points apart along their connecting direction, and identifies the pair realizing dmax and pulls both inward, trying several step sizes and greedily accepting any move that improves (dmin/dmax)^2. It repeats until no improvement. This is cheap (14 points, O(1) pairs per step) and directly targets the only two distances that matter to the objective. It is inserted after the SLSQP polish and inside the perturbation loop.

def _pair_hillclimb(points: np.ndarray, max_rounds: int = 400,
                    steps=(0.02, 0.01, 0.005, 0.002)) -> np.ndarray:
    """Greedy pair-move polish: push the current closest pair apart and
    pull the current farthest pair inward, trying multiple step sizes
    and accepting only strict improvements in (dmin/dmax)^2. These are
    the only two distances that directly affect the ratio; moving whole
    pairs (not single coordinates) lets coordinated escapes happen."""
    X = np.asarray(points, dtype=float)
    n = len(X)
    best = _score(X)
    IJ = np.triu_indices(n, k=1)
    for _ in range(max_rounds):
        d = np.linalg.norm(X[:, None, :] - X[None, :, :], axis=-1)[IJ]
        imin = int(np.argmin(d))
        imax = int(np.argmax(d))
        a, b = IJ[0][imin], IJ[1][imin]
        c, e_ = IJ[0][imax], IJ[1][imax]
        improved = False
        for s in steps:
            Y = X.copy()
            # push closest pair apart along their separating direction
            u = X[a] - X[b]
            nu = np.linalg.norm(u)
            if nu > 1e-12:
                u = u / nu
                Y[a] += 0.5 * s * u
                Y[b] -= 0.5 * s * u
            # pull farthest pair inward along their direction
            v = X[c] - X[e_]
            nv = np.linalg.norm(v)
            if nv > 1e-12:
                v = v / nv
                Y[c] -= 0.25 * s * v
                Y[e_] += 0.25 * s * v
            sc = _score(Y)
            if sc > best + 1e-12:
                best = sc
                X = Y
                improved = True
                break
        if not improved:
            break
    return X
