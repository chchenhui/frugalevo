<DESCRIPTION>
The best-known constructions for 14 points in 3D with maximal min/max distance ratio (ratio ≈ 0.22, squared ≈ 0.24) come from highly symmetric families — notably two staggered hexagonal rings (30° twist) plus two axial poles (a "D6" antiprism-with-poles family). The current program only uses random and icosahedral seeds, so its repulsion relaxation must discover this structure by luck and typically lands in the 0.21–0.22 basin without fine tuning. Adding an explicit 2-parameter grid search over the D6 family (fixing ring radius as scale), then feeding the best parametric seed through the existing relax() pipeline (and keeping the guarded best comparison), directly plants the optimizer inside the known optimal basin at negligible cost (~0.1 s for the grid). This is a low-risk mutation: the final best is still chosen by exact score comparison, so it cannot degrade the current output.

def d6_family(R, h, z0):
    """Two staggered hexagonal rings (30 deg offset) at z=+-h plus two poles."""
    th = np.arange(6) * (np.pi / 3.0)
    r1 = np.stack([R * np.cos(th), R * np.sin(th), np.full(6, h)], axis=1)
    r2 = np.stack([R * np.cos(th + np.pi / 6), R * np.sin(th + np.pi / 6),
                   np.full(6, -h)], axis=1)
    poles = np.array([[0.0, 0.0, z0], [0.0, 0.0, -z0]])
    return np.vstack([r1, r2, poles])
