<DESCRIPTION>
The current program is confined to the D6-symmetric basin: every candidate passed to `polish` is either the exact D6 parametric optimum or a tiny jitter of it, so the soft-min/soft-max annealing can never discover asymmetric configurations that may beat the D6 family (the reference squared ratio 1/4.1658 corresponds to ratio ≈ 0.49, and the earlier general-seed program reached 0.24 squared ratio vs. 0.22 here). Two targeted changes: (1) add a short force-based repulsion relaxation (each point is pushed away from its nearest neighbor, followed by re-normalization) applied before the L-BFGS-B annealing — this spreads cramped seeds apart so the annealed soft objective starts from a well-conditioned configuration; (2) diversify Stage 4 by adding, besides the jittered D6 restarts, several random-on-sphere seeds and small D6-perturbation seeds with larger magnitude, each pre-conditioned by repulsion and then fully annealed/polished. All candidates still go through the existing hill-climb stages, so quality can only improve. The repulsion is cheap (vectorized, ~100 iterations) so the runtime stays well within timeout.

def repulsion(P0, iters=120, step=0.05):
    """Force-based relaxation: push each point away from its nearest neighbor."""
    P = P0.copy()
    for _ in range(iters):
        P = P - P.mean(axis=0)
        nrm = np.linalg.norm(P, axis=1, keepdims=True)
        P = P / np.maximum(nrm, 1e-12)
        Dm = np.linalg.norm(P[:, None] - P[None, :], axis=-1)
        np.fill_diagonal(Dm, np.inf)
        j = Dm.argmin(axis=1)
        disp = P - P[j]
        lens = np.maximum(np.linalg.norm(disp, axis=1, keepdims=True), 1e-12)
        P = P + step * disp / lens
        step *= 0.97
    P = P - P.mean(axis=0)
    return P / np.maximum(np.linalg.norm(P, axis=1, keepdims=True), 1e-12)
