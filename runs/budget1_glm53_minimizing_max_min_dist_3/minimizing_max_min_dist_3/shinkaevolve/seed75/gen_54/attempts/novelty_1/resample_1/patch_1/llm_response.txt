Following the recommendation, I add a guarded basin-probe stage that runs several trials perturbing only the points involved in near-binding min/max pairs (±0.01–0.02 along random unit directions), each followed by the existing polish + hard climb, keeping the best exact ratio. Because only a handful of points are moved, the configuration stays in the same basin while exploring directions orthogonal to the axial moves; the strict "keep only improvements" guard ensures the incumbent can never degrade. I also reduce the expensive tight-restart loop from 8 to 5 iterations to offset the added runtime and stay well within the timeout.</DESCRIPTION>
