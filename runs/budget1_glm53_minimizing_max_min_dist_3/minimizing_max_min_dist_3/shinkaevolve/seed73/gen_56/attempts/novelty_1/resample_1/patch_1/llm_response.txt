<DESCRIPTION>
The current SLSQP polish maximizes `pdists(f).min()`, a non-smooth objective whose gradient only depends on the single shortest edge; SLSQP frequently stalls or zig-zags on it. Replacing it with a smooth soft-min lower bound (m - log(mean(exp(-alpha*(d-m))))/alpha), with alpha increased over successive passes, gives well-behaved gradients early on while still converging to the true minimum-distance objective. This lets the optimizer pull up nearly-short edges together instead of fighting over one edge at a time, which is exactly what pushes the min/diameter ratio past the reference value. Additionally, more restarts with per-seed independent RNGs (as recommended) widen the basin search without changing serial cost per seed, and structured icosahedron-based inits (known to be near-optimal geometry for 12–14 points) are added alongside the random ones.

    def softmin(f, alpha):
        # Smooth, always <= min(d): approaches the true min as alpha grows.
        ds = pdists(f)
        m = ds.min()
        return m - np.log(np.mean(np.exp(-alpha * (ds - m)))) / alpha
