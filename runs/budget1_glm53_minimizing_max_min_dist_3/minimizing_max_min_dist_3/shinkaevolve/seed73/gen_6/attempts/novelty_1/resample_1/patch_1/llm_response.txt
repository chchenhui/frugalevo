<DESCRIPTION>
The current program optimizes a spherical code (all points on the unit sphere), but the actual objective is dmin/dmax, which is not necessarily maximized by a spherical configuration — the best known 14-point configurations achieve ratio ≈ 0.49, while spherical codes only reach ≈ 0.446. Instead, optimize the ratio directly: at each step compute pairwise distances, rescale the configuration so its diameter (dmax) equals 1, and apply strong short-range repulsion (power-law weights emphasizing the closest pairs, which drives dmin up). Track the configuration with the best actual dmin/dmax ratio. Add multiple random restarts with fixed seeds (plus the icosahedron-based init) to escape bad local optima. Scaling by dmax each iteration keeps the objective equivalent to the true ratio, and evaluating the ratio on the rescaled points is scale-invariant, so we directly maximize the score. This should lift the ratio from ~0.46 toward ~0.49 (score > 0.95).
