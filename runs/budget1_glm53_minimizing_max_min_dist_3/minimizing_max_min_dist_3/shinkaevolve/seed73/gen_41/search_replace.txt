<DESCRIPTION>
The current code relies on a single smoothed L-BFGS-B pass per random seed, and the smooth min/max (softmin/softmax with beta=20) poorly approximates the true ratio near the optimum, leaving score at 0.93 while the reference is 1.0. Two targeted improvements: (1) better structured starting guesses (antipodal cube split, two concentric shells, points on a sphere perturbed inward), since the optimal 14-point 3D configuration is close to a combination of an outer antipodal framework with inner points; (2) add a polishing stage that optimizes the *exact* ratio: iteratively rescale so dmax = 1, then use SLSQP to maximize the true minimum pairwise distance subject to all pairwise distances <= 1 and pairwise distances >= current dmin (a standard "maximize t s.t. dist_ij >= t" Tammes-style formulation, which directly raises dmin/dmax). SLSQP handles the non-smooth min via a single variable t with inequality constraints. Also raise beta in the smoothed objective for a tighter approximation. Validation guards ensure malformed optimizer output never crashes the run. These changes directly target the true metric rather than its smooth surrogate.
