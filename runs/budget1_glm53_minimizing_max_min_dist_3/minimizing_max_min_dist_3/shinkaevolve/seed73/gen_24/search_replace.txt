<DESCRIPTION>
The best-known configurations for 14 points (icosahedron + antipodal poles) are centrally symmetric. After the SLSQP polishing loop, we add a final refinement pass: (1) attempt antipodal symmetrization — pair each point with its best-matching antipodal partner (via a greedy matching on -P), average each point with the negation of its partner to enforce exact central symmetry, (2) run a short, tight SLSQP polish (maxiter 200, ftol 1e-16) from the symmetrized configuration. Since the optimum is believed to be centrally symmetric, projecting onto the symmetric subspace and re-polishing can jump past local minima of the generic optimization and land on the (better) symmetric optimum. We keep the better of the original and symmetrized-polished results, so this can only improve the outcome.</DESCRIPTION>

    def symmetrize(P):
        P = P - P.mean(0)
        m = len(P)
        used = np.zeros(m, dtype=bool)
        pairs = {}
        # greedy antipodal matching: for each point, find closest unused -q
        order = np.arange(m)
        for i in order:
            if used[i]:
                continue
            dvec = np.linalg.norm(P - (-P[i]), axis=1)
            dvec[used] = np.inf
            dvec[i] = np.inf
            j = int(np.argmin(dvec))
            if not np.isfinite(dvec[j]):
                # odd leftover: leave point as is
                pairs[i] = None
                used[i] = True
                continue
            pairs[i] = j
            used[i] = True
            used[j] = True
