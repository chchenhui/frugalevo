<DESCRIPTION>
The previous SLSQP program (max dmin s.t. dmax ≤ 1) reached 0.98, while the current softmin/softmax pipeline only reaches 0.88. The soft-min/max surrogate smooths the objective and stalls away from the true ratio. Key insight: under the constraint dmax ≤ 1, the ratio dmin/dmax equals exactly the minimized dmin, so the constrained problem directly optimizes the true metric. I add a SLSQP stage (maximize min distance subject to max distance ≤ 1) applied to the top-ranked candidates from the cheap ranking pass, plus a final SLSQP polish of the best free-space point (after normalizing so dmax ≈ 1). This combines the good global search of the surrogate pipeline with the exact constrained optimizer that previously scored 0.98.

def _slsqp_packing(P0, n, maxiter=400):
    """Maximize min pairwise distance subject to max pairwise distance <= 1.
    Under this constraint, dmin/dmax equals dmin exactly."""
    if not HAVE_SCIPY:
        return None
    from itertools import combinations
    pairs = list(combinations(range(n), 2))
    ii = np.array([a for a, b in pairs])
    jj = np.array([b for a, b in pairs])

    def pdists(flat):
        P = flat.reshape(n, 3)
        return np.linalg.norm(P[ii] - P[jj], axis=1)

    def obj(flat):
        ds = pdists(flat)
        return -ds.min()

    def cons(flat):
        return 1.0 - pdists(flat).max()

    # scale so initial diameter is 1 (feasible start)
    P = np.asarray(P0, dtype=float).copy()
    P = P - P.mean(axis=0)
    dm = np.linalg.norm(P[:, None, :] - P[None, :, :], axis=-1)
    dm = dm[np.triu_indices(n, 1)].max()
    if dm > 0:
        P = P / dm
    res = minimize(obj, P.ravel(), method='SLSQP',
                   constraints={'type': 'ineq', 'fun': cons},
                   options={'maxiter': maxiter, 'ftol': 1e-14})
    P = res.x.reshape(n, 3)
    d2, _ = _pairwise_sq(P)
    iu = np.triu_indices(n, 1)
    dx2 = d2[iu].max()
    if dx2 <= 0:
        return None
    score = d2[iu].min() / dx2
    return P, score
