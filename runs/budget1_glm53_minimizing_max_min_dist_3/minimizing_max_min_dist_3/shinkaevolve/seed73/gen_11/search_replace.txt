<DESCRIPTION>
The key insight: the quantity to maximize is min pairwise distance subject to max pairwise distance, and since the metric is scale/rotation invariant, we can constrain dmax by projecting all points onto the unit sphere (dmax ≤ 2). Then the problem reduces to the classic spherical packing problem for 14 points, whose optimum squared ratio matches the reference (~0.24).

A plain 1/r repulsion (current code) converges poorly because it spreads effort over all pairs. Instead, use a smooth surrogate for the minimum: minimize LSE_ij(-d_ij / T) = -T·log Σ exp(-d_ij/T) with an annealed temperature T. At low temperature this is essentially the soft-min of distances, so the gradient concentrates on the closest pairs — exactly what we need. Gradient: with weights w_ij ∝ exp(-d_ij/T), the force on point i is Σ_j w_ij·(P_i−P_j)/d_ij. Projecting onto the unit sphere after each step keeps dmax ≤ 2 while directly pushing dmin up. Anneal T from ~0.5 down to ~0.02 so the final steps behave like true min-distance maximization.

This replaces the ad-hoc force heuristic with a principled, well-conditioned objective, should reach the known optimum ratio for 14 points on S² (dmin ≈ 0.977 with dmax = 2), and is fast since n=14 makes each step O(n²).

    def relax(P, steps=1200):
        # Smooth-min (log-sum-exp) surrogate for the minimum pairwise
        # distance with annealed temperature. Minimizing
        #   LSE_ij(-d_ij / T)
        # concentrates the gradient on the closest pairs as T -> 0,
        # which is exactly maximizing the soft-minimum distance.
        P = P / np.linalg.norm(P, axis=1, keepdims=True)
        iu = np.triu_indices(n, 1)
        for t in range(steps):
            frac = t / steps
            T = 0.5 * (0.02 / 0.5) ** frac  # anneal temperature geometrically
            step = 0.05 * (1.0 - frac) + 1e-4
            diff = P[:, None, :] - P[None, :, :]
            dist = np.linalg.norm(diff, axis=-1)
            w = np.zeros((n, n))
            dd = dist[iu]
            # softmax weights over pairs (soft-min of distances)
            e = np.exp(-(dd - dd.min()) / T)
            w[iu] = e
            w = w + w.T  # symmetric pair weights
            # gradient of LSE wrt points pushes close pairs apart
            forces = (w[:, :, None] * diff / np.maximum(dist, 1e-12)[:, :, None]).sum(axis=1)
            P = P + step * forces / n
            # project onto unit sphere: keeps dmax <= 2 (scale invariance)
            P = P / np.linalg.norm(P, axis=1, keepdims=True)
        return P

    best_s, best_P = -1.0, None
    for seed in range(20):
