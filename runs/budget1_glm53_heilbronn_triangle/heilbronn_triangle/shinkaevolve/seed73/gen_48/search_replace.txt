<DESCRIPTION>
The best prior variants score ~0.80 using random + coordinate polish. The key weakness: the greedy coordinate polish moves points along axes only and the random walk spends most moves on points not in any binding triangle. I add a deterministic directed polish that (a) identifies the ~10 smallest triangles each pass, (b) for each binding vertex probes moves along the outward normal directions of the two edges adjacent to that vertex inside the small triangle (moving a vertex away from the opposite edge increases that triangle's area fastest), and (c) uses step-halving on failure. Additionally, keep 20% random kicks (via a fixed RNG) so the sweep retains exploration. This directly targets the binding constraints that define the objective, which coordinate-axis moves miss.

    # Phase 3: deterministic coordinate-wise greedy polish on the best layout,
    # augmented with a directed normal sweep over the smallest triangles.
    comb_idx = np.array(list(itertools.combinations(range(n), 3)))
    p_rng = np.random.default_rng(31337)

    def _directed_sweep(pts, val, passes=25):
        """For the k smallest triangles, move each binding vertex along the
        outward normal of the opposite edge (increases that triangle's area
        with the steepest gradient); step-halve on failure."""
        step = 0.004
        for _ in range(passes):
            improved = False
            areas = _all_areas(pts)
            order = np.argsort(areas)[:10]
            for t in order:
                i0, i1, i2 = comb_idx[t]
                # try moving each vertex away from the opposite edge
                for (vi, a, b) in ((i0, i1, i2), (i1, i0, i2), (i2, i0, i1)):
                    e = pts[b] - pts[a]
                    el = np.hypot(e[0], e[1])
                    if el < 1e-12:
                        continue
                    # unit normal to edge (a,b)
                    nrm = np.array([e[1], -e[0]]) / el
                    # orient away from vertex vi
                    if np.dot(pts[vi] - pts[a], nrm) < 0:
                        nrm = -nrm
                    s = step
                    for _ in range(8):
                        trial = pts.copy()
                        trial[vi] = trial[vi] + s * nrm
                        # 20% exploration: also add a small random kick
                        if p_rng.random() < 0.20:
                            trial[vi] = trial[vi] + p_rng.normal(0, s * 0.3, size=2)
                        trial = _clip_to_triangle(trial)
                        tv = _min_area(trial)
                        if tv > val + 1e-15:
                            pts, val = trial, tv
                            improved = True
                            break
                        s *= 0.5
                        if s < 1e-7:
                            break
            if not improved:
                step *= 0.5
                if step < 1e-7:
                    break
        return pts, val

    best, best_val = _directed_sweep(best.copy(), best_val)

    cur, cur_val = best.copy(), best_val
