two_stage_seed_filter_multistart</NAME>
<DESCRIPTION>
Expand multi-start to ~10 seeds with a two-stage filter: run a cheap 20-iteration soft-min screening per seed, promote only the top 3 to the full pipeline (soft search + hard search + polish). This preserves layout diversity while keeping runtime near the current ~7s. Added seeds: perturbed variants of the winning triangular-lattice layout (σ ∈ {0.01, 0.05, 0.1}) and a second Dirichlet sample — these are known to explore different basins than boundary-heavy seeds. Screening uses _soft_obj which is already cheap and vectorized.
</DESCRIPTION>

def _hex_perturb_seed(pts: np.ndarray, sigma: float, seed: int) -> np.ndarray:
    """Deterministically perturb a layout with Gaussian noise."""
    r = np.random.default_rng(seed)
    return _clip_to_triangle(pts + r.normal(0.0, sigma, size=pts.shape))
