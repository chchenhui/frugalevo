<DESCRIPTION>
Apply the recommendation: in the hard refinement stage, direct search effort at the binding constraint. Instead of only trying axis-aligned ± step moves for every point, add a stochastic phase where with probability ~0.7 the perturbed point is drawn from the current argmin (smallest-area) triplet and otherwise uniform-random. This uses the argmin index already computed by `_min_area` at no extra cost, and focuses the expensive area evaluations on the points that actually limit the objective. Determinism is preserved with a fixed seed.</DESCRIPTION>

def _hard_refine(pts, triples, step, rounds):
    pts = _project_inside(pts.copy())
    best, kmin = _min_area(pts, triples)
    n = len(pts)
    rng = np.random.default_rng(31337)
    for r in range(rounds):
        improved = False
        tri = triples[kmin]
        # move each point of the minimal triangle first (binding constraint)
        order = list(tri) + [i for i in range(n) if i not in tri]
        for i in order:
            for d in range(2):
                for s in (+1, -1):
                    cand = pts.copy()
                    cand[i, d] += s * step
                    cand = _project_inside(cand)
                    val, _ = _min_area(cand, triples)
