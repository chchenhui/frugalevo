<DESCRIPTION>
The current simulated annealing moves a random point with a random perturbation — extremely inefficient since most moves don't affect the minimal triangle. The key insight from Heilbronn optimization: the objective is a max-min problem, and the most effective local search directly targets the vertices of the currently smallest triangle, pushing them away from its centroid (which enlarges that specific triangle) and also testing small boundary/lateral moves. Combined with multiple deterministic restarts from lattice-like seeds and geometric step decay, this converges much closer to the known optimum (~0.0365 normalized). I also vectorize the min-area computation fully and add a final "polish" phase with tiny steps.

    def _min_area_and_triplet(p):
        idx = _TRIPLETS
        q = p[idx]
        a = (q[:, 1, 0] - q[:, 0, 0]) * (q[:, 2, 1] - q[:, 0, 1]) - \
            (q[:, 1, 1] - q[:, 0, 1]) * (q[:, 2, 0] - q[:, 0, 0])
        a = np.abs(a)
        m = a.argmin()
        return a[m] / (2.0 * _TRI_AREA), idx[m]

    def _project(p):
        x, y = p
        y = min(max(y, 0.0), h)
        s3 = np.sqrt(3.0)
        if y > s3 * x:
            x = y / s3
        if y > -s3 * (x - 1.0):
            x = 1.0 - y / s3
        x = min(max(x, 0.0), 1.0)
        return np.array([x, y])
