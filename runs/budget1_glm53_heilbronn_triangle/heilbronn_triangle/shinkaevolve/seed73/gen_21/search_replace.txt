<DESCRIPTION>
Two improvements inspired by the Heilbronn optimization landscape:

1. **Precompute triplet indices at module level.** The current `_min_area` rebuilds the 165-combination index array on *every* call (40k+ times), which dominates the 3.87s runtime. Hoisting it to module level (as Gen 3/6 did) cuts per-iteration cost substantially, letting us afford more optimization within the same time.

2. **Soft-min coarse phase, then hard-min polish.** The hard `min` objective is extremely rugged — a single-point perturbation often leaves the argmin triangle unchanged (flat plateau) or jumps discontinuously, so greedy descent stalls (Gen 2, current program plateau at ~0.66). Gen 3 showed a log-sum-exp soft-min over the smallest ~15% of triangles smooths the landscape and guides points toward balanced configurations. We add a coarse phase minimizing `logsumexp(-k*a)/k` over the smallest triangles with simulated-annealing acceptance, then keep the existing (cheapened) hard-min annealing + fine polish to sharpen the actual minimum.

This combines Gen 3's smoothing with the current program's better schedule and clipping.

def _softmin(pts: np.ndarray, k: float = 60.0) -> float:
    """Smoothed (soft) minimum over the smallest ~15% of doubled areas.
    log( sum_{sel} exp(-k*a) ) / (-k): a smooth lower-bound surrogate
    that gradients the whole near-minimal set of triangles upward."""
    a = _all_areas(pts)
    m = a.min()
    sel = a <= m + 0.05 * _TRI_AREA * 2.0
    return m - np.log(np.exp(-k * (a[sel] - m)).sum()) / k
