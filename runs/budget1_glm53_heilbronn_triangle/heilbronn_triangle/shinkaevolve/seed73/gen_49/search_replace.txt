multi_start_seeded_restarts</NAME>
<DESCRIPTION>
The current program runs a single stochastic trajectory from one heuristic seed. Prior generations showed the gains came from exploring multiple distinct starting layouts (lattice, rings, jittered hex, random) and keeping the global best. I wrap the existing soft + hard + polish pipeline in a multi-start loop over several structurally distinct seeds (with fixed RNG seeds for determinism), and track the global best across restarts. This substantially raises the chance of landing in the basin containing the optimum while reusing all existing machinery. I also reduce per-start iteration counts slightly to keep runtime comparable.</DIFF>

    def _lattice_seed():
        q = []
        rows = [4, 3, 2, 1, 1]
        for r, cnt in enumerate(rows):
            y = h * (r + 0.5) / len(rows)
            xs = np.linspace(0.0, 1.0, cnt + 2)[1:-1]
            halfw = 0.5 * (1.0 - y / h)
            for x in xs:
                q.append((0.5 + (x - 0.5) * (2 * halfw) * 0.98, y))
        return np.array(q)

    def _rings_seed():
        out = [(0.0, 0.0), (1.0, 0.0), (0.5, h),
               (0.5, 0.0), (0.25, h / 2.0), (0.75, h / 2.0)]
        cx, cy = 0.5, h / 3.0
        for s in (0.5, 0.25):
            for (vx, vy) in [(0.0, 0.0), (1.0, 0.0), (0.5, h)]:
                out.append((cx + s * (vx - cx), cy + s * (vy - cy)))
        out.append((cx, cy))
        return np.array(out[:11])

        return np.stack([w1 + 0.5 * w2, h * w2], axis=1)
