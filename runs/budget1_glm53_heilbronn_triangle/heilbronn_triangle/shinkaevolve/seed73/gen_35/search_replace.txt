<DESCRIPTION>
Gen 32's annealing wastes most moves on points that are not part of any binding (smallest) triangle. The minimum-area objective is a max-min problem where only the ~10 smallest triangles matter: improvement comes from moving vertices of those triangles along directions that increase their area (roughly perpendicular to the opposite edge). I add a deterministic `_targeted_polish` phase that, per sweep, computes all areas, sorts to find the k smallest triangles, and for each vertex of each such triangle tries: (a) the outward-normal direction of the opposite edge (exactly the gradient of that triangle's area w.r.t. that vertex), (b) the negative direction, and (c) a small random perturbation — accepting strictly-improving moves on the hard min-area, with step-halving when a full sweep fails. This targets precisely the active constraints and is inserted after the hard phase in `_optimize` and after annealing, replacing part of the wasteful random sweeps. Since the gradient of |area| w.r.t. a vertex is the edge-normal, these moves are first-order optimal, converging far faster than blind coordinate moves. Fixed seed keeps determinism; try/except keeps error handling graceful.

# ---------- targeted polish on k smallest triangles ----------

def _targeted_polish(pts, k=10, step=0.004, max_sweeps=200):
    """Deterministic sweep over the k smallest triangles; try gradient-like
    moves (edge normals) for their vertices, accept strictly-improving."""
    rng = np.random.default_rng(777)
    pts = _project(pts.copy())
    best, _ = _min_area(pts)
    for _ in range(max_sweeps):
        areas = _areas(pts)
        small_idx = np.argsort(areas)[:k]
        improved = False
        for t in small_idx:
            i, j, m = _TRIP[t]
            for vi, vo in ((i, (j, m)), (j, (i, m)), (m, (i, j))):
                # outward normal of the opposite edge = gradient of the
                (unsigned) triangle area w.r.t. this vertex
                e = pts[vo[1]] - pts[vo[0]]
                nrm = np.array([-e[1], e[0]])
                ln = np.hypot(*nrm)
                if ln < 1e-15:
                    continue
                nrm /= ln
                base = pts[vi]
                for dr in (nrm, -nrm):
                    for st in (step, 0.5 * step):
                        cand = pts.copy()
                        cand[vi] = base + dr * st
                        cand = _project(cand)
                        v, _ = _min_area(cand)
                        if v > best + 1e-15:
                            pts, best = cand, v
                            improved = True
                # small random probe around this vertex
                cand = pts.copy()
                cand[vi] = base + rng.normal(0.0, step, size=2)
                cand = _project(cand)
                v, _ = _min_area(cand)
                if v > best + 1e-15:
                    pts, best = cand, v
                    improved = True
            if improved:
                # recompute small set lazily: areas changed
                areas = _areas(pts)
                small_idx = np.argsort(areas)[:k]
        if not improved:
            step *= 0.5
            if step < 1e-7:
                break
    return pts
