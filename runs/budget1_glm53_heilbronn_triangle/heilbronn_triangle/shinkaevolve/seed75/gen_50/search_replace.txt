<DESCRIPTION>
Following the recommendation, I interleave discrete worst-triplet refinement between the Powell annealing stages inside `_softmin_refine`. After each temperature stage, the argmin triplet is identified via a vectorized cross-product scan, and a cheap Powell pass optimizes only that triplet's 9 logits against a small softmin objective. This focuses effort exactly on the binding constraint (the triplet that actually determines the score) while the global softmax keeps all points inside the triangle. Since only 9 variables are perturbed and the objective only evaluates ~few triples plus the runner-up check, each refine costs far less than a global stage but can directly raise the minimum area, breaking the 0.03 plateau. The refined result is accepted only if the true global min area improves, so it can never hurt.
</DESCRIPTION>

        a = 0.5 * np.abs(cross)
