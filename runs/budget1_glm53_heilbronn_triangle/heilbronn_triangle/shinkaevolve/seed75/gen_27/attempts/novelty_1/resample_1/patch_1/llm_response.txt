<DESCRIPTION>
The current version only polishes 3 fixed seeds. Evidence in the prompt suggests independent restarts are the main driver of quality but saturate; the lowest-risk structural additions are (a) many deterministic jittered restarts around the best layouts, and (b) merging/perturbing with a shrinking-step stochastic hill climb (which the earlier successful programs used). I add a stochastic shrinking-perturbation phase (fixed seed) applied after each polish, plus a multi-restart loop generating jittered variants of each base layout. This substantially increases search coverage at modest time cost while keeping determinism and the existing fallback/error handling intact.

def _stochastic_refine(pts, rng, budget=2500, step0=0.03):
    """Shrinking-step stochastic hill climb: random one-point perturbations,
    accepted only if they raise the minimum triangle area."""
    pts = pts.copy()
    best, _ = _min_area(pts)
    step = step0
    it = 0
    n = len(pts)
    while step > 1e-5 and it < budget:
        improved = False
        for i in range(n):
            for _t in range(3):
                it += 1
                if it >= budget:
                    break
                cand = pts.copy()
                cand[i] = pts[i] + rng.normal(0.0, step, size=2)
                cand = _bary_repair(cand)
                if np.min(np.linalg.norm(np.delete(cand, i, axis=0) - cand[i], axis=1)) < 1e-9:
                    continue
                val, _ = _min_area(cand)
                if val > best + 1e-15:
                    pts, best = cand, val
                    improved = True
        if not improved:
            step *= 0.6
    return pts
