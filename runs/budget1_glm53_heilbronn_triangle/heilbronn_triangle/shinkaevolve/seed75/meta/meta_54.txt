# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Optimization Insights: Heilbronn Triangle Problem (n=11)

## Successful Algorithmic Patterns
- **Softmax-parametrized Powell softmin remains the winning paradigm — the current best program (0.82, 24.53s) survives a full second evaluation batch unbeaten.** Feasibility-by-construction via per-row stabilized softmax barycentric weights (`unpack(theta)`), a numerically-stabilized log-sum-exp softmin, temperature annealing 1e-2→1e-4 × area_T with Powell warm-restarts — no variant in Gens 50–53 came close to beating 0.82.
- **Incremental per-point area evaluation is the strongest new validated pattern.** Gen 53 (hybrid_incremental_heilbronn11, 0.78, 7.33s) recomputes only triples containing the moved point, achieving the second-best score of the batch at one-third the best program's runtime — confirming that O(n³) full enumeration inside loops (Gen 50's known bottleneck at ~20s) is wasteful, not necessary.
- **Discrete greedy worst-triangle repair caps below smooth softmin.** Gen 50 (worst_triplet_refine_between_temps, 0.72, 20.36s) and Gen 53 (0.78) both note that greedy repair leaves a near-degenerate triangle (min_area 0.03); Gen 53's feedback explicitly recommends balanced global optimization over worst-triangle repair. Smooth global softmin (0.82) > incremental discrete local search (0.78) > heuristic pipeline (0.72).
- **Mirror-symmetric seeds persist as a top-tier feature** in the best program (barycentric [1,0,2] swaps reflecting across x=0.5) and in Gen 53's warm starts (boundary, lattice, symmetric, edge-heavy seeds), both top scorers of this batch.

## Ineffective Approaches
- **Elaborate time-budgeted hybrid machinery can score 0.00 if it never returns a valid configuration.** Gen 51 (hybrid_powell_triplet_refine, score 0.00) — alternating global Powell softmin with discrete worst-triplet refinement under an 8s budget — failed validation entirely, plausibly a dependency/harness issue or constraint violation despite its `proj_tri` safety projection. Runtime-budgeting code and safety nets do not substitute for a verified return path.
- **Syntax-level patch failures are catastrophic and undetectable by design intent.** Gen 52 (worst_triplet_refinement, score 0.00) died on an `IndentationError` — the `try` block body left unindented. Its active-set soft-min design (bottom-40, annealed, multi-start with mirror seeds — i.e., near-copies of proven 0.80+ patterns) was never evaluated. This is the third consecutive batch where non-algorithmic failure modes (crash, syntax, validation) produce 0.00 scores and waste evaluation slots.
- **Greedy worst-triplet refinement as a polish stage doesn't break the 0.03 plateau.** Gen 50 added triplet refinement between temperature stages to the proven softmin family and still got 0.72 at 20.36s — worse than the simpler full-softmin best (0.82) and slower than Gen 53. Refinement stages attached to a converged basin add runtime without score, consistent with prior Gen 43 findings.

## Implementation Insights
- **The best program's projection-free parametrization remains the safest design.** No barycentric repair, no clipping in the optimization loop; all points valid by construction. Meanwhile both failure cases this batch (Gens 51, 52) had more complex control flow (time budgets, `try` blocks in polish loops) — structural simplicity of the best program is directly tied to its reliability.
- **Incremental triple-list precomputation is now validated in a 0.78-scoring program** (Gen 53), extending the prior Gen 41/42 evidence: precomputed per-point triple lists with K=24 random candidate moves plus perpendicular guided moves deliver near-best scores at 7.33s — the efficiency path if runtime matters.
- **Strictly-positive min-area guards with rescue restarts, as in the best program** (`min_area(best_pts) <= 0.0` triggering rescue before falling back to a hardcoded non-degenerate layout), were absent from Gen 51, which returned invalid configurations with no diagnostic — silent invalidity is the worst failure mode.
- **Both correct programs this batch (Gens 50, 53) plus the best (0.82) all plateau at min_area 0.03**, while the two incorrect programs scored 0.00. Correctness and runtime now vary, but min_area is frozen at 0.03 across ~35 programs — the ceiling is structural, not a matter of optimizer tuning.

- **Batch score tiers (Gens 50–53):** syntax/validation failures (Gens 51, 52: 0.00) → heuristic multi-stage pipeline (Gen 50: 0.72, 20.36s) → incremental discrete local search (Gen 53: 0.78, 7.33s) → **current best softmax-Powell softmin (0.82, 24.53s)**. # META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

# Recommendations for Future Mutations

1. **Add an exact-argmin triplet polish stage after the final annealing stage.** After the 1e-4 × area_T Powell stage converges, unpack points, identify the argmin triplet via the existing vectorized cross-product scan, and run a small Powell pass (maxiter ~100) optimizing only those 3 points' 9 logit coordinates — with the other 24 logits frozen — against the exact `min_area` objective (not softmin). Accept only if global min_area strictly improves. This directly targets the 0.03 plateau: the softmin at 1e-4 × area_T ≈ 4.3e-4 still blends several near-worst triangles, so the optimizer never sharpens onto the single binding constraint.

2. **Swap the 3 mirrored random starts for structured seed families validated in Gen 53 (0.78).** Replace two of the three `rng.normal` mirror starts with (a) an edge-heavy barycentric layout — all 3 vertices plus 8 points with barycentric weight concentrated on edge pairs (e.g., [0.5,0.5,ε]-type rows) — and (b) a triangular-lattice seed derived from the equilateral grid, both converted via the safe `np.log(np.clip(bary, 1e-6, 1.0))` inverse-softmax already in the code. Gen 53's warm starts from boundary/lattice/symmetric/edge-heavy families produced its strong 0.78 basin; importing these into the smooth pipeline costs nothing in runtime and diversifies the basin pool of the current 7-start best.

3. **Use incremental per-point area updates inside a fourth annealing stage to make a deeper temperature ladder affordable.** Precompute per-point triple lists (each of the 11 points appears in C(10,2)=45 of the 165 triples), then implement the softmin objective so a Powell line search along one point's logits recomputes only its 45 triangle areas while caching the other 120. Gen 53 proved this pattern scores 0.78 in 7.33s (3× score/s of the best); applying it to the best program's objective evaluation would let the ladder extend to 1e-5 × area_T (or add a 5th mirror-paired stage) within the same 24.5s budget.

4. **Add a pairwise-collision degeneracy guard on every candidate before acceptance, and raise the rescue threshold from `> 0.0` to `> 0.02`.** In the main loop, before accepting `val > best_val`, compute minimum pairwise Euclidean distance and reject candidates below ~0.02 (near-collisions produce fragile local optima that the min_area check only catches after convergence, per Gen 38's failure mode). When triggered, perturb the colliding point's logits by a fixed ±0.5 offset and re-run only the last temperature stage — cheap recovery instead of a wasted start. All successful programs cluster at min_area 0.02–0.03, so a 0.02 rescue threshold matches the observed success envelope.

5. **Add a symmetry-regularized variant of the softmin objective as one additional start, enforcing exact reflection symmetry across x = 0.5.** Parametrize only 7 "free" points (the 3 vertices are fixed by symmetry to lie on the axis or vertices) and construct their 4 mirrors via the `[1,0,2]` barycentric swap already used in the seed code, reducing the search space from 33 to ~21 free logits. Run the standard 3-stage ladder on this reduced parametrization as one more start in the pool. The best program's mirror-symmetric seeds are its strongest feature and top-tier configurations respect the triangle's reflection symmetry; hard-constraining it (rather than seeding it) is the untested half of that pattern and could escape the asymmetric basins that cap the current 0.82.
