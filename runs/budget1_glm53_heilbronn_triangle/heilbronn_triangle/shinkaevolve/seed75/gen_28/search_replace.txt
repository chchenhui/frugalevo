directed_perp_moves</NAME>

<DESCRIPTION>
Add gradient-informed (directed) perturbation moves to the batched worst-triplet polish loop. For each hot point that belongs to a currently-bad triplet, compute the analytic escape direction: the unit vector perpendicular to the line through the other two vertices of that point's worst triplet, pointing away from the line (which provably increases that triplet's area at first order). These directed candidates are appended to the existing isotropic Gaussian batch, so half the batch exploits free analytic gradient information while the other half keeps exploration diversity. Acceptance is still gated on global min-area improvement via `_min_area_batch`, so feasibility and monotonic progress are preserved. This replaces wasted random attempts with moves that are locally guaranteed to relieve the binding constraint, which should raise the final min-area substantially (currently only 0.46 of benchmark).

    # precompute per-point worst-triplet lookup helpers
    def _worst_triplet_for_point(areas, pi):
        """Index of the worst triplet containing point pi."""
        mask = (TRIPLES[:, 0] == pi) | (TRIPLES[:, 1] == pi) | (TRIPLES[:, 2] == pi)
        tmask = np.where(mask)[0]
        return tmask[np.argmin(areas[tmask])] if len(tmask) else -1

    def _escape_dirs(pts, areas, hot):
        """Analytic escape directions for hot points: move perpendicular to the
        line through the other two vertices of that point's worst triplet,
        away from the line (increases that triplet's area)."""
        dirs = []
        idxs = []
        for pi in hot:
            t = _worst_triplet_for_point(areas, int(pi))
            if t < 0:
                continue
            i, j, k = TRIPLES[t]
            others = [q for q in (i, j, k) if q != pi]
            o1, o2 = pts[others[0]], pts[others[1]]
            d = o2 - o1
            L = np.hypot(*d)
            if L < 1e-12:
                continue
            perp = np.array([-d[1], d[0]]) / L
            rel = pts[pi] - o1
            sgn = np.sign(perp @ rel)
            if sgn == 0:
                sgn = 1.0
            dirs.append(sgn * perp)
            idxs.append(int(pi))
        if not dirs:
            return np.empty(0, dtype=int), np.empty((0, 2))
        return np.array(idxs), np.array(dirs)
