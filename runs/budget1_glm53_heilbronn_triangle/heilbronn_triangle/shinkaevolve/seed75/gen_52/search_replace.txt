<DESCRIPTION>
The recommendation: interleave discrete worst-triplet refinement between annealing stages. After each Powell temperature stage in `run_start`, find the argmin triplet, extract its 3 points' 9 barycentric params, and run a cheap Powell optimization on only those 9 variables with a low-temperature softmin. This adds targeted, triplet-aware local moves at low cost, breaking the 0.03 plateau while keeping the global schedule. Also reduce the per-stage iteration budgets slightly to offset added time, and add a final extra polish loop over the incumbent.

    def worst_triplet_refine(theta, it=25, temp=None):
        """Optimize only the 3 points of the current argmin triplet (9 params)
        against the softmin objective. Cheap, targeted, triple-aware move."""
        if not _HAVE_SCIPY:
            return theta
        theta = np.asarray(theta, dtype=float).ravel().copy()
        for _ in range(2):  # re-identify the worst triplet once after a pass
            pts = unpack(theta)
            a = all_areas(pts)
            t = int(np.argmin(a))
            i, j, k = triples[t]
            loc = np.concatenate([[3 * i, 3 * i + 1, 3 * i + 2],
                                  [3 * j, 3 * j + 1, 3 * j + 2],
                                  [3 * k, 3 * k + 1, 3 * k + 2]])
            lo = theta[loc].copy()

            def obj9(sub, temp_=temp):
                th = theta.copy()
                th[loc] = sub
                return active_softmin(th, temp_)

            try:
                res = _scipy_minimize(
                    obj9, lo, method="Powell",
                    options={"maxiter": it, "xtol": 1e-8, "ftol": 1e-11},
                )
                if np.all(np.isfinite(res.x)):
                    th = theta.copy()
                    th[loc] = res.x
                    # accept only if the true min-area does not degrade
                    if min_area(unpack(th)) >= min_area(unpack(theta)) - 1e-15:
                        theta = th
            except Exception:
                pass
        return theta
