<DESCRIPTION>
Two targeted improvements: (1) The current Jacobian contains a Python loop over all C(11,3)=165 triples, called on every SLSQP iteration — this is the dominant cost and makes the optimizer painfully slow. The gradient can be fully vectorized with `np.add.at`, giving identical results but ~100x faster per call, allowing more starts/iterations within the same time budget. (2) Per the recommendation, add a hybrid global relocation phase after the SLSQP runs: when local refinement stalls, pick the point in the worst triplet and teleport it to a fresh sqrt-transformed barycentric sample, accepting if min_area improves, followed by small Gaussian polish. This escapes local optima where pure gradient descent on a smooth softmin gets stuck.
