<DESCRIPTION>
Key weakness: the current refiner perturbs all 22 coordinates at once, so a random step almost never improves the *global* minimum triangle (which is what the score is). Expert practice for maximin geometry optimization is to (a) identify the point(s) participating in the smallest-area triangles and perturb only those (coordinate descent on the binding constraints), and (b) use a geometric annealing of step sizes with occasional larger restarts. This makes each accepted move directly relax the bottleneck triangle instead of randomly shuffling the whole configuration. I also increase the number of curated seeds (vertices pinned plus a symmetric sublattice, which is a strong inductive bias for Heilbronn-type problems) while keeping everything deterministic. The change is purely in the refine loop and seed list, so the fallback and geometry kernel remain untouched and the program still runs if anything fails.

    def refine(self, b):
        """Maximin hill-climb that targets only the points involved in the
        smallest triangles (the binding constraints), with annealed step sizes."""
        b = self.geom.project(b.copy())
        best = self.score(b)

        def point_scores(bb):
            # min area per point: the worst triangle each point belongs to
            a = self.geom.areas(self.geom.to_xy(bb), self.tri)
            pmin = np.full(self.n, np.inf)
            for t, tri_idx in enumerate(self.tri):
                for pt in tri_idx:
                    if a[t] < pmin[pt]:
                        pmin[pt] = a[t]
            return a, pmin

        schedule = list(self.scales) + [s * 0.25 for s in self.scales]
        stall = 0
        for it in range(self.iters):
            a, pmin = point_scores(b)
            if a.min() >= best:
                best = a.min()
            # focus on the worst few points
            worst = np.argsort(pmin)[:3]
            improved = False
            for scale in schedule:
                cand = b.copy()
                for pt in worst:
                    cand[pt] += self.rng.normal(0.0, scale, 2)
                cand = self.geom.project(cand)
                val = self.score(cand)
                if val > best + 1e-13:
                    b, best = cand, val
                    improved = True
                    break
            if improved:
                stall = 0
            else:
                stall += 1
                if stall > 60:
                    # re-anneal with a bigger jump to escape flat regions
                    cand = self.geom.project(b + self.rng.normal(0.0, 0.05, b.shape))
                    val = self.score(cand)
                    if val > best:
                        b, best = cand, val
                    stall = 0
        return b, best
