<DESCRIPTION>
The tightest bottleneck in Heilbronn-11 configurations is typically a small cluster of 3-4 points whose triangles bind simultaneously. Single-point moves cannot escape these "pair-traps" because moving either point alone decreases the min area even though moving both together increases it. I replace the random-jitter final polish in `_refine` with a structured greedy polish that (a) identifies the top-2 bottleneck triangles, (b) tries moving their involved points individually AND simultaneously along 12 fixed directions (plus opposites), and (c) continues scanning remaining directions at the same step size after an improvement before shrinking. This gives the optimizer a mechanism to escape coordinated constraints, which should raise the achievable min area. Since only bottleneck-involved points are moved (not all 11 × 12 directions), per-iteration cost stays modest, and the random 200-sample loop (which wastes evaluations on irrelevant points) is removed, recovering runtime.
</DESCRIPTION>

def _polish(best, best_v):
    """Greedy structured polish: move the points involved in the top-2
    bottleneck triangles, individually AND simultaneously in pairs, along 12
    fixed directions (with opposites). Pair moves escape coordinated
    constraints that single-point moves cannot."""
    n_dirs = 12
    ang = 2.0 * np.pi * np.arange(n_dirs) / n_dirs
    dirs = np.stack([np.cos(ang), np.sin(ang)], axis=1)
    # full direction set includes opposites for backward moves
    full_dirs = np.concatenate([dirs, -dirs], axis=0)

    def bottlenecks(pts, m):
        a = pts[_TRIP[:, 0]]
        b = pts[_TRIP[:, 1]]
        c = pts[_TRIP[:, 2]]
        cross = np.abs((b[:, 0] - a[:, 0]) * (c[:, 1] - a[:, 1])
                       - (b[:, 1] - a[:, 1]) * (c[:, 0] - a[:, 0]))
        order = np.argsort(cross)[:m]
        idxs = set()
        for t in order:
            idxs.update(int(x) for x in _TRIP[t])
        return sorted(idxs)

    step = 0.002
    while step > 1e-5:
        improved = False
        # candidate points: those in the top-2 (usually 3-4) bottleneck triangles
        cand_idx = bottlenecks(best, 2)
        ni = len(cand_idx)
        for ai in range(ni):
            i = cand_idx[ai]
            for d in full_dirs:
                cand = best.copy()
                cand[i] += step * d
                cand = _clip(cand)
                v = _min_area(cand)
                if v > best_v + 1e-12:
                    best_v, best, improved = v, cand, True
            # simultaneous pair moves (same direction) with the other candidates
            for bi in range(ai + 1, ni):
                j = cand_idx[bi]
                for d in full_dirs:
                    cand = best.copy()
                    cand[i] += step * d
                    cand[j] += step * d
                    cand = _clip(cand)
                    v = _min_area(cand)
                    if v > best_v + 1e-12:
                        best_v, best, improved = v, cand, True
                # opposite-direction pair move (separating move)
                for d in dirs:
                    cand = best.copy()
                    cand[i] += step * d
                    cand[j] -= step * d
                    cand = _clip(cand)
                    v = _min_area(cand)
                    if v > best_v + 1e-12:
                        best_v, best, improved = v, cand, True
        if not improved:
            step *= 0.5
        # re-accept: on improvement keep same step and re-identify bottlenecks
    return best, best_v
