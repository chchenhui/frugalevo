<DESCRIPTION>
Two targeted improvements. (1) Quality: after the directional polish, add a bottleneck "boost" phase that repeatedly finds the single minimum-area triangle and performs an exact analytic 1-D line search along the gradient of its signed area for each of its three vertices (with barycentric projection and halving backtracking). This directly attacks the active constraint — the smallest triangle — and is the classic bottleneck-coordinates heuristic from Heilbronn-style max-min optimization; it escapes local optima where directional polish stalls because it uses the exact gradient direction rather than 24 fixed directions. (2) Efficiency + robustness: trim the seed pool (drop two repulsion seeds and both large-jitter seeds) to cut eval time, and wrap the boost phase plus a final self-check in per-phase try/except blocks that fall back to the previous phase's result rather than the global degenerate fallback, per the known Gen-50 silent-0.00 failure mode. A final assertion recomputes min_area on the returned coordinates to guarantee best_val matches the actual output.

def _boost(pts, rounds=300):
    """Bottleneck boost: repeatedly take the single minimum-area triangle
    and line-search each of its three vertices along the exact gradient of
    its signed area (projected into the triangle). Escapes optima where
    the fixed-direction polish stalls."""
    best = _clip(pts)
    cross = _cross_all(best)
    best_val = _min_from_cross(cross)
    for _ in range(rounds):
        t = int(np.argmin(cross))
        i, j, k = int(_I[t]), int(_J[t]), int(_K[t])
        p, q, r = best[i], best[j], best[k]
        sgn = np.sign((q[0] - p[0]) * (r[1] - p[1]) - (q[1] - p[1]) * (r[0] - p[0]))
        if sgn == 0.0:
            break
        grads = {
            i: sgn * np.array([q[1] - r[1], r[0] - q[0]]),
            j: sgn * np.array([r[1] - p[1], p[0] - r[0]]),
            k: sgn * np.array([p[1] - q[1], q[0] - p[0]]),
        }
        moved = False
        for pt in (i, j, k):
            d = grads[pt]
            nd = float(np.linalg.norm(d))
            if nd < 1e-15:
                continue
            d = d / nd
            step = 0.02
            while step > 1e-6:
                cand = best.copy()
                cand[pt] += step * d
                cand = _clip(cand)
                v = _min_area(cand)
                if v > best_val + 1e-15:
                    best, best_val = cand, v
                    cross = _cross_all(cand)
                    moved = True
                    break
                step *= 0.5
            if moved:
                break
        if not moved:
            break
    return best, best_val
