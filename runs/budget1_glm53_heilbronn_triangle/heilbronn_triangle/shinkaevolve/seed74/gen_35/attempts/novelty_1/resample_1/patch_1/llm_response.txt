<DESCRIPTION>
The prior evidence (Gen 17/22) shows that all current seeds are perturbed copies of the same symmetric order-3 triangular lattice, so the annealing multistart gets trapped in the same symmetry-biased basin — every seed produces essentially the same local optimum. I add two fundamentally different seed families:

1. A **golden-ratio low-discrepancy seed**: barycentric coordinates built from fractional parts of (k·φ, k·φ²), giving a highly uniform, asymmetric initial layout with no lattice collinearity to fight against.

2. A **repulsion seed**: ~60 vectorized inverse-square repulsion iterations from a jittered layout, projected back with `_clip` after each step. This spreads points toward a well-separated configuration, which is exactly what large minimum triangle areas require (near-uniform point spacing).

Since these new seeds start from different basins, they give the annealer a real chance to find a better optimum rather than re-confirming the lattice basin. To keep total runtime in budget (the current version already takes 15s, which is costly for eval_time), I slightly reduce the number of lattice seeds (8 → 4) since they are highly redundant with each other, freeing time for the two new asymmetric seeds. All methods remain fully deterministic (fixed seeds, vectorized numpy), and the fallback behavior is unchanged.

            l = k - i - j

    pts = np.array(pts)
    return _clip(pts + rng.normal(0.0, 0.02, pts.shape))


def _initial_golden():
    """Golden-ratio low-discrepancy seed in barycentric coordinates.
    Deterministic, asymmetric, no lattice collinearity."""
    phi = (1.0 + np.sqrt(5.0)) / 2.0
    k = np.arange(11) + 1
    u = np.mod(k * phi, 1.0)
    v = np.mod(k * phi * phi, 1.0)
    l1 = u
    l2 = v * (1.0 - u)
    l0 = 1.0 - l1 - l2
    # ensure nonnegativity via clipping + renormalization
    lam = np.stack([l0, l1, l2], axis=1)
    lam = np.maximum(lam, 0.0)
    lam /= lam.sum(axis=1, keepdims=True)
    pts = lam[:, 0:1] * _V0 + lam[:, 1:2] * _V1 + lam[:, 2:3] * _V2
    return _clip(pts)


def _initial_repulsion(seed, iters=60):
    """Repulsion seed: vectorized inverse-square repulsion from a jittered
    layout, projected back into the triangle each step."""
    rng = np.random.default_rng(seed)
    pts = _initial(seed) + rng.normal(0.0, 0.06, (11, 2))
    step0 = 0.002
    for t in range(iters):
        d = pts[:, None, :] - pts[None, :, :]
        dist2 = np.sum(d * d, axis=2) + 1e-6
        np.fill_diagonal(dist2, np.inf)
        f = d / (dist2[:, :, None] ** 1.5)
        pts = _clip(pts + step0 * f.sum(axis=1))
    return _clip(pts)
