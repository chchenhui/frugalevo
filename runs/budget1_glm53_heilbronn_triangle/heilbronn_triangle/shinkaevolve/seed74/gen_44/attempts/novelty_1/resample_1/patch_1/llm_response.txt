<DESCRIPTION>
The bottleneck in this configuration is typically a tight cluster of 3-4 points whose small triangles bind simultaneously; single-point moves cannot always relieve such pair-traps because moving either point alone decreases some other triangle. We add a pair-move search: identify the two points involved in the smallest-area triangles and try moving them together along shared directions (same direction and opposite directions), each candidate fully projected and evaluated. This is placed in a `_polish` routine called after annealing, plus targeted single-point moves around the bottleneck point. Also cache the best solution across calls and keep the annealing schedule but with slightly more iterations at low temperature. The polish loop repeatedly finds the bottleneck triangle, tries 12 single-point directions for each of its 3 vertices plus 24 pair moves (same/opposite directions for the two extremal vertices of the bottleneck triangle), accepts any improving move, and iterates until no improvement. This directly addresses the correlated-pair trap that plain annealing fails to escape at low temperature.

    def _polish(pts, rng):
        """Targeted local search with single-point and correlated pair moves."""
        dirs = np.array([[np.cos(a), np.sin(a)]
                         for a in np.linspace(0, 2 * np.pi, 12, endpoint=False)])
        steps = [0.05, 0.02, 0.008, 0.003, 0.001]
        cur = pts.copy()
        cur_val = _min_triangle_area(cur)
        improved = True
        while improved:
            improved = False
            # find bottleneck triangle vertices
            bot, bval = None, cur_val
            n_ = len(cur)
            for i in range(n_ - 2):
                for j in range(i + 1, n_ - 1):
                    ax, ay = cur[i]
                    bx, by = cur[j]
                    dxc = cur[j + 1:, 0] - ax
                    dyc = cur[j + 1:, 1] - ay
                    areas = 0.5 * np.abs((bx - ax) * dyc - (by - ay) * dxc)
                    k = int(np.argmin(areas))
                    if areas[k] < bval:
                        bval = areas[k]
                        bot = (i, j, j + 1 + k)
            if bot is None:
                break
            i0, j0, k0 = bot
            # single-point moves for each bottleneck vertex
            cands = [(p, d * s, None) for p in (i0, j0, k0)
                     for d in dirs for s in steps]
            # pair moves: same and opposite directions for bottleneck pairs
            pairs = [(i0, j0), (i0, k0), (j0, k0)]
            for (p, q) in pairs:
                for d in dirs:
                    for s in steps:
                        cands.append((p, d * s, (q, d * s)))       # same dir
                        cands.append((p, d * s, (q, -d * s)))      # opposite dir
            for p, dvec, pm in cands:
                if p < 3:
                    continue
                cand = cur.copy()
                cand[p] += dvec
                if pm is not None:
                    q, d2 = pm
                    if q >= 3:
                        cand[q] += d2
                cand = _project_into_triangle(cand)
                v = _min_triangle_area(cand)
                if v > cur_val + 1e-15:
                    cur, cur_val = cand, v
                    improved = True
                    break
        return cur, cur_val
