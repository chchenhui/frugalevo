rank_quantile_reweighting

<DESCRIPTION>
The generated item weights follow an exponential distribution. The existing pivot-gap reconstruction attempts to infer numerical differences from `1 vs 2` comparisons, but these estimates are noisy and can become distorted by sparse/random pivot spacing.

After all item-to-pivot binary searches, the program knows a much more reliable signal: the ordinal interval of every item among the sorted pivots. This edit records those intervals and recalibrates estimated weights from their implied ranks using the exponential quantile function `-log(1-p)`. It retains the existing estimator for very small pivot counts, while for at least four pivots it uses the distribution information explicitly supplied by the input generator. Items in the same unresolved interval receive the interval's expected rank, which is preferable to arbitrary geometric interpolation for exponential data.
</DESCRIPTION>
