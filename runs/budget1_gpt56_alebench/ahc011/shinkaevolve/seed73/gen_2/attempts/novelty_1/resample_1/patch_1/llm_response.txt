<DESCRIPTION>
The incumbent update reconstructs a complete beam-history path even when the score is tied. This is extremely expensive: for incomplete trees, the actual score depends only on S, so many candidates tie, while reconstructing each candidate is O(depth). Moreover, a tied incomplete score receives no benefit from a shorter move sequence; only a strictly better S can improve the official score. For a complete tree, the score already strictly improves when K decreases.

Therefore, retain the incumbent only on a strictly better actual score. This avoids a large amount of repeated history traversal and string allocation, allowing the beam search to evaluate substantially more states within the time limit.
</DESCRIPTION>
