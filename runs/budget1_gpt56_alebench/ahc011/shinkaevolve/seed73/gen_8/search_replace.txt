<DESCRIPTION>
Remove unnecessary path reconstruction on equal-score candidates and replace per-candidate DSU heap allocations with fixed-size arrays. Equal-score candidates generated in the same beam layer always have the same move count, so reconstructing both complete paths cannot improve the tie-break result. This avoids substantial repeated string work. The fixed-size DSU eliminates several vector allocations and initializations for every uncached board evaluation, allowing more beam expansion within the time limit.
</DESCRIPTION>
