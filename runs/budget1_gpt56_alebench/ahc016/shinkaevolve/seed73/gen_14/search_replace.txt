<DESCRIPTION>
Replace the heuristic separation-based edge-count graph-size formula with direct maximization of an expected-score approximation. The objective explicitly balances the probability of crossing an adjacent edge-count decision boundary against the scoring penalty of using a larger N. This approach was previously stronger than the current K_SEP-based sizing rule, and it is consistent with the actual decoder, which classifies using total edge count.

For each candidate N, the approximation models the noisy edge count with variance L*epsilon*(1-epsilon), estimates nearest-boundary error using a Gaussian tail, converts this to the expected multiplicative 0.9^E effect over 100 queries, and includes the 1/N score factor.
</DESCRIPTION>

    double L_ideal = 0.0;
    int N_candidate_EC = 4;
    if (epsilon_noise_rate > 1e-12 && M_graphs > 1) {
        double best_log_expected_score = -1e100;
        for (int candidate_n = 4; candidate_n <= 100; ++candidate_n) {
            const double candidate_l = 0.5 * candidate_n * (candidate_n - 1);
            const double spacing = candidate_l / (M_graphs - 1.0);
            const double sigma = std::sqrt(
                candidate_l * epsilon_noise_rate * (1.0 - epsilon_noise_rate));
            const double z = (1.0 - 2.0 * epsilon_noise_rate) * spacing /
                             (2.0 * sigma);
            const double one_side_error =
                0.5 * std::erfc(z / std::sqrt(2.0));

                1.0, 2.0 * (M_graphs - 1.0) / M_graphs * one_side_error);

            // E[0.9^E] for 100 independent queries is

                best_log_expected_score = log_expected_score;
                N_candidate_EC = candidate_n;

        }
