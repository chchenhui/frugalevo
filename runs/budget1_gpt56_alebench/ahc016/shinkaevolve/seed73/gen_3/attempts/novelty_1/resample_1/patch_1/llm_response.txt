<DESCRIPTION>
Replace the fixed separation constant used to choose the edge-count strategy's graph size with a direct score-oriented search over all valid vertex counts.

For edge-count decoding, the noisy edge total has mean spacing approximately
`L * (1 - 2*epsilon) / (M-1)` between neighboring messages and standard deviation
`sqrt(L * epsilon * (1-epsilon))`.  The previous fixed `K_SEP=2.5` targets a relatively small adjacent-code separation, which tends to create many errors across 100 queries; because the score exponentially penalizes errors, using a somewhat larger graph is often worthwhile despite the `/N` factor.

The replacement estimates nearest-neighbor Gaussian classification error for each possible `N=4..100`, converts it into the expected `0.9^E/N` score proxy, and selects the best size. It also preserves the GED choice whenever this estimated edge-count size is no larger than the small exact-isomorphism graph size.
</DESCRIPTION>

    // After noise, the edge count has variance L*eps*(1-eps), independent of
    // the original number of edges.  For evenly spaced codewords, an interior
    // codeword crosses either neighboring decision boundary with probability
    // Q(spacing/(2*sigma)).
    double L_ideal = 0.0;
    int N_candidate_EC = 4;
    if (epsilon_noise_rate > 0.0 && epsilon_noise_rate < 0.5 && M_graphs > 1) {
        double best_log_score = -1e100;
        for (int candidate_n = 4; candidate_n <= 100; ++candidate_n) {
            const int candidate_l = candidate_n * (candidate_n - 1) / 2;
            if (candidate_l < M_graphs - 1) continue; // require distinct edge totals

            const double spacing =
                (double)candidate_l * (1.0 - 2.0 * epsilon_noise_rate) / (M_graphs - 1);
            const double sigma =
                std::sqrt((double)candidate_l * epsilon_noise_rate * (1.0 - epsilon_noise_rate));
            const double boundary_z = spacing / (2.0 * sigma);
            const double one_side_error = 0.5 * std::erfc(boundary_z / std::sqrt(2.0));

            // Endpoints have one neighboring boundary; all other messages have two.
            const double per_query_error =
                2.0 * (M_graphs - 1.0) / M_graphs * one_side_error;

            const double log_score =
                expected_errors * std::log(0.9) - std::log((double)candidate_n);

                best_log_score = log_score;
                N_candidate_EC = candidate_n;
            }
        }
