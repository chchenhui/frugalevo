The large-N branch currently encodes only through total edge count, despite spending many vertices on each codeword. Replace random graphs with nested dense-core (colex) graphs, whose sorted degree sequences provide an additional permutation-invariant signature. Decode using the edge-count likelihood plus a conservatively weighted degree-spectrum residual. The degree term is centered so it captures shape rather than merely counting every edge twice, and it is normalized by the noise-induced per-vertex degree variance.

This retains the robust edge-count channel while extracting useful information from the graph structure after vertex shuffling. Dense-core graphs make these degree signatures much more separated than the current uniformly random graphs.

// A colex initial segment consists of a clique plus one partially connected
// vertex.  Compared with a random graph of the same density, its degree
// spectrum is a strong label-invariant feature after vertices are shuffled.
std::string generate_dense_core_graph_string(int num_edges, int N_nodes) {
    const int current_L = N_nodes * (N_nodes - 1) / 2;
    std::string s_out(current_L, '0');
    int remaining = std::max(0, std::min(current_L, num_edges));
    for (int hi = 1; hi < N_nodes && remaining > 0; ++hi) {
        int take = std::min(hi, remaining);
        for (int lo = 0; lo < take; ++lo) {
            int a = lo, b = hi;
            if (a > b) std::swap(a, b);
            int pos = 0;
            for (int r = 0; r < a; ++r) pos += N_nodes - r - 1;
            pos += b - a - 1;
            s_out[pos] = '1';
        }
        remaining -= take;
    }
    return s_out;
}

std::vector<int> sorted_degrees_from_string(const std::string& s, int N_nodes) {
    std::vector<int> deg(N_nodes, 0);
    int pos = 0;
    for (int i = 0; i < N_nodes; ++i) {
        for (int j = i + 1; j < N_nodes; ++j, ++pos) {
            if (s[pos] == '1') {
                ++deg[i];
                ++deg[j];
            }
        }
    }
    std::sort(deg.begin(), deg.end());
    return deg;
}
