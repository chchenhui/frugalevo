<DESCRIPTION>
The edge-count code selection currently optimizes `100 * p * log(0.9)`, which treats the number of failures as deterministically equal to its expectation. However, the actual independent-query expectation is:

`E[0.9^E] = (1 - 0.1*p)^100`

where `p` is the per-query error probability. Since the score is exponentially sensitive to errors, using the exact binomial expectation chooses a more appropriate tradeoff between graph size and decoding reliability. The normal approximation for `p` and the code construction remain unchanged; only the objective used to select N is corrected.
</DESCRIPTION>
