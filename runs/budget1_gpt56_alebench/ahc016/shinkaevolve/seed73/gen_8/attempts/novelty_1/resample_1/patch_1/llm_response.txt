<DESCRIPTION>
Augment the large-N edge-count code with sorted degree profiles. Vertex shuffling preserves the degree multiset, and independently generated graphs with the same or nearby edge counts have distinguishable degree shapes. During decoding, compare the received sorted degree profile against the noise-attenuated template profile in addition to the statistically expected total edge count. This retains the robust density channel while exploiting graph information currently discarded by the edge-count-only decoder.
</DESCRIPTION>

std::vector<int> sorted_degrees_from_string(const std::string& s, int N_nodes) {
    std::vector<int> degrees(N_nodes, 0);
    int pos = 0;
    for (int i = 0; i < N_nodes; ++i) {
        for (int j = i + 1; j < N_nodes; ++j, ++pos) {
            if (s[pos] == '1') {
                ++degrees[i];
                ++degrees[j];
            }
        }
    }
    std::sort(degrees.begin(), degrees.end());
    return degrees;
}
