<DESCRIPTION>
The current static-guide snap chooses uniformly from every fish coordinate on the whole board. Most such moves relocate an edge or a bulge by tens of thousands of units, which tends to create self-intersections, excessively disruptive score changes, or proposals that cannot refine the current promising region.

Add a guide sampler that usually chooses a coordinate near the current edge coordinate in sorted guide order. Its radius shrinks during annealing, allowing broad exploration early while making fish-aligned local refinements late. A limited global-sampling probability is retained early so the search can still escape an initially poor rectangle or discover distant clusters.
</DESCRIPTION>

// Fish-coordinate guides are dense enough that selecting uniformly from all of
// them normally produces an unnecessarily huge move.  Sample near the current
// coordinate for local fish-aware optimization, while retaining some global
// jumps in the exploratory part of annealing.
int choose_static_guide(const std::vector<int>& guides, int current_coord, double time_ratio) {
    if (guides.empty()) return current_coord;

    double global_probability = 0.08 + 0.27 * (1.0 - time_ratio);
    if (rng.next_double() < global_probability) {
        return guides[rng.next_int((int)guides.size())];
    }

    int center = (int)(std::lower_bound(guides.begin(), guides.end(), current_coord) - guides.begin());
    int rank_radius = std::max(25, (int)(900.0 * (1.0 - time_ratio) + 25.0));
    int lo = std::max(0, center - rank_radius);
    int hi = std::min((int)guides.size() - 1, center + rank_radius);
    return guides[rng.next_int(lo, hi)];
}
