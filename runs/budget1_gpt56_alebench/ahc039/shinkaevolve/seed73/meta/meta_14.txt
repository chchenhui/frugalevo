# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- **The current best configuration combines strong global initialization with flexible local refinement.** The top result, **Generation 8 (`fix_bulge_boundary_delta`) at 3734.38**, starts from a **350×350 coarse-grid 2D Kadane rectangle** and then refines it using simulated annealing over orthogonal polygons. This substantially outperformed the grid-only polygon methods: **Coarse Grid Banded Polygon Search** scored **1989.70**, and **Grid-Based Connected Polygon Search** scored **1948.62**. The evidence strongly favors Kadane initialization followed by unrestricted-but-validated polygon editing over committing to a coarse raster representation.

- **Exact closed-boundary delta accounting is a key successful detail in the best program.** The current best preserves inclusive fish-on-boundary semantics by querying only the changing strip. For example, a vertical edge moving right queries `old_x + 1..new_x`, while a left move queries `new_x..old_x - 1`; bulges use the same asymmetric treatment. Fish on the unchanged old edge are therefore neither removed nor double-counted. This boundary-correct implementation is consistent with the top score of **3734.38**, exceeding related successful KD-tree annealing variants such as **Generation 13 at 3711.54** and **Generation 12 at 3694.86**.

- **Broad fish-coordinate guides plus dynamic best-polygon guides support productive exploration.** The best program creates static guides from every fish coordinate and its neighboring coordinates (`x-1`, `x`, `x+1`, similarly for `y`), then increasingly samples coordinate values from the best polygon found so far. Dynamic-guide probability rises from **20% to 40%** during the search, while static guides remain dominant otherwise. This preserved broad search coverage while exploiting promising boundary alignments, and it was stronger than the prior local-guide experiments: **Generation 4 scored 3612.92** and **Generation 5 scored 3654.76**, both below the current best.

- **The move set balances shape expressiveness and feasibility.** The best program mixes edge translation, two-vertex rectangular bulge insertion, and collinear-vertex removal. It also reduces bulge probability as vertex count or perimeter becomes large. This allows the search to capture separated positive fish clusters or exclude localized negatives without uncontrolled complexity, while retaining the same reliable legality profile seen in the KD-tree annealing family: all reported variants, including the current best, passed **50/50** cases.

## Ineffective Approaches

- **Purely coarse/rasterized construction was much weaker than continuous-coordinate annealing.** The two correct grid-oriented methods scored roughly half of the current best: **Coarse Grid Banded Polygon Search: 1989.70** and **Grid-Based Connected Polygon Search: 1948.62**, versus **3734.38**. Their validity handling was reliable, but the coarse cell or band representation limited boundary placement precision and constrained the ability to selectively include positive fish while excluding nearby negative fish.

- **The simpler simulated-annealing configuration underperformed sharply despite using the same broad paradigm.** **Generation 7, “Simulated Annealing Orthogonal Polygon Search,” scored 2188.18**, which is **1546.20 below** the current best. It was fully accepted, so its weakness was optimization quality rather than geometry correctness. Relative to the best implementation, its less developed initialization/search configuration—described as using a **250×250** coarse grid and weaker move/search mechanics—correlates with much poorer final polygons.

- **Replacing broad coordinate guidance with more local sampling did not improve search quality.** The local-guide variants, **Generation 4 at 3612.92** and **Generation 5 at 3654.76**, were valid but trailed the current best by **121.46** and **79.62**, respectively. The measured results indicate that narrowing coordinate proposals reduced exploration more than it improved local targeting. The current best’s static fish-adjacent coordinates plus best-polygon coordinate guides produced better aggregate performance.

- **Boundary-delta fixes alone were not sufficient to guarantee a score improvement.** Earlier boundary-focused variants, **Generations 1–3**, scored **3686.34**, **3682.00**, and **3685.90**, all slightly below the earlier **Generation 0 baseline at 3700.20**. Since all were accepted, the lower scores reflect search-dynamics interactions rather than invalid scoring or output. The later best result shows that exact boundary accounting is most effective when combined with stronger guide scheduling, move adaptation, and annealing behavior.

## Implementation Insights

- **The current best’s incremental scoring matches the actual containment rule.** `is_inside_polygon_wn` explicitly counts fish on polygon edges as inside. The edge-shift and bulge score updates correctly reflect this by excluding the old boundary line from the changed region and including the new one. For example, a vertical expansion uses `[old_x + 1, new_x]`; a contraction uses `[new_x, old_x - 1]`. This alignment is especially important because incorrect handling of edge fish can distort the annealing objective even if final output remains valid.

- **KD-tree strip/rectangle queries make a rich move set practical within the time budget.** Rather than recomputing full point-in-polygon membership after each candidate, the program queries only the rectangle altered by an edge move or bulge and updates mackerel/sardine counts incrementally. Full scoring is used primarily at initialization and fallback. This is a major distinction from the grid-only approaches and supports the current best’s ability to perform many candidate evaluations during its approximately **1.9-second effective search interval** (`2.0 - 0.1` safety margin).

- **Validity checks are deliberately layered and localized.** Each candidate is screened for coordinate bounds, axis-aligned nonzero edges, maximum perimeter, maximum vertex count, and duplicate vertices. The program then runs a local self-intersection check only on altered edges, while applying a full intersection check to the final best polygon. This is an effective implementation compromise: it keeps most iterations cheap while preserving the perfect **50/50 accepted** result of the best program.

- **The annealing schedule is not static.** Temperature cools geometrically from **150.0** to **0.01**, with an extra aggressive low-temperature phase near the end. Random displacement and bulge depth shrink as elapsed time rises, including frequent `±1`/`±2`-scale moves late in the run. The program also shifts more weight toward dynamic best-polygon guide coordinates over time. This combination explains why the best program can first explore large geometric changes and later tune boundaries around individual fish coordinates.

## Performance Analysis

- **Generation 8 is the strongest measured result at 3734.38.** It exceeds **Generation 13’s KD-Tree Guided Polygon Simulated Annealing at 3711.54** by **22.84**, **Generation 12’s KD-Tree Guided Polygon Annealing at 3694.86** by **39.52**, and the earlier **Generation 0 baseline at 3700.20** by **34.18**. All of these were accepted on all 50 cases, so the observed differences isolate optimization effectiveness rather than correctness.

- **The high-performing KD-tree annealing family forms a relatively narrow upper tier.** Generations **0, 1, 2, 3, 5, 6, 8, 12, and 13** are mostly in the approximate **3655–3734** range, with the current best at the top. This clustering indicates that the principal architecture—Kadane initialization, incremental rectangle deltas, guided orthogonal edits, and robust validation—is consistently strong. Differences of tens of points are associated with guide selection, boundary handling, and search tuning.

- **The performance gap between polygon-annealing and raster/grid construction is large.** The current best’s **3734.38** is approximately **1744.68 above** Coarse Grid Banded Polygon Search (**1989.70**) and **1785.76 above** Grid-Based Connected Polygon Search (**1948.62**). All three approaches were fully correct, making the contrast strong evidence that fine-grained coordinate movement and non-grid-constrained polygon adaptation are central to score quality.

- **Correctness was stable; optimization quality was the differentiator.** Every listed program achieved full acceptance, including the low-scoring Generation 7 and the two grid methods. Consequently, the results do not suggest that more validation alone drives score. The strongest correlation with performance is the combination present in the current best: high-resolution Kadane seeding, inclusive-boundary-correct KD-tree deltas, mixed shape-edit operations, broad static fish guides, dynamic best-shape guides, and time-adaptive annealing.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Add late-stage micro-bulges with guide-aligned depth and short edge spans.** During the final 30–40% of the budget, select an edge and insert a shallow 1–10 unit protrusion/notch, preferably snapping its displaced coordinate to the nearest fish-derived `coord-1/coord/coord+1` guide rather than a uniformly random static guide. Preserve the current inclusive-boundary delta convention—exclude the old edge line and include the new line—so the move can finely include a nearby mackerel or exclude a sardine without destabilizing the successful large-scale shape.

2. **Bias static guide selection using local weighted KD-tree queries rather than choosing all fish guides uniformly.** When proposing a new edge or bulge coordinate, sample several nearby candidate guides and score their affected strip with a cheap KD-tree rectangle query; favor coordinates with positive `mackerels - sardines` delta, while still retaining some uniform guide sampling for exploration. This extends the best program’s broad fish-adjacent guide mechanism, which outperformed local-only guidance, but makes the already-successful snapping proposals more score-aware.

3. **Introduce occasional paired parallel-edge moves to translate or resize a corridor-like region.** For example, choose two vertical edges and move both horizontally by the same displacement, or move them apart/together to widen or narrow a subregion; use disjoint changed-strip queries or explicitly subtract overlap so incremental counts remain exact. Single-edge translations and bulges are proven effective, but paired moves can cross local optima where a beneficial cluster requires moving both sides of a narrow region together.

4. **Use a small multi-start schedule around the strong 350×350 Kadane seed.** Keep the current Kadane rectangle as the primary initialization, but reserve roughly 15–25% of the time for a few short annealing runs initialized from independently snapped versions of its four sides, nearby high-value fish guides, or small outward/inward perturbations. Retain the global best across runs; this preserves the highly successful Kadane-plus-refinement architecture while reducing dependence on one annealing trajectory and random early mutations.

5. **Add periodic exact score reconciliation for accepted complex states, especially after bulge-heavy evolution.** Every fixed number of accepted moves, or whenever the polygon gains many vertices, recompute fish counts from scratch and replace the incremental counts if they differ; continue using KD-tree deltas for nearly all proposals. The existing delta logic is a major success factor and should remain unchanged, but occasional reconciliation provides protection against rare sign/overlap accounting drift as more expressive moves such as micro-bulges and paired-edge changes are added.
