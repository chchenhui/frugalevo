# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- **Boundary-accurate incremental scoring is associated with the strongest results.** The current best program, **Generation 8 (`fix_bulge_boundary_delta`)**, scored **3734.38**, ahead of Generation 6’s similarly named boundary-delta fix at **3712.84** and the initial program at **3700.20**. Its edge-shift and bulge queries explicitly exclude the old boundary line and include the new boundary line—for example, moving a vertical boundary right queries `[old_x + 1, new_x]`. This matches the inclusive polygon-containment semantics and avoids double-counting fish that remain on the original edge.

- **Coarse 2D Kadane rectangle initialization plus orthogonal-polygon refinement consistently performs well.** Generations 0–8, except the weaker simplified Generation 7 variant, all use this pattern and score roughly **3612.92–3734.38** with complete acceptance. The current best uses a **350×350** coarse grid to find a favorable initial rectangle before simulated annealing, providing a much stronger starting point than unstructured polygon search.

- **Guided coordinate snapping is a productive search bias when combined with random moves.** The best program uses both static fish-derived coordinates (`x`, `x±1`, `y`, `y±1`) and dynamic coordinate guides extracted from the incumbent best polygon. Dynamic-guide usage increases from **20% to 40%** over time, while static fish-guide snapping is used frequently otherwise. This combination appears stronger than purely local guide sampling: Generation 8 scored **3734.38**, versus Generations 4 and 5’s local-guide variants at **3612.92** and **3654.76**.

- **A mixed move set supports high-quality feasible polygons.** The current best combines edge translations, rectangular bulge insertion, and collinear-vertex removal, while adapting move probabilities as vertex count and perimeter grow. This preserves the ability to add useful shape detail without allowing uncontrolled complexity. Generations using this fuller move set were consistently near the top: Generation 0 at **3700.20**, Generation 6 at **3712.84**, and Generation 8 at **3734.38**.

## Ineffective Approaches

- **The simpler simulated-annealing variant was substantially weaker despite being correct.** Generation 7, **“Simulated Annealing Orthogonal Polygon Search,”** scored only **2188.18**, over **1546 points below** the current best’s **3734.38**. It still had KD-tree deltas, guided fish-adjacent coordinates, edge shifts, and occasional bulges, so correctness was not the issue. Relative to the best approach, its weaker initialization/search configuration—described as a coarse **250×250** grid with fewer or less developed move mechanisms—correlates with much poorer solution quality.

- **Local guide sampling changes did not improve the established guide strategy.** Generation 4 (`local_guide_sampling`) scored **3612.92**, and Generation 5 with the same patch name scored **3654.76**. Both remained fully valid on all 50 cases, but trailed the baseline Generation 0 (**3700.20**) and boundary-fix generations. The results indicate that narrowing coordinate selection to local guides reduced useful exploration or did not improve the global quality of candidate boundaries.

- **Boundary-delta changes alone were not automatically beneficial in every evaluated run.** Generations 1–3, which focused on exact or bulge-boundary delta corrections, scored **3686.34**, **3682.00**, and **3685.90**, respectively—below Generation 0’s **3700.20**. They were fully correct, so the lower scores are best interpreted as search-quality variation or interaction with annealing behavior rather than a correctness problem. The later Generation 6 and especially Generation 8 show that accurate boundary handling becomes highly effective when paired with the stronger tuning present in the best configuration.

## Implementation Insights

- **The current best’s count-update logic is carefully aligned with closed-boundary containment.** `is_inside_polygon_wn` treats fish on polygon segments as inside. Accordingly, edge shifts and bulges use asymmetric rectangle ranges such as `old_x + 1..new_x` when expanding right and `new_x..old_x - 1` when contracting left. This is an important implementation detail behind the successful `fix_bulge_boundary_delta` result of **3734.38**, because it prevents fish on unchanged boundaries from being incorrectly added or removed.

- **Fast incremental evaluation is central to fitting a rich search into the time budget.** The best program builds a KD-tree over all fish and queries only the changed rectangular strip for edge moves or the added/removed rectangular region for bulges. It avoids recalculating polygon containment for every fish on each candidate. Full fish-by-polygon scoring is limited to initialization and fallback situations.

- **Validity checking is layered rather than relying solely on a final check.** Candidate polygons are screened through coordinate bounds, Manhattan perimeter, nonzero axis-aligned edges, distinct-vertex checks, and local self-intersection checks involving only modified edges. The best solution then receives a final all-edge intersection validation before output. This design is supported by the perfect **50/50 ACCEPTED** outcome for Generation 8 and for all other KD-tree polygon variants.

- **The best program uses time-dependent search behavior rather than a fixed random walk.** Its temperature decays from **150.0 to 0.01**, becomes even more exploitative near the end, and random displacements/depths shrink over time. It also shifts toward dynamic best-polygon guides later in the run. These details match the Generation 8 feedback noting that “fish-coordinate guide snapping” and “time-adaptive move sizes” likely supported its leading score.

## Performance Analysis

- **Generation 8 is the top measured configuration at 3734.38.** It exceeds Generation 6 (**3712.84**) by **21.54**, Generation 0 (**3700.20**) by **34.18**, and the next lower boundary-focused variants, Generations 1–3 (**3682.00–3686.34**), by roughly **48–52 points**. All of these programs were accepted on all 50 cases, so the score differences reflect optimization quality rather than validity failures.

- **The high-performing family is tightly clustered once it includes full Kadane initialization, guided moves, KD-tree deltas, and robust polygon editing.** Generations 0, 1, 2, 3, 5, 6, and 8 occupy approximately **3655–3734**. This indicates that the core architecture is reliable and strong, while guide-selection details, boundary accounting, and annealing tuning determine the remaining score spread.

- **The local-guide experiments were below the strongest global/static-plus-dynamic guide strategy.** Generation 4’s **3612.92** and Generation 5’s **3654.76** are respectively **121.46** and **79.62** below the current best. The current best retains broad fish-coordinate guides while supplementing them with coordinates from the best-so-far polygon, rather than replacing the broader coordinate pool with local sampling.

- **Correctness was stable across every reported variant, but search quality varied greatly.** Every listed program passed **50/50** validation cases, including the low-scoring Generation 7. Therefore, the dominant measurable distinction is not geometric validity but the effectiveness of initialization, incremental boundary accounting, coordinate guidance, and move-set/search scheduling.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Preserve the exact closed-boundary delta convention and extend it to every new move.** Any added mutation—such as notch insertion, edge splitting, or multi-edge translation—should query only the region whose membership actually changes: exclude the old boundary line and include the new boundary line, exactly as Generation 8 does with ranges like `[old_x + 1, new_x]`. This is a non-negotiable foundation because fish on polygon edges count as inside, and the current best score was achieved with this precise accounting.

2. **Add a boundary-focused “micro-bulge” move for late-stage refinement.** In the last 30–40% of the annealing budget, introduce small rectangular dents/protrusions on a randomly selected edge, with depth chosen primarily from nearby static fish guides (`coordinate`, `coordinate ± 1`) and constrained to 1–10 units or the nearest guide. The existing bulge move is strong, but a dedicated fine-grained version should better exploit the highly productive fish-adjacent coordinate lattice without disrupting the larger shape found by Kadane initialization and earlier exploration.

3. **Use score-aware guide sampling instead of uniformly selecting from all fish-derived guides.** Retain the successful broad static guide pool and dynamic best-polygon guides, but bias coordinate selection toward guides near mackerels, away from sardines, or with positive local strip score estimated by a narrow KD-tree rectangle query. This extends the best program’s proven snapping mechanism while addressing a likely weakness of uniform guide selection: many static coordinates are not equally promising boundaries.

4. **Introduce occasional compound two-edge moves that preserve a rectangle-like corridor.** For example, choose two parallel vertical edges and shift both to expand, contract, or translate a subregion, evaluating the union/difference of their changed strips with boundary-safe disjoint rectangle queries. Such moves can cross shallow local optima that single-edge translations cannot, while remaining compatible with the current KD-tree incremental scoring and local intersection validation architecture.

5. **Run several cheap seeded refinement phases rather than relying on one Kadane-seeded trajectory.** Keep the 350×350 Kadane rectangle as the main seed, but reserve a fraction of the time for 2–4 short annealing restarts from perturbations of that rectangle—for example, independently snap each initial side to nearby high-value fish guides, then retain the best incumbent across runs. This builds on the strongly validated Kadane-plus-refinement pattern while increasing exploration diversity without reverting to the weaker unstructured or local-guide-only strategies.
