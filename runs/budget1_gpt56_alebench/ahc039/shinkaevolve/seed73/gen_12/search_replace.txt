<DESCRIPTION>
The score cache used by simulated annealing must exactly match the fish contained by the current polygon. The existing incremental updates include/exclude edge points incorrectly: fish on both old and new boundaries can be counted twice or removed although they remain inside. This is especially harmful because guide coordinates intentionally target fish coordinates.

Introduce a swept-edge query which excludes the old boundary when adding area and excludes the new boundary when removing area. Apply it to translations and bulges, so SA acceptance uses correct mackerel/sardine deltas.
</DESCRIPTION>

// Count exactly the points whose membership changes while an edge is swept.
// During expansion, the old boundary was already included. During contraction,
// the new boundary remains included because polygon edges are inside.
void calculate_score_delta_for_swept_edge(int old_coord, int new_coord,
                                          int span_min, int span_max,
                                          bool is_vertical, bool expanding,
                                          int& delta_m, int& delta_s) {
    int lo = std::min(old_coord, new_coord);
    int hi = std::max(old_coord, new_coord);
    if (expanding) {
        if (new_coord > old_coord) ++lo;
        else --hi;
    } else {
        if (new_coord > old_coord) --hi;
        else ++lo;
    }

    if (is_vertical) {
        calculate_score_delta_for_rectangle(lo, hi, span_min, span_max, delta_m, delta_s);
    } else {
        calculate_score_delta_for_rectangle(span_min, span_max, lo, hi, delta_m, delta_s);
    }
}
