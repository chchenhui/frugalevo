<DESCRIPTION>
Fish-coordinate snapping is currently uniform over up to roughly 30,000 coordinates. Most such proposals move an edge across a very large region, causing frequent self-intersections, poor annealing acceptance, and expensive broad KD-tree queries.

Use sorted guide coordinates locally: primarily sample a coordinate within a rank window around the current edge coordinate, while retaining a modest probability of a global jump early in annealing. This gives the search fine-grained fish-boundary adjustments, especially later in the run, without removing global exploration.
</DESCRIPTION>

// Prefer nearby fish-derived boundaries.  Uniform selection from all fish
// coordinates creates excessively large moves on this 100000-wide board.
int choose_static_guide(const std::vector<int>& guides, int current_coord, double time_ratio) {
    if (guides.empty()) return current_coord;

    // Keep global jumps mostly for the exploratory phase.
    if (rng.next_double() < 0.08 + 0.27 * (1.0 - time_ratio)) {
        return guides[rng.next_int((int)guides.size())];
    }

    int center = (int)(std::lower_bound(guides.begin(), guides.end(), current_coord) - guides.begin());
    int rank_radius = std::max(25, (int)(900.0 * (1.0 - time_ratio) + 25.0));
    int lo = std::max(0, center - rank_radius);
    int hi = std::min((int)guides.size() - 1, center + rank_radius);
    return guides[rng.next_int(lo, hi)];
}
