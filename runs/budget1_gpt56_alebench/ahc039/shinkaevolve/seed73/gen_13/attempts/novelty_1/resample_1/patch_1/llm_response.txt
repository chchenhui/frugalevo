<DESCRIPTION>
Static fish-coordinate snapping currently selects uniformly from every fish-derived coordinate. Once the polygon has found a promising region, this makes most proposals jump across the entire board, causing rejected moves, self-intersections, and ineffective late-stage annealing.

Select static guide coordinates within a radius around the moved edge instead. The radius gradually shrinks with elapsed time, retaining broad exploration early while making late moves local refinements. If no guide is in range, use the closest available guide, so every proposal remains meaningful. This is especially beneficial for edge movement and bulge insertion because their score deltas are local rectangles.
</DESCRIPTION>

// Choose a fish-derived coordinate near the current edge.  Global uniform
// sampling is useful only at the very beginning and otherwise produces jumps
// that usually destroy a good local shape.
int select_local_guide(const std::vector<int>& guides, int center, double time_ratio) {
    if (guides.empty()) return center;

    int radius = (int)(18000.0 * (1.0 - time_ratio) + 500.0);
    int lo_value = std::max(0, center - radius);
    int hi_value = std::min(MAX_COORD_VAL, center + radius);
    auto lo = std::lower_bound(guides.begin(), guides.end(), lo_value);
    auto hi = std::upper_bound(guides.begin(), guides.end(), hi_value);

    if (lo == hi) {
        auto near = std::lower_bound(guides.begin(), guides.end(), center);
        if (near == guides.end()) --near;
        if (near != guides.begin()) {
            auto previous = near - 1;
            if (std::abs(*previous - center) < std::abs(*near - center)) near = previous;
        }
        return *near;
    }
    return *(lo + rng.next_int((int)(hi - lo)));
}
