<DESCRIPTION>
Static fish-coordinate guides are currently sampled uniformly from roughly 20,000 coordinates. Most proposed edge moves therefore jump across a large portion of the board, which is especially harmful after the polygon has developed many edges: such moves are frequently rejected due to intersections and do not provide effective local refinement.

Sample static guides from a coordinate-distance window centered on the selected edge instead. The window is broad early in the search to retain exploration, then shrinks substantially for profitable local boundary adjustments. Fish coordinates and their adjacent coordinates remain the candidate set, so this preserves the important ability to place boundaries immediately beside fish.
</DESCRIPTION>

// Select a fish-derived coordinate near the current boundary.  Uniform sampling
// from all fish coordinates makes almost every late SA proposal a huge jump.
int select_local_guide(const std::vector<int>& guides, int center, double time_ratio) {
    if (guides.empty()) return center;
    int radius = (int)(18000.0 * (1.0 - time_ratio) + 500.0);
    int lo_value = std::max(0, center - radius);
    int hi_value = std::min(MAX_COORD_VAL, center + radius);
    auto lo = std::lower_bound(guides.begin(), guides.end(), lo_value);
    auto hi = std::upper_bound(guides.begin(), guides.end(), hi_value);
    if (lo == hi) {
        auto near = std::lower_bound(guides.begin(), guides.end(), center);
        if (near == guides.end()) --near;
        return *near;
    }
    return *(lo + rng.next_int((int)(hi - lo)));
}
