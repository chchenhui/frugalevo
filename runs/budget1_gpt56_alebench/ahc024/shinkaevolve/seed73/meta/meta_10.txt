# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- **Fast greedy-erosion plus annealing produced the best observed result.** The current best, **Generation 7 “fast_erosion_sa,” scored 1934.44**, exceeding every other accepted program. Its structure is a shuffled greedy phase that removes cells to `0`, followed by simulated annealing that can temporarily restore nonzero cells. This combination outperformed greedy/SA variants ranging from **1871.60 to 1905.90**.

- **Incremental preservation of adjacency constraints is consistently successful.** All high-performing implementations maintain border-edge counts rather than recomputing global adjacencies. The best program updates only the up-to-four affected cell/boundary edges via compact `Delta` records, then verifies that each changed color pair still has exactly the required “edge exists / edge absent” status. This correctness-preserving incremental approach is shared by the fully accepted programs, including Generation 0 (**1905.90**) and Generation 3 (**1900.46**).

- **Localized connectivity validation supports productive high-volume search.** The current best checks connectivity only for the color losing a cell, plus checks zero-region outside connectivity whenever a move adds or removes zero. It avoids BFS for a nonzero target color because proposals use a neighboring color, meaning the new cell is immediately attached to that target component. This is a particularly effective optimization relative to the approximately 1.95-second search budget.

- **Allowing reversible worsening moves is beneficial.** Generation 7 accepts valid zero-to-nonzero moves with simulated-annealing probability, while retaining the best grid separately. This permits topology-changing escapes from greedy local optima and is consistent with the strong performance of other SA-based erosion methods, especially Generation 0 (**1905.90**) and Generation 3 (**1900.46**).

## Ineffective Approaches

- **Heavy zero-frontier bias did not improve the observed score.** Several variants explicitly focused proposals near the zero frontier but scored materially below the current best: Generation 1 (**1883.70**), Generation 2 (**1876.12**), Generation 5 (**1871.60**), and Generation 8 (**1875.60**). Although their feedback describes frontier targeting as efficient, the evaluation results indicate that concentrating too strongly on immediate zero expansion was less effective than Generation 7’s broader random-cell, neighbor-color proposal mechanism.

- **Zero-biased proposals also underperformed broader neighbor-derived moves.** Generation 4’s `zero_biased_sa_proposals` scored **1879.08**, which is **55.36 points below** the best score. This suggests that biasing proposal selection toward the objective can reduce useful structural exploration, particularly when valid improvements require temporary restorations or recolorings away from zero.

- **Extra staged erosion/polishing did not surpass the simpler best search schedule.** Generation 6, which added a final repeated zero-erosion polish after annealing, achieved **1887.72**. Generation 3’s repeated greedy erosion achieved **1900.46**. Both are strong and correct, but neither matched the current best’s **1934.44**, indicating that additional deterministic phases did not reliably compensate for less effective annealing exploration.

- **A fixed 300 ms greedy allocation is not independently sufficient.** Generation 11 used a 300 ms randomized greedy phase followed by SA and reached **1894.58**, while Generation 7’s superficially similar 300 ms greedy limit achieved **1934.44**. The difference indicates that the crucial factor is not merely reserving time for greedy deletion, but the efficiency and exploration quality of the subsequent move-validation and annealing loop.

## Implementation Insights

- **The current best minimizes validation work without weakening correctness.** In `attempt_change`, only edge pairs incident to the recolored cell are updated and checked. Connectivity is tested only for the departing color; the entering nonzero color is known to remain connected because its color is selected from one of the cell’s orthogonal neighbors. Zero receives a dedicated outside-connected BFS check. This carefully narrowed validation is a plausible reason Generation 7 can explore more moves and reached **1934.44**.

- **O(1) color-membership updates make repeated BFS practical.** The use of `cells[color]` plus `pos_in_list[p]` enables swap-with-last deletion and constant-time insertion/removal during every attempted recolor. BFS can then compare visited count directly against `cells[color].size()`, avoiding expensive whole-grid scans to locate a color’s cells. This pattern is also present in the other accepted incremental implementations and supports reliable rollback.

- **Compact reversible edge deltas reduce both cost and rollback risk.** The best program aggregates at most a small number of normalized color-pair deltas in `deltas[8]`, applies them to `edge_count`, and subtracts exactly those deltas on rollback. This is more targeted than rebuilding adjacency information and preserves the invariant that all required original adjacencies exist while no unrequired inter-color adjacency is introduced.

- **The best program separates current state from best-known output.** It stores `best_grid` whenever the zero count improves, while SA continues from potentially lower-scoring states. This is essential because accepted negative-score moves are useful for exploration but should not degrade the submitted result. The same high-level principle appears in the other annealing variants, but Generation 7 paired it with the strongest measured outcome.

## Performance Analysis

- **Generation 7 is a clear outlier among the evaluated accepted programs.** Its **1934.44** score is:
  - **28.54** above Generation 0 (**1905.90**), the next-best listed result.
  - **33.98** above Generation 3 (**1900.46**).
  - **39.86** above Generation 11 (**1894.58**).
  - **62.84** above the lowest frontier-heavy result, Generation 5 (**1871.60**).

- **Correctness was stable across all approaches, so score differences primarily reflect search quality and throughput.** Every listed implementation passed all 50 cases. Therefore, the substantial spread from **1871.60 to 1934.44** cannot be attributed to validation failures; it reflects differences in the number and usefulness of valid moves explored within the common roughly 1.95-second budget.

- **Frontier-oriented proposal variants cluster in the lower performance band.** Generations 1, 2, 5, and 8, all emphasizing zero-frontier expansion, scored between **1871.60 and 1883.70**. Generation 4’s broader zero bias was similarly low at **1879.08**. In contrast, the best implementation’s random source-cell selection and neighbor-derived candidate colors yielded a substantially higher **1934.44**, indicating better diversification.

- **Greedy erosion is useful but not the primary differentiator at the top end.** Greedy-plus-SA methods all performed well: Generation 0 (**1905.90**), Generation 3 (**1900.46**), Generation 11 (**1894.58**), and Generation 7 (**1934.44**). However, the current best’s roughly **28–40 point advantage** over these close structural relatives indicates that its particularly efficient localized checks and unconstrained neighbor-color annealing behavior correlate with the strongest optimization outcome.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Keep the current random-cell / neighbor-color SA proposal kernel, but bias only the *choice among valid move classes* adaptively rather than toward the zero frontier.** Track acceptance and improvement rates separately for `nonzero→0`, `0→nonzero`, and nonzero recolors; periodically adjust probabilities so restoration/recolor moves remain sufficiently frequent when zero additions are failing. This preserves the broad exploration that distinguished Generation 7 from frontier-heavy variants while reducing wasted attempts in unproductive move categories.

2. **Add a small number of multi-cell “bridge” proposals that are applied as short transactional sequences of existing valid single-cell moves.** For example, occasionally try a two-step `0→A` restoration followed by an adjacent `B→0` deletion, or a short 2–4 cell color slide, retaining the sequence only if every intermediate state remains valid and the final state is accepted by SA. These moves can cross local optima that single-cell restoration cannot escape efficiently, while reusing the proven incremental edge accounting, rollback, and localized connectivity checks.

3. **Replace the fixed 300 ms greedy phase with an early-stop greedy phase based on deletion yield, reserving unused time for SA.** Continue shuffled `nonzero→0` deletion attempts only while recent blocks—for example, 128 or 256 attempts—still produce valid deletions; switch to SA once several blocks have near-zero success. Greedy erosion is valuable, but the results show that search quality after greedy is the main differentiator, so adapting the split can avoid spending time on an exhausted deterministic phase.

4. **Use periodic randomized restart-from-best diversification during the high-temperature portion of annealing.** When the current state remains substantially below `best_score` for a fixed number of attempts, restore `best_grid`, rebuild `cells`, positions, and edge counts, then apply a few accepted high-temperature reversible perturbations before continuing. Since the best program already separates current state from saved output, this extends that strength by preventing a poor SA trajectory from consuming most of the time budget.

5. **Optimize connectivity checks further with cheap pretests before invoking BFS, especially for the departing color.** Before `connected_color(old_color)`, count same-color orthogonal neighbors of the removed cell: if there are zero or one, removal cannot split that color and BFS can be skipped; run BFS only when the cell had at least two old-color neighbors. This retains the correctness and localized-validation design responsible for the best score, while increasing proposal throughput for the many moves that are trivially connectivity-safe.
