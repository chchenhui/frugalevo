<DESCRIPTION>
Use common deterministic stratified rollout placements for all candidate directions at the same turn/depth. The current random phase is independently consumed while evaluating different root actions, introducing Monte-Carlo noise directly into the direction comparison. A phase derived only from the simulated turn and depth makes every competing action estimate its expectation using the same empty-cell ranks, while still varying the sampled ranks over time. This should make greedy action selection more stable without increasing computational cost.
</DESCRIPTION>
