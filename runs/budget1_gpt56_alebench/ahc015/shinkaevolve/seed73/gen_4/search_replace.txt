stratified_boundary_shaping
</NAME>

<DESCRIPTION>
Replace independent random placement samples with stratified samples over the empty-cell rank space. The current Monte Carlo sampling can select the same empty cell multiple times and leave large portions of the board unrepresented, making direction selection noisy. Stratification preserves broad coverage at both lookahead levels while retaining a randomized offset.

Also add a penalty for adjacent candies of different flavors. Near a full board, minimizing mixed-color edges is a useful proxy for obtaining compact flavor regions and complements the component-square objective: component score rewards already completed merges, while this term helps select moves that create cleaner interfaces before those merges occur. Its coefficient grows with the turn because mixed adjacency is much more meaningful as empty space disappears.
</DESCRIPTION>

    int calculate_mixed_adjacency() const {
        int mixed_edges = 0;
        for (int r = 0; r < GRID_SIZE; ++r) {
            for (int c = 0; c < GRID_SIZE; ++c) {
                int flavor = board[r][c];
                if (flavor == 0) continue;
                if (r + 1 < GRID_SIZE && board[r + 1][c] != 0 &&
                    board[r + 1][c] != flavor) {
                    ++mixed_edges;
                }
                if (c + 1 < GRID_SIZE && board[r][c + 1] != 0 &&
                    board[r][c + 1] != flavor) {
                    ++mixed_edges;
                }
            }
        }
        return mixed_edges;
    }
