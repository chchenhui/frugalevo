<DESCRIPTION>
Replace per-node stratified random phases with partial Fisher–Yates samples drawn once per decision and shared by all four root actions.

The earlier no-replacement approach outperformed deterministic stratification, likely because it retains broader random coverage without repeatedly evaluating the same insertion rank. The current policy also draws a separate random phase inside each root action and descendant state, adding avoidable comparison noise: directions are judged against different chance outcomes. This edit creates one distinct-rank schedule for the first forecasted placement and one for the second forecasted placement, then reuses them for every corresponding chance node in the current action decision. The schedules remain fresh between real turns, retain no-replacement coverage, and make root-direction comparisons substantially fairer.
</DESCRIPTION>

        // same distinct chance ranks for all of them so their estimates differ

        array<int, CELLS> firstRanks{};
