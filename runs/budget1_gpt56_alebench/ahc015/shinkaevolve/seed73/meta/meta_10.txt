# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- **Distinct random chance-node placement sampling is the strongest observed pattern.** The current best, **Generation 2 – “Stochastic Two-Ply Candy Tilt Search,” scored 725,015.74**, using `{18, 7}` samples and a partial Fisher–Yates selection of **unique empty-cell ranks** at each chance node. This outperformed the initial stochastic version (**Generation 0, 707,430.50**) by **17,585.24**. Avoiding repeated insertion positions increases useful state coverage without increasing rollout count.

- **Depth-2 sampled expectimax with all four tilt actions consistently produced accepted, high-scoring solutions.** Every listed program uses board simulation, evaluates each of `F/B/L/R`, samples future placements, and takes the best response tilt after each sampled placement. Scores clustered from **675,292.62** to **725,015.74**, with all programs passing **50/50** cases, showing that this search structure is robust under the interactive time constraint.

- **Connectivity-first evaluation combined with spatial organization was effective.** The best program combines squared same-flavor connected-component size with center-of-mass compactness, proportional flavor-specific column strips, and edge bonuses. Similar formulations were strong: **Generation 8/11**, adding mixed-adjacency penalties to this family, reached **714,590.82**, while **Generation 4** reached **709,905.82**.

- **The reduced `{18, 7}` sampling budget was a successful operational optimization.** Programs 0–6 and 8/11 explicitly report that reducing prior `{23, 9}` sampling avoided CPU-limit failures while preserving search quality. The current best demonstrates that this lower budget is not merely safe: coupled with unique sampling, it delivered the highest measured mean.

## Ineffective Approaches

- **Deterministic stratification did not beat stochastic unique sampling in the available evaluations.** Despite its lower comparison variance, **Generation 1 – “Stratified Lookahead Candy Tilt Search” scored 675,292.62**, which is **49,723.12 below** the current best. Likewise, deterministic rotated sampling in **Generation 6** scored **678,592.72**, **46,423.02 below** the best. Stable common samples may improve consistency, but did not translate into the highest aggregate game score here.

- **The original heavier `{23, 9}` rollout budget was operationally ineffective.** Multiple summaries state that it could exhaust the two-second CPU budget before outputting all 100 actions. It therefore traded theoretical search quality for completion risk. The accepted `{18, 7}` variants show that preserving full-turn execution was more valuable than increasing samples.

- **Unique sampling alone was not sufficient to guarantee top performance.** **Generation 5**, also described as using `18` then `7` distinct random placements, scored only **689,819.30**, versus **725,015.74** for Generation 2. Thus, the gain is associated with the interaction of unique sampling with the particular evaluator and decision dynamics, rather than being a universally dominant isolated modification.

- **Additional evaluator complexity did not reliably exceed the best simpler formulation.** Mixed-adjacency penalties and more explicitly late-game shaping were helpful in some variants, but **Generation 4’s 709,905.82** and **Generation 8/11’s 714,590.82** remained below Generation 2. The available scores do not show that these extra terms consistently surpass the best connectivity/CoM/region/edge balance.

## Implementation Insights

- **Generation 2’s chance-node sampling is a concrete high-value implementation detail.** It initializes ranks `1..num_empty` and, for each sample `s`, swaps rank `s` with a uniformly selected rank in `[s, num_empty-1]`. This produces a no-replacement sample of empty-cell ranks. Since insertion positions are identified through `find_pth_empty_cell`, it ensures each sampled rollout at that node evaluates a different legal placement.

- **Exact deterministic tilt compaction supports reliable search-state simulation.** The current best rewrites each row or column toward its target edge, then rebuilds `candies_list` from the board. This keeps the board, emptiness count, BFS component evaluation, and coordinate-dependent heuristics synchronized after every simulated and actual move.

- **The best evaluator shifts emphasis over the game horizon.** In Generation 2, connectivity weight rises from `15.0 + 1.1 * turn`, while center-of-mass penalty declines from `max(0, 170 - 1.7 * turn)`. Region penalties also decline but retain a floor, and edge bonuses rise. This makes early placement favor compact, organized future structure while increasingly prioritizing realized large components later.

- **Small fixed-size data structures are aligned with the tight runtime budget.** BFS uses a fixed `100`-cell array queue; board storage is `std::array`; the empty-rank buffer is fixed-size; and each rollout copies a small 10×10 state. These choices are suitable for the roughly four-direction, two-chance-layer search repeated across 100 interactive turns.

## Performance Analysis

- **Generation 2 is the clear best measured program at 725,015.74.** It exceeds the next-best listed result, **Generation 8/11 at 714,590.82**, by **10,424.92** (about **1.46%**), and exceeds **Generation 4 at 709,905.82** by **15,109.92**. Its perfect **50/50 accepted** record confirms that the score lead did not come from reduced correctness or timeout exposure.

- **The same `{18, 7}` budget spans a wide score range, so sampling count is not the primary remaining differentiator.** With that budget, reported scores include **675,292.62** (Generation 1), **678,592.72** (Generation 6), **689,819.30** (Generation 5), **694,365.32** (Generation 3), **707,430.50** (Generation 0), **709,905.82** (Generation 4), **714,590.82** (Generation 8/11), and **725,015.74** (Generation 2). The approximately **49.7k** spread indicates that sampling method and evaluator details materially affect play quality.

- **Generation 2’s improvement over the initial stochastic program supports the unique-sample explanation.** Generation 0 and Generation 2 share the same general stochastic two-ply architecture and `{18, 7}` budget, but Generation 2 explicitly removes duplicate chance placements and scores **2.49% higher**: `725,015.74` versus `707,430.50`.

- **Larger sampling was not demonstrated to be better under the real execution environment.** **Generation 7** retained a heavier `22/9` lookahead and achieved **694,548.68**, below Generation 2 by **30,467.06**, while other feedback warns that prior `23/9` setups could hit the CPU limit. The measured evidence favors efficient, nonduplicating rollout coverage over simply increasing rollout volume.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Retain no-replacement chance sampling, but make the sampled ranks common across the four root actions within each turn.** Generate the depth-1 and depth-2 partial Fisher–Yates rank permutations once for the current decision, then reuse corresponding sampled placements when evaluating `F/B/L/R` where their empty-cell counts match. This preserves Generation 2’s high-value unique coverage while reducing action-comparison noise, potentially improving selection without reverting to the underperforming fully deterministic stratification schemes.

2. **Use an adaptive unique-sampling allocation across the game horizon rather than a fixed `{18, 7}` budget.** Keep the proven `18/7` configuration during the middle game, but reduce depth-2 samples when few candies are present and shift that saved budget to more distinct depth-1 placements or a small number of extra depth-2 samples in late, high-connectivity positions. The evidence favors completion-safe rollout counts, so this should be capped conservatively—for example, keep total simulated tilt evaluations at or below the current worst-case budget.

3. **Add selective exact enumeration when the number of empty cells becomes small.** At each chance node, replace random unique samples with all legal insertion ranks whenever `num_empty <= sample_count_this_depth`; this is already implicit for the configured sample count, but extend the idea by allowing full depth-1 enumeration in late turns while reducing or skipping depth-2 sampling if needed to stay within runtime. Exact late-game chance evaluation should be especially valuable because the current evaluator increasingly emphasizes realized connected-component score as `turn_num_1_indexed` rises.

4. **Introduce a root-action candidate filter followed by asymmetric search effort.** First evaluate all four tilt directions using the existing unique `{18,7}` sampled expectimax or a cheaper unique preliminary sample; then spend a small additional independent unique rollout batch only on the top two root directions when their values are close. This builds directly on the robust all-four-action two-ply structure while directing extra computation toward decisions where Monte Carlo variance can actually change the selected move.

5. **Use antithetic spatial sampling in addition to random no-replacement ranks.** For each randomly selected empty-cell rank, also sample an empty cell near the mirrored board coordinate—e.g., map `(r,c)` toward `(9-r,9-c)` and select the nearest currently empty rank—while ensuring the final sample set remains distinct. This remains stochastic and coverage-oriented like Generation 2, unlike the weaker purely deterministic samplers, but makes chance-node estimates less dependent on one board region and better tests the consequences of directional tilts.
