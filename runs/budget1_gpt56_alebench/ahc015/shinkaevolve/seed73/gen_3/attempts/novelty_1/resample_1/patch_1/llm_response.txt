<DESCRIPTION>
Exploit the rotational symmetry of the board by evaluating both vertical flavor strips and their 90-degree-rotated horizontal equivalent. The original region heuristic artificially commits all flavors to columns, even though horizontal clustering is equally valid and may be substantially easier given the current arrangement. Using the better of the two layouts preserves the intended separation pressure while allowing the search to discover either orientation.

Also replace independently sampled placement indices with stratified samples. The old Monte Carlo sampling can select the same empty cell multiple times, wasting expensive lookahead evaluations and increasing decision noise. One random sample from each equal-sized index interval covers the full empty-cell order more evenly while retaining randomness.
</DESCRIPTION>

    double calculate_region_penalty() const {
        if (candies_list.empty()) return 0.0;

        // A column-strip solution and its 90-degree rotated row-strip solution
        // are equivalent for the actual score.  Do not force the search to use
        // just one of these two otherwise identical layouts.
        double column_penalty = 0.0;
        double row_penalty = 0.0;
        for (const auto& candy : candies_list) {
            if (!G_flavor_active[candy.flavor]) continue;

            const auto& range = G_target_col_ranges[candy.flavor];
            const int lo = range.first;
            const int hi = range.second;
            if (lo > hi) continue;

            if (candy.c < lo) column_penalty += lo - candy.c;
            else if (candy.c > hi) column_penalty += candy.c - hi;

            if (candy.r < lo) row_penalty += lo - candy.r;
            else if (candy.r > hi) row_penalty += candy.r - hi;
        }
        return std::min(column_penalty, row_penalty);
    }
