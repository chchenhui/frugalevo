<DESCRIPTION>
Improve the initial constructive solution with a bounded one-segment lookahead.

The previous greedy initializer selected the strategy with the smallest immediate segment cost. This strongly favors `direct + no post alter`, because useful block placements usually cost one extra turn now but can substantially reduce the route to the following target through a slide stopper.

The replacement first collects all strategies within one turn of the immediate optimum. For a bounded random subset of these candidates, it simulates the resulting board and evaluates the best no-post-action base strategy for the next segment. It then chooses the candidate minimizing current cost plus next-segment cost. This retains cheap construction time while producing much more strategically useful initial block layouts for the subsequent simulated annealing phase.
</DESCRIPTION>
