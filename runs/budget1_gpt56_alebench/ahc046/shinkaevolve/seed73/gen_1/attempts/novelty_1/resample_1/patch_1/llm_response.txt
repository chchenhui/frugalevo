<DESCRIPTION>
Extend the post-target modification neighborhood with slide-based repositioning.

The current post-action choices only allow staying at the target, toggling an adjacent block, or moving one cell and toggling a block. Since slides are the key low-cost transport mechanic, this misses useful states where the player visits a target, slides to a distant stopping point in one action, and prepares a block for the following segment.

This edit adds:
- `Slide` only after reaching a target.
- `Slide + Alter` after reaching a target.

The latter uses the same three non-reverse alter directions as the existing `Move + Alter` choices. This keeps the strategy representation compact while enabling substantially more useful inter-segment positions and block layouts.
</DESCRIPTION>
