post_move_target_block
</NAME>

<DESCRIPTION>
Expand the post-segment block-placement neighborhood to allow moving one square away from a visited target and then altering back onto that target square. The existing code deliberately excludes the reverse direction after a post-target move, but that direction is legal: the target has already been visited, and turning it into a block can create a valuable stopper for future slides. This adds four useful configurations (one for each move direction) while preserving all existing options and strategy-code layout semantics otherwise.
</DESCRIPTION>
