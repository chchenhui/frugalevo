<DESCRIPTION>
Replace the fixed 15/15 ownership split of every shared horizontal boundary with a deterministic adaptive split. For each boundary, test split columns 8 through 22 and choose the one minimizing the larger estimated construction burden of its two neighboring humans. The estimate includes segment length and lateral distance to the assigned segment.

This preserves the existing complete, non-overlapping partition layout, but gives a larger share of the left or right half to the neighboring person who starts closer to it. It should reduce travel and make simultaneous boundary construction finish more reliably than always assigning exactly 15 cells per side.
</DESCRIPTION>

            const Point& upper_pos = humans_global_state[human_order[upper_rank]].pos;
            const Point& lower_pos = humans_global_state[human_order[upper_rank + 1]].pos;

            int best_split = GRID_SIZE / 2;
            int best_cost = INF;
            for (int split = 8; split <= 22; ++split) {
                int upper_horizontal = 0;
                if (upper_pos.c > split) upper_horizontal = upper_pos.c - split;
                int lower_horizontal = 0;
                if (lower_pos.c <= split) lower_horizontal = split + 1 - lower_pos.c;

                // Length approximates build time; horizontal distance
                // approximates the initial trip to the assigned segment.
                int upper_cost = split + upper_horizontal;
                int lower_cost = (GRID_SIZE - split) + lower_horizontal;
                int cost = std::max(upper_cost, lower_cost);

                    best_split = split;
