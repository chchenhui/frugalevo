# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- **Removing redundant outer-boundary wall work is the strongest observed structural improvement.** The current best, **Strip Partition Wall Builder** (Generation 2, `remove_redundant_boundary_walls`), scored **3,689,312.64**, narrowly exceeding Generation 0’s **3,669,080.60** and Generation 7’s **3,672,557.92**. Its code explicitly avoids building cells on rows/columns already protected by the board boundary and constructs only internal strip cuts. This preserves turns for useful enclosure walls.

- **Horizontal strip partitioning with split responsibility for shared cuts is consistently effective.** The best program assigns each human a row strip and splits each internal horizontal boundary between the neighboring strips: one side constructs columns 1–15 and the other columns 16–30. This avoids duplicate assignments while producing complete row barriers. Other successful variants using the same core approach include Generation 7 (**3,672,557.92**) and Generation 6 (**3,643,761.58**).

- **Sequential same-turn reservations plus BFS routing are robust high-value coordination mechanisms.** The current best tracks `tentative_walls_this_turn` and `tentative_move_targets_this_turn`, preventing humans from moving into a wall scheduled that turn or selecting conflicting destinations. All high-scoring accepted programs use closely related protections, including Generation 0 (**3,669,080.60**) and Generation 7 (**3,672,557.92**).

- **Strong preference for build positions reachable from inside the strip is beneficial.** The current best assigns a large `STAND_OUTSIDE_INNER_SAFE_PENALTY = 1000`, so humans favor constructing strip cuts from their own interior. This supports completed barriers without repeatedly placing humans on the wrong side of a developing cut, while BFS handles travel to the selected adjacent standing cell.

## Ineffective Approaches

- **The `reachable_wall_targeting` family underperformed the best structural variants.** Generations 3 and 4 both scored **3,395,892.28**, which is **293,420.36 below** the current best. Although they retained BFS and reservation logic, their target-selection changes did not translate into stronger scores than the simpler, more focused internal-cut construction used by Generation 2.

- **Contiguous/adjacency-oriented wall targeting was not enough by itself.** Generation 1, **Strip-Based Cooperative Wall Builder** (`contiguous_barrier_priority`), scored only **3,202,376.04**, the lowest listed result and **486,936.60 below** the current best. Its wall-target scoring included adjacency bonuses and safe-region terms, but its pet-proximity penalty was zero and the feedback indicates it primarily optimized structural completion. The result suggests that scoring sophistication without the best assignment/construction layout can hurt execution efficiency.

- **Fixed strip strategies with additional pet-aware scoring did not outperform the simpler best configuration.** Generation 5, with distance, boundary, wall-adjacency, and pet-proximity scoring, reached **3,384,198.56**, still **305,114.08 below** Generation 2. The evaluation feedback specifically notes that fixed partitions limit adaptation; however, the score shows that the added local scoring did not compensate for the cost or disruption of that targeting behavior.

- **The `allow_human_overlap` patch was not a competitive scoring change.** Generation 11 scored **3,605,180.02**, below the current best by **84,132.62**. It remained correct, but its score indicates that loosening or altering overlap-related handling did not improve on explicit movement reservation and controlled sequential scheduling.

## Implementation Insights

- **The current best’s assignment construction is unusually economical.** In `initialize_game`, each human receives only internal boundary cells:
  - upper shared cut: columns 16–30 when `i > 0`;
  - lower shared cut: columns 1–15 when `i < M-1`.
  
  The program deliberately skips board-edge walls because “the outer room border is already impassable.” This concrete reduction in unnecessary build actions aligns with Generation 2’s leading **3,689,312.64** score.

- **Its target selector separates legal construction from preferred construction.** `can_theoretically_build_at` rejects occupied wall cells, pet-occupied cells, cells adjacent to pets, and cells occupied by another human. Then the selection loop evaluates adjacent standing positions and rejects tentative wall/move conflicts. This layered legality model is a key reason the solution was accepted on **all 50/50 cases**.

- **The current best emphasizes safe-side positioning while retaining deterministic tie-breaking.** Candidate score is primarily Manhattan distance plus a very large outside-inner-region penalty. Ties are resolved lexicographically by wall cell and then standing cell. This makes behavior reproducible and avoids unstable competition between humans, consistent with the feedback describing deterministic strip strategies as robust.

- **The stuck-build fallback prevents permanent inactivity without destabilizing the plan.** After `MAX_STUCK_TURNS = 10`, a human temporarily switches to `REPOSITIONING_STUCK` and BFSes toward its strip’s central safe position. Generation 2 combines this with rebuild attempts on subsequent turns, which helps maintain legal activity when a pet temporarily blocks an assigned wall cell.

## Performance Analysis

- **Generation 2 is the top measured configuration, but the margin over related internal-cut designs is modest.** Its **3,689,312.64** exceeds Generation 7’s **3,672,557.92** by **16,754.72** and Generation 0’s **3,669,080.60** by **20,232.04**. This indicates that the common strip/BFS/reservation foundation is already strong, while removing redundant boundary walls provides the decisive incremental advantage.

- **Row/strip assignment quality appears more important than local wall-score heuristics.** Generation 6’s row-matched assignment scored **3,643,761.58**, close to the best and well ahead of the `reachable_wall_targeting` variants at **3,395,892.28**. Similarly, Generation 7’s coordinated half-width boundaries nearly matches the best. The score pattern favors efficient distribution of barrier work over elaborate target ranking.

- **The high-performing cluster is approximately 3.60M–3.69M and shares the same practical architecture.** Generation 11 (**3,605,180.02**), Generation 6 (**3,643,761.58**), Generation 0 (**3,669,080.60**), Generation 7 (**3,672,557.92**), and Generation 2 (**3,689,312.64**) all rely on deterministic strips, BFS movement, wall legality checks, and same-turn coordination. Every one passed all 50 cases.

- **Added pet-aware or adjacency-focused terms did not show a positive score correlation in these evaluations.** The current best leaves `ADJACENT_WALL_PRIORITY_BONUS` and `NEAR_PET_PENALTY_POINTS_PER_PET` at zero, yet leads the set. Generation 5’s more explicit pet-aware scoring was **305k** behind, while Generation 1’s structural scoring variant was nearly **487k** behind. In this evaluated set, clean barrier assignment and construction efficiency dominated those local prioritization additions.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Keep the internal horizontal-strip cut layout, but mutate only the split point of each shared boundary.** The current best uses a fixed 15/15 column split; test a small deterministic family such as 10/20, 12/18, 18/12, and alternating split ownership by boundary index. This directly preserves the proven no-redundant-boundary-wall and non-overlapping-responsibility structure while potentially reducing travel for humans whose initial positions are concentrated on one side.

2. **Assign strip indices to humans by initial-row matching rather than fixed input order.** Sort humans by starting row before assigning top-to-bottom strips, while retaining each strip’s same half-cut responsibilities and safe-side target logic. Generation 6’s row-matched assignment was close to the top score, and this mutation could reduce initial travel to build locations without introducing the weaker adaptive target-selection behavior seen in Generations 3–5.

3. **Replace Manhattan target ranking with BFS-reachable path distance for only the final shortlist of candidate standing cells.** First retain the current inexpensive Manhattan/safe-side scoring to identify, for example, the best 4–8 wall-and-standing candidates; then run BFS to choose the one with the shortest currently feasible route around completed and tentative walls. This extends the existing robust BFS architecture and can avoid repeatedly preferring geometrically close targets that are separated by already-completed strip segments.

4. **Add a deterministic “complete-nearest gap” priority once a cut has begun, without adding general wall-adjacency heuristics.** For an assigned half-boundary, detect whether built cells form a partial contiguous segment and prioritize the unbuilt endpoint adjacent to that segment when it is legally reachable from the strip interior. This is narrower than Generation 1’s broad adjacency scoring, which underperformed, but may reduce fragmented construction and close barriers sooner while preserving the best program’s distance-first behavior.

5. **Upgrade same-turn reservation to reserve occupied human positions as temporary movement obstacles during BFS, except for the moving human’s own cell.** Continue allowing a human to build adjacent to itself, but prevent later humans from routing into a square occupied by an earlier stationary human or from selecting moves that create direct swaps/crossings where avoidable. The best solution already gains value from sequential wall and destination reservations; this is a conservative coordination extension that should reduce wasted or blocked moves without relaxing the successful controlled-scheduling model.
