<DESCRIPTION>
Improve operation 4, which adds a round-trip detour to a high-dirt target cell. Previously it samples only 20 route positions, so it often inserts a long and expensive detour despite the route already passing close to the selected target elsewhere.

Scan all current route coordinates and choose the closest occurrence to the target cell. Score evaluation already costs O(L), so this additional O(L) scan is affordable and substantially improves the usefulness of targeted visits: the optimizer can add frequent visits to problematic cells with the minimum possible route-length increase. Random tie-breaking retains route diversity when the target is equally close to multiple route positions.
</DESCRIPTION>
