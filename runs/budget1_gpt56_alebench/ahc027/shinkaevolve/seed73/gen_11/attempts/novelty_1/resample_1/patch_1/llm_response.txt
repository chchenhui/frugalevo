<DESCRIPTION>
Improve Op4’s insertion-point selection. Previously it selected the sampled position with the shortest detour to the dirty target, ignoring where in the target cell’s cleaning cycle that new visit occurs. A slightly longer detour can be substantially better if it splits the target’s largest revisit gap.

The added helper evaluates the target cell’s exact periodic dirt term after a proposed closed detour. Op4 still limits itself to positions whose detour is close to the shortest sampled detour, avoiding wasteful route growth, but selects among them by the predicted reduction in the target’s weighted average contribution. This preserves the cheap sampled neighborhood while making targeted insertions phase-aware.
</DESCRIPTION>

// Return the periodic dirt triangle-sum of target after inserting a closed
// detour at route coordinate insert_index.  The detour reaches target after
// outward_distance moves and has total length 2*outward_distance, except for
// a local wiggle at target itself, which returns there after two moves.
long double target_term_after_detour(const PathData& pd, Pos target,
                                    int insert_index, int outward_distance) {
    const int old_length = (int)pd.moves.size();
    const int added_length = (outward_distance == 0) ? 2 : 2 * outward_distance;
    const int new_length = old_length + added_length;
    const int added_visit_time = insert_index +
        ((outward_distance == 0) ? 2 : outward_distance);

    std::vector<int> visits;
    const auto& old_visits = CELL_VISIT_TIMES_GLOBAL_BUFFER[target.r][target.c];
    visits.reserve(old_visits.size() + 1);
    for (int t : old_visits) {
        visits.push_back(t > insert_index ? t + added_length : t);
    }
    visits.push_back(added_visit_time);
    std::sort(visits.begin(), visits.end());

    long double term = 0.0L;
    for (int i = 0; i < (int)visits.size(); ++i) {
        int previous = (i == 0) ? visits.back() - new_length : visits[i - 1];
        long long gap = (long long)visits[i] - previous;
        term += (long double)gap * (gap - 1) / 2.0L;
    }
    return term;
}
