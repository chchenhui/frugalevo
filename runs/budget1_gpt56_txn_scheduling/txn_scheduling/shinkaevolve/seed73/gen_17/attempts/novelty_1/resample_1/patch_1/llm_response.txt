<DESCRIPTION>
Replace the current prefix-shuffle perturbation with a simulator-guided destroy-and-repair neighborhood. Prefix shuffling discards many useful pairwise conflict orientations at once and only rebuilds the suffix, whereas destroy-and-repair retains most of a strong local optimum and selectively repositions a small conflict-heavy region.

The new helper removes either a contiguous block or scattered transactions, then reinserts each removed transaction at the position with the lowest exact simulated makespan. This directly evaluates the transaction conflict effects rather than relying on transaction size or random ordering. Applying several repairs to the best refined schedules creates moves that cannot be reached by a single insertion, swap, or reversal descent, while the subsequent exact local refinement recovers any remaining small improvements.

    def destroy_and_repair(order, diversity=False):
        """
        Rebuild a small neighborhood of an already good schedule.  Keeping the
        unaffected transactions fixed preserves proven conflict orientations,
        while exact insertion scoring can jointly repair a poor local region.
        """
        remove_count = min(num_txns // 3, max(3, min(6, num_txns // 8 + 2)))

        if random.random() < 0.55:
            first = random.randrange(num_txns - remove_count + 1)
            removed = order[first:first + remove_count]
        else:
            indices = set(random.sample(range(num_txns), remove_count))
            removed = [txn for index, txn in enumerate(order) if index in indices]

        removed_set = set(removed)
        partial = [txn for txn in order if txn not in removed_set]
        random.shuffle(removed)

        for txn in removed:
            if len(partial) <= 44:
                positions = range(len(partial) + 1)
            else:
                positions = {0, len(partial)}
                positions.update(random.sample(
                    range(1, len(partial)),
                    min(36, len(partial) - 1),
                ))

            scored = []
            for position in positions:
                candidate = partial[:]
                candidate.insert(position, txn)
                scored.append((schedule_cost(candidate), position))

                    position for cost, position in scored
                    if cost <= best + slack
                ]
                position = random.choice(choices[:min(4, len(choices))])
            else:
                position = scored[0][1]
            partial.insert(position, txn)
