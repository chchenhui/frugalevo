<DESCRIPTION>
Add a bounded two-transaction ejection-chain neighborhood after the existing beam, local descent, and kick phases.

1. Start from the current globally best complete permutation, so the chain search spends its budget in the strongest basin found so far.
2. Estimate removal impact using the actual simulator objective: temporarily remove each transaction and measure the makespan reduction. Transactions whose removal reduces makespan the most are likely to lie on critical conflict paths.
3. For a small set of high-impact transactions, relocate a first transaction to several schedule anchors.
4. From that modified permutation, relocate a second high-impact transaction to another anchor. This coordinated pair of relocations can escape optima where neither individual insertion is improving.
5. Evaluate every resulting complete permutation directly with `get_opt_seq_cost`, accept only strict makespan improvements, and run the existing descent only after a promising chain is found.

The neighborhood is deliberately bounded by five high-impact transactions and five anchor positions, keeping the extra simulator calls controlled while allowing coordinated changes that insertion, swap, reversal, and the existing single-block kicks cannot represent.
</DESCRIPTION>

    # relocate one high-impact transaction, then relocate a second one in the
    # altered order.  The impact ranking and all acceptance decisions use the
    # simulator's conflict-aware makespan directly.
    chain_base = list(best_schedule)
    chain_base_cost = best_cost
    removal_impacts = []
    for position, txn in enumerate(chain_base):
        without_txn = chain_base[:position] + chain_base[position + 1:]
        removal_impacts.append((chain_base_cost - evaluate(without_txn), txn))

    removal_impacts.sort(key=lambda entry: (-entry[0], entry[1]))
    chain_txns = [txn for _impact, txn in removal_impacts[:min(5, num_txns)]]
    chain_anchors = sorted(
        set([0, num_txns // 4, num_txns // 2, (3 * num_txns) // 4, num_txns - 1])
    )

    for first_txn in chain_txns:
        first_source = chain_base.index(first_txn)
        first_remainder = (
            chain_base[:first_source] + chain_base[first_source + 1:]
        )

        for first_destination in chain_anchors:
            first_insert_at = min(first_destination, len(first_remainder))
            first_schedule = (
                first_remainder[:first_insert_at]
                + [first_txn]
                + first_remainder[first_insert_at:]
            )

                if second_txn == first_txn:

                    first_schedule[:second_source]

                            best_schedule = chained_schedule
