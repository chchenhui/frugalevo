<DESCRIPTION>
Add deterministic perturbation seeds before the existing strict-improvement local search. The current insertion/swap descent can become trapped when every single improving move is blocked by an ordering barrier. Reversing a medium interval, relocating a small block, and exchanging distant transactions deliberately cross such barriers while preserving a valid permutation.

The perturbed schedules are evaluated using the same exact conflict-aware makespan objective and are then passed through the existing insertion/swap descent. This combines broad deterministic diversification with the current strong local optimizer, without relying on transaction-length proxies or random behavior. The original best beam seeds are retained, so this extends rather than replaces the existing search.
</DESCRIPTION>
