<DESCRIPTION>
Add a bounded deterministic perturb-and-reoptimize phase after the existing beam-seeded local search. The current strict insertion/swap/reversal descent can stop at a local optimum even though reaching a better transaction order requires temporarily accepting a worse ordering. This edit creates several objectively best non-improving “kicks” from the best schedule using medium interval reversals, distant exchanges, and short block relocations. Each perturbed schedule is then reoptimized with the same conflict-aware objective.

Step-by-step:
1. Preserve the best schedule obtained from the existing beam and local-search phase.
2. Enumerate diverse deterministic perturbations that alter several conflict precedence relations at once.
3. Rank perturbations using `get_opt_seq_cost`, retaining only a small bounded number of promising kicks.
4. Run strict insertion, exchange, and interval-reversal descent from each kick.
5. Keep the globally best makespan found across the original and perturbed local optima.

All decisions continue to use the simulator’s actual makespan rather than transaction-length proxies. The bounded number of kicks limits runtime while allowing the search to cross local-optimum barriers.
</DESCRIPTION>
