<DESCRIPTION>
Refactor the existing local-search loop into a reusable strict best-improvement variable-neighborhood descent (VND), then apply deterministic perturbation-reoptimization to several distinct elite beam schedules.

Step-by-step:
1. The beam search supplies several good but structurally different complete transaction orders.
2. Each seed is first optimized using the existing objective-driven insertion, exchange, and interval-reversal neighborhoods.
3. A single local optimum can be trapped: no one insertion, swap, or reversal improves it, while a coordinated multi-transaction displacement could.
4. For the best distinct local optima, generate controlled “kicks” that preserve schedule validity: interval reversal, block relocation, and distant exchange.
5. Re-run the same strict VND after every kick. A kicked schedule is never accepted merely because it is different; it must eventually improve according to `workload.get_opt_seq_cost`.
6. This explores multiple attraction basins while retaining deterministic behavior and using the true simulator makespan for every decision.

The change is targeted to the local-search stage and keeps exact search for small workloads and the conflict-aware beam construction unchanged.
</DESCRIPTION>
