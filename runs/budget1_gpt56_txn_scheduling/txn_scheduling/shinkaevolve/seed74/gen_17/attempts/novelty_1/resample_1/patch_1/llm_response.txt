<DESCRIPTION>
Add a deterministic iterated-local-search phase after the existing beam-seeded descent.

The current code performs strong strict-improvement local search, but once every beam seed reaches an insertion/swap/reversal local optimum it cannot cross a makespan barrier requiring one temporary non-improving move. Transaction conflict landscapes commonly have these barriers: a group of mutually conflicting transactions may need to be reordered together before any individual move reduces the critical-path delay.

This edit generates several deterministic, structurally different perturbations of the best schedule, including interval reversals, distant exchanges, and short block relocations. Each perturbed schedule is then reoptimized using the same actual simulator makespan objective and the same insertion/swap/reversal neighborhoods. The schedule is replaced only if the complete reoptimization produces a strictly better makespan, preserving validity and never sacrificing an already-found solution.

The phase is bounded to avoid excessive simulator calls while allowing the search to escape local optima that the ordinary descent cannot improve directly.
</DESCRIPTION>

    for perturbation_index in range(perturb_count):

        if mode == 0:

            # once while retaining the transactions on either side.
            left = (perturbation_index * 3) % max(1, num_txns - 1)
            width = min(
