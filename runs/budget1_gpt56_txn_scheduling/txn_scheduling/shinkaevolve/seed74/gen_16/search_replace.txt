<DESCRIPTION>
The current large-workload local search samples positions uniformly. Uniform spacing can miss the transactions responsible for the dominant conflict chain, so it can spend evaluations on moves that cannot reduce the simulator’s actual makespan.

This edit restores objective-guided selection for large schedules: temporarily remove each transaction and measure its marginal impact with `get_opt_seq_cost`. Transactions with the largest measured impact, together with evenly spaced anchors, become candidate move sources and nearby destinations. This focuses insertion and exchange search on conflict bottlenecks without using operation-count proxies.

It also adds interval-reversal moves to local descent. A reversal changes many precedence relationships simultaneously, allowing descent to escape schedules where every single insertion and pair exchange is non-improving. Reversals are evaluated with the same exact simulator objective and are restricted to the already selected positions for large workloads, keeping the search bounded and deterministic.
</DESCRIPTION>

                if anchor_positions[-1] != num_txns - 1:

                removal_impacts = []
                for position in range(num_txns):
                    reduced = current[:position] + current[position + 1:]
                    removal_impacts.append(
                        (current_cost - evaluate(reduced), position)
                    )

                impact_budget = min(num_txns, max(8, num_txns // 12))
                removal_impacts.sort(key=lambda entry: (-entry[0], entry[1]))

                    position
                    for _impact, position in removal_impacts[:impact_budget]

                    set(anchor_positions).union(impact_positions)
