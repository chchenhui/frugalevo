<DESCRIPTION>
Replace the fixed six-pass improvement limit with descent to a true local optimum over the evaluated neighborhoods.

Step-by-step:
1. The construction phase already produces several conflict-aware schedules using exact simulator makespans.
2. Each relocation, swap, and adjacent-pair relocation is evaluated with the authoritative `get_opt_seq_cost`, so accepting only strict improvements cannot worsen a schedule.
3. A fixed pass cap can stop while an improving move still exists, especially when several independent conflict chains must be repaired one after another.
4. Continue until none of the three neighborhoods offers an improvement. After a swap or pair move, relocation search is revisited, allowing the new ordering to expose further conflict-reducing moves.
5. Because every accepted move strictly lowers makespan and there are finitely many permutations, this terminates while producing a schedule no worse than the capped search and commonly better.

This preserves the existing targeted search operators and cache, but avoids returning prematurely before the local conflict structure is fully optimized.
</DESCRIPTION>
