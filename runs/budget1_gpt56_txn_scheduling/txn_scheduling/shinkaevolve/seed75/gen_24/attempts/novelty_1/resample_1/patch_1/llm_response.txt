<DESCRIPTION>
Replace random two-relocation perturbations with a deterministic destroy-and-repair restart.

1. Start from several already simulator-optimized local optima.
2. Remove a small contiguous transaction segment while preserving the order of all remaining transactions.
3. Reinsert each removed transaction by evaluating every possible insertion position with the exact simulator makespan.
4. Try both the original and reversed removed-block orders, since coupled conflicting transactions can need to cross one another together.
5. Run the existing VND descent from the repaired result.

This is stronger than random kicks because every repair decision is based on the actual conflict-derived makespan. Removing a short block can cross local-optimum barriers that cannot be improved through an individual relocation, while reinserting against the fixed residual order keeps the search focused and permutation-safe.
</DESCRIPTION>

    def destroy_and_repair(sequence, start, length):
        """
        Remove a short coupled region, preserve the residual order, and insert
        the removed transactions back at simulator-optimal positions.  Trying
        both directions lets a repair change the relative order of transactions
        that must cross a conflict boundary together.
        """
        removed = sequence[start:start + length]
        residual = sequence[:start] + sequence[start + length:]
        best_value = None
        best_sequence = None

        insertion_orders = [removed]
        if length > 1:
            insertion_orders.append(list(reversed(removed)))

        for insertion_order in insertion_orders:
            repaired = residual[:]
            for txn in insertion_order:
                insertion_value = None
                insertion_sequence = None
                for position in range(len(repaired) + 1):
                    candidate = repaired[:position] + [txn] + repaired[position:]
                    value = sequence_cost(candidate)
                    if insertion_value is None or value < insertion_value:
                        insertion_value = value
                        insertion_sequence = candidate
                repaired = insertion_sequence

            value = sequence_cost(repaired)
            if best_value is None or value < best_value:
                best_value = value
                best_sequence = repaired

        return best_value, best_sequence
