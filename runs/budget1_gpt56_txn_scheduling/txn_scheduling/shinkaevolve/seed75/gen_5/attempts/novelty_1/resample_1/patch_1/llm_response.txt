<DESCRIPTION>
Instead of applying relocation/swap descent only to the single best greedy construction, preserve the diversified greedy starts and locally optimize each of the strongest constructed schedules.

Step-by-step:
1. Greedy construction is sensitive to its first transaction and tie ordering, so different starts can reach different conflict-ordering basins.
2. The current code sorts these schedules but immediately discards every schedule except the first one.
3. A schedule that is slightly worse before local optimization can become substantially better after relocation moves because it may contain different transaction groups and conflict boundaries.
4. Run the existing exact relocation/swap variable-neighborhood descent independently over a bounded set of the best diversified constructions.
5. Retain the globally lowest exact simulator cost across all descents.

This reuses the existing cost cache and exact makespan evaluator, while making the already-generated restart diversity effective rather than merely selecting the best unoptimized greedy schedule.
</DESCRIPTION>

    def descend(schedule, current_cost):
        """Exact variable-neighborhood descent for one diversified restart."""
        relocation_passes = max(2, min(6, n))
        for _ in range(relocation_passes):
            improved_cost, improved_schedule = best_relocation(schedule, current_cost)
            if improved_cost < current_cost:
                current_cost, schedule = improved_cost, improved_schedule
                continue

            # A non-improving insertion neighborhood can still be escaped by
            # exchanging two transactions and resuming insertion descent.
            swapped_cost, swapped_schedule = best_swap(schedule, current_cost)
            if swapped_cost >= current_cost:
                break
            current_cost, schedule = swapped_cost, swapped_schedule

        return current_cost, schedule

    # Different greedy starts frequently place a conflicting transaction group
