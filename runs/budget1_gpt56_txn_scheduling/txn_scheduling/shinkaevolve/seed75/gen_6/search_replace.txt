<DESCRIPTION>
Instead of applying expensive local search only to the single best greedy construction, retain a small elite set of the best independently constructed schedules and run variable-neighborhood descent on each.

Step-by-step:
1. Greedy construction is sensitive to its starting transaction and may produce several schedules with similar initial makespan but very different local-search potential.
2. The currently selected best greedy schedule can be trapped in a local minimum that is worse than another elite schedule after relocation and swap optimization.
3. Keep up to four lowest-cost constructed schedules as elite candidates.
4. Apply the existing exact relocation and swap neighborhoods to every elite candidate.
5. Select the globally best improved result using the authoritative simulator cost.

This exploits diversified starts already generated by the function while avoiding the cost of optimizing every constructed schedule. It is particularly effective for transactional conflict graphs because a greedy prefix can look good initially while placing a later high-conflict transaction in a poor relative order.
</DESCRIPTION>
