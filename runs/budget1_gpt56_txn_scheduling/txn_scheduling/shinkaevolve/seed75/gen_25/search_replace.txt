<DESCRIPTION>
Replace the sequential greedy reinsertion used by destroy-and-repair with an exact joint repair for a removed pair.

1. The existing repair scores the first removed transaction against an incomplete schedule and irrevocably commits to its best partial insertion position.
2. That partial choice can be wrong: the best position for one transaction often depends on where its coupled conflicting transaction is inserted.
3. The new method removes two adjacent transactions, preserves all other transaction order, and evaluates every pair of reinsertion positions under both pair orders using the full simulator cost.
4. This exactly finds the best schedule in this destroy-and-repair neighborhood, including cases where the two transactions must cross different conflict boundaries together.
5. Pair repair is deliberately used instead of a three-transaction greedy repair: it is exhaustive but remains computationally bounded at O(n²) simulator evaluations per restart, making it practical before the existing VND descent.

The repair seeds and restart positions are retained, so this strengthens the current escape mechanism without replacing the effective beam search or local neighborhoods.

    def destroy_and_repair(sequence, start, length):
        """
        Exactly reinsert a small removed region while preserving the order of
        all residual transactions.  For a pair, every combination of final
        insertion positions is scored as a complete schedule; this avoids the
        misleading partial-cost commitment made by sequential greedy repair.
        """
        removed = sequence[start:start + length]
        residual = sequence[:start] + sequence[start + length:]

        # Pair removal is intentionally exhaustive.  It can move two coupled
        # transactions independently or reverse them, while still being only
        # quadratic in the number of transactions.
        if length == 2:
            best_value = None
            best_sequence = None
            insertion_orders = [removed, [removed[1], removed[0]]]

            for first_txn, second_txn in insertion_orders:
                for first_position in range(len(residual) + 1):
                    partially_repaired = (
                        residual[:first_position] +
                        [first_txn] +
                        residual[first_position:]
                    )
                    for second_position in range(len(partially_repaired) + 1):
                        candidate = (
                            partially_repaired[:second_position] +
                            [second_txn] +
                            partially_repaired[second_position:]
                        )
                        value = sequence_cost(candidate)
                        if best_value is None or value < best_value:
                            best_value = value
                            best_sequence = candidate

            return best_value, best_sequence

        # one-path greedy insertion, alternatives that are temporarily worse
        # can survive until the remaining coupled transactions are inserted.
