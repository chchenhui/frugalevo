<DESCRIPTION>
Add a contiguous two-transaction block relocation neighborhood to the existing exact-cost local search.

1. The current relocation move can only move one transaction at a time. Some conflict reductions require two adjacent transactions to move together: moving either transaction individually can retain the same dependency delay, while moving their ordered pair before/after another transaction removes the delay.
2. The new move removes every adjacent pair and reinserts it at every other valid position. Every candidate is evaluated through the existing cached authoritative `cost()` function, so decisions directly optimize simulator makespan rather than surrogate transaction statistics.
3. When ordinary relocation stagnates, compare the best swap and best block relocation. Select the strictly best improving move, then allow subsequent relocation passes to exploit the newly reached ordering basin.
4. The move preserves schedule validity because it only removes and reinserts existing transaction IDs, maintaining a complete permutation.

This is a bounded variable-neighborhood descent that broadens the search without replacing the effective greedy construction and single-relocation optimization already present.
</DESCRIPTION>

    def best_block_relocation(schedule, current_cost):
        """
        Move an adjacent pair as one ordered block.  This reaches schedules
        that require two cooperating transactions to cross another transaction
        together, which neither a strict single relocation nor a swap need
        expose as an improving intermediate move.
        """
        best_value = current_cost
        best_order = schedule

        for source in range(n - 1):
            block = schedule[source:source + 2]
            reduced = schedule[:source] + schedule[source + 2:]

            for destination in range(n - 1):
                # This insertion position recreates the original order.
                if destination == source:
                    continue

                candidate = reduced[:destination] + block + reduced[destination:]
                candidate_cost = cost(candidate)
                if candidate_cost < best_value:
                    best_value = candidate_cost
                    best_order = candidate

        return best_value, best_order
