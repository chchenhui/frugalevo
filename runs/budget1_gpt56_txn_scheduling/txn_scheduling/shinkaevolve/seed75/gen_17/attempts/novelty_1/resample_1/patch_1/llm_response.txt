<DESCRIPTION>
The beam search already produces several complete, conflict-aware candidate schedules, but the current code discards every final beam member except the single lexicographically first minimum-cost result before local search. This can miss better local minima because schedules with equal or near-equal prefix cost can have substantially different downstream conflict critical paths.

This edit adds a cached simulator-cost wrapper and performs the existing exact variable-neighborhood descent from several elite final beam schedules rather than only one. The simulator remains the sole scheduling objective: every relocation, swap, and block move is evaluated using actual makespan. Caching avoids repeated simulator calls when local-search neighborhoods overlap across elite candidates. The best locally optimized elite schedule is returned.

        Reach a local optimum from one complete beam member using exact
        makespan evaluations.  Different beam members can expose different
        conflict-chain basins even when their initial costs are tied.
        """
        best_cost = initial_cost
        best_schedule = list(initial_schedule)

        while True:
            next_cost = best_cost
            next_schedule = None

            # Search the complete one-transaction relocation neighborhood.
            for source in range(num_txns):
                txn = best_schedule[source]
                without_txn = best_schedule[:source] + best_schedule[source + 1:]
                for destination in range(num_txns):
                    if destination == source:
                        continue
                    candidate = (
                        without_txn[:destination]
                        + [txn]
                        + without_txn[destination:]
