<DESCRIPTION>
The current greedy assigns each model to the GPU with the lowest current KVPR, but never refines the result. Adding a local-search pass that repeatedly moves a model off the GPU with maximum KVPR to another GPU (when it strictly lowers the max KVPR) directly reduces the objective. This is the same refinement that helped the second prior program reach a higher score (21.52 vs 20.89 max_kvpr), and it is deterministic, fast, and keeps the same feasibility guarantees (moves only allowed when the model fits in the destination GPU's remaining memory).
