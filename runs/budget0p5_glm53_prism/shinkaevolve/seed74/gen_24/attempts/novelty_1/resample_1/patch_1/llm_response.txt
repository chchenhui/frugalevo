<DESCRIPTION>
The current algorithm is deterministic: models are sorted by density r/s descending, with ties and near-ties broken arbitrarily by Python's stable sort. First-fit-style greedy placement is highly order-sensitive, so different orderings of near-equal-density models can lead to different local optima after refinement. Since execution time is 0.00s, we can afford to run the entire greedy + local-search pipeline multiple times (e.g., 30 restarts) with small random perturbations to the sort key (±2% jitter), keeping the placement with the lowest final max KVPR. This Las Vegas restart scheme can only improve (never degrade) the final result, since we always keep the best-scoring assignment found. Each candidate uses the same crash-proof placement path, so feasibility is preserved.
