<DESCRIPTION>
The current greedy assigns each model to the GPU with the lowest *current* KVPR, which ignores how the assignment changes the ratio. A better greedy places each model on the GPU where the resulting KVPR (after adding the model's r/s and subtracting its size) is minimized. This directly targets the objective — minimizing the max KVPR — and balances load across memory and request pressure simultaneously.
