<DESCRIPTION>
The current local search only tries to relocate models from the single hottest GPU. This can get stuck: sometimes the max KVPR can only be reduced by moving a model between two non-hottest GPUs (e.g., moving load from the 2nd-hottest GPU into the coolest one lowers the second-highest value after a subsequent move). I add an extra refinement pass that considers ALL (src, model, dst) pairs and accepts any move that strictly lowers the global maximum KVPR, running after the hottest-GPU passes converge. I also increase the multistart count and widen the jitter range for more diverse orderings. These changes are safe (crash-free, only accept strict improvements) and keep runtime tiny.
</DESCRIPTION>
