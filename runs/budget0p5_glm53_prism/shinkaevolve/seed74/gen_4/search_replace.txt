<DESCRIPTION>
Two improvements: (1) when assigning each model, choose the GPU that minimizes the KVPR *after* placing the model (not before), which is the correct greedy criterion; (2) after the greedy pass, run a simple local-search refinement that tries moving a model from the max-KVPR GPU to another GPU when it reduces the max KVPR, without violating memory. This typically lowers the maximum KVPR across GPUs.

        den = GPU_MEM_SIZE - sum(m.model_size for m in placement[gpu_id])
        if den <= 0:
            return float('inf')

    for _ in range(50):
        kvs = [gpu_kvpr(g) for g in range(gpu_num)]
        src = max(range(gpu_num), key=lambda g: kvs[g])
        cur_max = max(kvs)
        improved = False
        # try moving one model from src to any other GPU
        for model in placement[src]:
            w = model.req_rate / model.slo
            for dst in range(gpu_num):
