<DESCRIPTION>
Two improvements inspired by the analysis of prior generations:

1. **Restore swap moves in the local search.** The prior generation that included move+swap refinement (Gen 3, score 25.96) outperformed the current move-only version (25.71). Swaps let the search escape configurations where the hottest GPU's models are all too large to move but can be exchanged with smaller models on other GPUs.

2. **Add a worst-pair rebalancing pass before the local search.** As recommended, run a bounded (200-iteration) pass that simultaneously targets the two highest-KVPR GPUs: for each model on the top GPU, try (a) moving it to any GPU, and (b) swapping it with any model on the second-highest GPU, accepting any strict decrease in the global max KVPR. This greedy family was previously the strongest refinement, and combining it with the binary-search packing core (which greedy never had) should yield the best of both.

The pass is guarded for gpu_num < 2 and infinite KVPR states, and all acceptance criteria ensure strict max-KVPR decrease so it terminates and never worsens the solution.

    def try_move(m, i, j):
        """Move model m from GPU i to GPU j if it strictly lowers max KVPR."""
        w = m.req_rate / m.slo
        s = m.model_size
        if s > GPU_MEM_SIZE - used[j]:
            return False
        n1 = safe_ratio(W[i] - w, used[i] - s)
        n2 = safe_ratio(W[j] + w, used[j] + s)
        if gpu_num > 2:
            others = max(kvpr(k) for k in range(gpu_num)
                         if k != i and k != j)
            nmax = max(n1, n2, others)
        else:
            nmax = max(n1, n2)
        cur = max(kvpr(k) for k in range(gpu_num))
        if nmax < cur - 1e-12:
            placement[i].remove(m)
            placement[j].append(m)
            W[i] -= w
            used[i] -= s
            W[j] += w
            used[j] += s
            return True
        return False

    def try_swap(m1, i, m2, j):
