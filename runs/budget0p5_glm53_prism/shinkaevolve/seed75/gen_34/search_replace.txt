<DESCRIPTION>
Add a bounded 3-way cyclic rotation as a fourth candidate operator in the local search scan. Moves and swaps can't escape optima where hot must receive a model from B while a model on hot goes to A and one from A goes to B. After the move/swap/swap2 scans, if no op was found (to keep runtime bounded), try rotations: for each model on hot, each destination A, each model on A, each destination B, and each model on B that fits hot's freed space. Compute the three affected GPUs' new KVPRs and accept the best strict improvement. Apply atomically with symmetric load/free_mem updates.
</DESCRIPTION>
