<DESCRIPTION>
Add a randomized multi-restart wrapper around the greedy + local-search placement. For each restart, use a small random tie-break/tax on GPU selection (seeded via a provided rng) so different restarts explore different placements, then keep the best (lowest max KVPR) result. This diversifies beyond the deterministic greedy, which can get stuck in lockstep, while remaining simple and fast. The seeded random tax on the candidate GPU's KVPR perturbs tie-breaks among near-equal candidates. Only accept a restart's result if it improves the best max KVPR found so far. A fallback deterministic run is included so the algorithm always returns a valid placement.</DESCRIPTION>
