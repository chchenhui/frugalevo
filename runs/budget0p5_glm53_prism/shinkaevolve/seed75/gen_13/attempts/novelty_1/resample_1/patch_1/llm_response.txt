<DESCRIPTION>
The current greedy assigns each model to the GPU with the lowest current load/free-mem ratio, but the correct objective is the resulting KVPR after placement: (load + w) / (GPU_MEM_SIZE - (free - size)). Selecting the GPU that directly minimizes the post-placement KVPR gives a strictly better greedy. On top of that, add a local-search pass that repeatedly moves a model off the GPU with maximum KVPR to another GPU whenever it reduces the global maximum KVPR. This mimics the well-known "minimize makespan via LPT + local improvement" strategy: greedy seeding plus move-based refinement drives the maximum KVPR down toward the optimal balanced partition.

    def kvpr_of(load, used_mem):
        denom = GPU_MEM_SIZE - used_mem
        if denom <= 0:
            return float('inf')
        return load / denom

    placement = {gpu_id: [] for gpu_id in range(gpu_num)}
    free_mem = [GPU_MEM_SIZE for _ in range(gpu_num)]  # remaining memory per GPU

    # 3) Assign each model to the GPU minimizing the resulting post-placement KVPR

        load[best_idx] += w

    # 4) Local search: move models off the hottest GPU to reduce max KVPR
    for _ in range(30):
        kvprs = [kvpr_of(load[g], GPU_MEM_SIZE - free_mem[g]) for g in range(gpu_num)]
        hot = max(range(gpu_num), key=lambda g: kvprs[g])
        hot_kvpr = kvprs[hot]
        others = [kvprs[g] for g in range(gpu_num) if g != hot]
        base_others = max(others) if others else 0.0

        best_gain, best_move = 0.0, None
        for model in placement[hot]:
            w = model.req_rate / model.slo
            # source GPU after removal
            new_used = GPU_MEM_SIZE - free_mem[hot] - model.model_size
            src_kvpr = kvpr_of(load[hot] - w, new_used) if new_used > 0 else 0.0
            for g in range(gpu_num):

                    continue
                dst_kvpr = kvpr_of(load[g] + w,
                                   GPU_MEM_SIZE - free_mem[g] + model.model_size)
                new_max = max(base_others, src_kvpr, dst_kvpr)
                gain = hot_kvpr - new_max
                if gain > best_gain:
                    best_gain = gain
                    best_move = (model, g)

        load[hot] -= w
        free_mem[hot] += model.model_size
        load[dst] += w
        free_mem[dst] -= model.model_size
