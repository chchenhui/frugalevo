The current greedy places each model on the GPU with the lowest current load ratio, ignoring the memory the model will consume — this yields poor KVPR. Replace with a best-fit greedy that directly evaluates the resulting KVPR after placement, plus a local-search refinement that moves models off the worst GPU when it lowers the global max KVPR. This matches the previously best-performing program (score 1.00 on max_kvpr).
