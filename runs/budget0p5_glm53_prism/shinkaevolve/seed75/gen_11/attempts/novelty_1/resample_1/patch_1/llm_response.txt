<DESCRIPTION>
The current local search only tries moving a single model from the worst GPU to another GPU. A common bottleneck is that pairwise swaps between the worst GPU and another GPU can reduce max KVPR when no single move fits or helps. I add a swap phase: after the move phase stalls, try swapping each model on the worst GPU with each model on another GPU, and accept if the new max KVPR decreases.
