<DESCRIPTION>
Instead of greedily choosing the GPU with the lowest current KVPR, choose the GPU where placing the model would result in the lowest resulting KVPR (the actual objective). This directly targets minimizing the maximum KVPR: for each model (sorted by r/s descending), we evaluate the post-placement KVPR of each candidate GPU and pick the minimum, which balances memory usage and request pressure better than the current heuristic that ignores the model's own contribution.
