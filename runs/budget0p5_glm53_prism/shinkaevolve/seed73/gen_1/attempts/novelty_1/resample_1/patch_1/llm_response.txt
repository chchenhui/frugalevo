</DESCRIPTION>
The current greedy places each model on the GPU with the *current* lowest KVPR, which ignores how the new model changes each GPU's pressure. A better rule: for each candidate GPU that fits the model, compute the KVPR *after* placing the model there, and pick the GPU minimizing that resulting value. Additionally, after the greedy pass, run a simple local search (move a model to another GPU if it lowers the global max KVPR) to further reduce the maximum KVPR. This keeps the algorithm simple while directly targeting the objective.
