<DESCRIPTION>
The current greedy assigns each model to the GPU with the lowest resulting KVPR, but it ignores the global objective: minimizing the maximum KVPR across GPUs. Two improvements: (1) when choosing a GPU, consider the resulting global max KVPR (i.e., prefer a GPU whose new KVPR stays below the current max if possible, otherwise pick the one minimizing the new KVPR) — equivalently always pick the GPU minimizing the resulting KVPR but never exceed the current max unnecessarily; (2) add a lightweight post-placement local search that repeatedly moves a model from the worst-KVPR GPU to another GPU whenever it strictly lowers the global maximum KVPR, which fixes greedy mistakes. This keeps runtime tiny while reducing the peak KVPR.
