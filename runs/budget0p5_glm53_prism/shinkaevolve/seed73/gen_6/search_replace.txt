<DESCRIPTION>
The current greedy assigns each model to the GPU with the lowest *current* KVPR, ignoring how the new model itself changes that GPU's KVPR. A better greedy picks the GPU that minimizes the KVPR *after* placing the model (i.e., (W + r/s)/(mem - s)). Also, models that don't fit should be allowed on any GPU with enough memory; if none fit we keep the error. Additionally, a small improvement: tie-break by preferring the fuller GPU to reduce fragmentation.
</DESCRIPTION>
