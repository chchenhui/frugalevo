<DESCRIPTION>
Replace the round-robin single-model move (which wastes rounds moving from random hot GPUs to random destinations) with a targeted perturbation: pick the highest-KVPR GPU with probability 0.8, relocate its highest req_rate/slo model to the destination yielding the lowest post-placement max KVPR (rather than first-improvement). This targets the bottleneck directly and explores better destinations per round.

    import random as _random

    for _round in range(30):
        improved = False
        best_max = max_kvpr()

        # Move 1: targeted relocation from the hottest GPU(s).
        # With prob 0.8 pick THE hottest GPU; otherwise a random one.
        # Relocate its highest req_rate/slo model to the destination
        # minimizing the resulting max KVPR (best-improvement).
        kvs = [gpu_kvpr(g) for g in range(gpu_num)]
        src = max(range(gpu_num), key=lambda g: kvs[g])
        if _random.random() > 0.8:
            src = _random.randrange(gpu_num)
        if placement[src]:
            # order models on src by weight desc: try to offload the heaviest first
            positions = sorted(
                range(len(placement[src])),
                key=lambda p: -(placement[src][p][1].req_rate / placement[src][p][1].slo),
            )
            best_found = None  # (new_max, pos, dst, item)

                idx, model = placement[src][pos]
