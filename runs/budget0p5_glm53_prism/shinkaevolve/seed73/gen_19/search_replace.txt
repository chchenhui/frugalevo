<DESCRIPTION>
Two targeted improvements: (1) The local-search `refine` only considers moving a model off the hottest GPU; when all moves fail, it can still often improve via a swap between the hottest GPU and another GPU (exchanging models with different load/size can lower the hot KVPR when no model alone fits elsewhere). I add a swap phase to `refine`. (2) The ILS perturbation currently relocates a single random model; a stronger perturbation (1–3 random relocations) helps escape local optima that single moves cannot, and since runtime is essentially free (0.01s), more aggressive restarts are affordable. Both changes keep determinism via the fixed RNG seed.</DESCRIPTION>
