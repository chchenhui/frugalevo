greedy-resulting-kvpr

<DESCRIPTION>
The current algorithm picks the GPU with the lowest current KVPR, which doesn't account for how much the new model will increase the KVPR or how much memory it consumes. A better greedy choice: for each model, compute the resulting KVPR if placed on each candidate GPU, i.e. (current_weighted + r_j/s_j) / (remaining_mem - s_j), and pick the minimum. This directly minimizes the incremental increase in the max KVPR per step and typically yields lower final max KVPR.
