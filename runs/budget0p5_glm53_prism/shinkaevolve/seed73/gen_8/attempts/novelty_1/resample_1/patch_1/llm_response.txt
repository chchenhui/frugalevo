<DESCRIPTION>
The greedy assignment can leave the max-KVPR GPU unbalanced. Add a local search phase after greedy: repeatedly try moving a model from the GPU with highest KVPR to another GPU (if it fits) whenever it reduces the max KVPR across all GPUs. This directly targets the objective, minimizing the maximum KVPR, and is cheap since problem sizes are small.

        # second highest KVPR (that would become the max after reducing `worst`)
        other_kvprs = [kvpr(g) for g in range(gpu_num) if g != worst]
        second_kvpr = max(other_kvprs) if other_kvprs else 0.0

        best_move = None
        best_new_max = worst_kvpr
        for model in placement[worst]:
            req_per_slo = model.req_rate / model.slo
            src_after = (weighted_req_rate[worst] - req_per_slo) / (shared_kv[worst] + model.model_size)
            for dst in range(gpu_num):
