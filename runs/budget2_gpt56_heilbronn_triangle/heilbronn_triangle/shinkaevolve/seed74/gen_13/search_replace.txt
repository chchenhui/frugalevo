<DESCRIPTION>
Replace purely minimum-area Metropolis decisions with a lower-tail soft-min energy. The raw minimum is highly nonsmooth: moving a point often improves one active triangle only to expose another nearly active triangle, so a move can be rejected despite improving the local bottleneck structure. A soft-min energy simultaneously penalizes all small-area triples, providing a substantially smoother continuation objective early in the search, while cooling it toward the true minimum-area objective near the end. The returned incumbent is still selected exclusively by the exact minimum normalized area.

The same change also makes proposal selection consider all triangles in the lower tail rather than only the single worst triple, avoiding repeated attempts to move a point when a cluster of nearly tied constraints is responsible.
</DESCRIPTION>

        interior_bary = rng.dirichlet((1.15, 1.15, 1.15), size=8)
        current = np.vstack((vertices, interior_bary[:, 1:]))
        current_areas, current_score = areas_and_score(current)

        # The exact minimum is discontinuous whenever the active triple
        # changes.  This exponentially weighted lower-tail energy is a smooth
        # surrogate which converges to the minimum as its scale is cooled.
        def tail_energy(areas: np.ndarray, scale: float) -> float:
            shifted = areas - float(np.min(areas))
            return float(np.min(areas) - scale * np.log(np.mean(np.exp(-shifted / scale))))
