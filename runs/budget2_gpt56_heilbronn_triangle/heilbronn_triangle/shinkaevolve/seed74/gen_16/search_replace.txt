adaptive_tail_merit
</NAME>

<DESCRIPTION>
Make the annealing merit adaptive across the search horizon. Early iterations use a broad low-area tail, which rewards globally robust spacing and helps escape order types with many nearly-collinear triples. Late iterations use only the tightest constraints and substantially reduce the smoothing contribution, so acceptance increasingly follows the true maximin objective. The current state merit is recomputed at the current phase before each comparison, avoiding comparisons between scores defined with different tail widths.
</DESCRIPTION>

    def merit(p: np.ndarray, phase: float = 1.0) -> tuple[float, float]:
        values = np.abs(determinants(p))
        minimum = float(values.min())

        # Broad low-tail smoothing is valuable while selecting a promising
        # order type, but near convergence it must not obscure the actual
        # bottleneck determinant.  Interpolate both tail width and weight.
        early_count, late_count = 32, 8
        count = int(round(early_count + (late_count - early_count) * phase))
        tail = np.partition(values, count - 1)[:count]
        tail_weight = 0.040 * (1.0 - phase) + 0.012 * phase
        return minimum, minimum + tail_weight * float(tail.mean())

retain_feasible_slsqp_iterates
</NAME>

<DESCRIPTION>
SLSQP frequently reports a non-success status near a degenerate active-set solution even when its final iterate is feasible and improves the actual absolute-determinant objective. Rather than immediately discarding such an iterate, validate it directly against simplex membership and the true min-area score. This is especially useful in Heilbronn optimization because sign-pattern changes and nearly coincident active constraints can trigger conservative SLSQP termination statuses.
</DESCRIPTION>
