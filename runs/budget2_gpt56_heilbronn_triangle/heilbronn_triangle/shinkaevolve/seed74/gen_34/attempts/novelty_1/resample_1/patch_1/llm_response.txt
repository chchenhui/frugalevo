<DESCRIPTION>
Replace the single log-sum-exp acceptance objective with a phase-dependent composite lower-tail merit. Early annealing should reward configurations with a broadly improved set of the lowest determinant constraints, rather than allowing a temporary improvement in only one triangle to dominate. As cooling progresses, the merit transitions toward the exact minimum and a narrower tail, which is the appropriate regime for equalizing the active constraints of a near-optimal Heilbronn configuration. This directly implements the recommended broad-to-narrow lower-tail guidance while retaining exact-minimum selection for the final returned arrangement.
</DESCRIPTION>

    def annealing_merit(value: np.ndarray, progress: float) -> float:
        """
        During basin discovery reward a healthy broad lower tail; near the
        end concentrate on the genuinely active constraints.  This is less
        brittle than optimizing either the raw minimum or log-sum-exp alone.
        """
        minimum = float(value.min())
        count = max(10, min(len(value), int(round(30.0 - 20.0 * progress))))
        low = np.partition(value, count - 1)[:count]
        tail_mean = float(low.mean())

        scale = 0.0090 * (1.0 - progress) ** 1.25 + 0.00030
        shifted = (low - minimum) / scale
        soft_min = minimum - scale * np.log(np.exp(-shifted).mean())

        tail_weight = 0.60 * (1.0 - progress) ** 1.45 + 0.08
        return float(
            (1.0 - tail_weight) * minimum
            + tail_weight * (0.55 * tail_mean + 0.45 * soft_min)
        )
