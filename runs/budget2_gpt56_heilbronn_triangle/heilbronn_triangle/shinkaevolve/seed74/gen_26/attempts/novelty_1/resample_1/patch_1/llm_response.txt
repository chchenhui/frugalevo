<DESCRIPTION>
Replace the final single-worst-triangle coordinate polish with a deterministic active-set refinement. Heilbronn optima are governed by several nearly tied triangle constraints, so moving only points of one arbitrarily selected minimum triangle often stalls immediately. The new polish considers all near-active triples, generates axial, simplex-diagonal, partner-centroid, and boundary-tangent directions, and performs a short deterministic line search at several displacement lengths. This is particularly useful near simplex boundaries, where projection changes the effective direction of a move. Candidates are still accepted only on a strict improvement of the true minimum area, preserving the primary objective exactly.
</DESCRIPTION>

    # Deterministic active-set polishing.  Near an optimum several triples,
    # rather than only the single numerically smallest one, are normally
    # active.  A short line search also avoids losing useful directions when
    # projection onto a nearby simplex edge distorts a fixed-size move.
    for step in (0.012, 0.006, 0.003, 0.0015, 0.0007, 0.0003):
        improved = True
        passes = 0
        while improved and passes < 18:
            improved = False
            passes += 1
            areas, score = areas_and_score(best)
            active = triples[areas <= score + max(2.5e-6, 0.18 * step)]

            # Keep a stable point order while collecting every movable point
            # occurring in the current lower-tail constraints.
            indices = []
            for triple in active:
                for index in triple:
                    if index >= 3 and index not in indices:
                        indices.append(int(index))

            for index in indices:
                directions = [
                    np.array((1.0, 0.0)), np.array((-1.0, 0.0)),
                    np.array((0.0, 1.0)), np.array((0.0, -1.0)),
                    np.array((1.0, -1.0)), np.array((-1.0, 1.0)),
                ]

                # For each active constraint containing this point, the line
                # through its two partners supplies a geometry-aware normal.
                for triple in active:
                    if index not in triple:
                        continue
                    partners = [int(q) for q in triple if q != index]
                    midpoint = 0.5 * (best[partners[0]] + best[partners[1]])
                    direction = midpoint - best[index]
                    length = float(np.linalg.norm(direction))
                    if length > 1.0e-12:
                        direction /= length
                        directions.extend((direction, -direction))

                p = best[index]
                # Explicit tangential moves prevent boundary points from being
                # restricted to an inward radial displacement by projection.
                if p[0] < 2.0 * step:
                    directions.extend((np.array((0.0, 1.0)), np.array((0.0, -1.0))))
                if p[1] < 2.0 * step:
                    directions.extend((np.array((1.0, 0.0)), np.array((-1.0, 0.0))))
                if 1.0 - p.sum() < 2.0 * step:
                    directions.extend((np.array((1.0, -1.0)), np.array((-1.0, 1.0))))

                for direction in directions:
                    for length in (0.5 * step, step, 1.5 * step, 2.0 * step):
                        candidate = best.copy()
                        candidate[index] = normalize_simplex(
                            candidate[index] + length * direction
                        )
                        _, candidate_score = areas_and_score(candidate)
                        if candidate_score > best_score + 1.0e-13:
                            best = candidate
                            best_score = candidate_score
                            improved = True
