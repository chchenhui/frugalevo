<DESCRIPTION>
Add a deterministic, boundary-aware active-set line search immediately before the signed epigraph solve. Differential evolution often identifies the correct orientation cell but leaves several nearly active triangle constraints slightly unbalanced. A short greedy refinement over axial, diagonal, partner-centroid, and simplex-edge tangent directions can improve that balance without the cost or noise of another global search.

The refinement only accepts moves preserving the true minimum area up to numerical tolerance, using the low-area tail as a secondary criterion. It therefore cannot degrade the returned configuration, while providing SLSQP with a better-conditioned point in the same oriented-matroid cell. Edge tangents are explicitly included when points are near a simplex boundary, where ordinary projected displacements can be strongly distorted.

        # because differential evolution usually finds the right orientation
        # cell but not the narrow intersection where its active areas equalize.
        def tail_rank(p: np.ndarray) -> tuple[float, float]:
            values = np.abs(determinants(p))
            low = np.partition(values, 11)[:12]
            return float(low[0]), float(low.mean())
