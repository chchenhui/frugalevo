<DESCRIPTION>
Add two deterministic near-boundary initialization islands while retaining the existing fully interior Dirichlet population and the structured grid seeds. In normalized barycentric coordinates, strong Heilbronn layouts often have useful hull/near-edge structure, but putting several points exactly on a side creates zero-area collinear triples. The new islands therefore set one randomly selected barycentric weight of each movable point to a small strictly positive value, keeping every movable point inside the simplex.

One island is predominantly near-edge, and another is mixed interior/near-edge. This broadens the explored combinatorial families without changing feasibility, the objective, or the later evolutionary and polishing mechanisms. The original random population remains present, so this only adds structured diversity rather than committing the search to a boundary-heavy family.
</DESCRIPTION>

    # Initialization mixes broad interior samples with strictly interior
    # near-boundary islands.  Boundary-adjacent structure is often useful in
    # small Heilbronn configurations, but exact side points would introduce
    # collinear triples.  Each island point instead has one barycentric weight
    # made small and positive, so all movable points remain in the simplex
    # interior under the common representation used by later search stages.
    weights = rng.dirichlet((0.9, 0.9, 0.9), size=(population_size, n))
    population = weights[..., 1:].copy()
    population[:, :free_start] = corners

    def near_edge_weights(count: int) -> np.ndarray:
        """Draw simplex weights with a randomly chosen positive small weight."""
        result = rng.dirichlet((0.9, 0.9, 0.9), size=(count, free_count))
        edge_ids = rng.integers(0, 3, size=(count, free_count))
        gap = rng.uniform(0.004, 0.075, size=(count, free_count))
        old = np.take_along_axis(result, edge_ids[..., None], axis=2)
        result *= ((1.0 - gap)[..., None] / np.maximum(1.0 - old, 1.0e-12))
        np.put_along_axis(result, edge_ids[..., None], gap[..., None], axis=2)
        return result

    # One island samples perimeter-like configurations; a second preserves
    # mixed layouts in which only some points provide near-edge structure.
    boundary_island = near_edge_weights(24)
    population[12:36, free_start:] = boundary_island[..., 1:]

    mixed_island = rng.dirichlet((0.9, 0.9, 0.9), size=(24, free_count))
    mixed_boundary = near_edge_weights(24)
    mixed_mask = rng.random((24, free_count)) < 0.48
    mixed_island = np.where(
        mixed_mask[..., None], mixed_boundary, mixed_island
    )
