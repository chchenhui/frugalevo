<DESCRIPTION>
Introduce a staged selection objective for the evolutionary phase. The exact minimum-area objective is highly nonsmooth: most mutations are rejected because they do not immediately improve the single active triangle. During the exploratory phase, a stable soft minimum rewards layouts that improve several nearly-active triangle constraints simultaneously. The final phase returns to exact maximin selection, preserving direct optimization of the benchmark metric.

The elite pool, mutation scale, crossover rate, and restart noise are also staged: early generations retain diversity and make larger coordinated moves; later generations use a much smaller elite pool and more conservative changes to polish a promising basin. The incumbent is still always tracked using the exact normalized minimum area.
</DESCRIPTION>

    def soft_score(configurations: np.ndarray, temperature: float) -> np.ndarray:
        """
        Stable soft minimum of normalized determinants.

        This is used only while exploring: it distinguishes layouts having the
        same active minimum by rewarding improvement of nearby constraints.
        """
        a = configurations[:, triples[:, 0]]
        b = configurations[:, triples[:, 1]]
        c = configurations[:, triples[:, 2]]
        det = np.abs(
            (b[:, :, 0] - a[:, :, 0]) * (c[:, :, 1] - a[:, :, 1])
            - (b[:, :, 1] - a[:, :, 1]) * (c[:, :, 0] - a[:, :, 0])
        )
        lo = det.min(axis=1)
        return lo - temperature * np.log(
            np.exp(-(det - lo[:, None]) / temperature).sum(axis=1)
        )
