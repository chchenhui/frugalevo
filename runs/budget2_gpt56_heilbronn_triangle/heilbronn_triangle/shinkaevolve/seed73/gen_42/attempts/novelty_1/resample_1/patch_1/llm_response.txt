<DESCRIPTION>
Strengthen the deterministic local phase rather than spending additional time on broad random search.  Maximin configurations commonly lie on plateaus: a one-coordinate LP move can preserve the current minimum area while increasing the next several nearly-active areas, thereby enabling a later coordinate move to improve the true minimum.  The current code rejects all such moves and uses a random coordinate order.

This edit accepts objectively neutral coordinate moves only when the existing lower-tail surrogate improves, so the exact objective cannot materially regress while plateaus are traversed monotonically.  It also prioritizes free points which occur most often among the current fifteen smallest triangles, directly attacking the active constraint set.  More coordinate passes allow these plateau transitions to propagate through the configuration.
</DESCRIPTION>
