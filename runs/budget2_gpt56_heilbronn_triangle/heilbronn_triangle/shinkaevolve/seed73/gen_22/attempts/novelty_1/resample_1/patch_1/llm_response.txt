<DESCRIPTION>
Replace the nearly-zero fixed tail reward with an annealed low-tail objective. Early generations receive a meaningful reward for improving the eight smallest triangle areas, which discourages fragile configurations dominated by many nearly-degenerate triples and helps escape poor maximin basins. The reward then decays to a small tie-breaking term, so the latter part of the search is focused on the actual minimum-area metric. Rankings are recomputed under the current coefficient each generation, avoiding comparison of stale scores produced with different objectives.
</DESCRIPTION>

    def quality(configurations: np.ndarray, tail_weight: float) -> np.ndarray:
        selected = configurations[:, triples]
        vectors1 = selected[:, :, 1] - selected[:, :, 0]
        vectors2 = selected[:, :, 2] - selected[:, :, 0]
        areas = np.abs(vectors1[..., 0] * vectors2[..., 1]
                       - vectors1[..., 1] * vectors2[..., 0])
        ordered = np.partition(areas, 7, axis=1)[:, :8]
        # A low-tail reward initially provides a smoother search signal and
        # prevents clusters of almost-active degenerate triples.  It is
        # annealed later, leaving the true bottleneck dominant at convergence.
        return ordered[:, 0] + tail_weight * ordered.mean(axis=1)
