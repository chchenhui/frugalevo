<DESCRIPTION>
Replace periodic weak-trajectory cloning with conservative pointwise elite recombination. Heilbronn configurations have no intrinsic labels on the eight movable points, so independently inheriting point locations from two strong but distinct elite layouts can combine complementary locally successful placements. A small fraction of convex barycentric blends adds controlled interpolation without the destructive effects of full-layout crossover. The existing annealed noise and simplex projection preserve feasibility and continue basin exploration.
</DESCRIPTION>

            # Periodically rebuild weak trajectories from several elite
            # basins.  Since movable-point labels have no geometric meaning,
            # pointwise inheritance can preserve complementary successful
            # placements from two different maximin layouts.
            if step % 160 == 159 and step < 2700:
                now = areas(pop).min(axis=1)
                order = np.argsort(now)[::-1]
                weak = order[-14:]
                sources = order[:10]
                first = sources[np.arange(len(weak)) % len(sources)]
                second_parent = sources[rng.integers(len(sources), size=len(weak))]

                pop[weak] = pop[first]
                inherit_second = rng.random((len(weak), n - 3, 1)) < 0.42
                pop[weak, 3:] = np.where(
                    inherit_second, pop[second_parent, 3:], pop[weak, 3:]
                )

                # A few coordinatewise blends explore between compatible
                # elite placements while retaining mostly exact inheritance.
                blend = rng.random((len(weak), n - 3, 1)) < 0.18

                         + fraction * pop[second_parent, 3:])
