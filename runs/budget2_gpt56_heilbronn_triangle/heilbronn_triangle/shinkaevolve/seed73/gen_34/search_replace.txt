<DESCRIPTION>
Reserve a late-search offspring class for constraints that actually limit the current configuration. The existing mutation perturbs every coordinate of every candidate, which is useful for broad exploration but becomes inefficient after the population has found a reasonably structured arrangement. During the final third of each island search, this edit identifies the twelve smallest-area triples of selected parent configurations, finds the non-vertex points participating in those triples, and applies a substantially smaller perturbation only to those points. This directly targets the active constraints responsible for the current minimum area while retaining the original differential and full-coordinate Gaussian mutations for the majority of candidates.
</DESCRIPTION>

                # Near convergence, reserve some offspring for an active-set
                # local search.  The points occurring in the currently
                # smallest triples are precisely those whose displacement can
                # raise the max-min objective.  Other offspring retain the
                # unbiased, full-dimensional mutation needed for exploration.
                noise = rng.normal(0.0, sigma, trial.shape)
                targeted_rows = (
                    (frac > 0.64)
                    & (rng.random(population_size) < 0.30)
                )
                if np.any(targeted_rows):
                    target_indices = np.flatnonzero(targeted_rows)
                    parent_areas = areas_for(pop[target_indices])
                    limiting = np.argpartition(parent_areas, 11, axis=1)[:, :12]
                    limiting_triples = triples[limiting]
                    movable = np.zeros((len(target_indices), n), dtype=bool)
                    for point in range(3, n):
                        movable[:, point] = np.any(
                            limiting_triples == point, axis=(1, 2)
                        )

                    # Make these candidates true local offspring rather than
                    # allowing an unrelated differential jump to move every
                    # inactive coordinate.  Boundary enforcement below still
                    # restricts boundary slots to their designated faces.
                    trial[target_indices] = pop[target_indices]
                    noise[target_indices] *= movable[:, :, None]
                    noise[target_indices] *= 0.34 + 0.16 * (1.0 - frac)

                trial += noise
                trial = enforce(trial, edge_count)
                trial_score, _ = evaluate(trial, tail_weight)
