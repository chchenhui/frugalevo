<DESCRIPTION>
The evolutionary ranking currently gives a comparatively large bonus to the average of the eight smallest constraints. This can select configurations with a better constraint “tail” but a worse actual minimum triangle area, while the reported metric only evaluates that minimum. Reduce this auxiliary pressure substantially and retain the best configuration using the true minimum determinant rather than the surrogate score. This makes every generation directly aligned with `min_area_normalized`, while the small secondary term still helps break ties and avoid degenerate active-constraint clusters.
</DESCRIPTION>

    def minimum_area(configurations: np.ndarray) -> np.ndarray:
        """Return the true normalized minimum triangle area."""
        selected = configurations[:, triples]
        vectors1 = selected[:, :, 1] - selected[:, :, 0]
        vectors2 = selected[:, :, 2] - selected[:, :, 0]
        areas = np.abs(vectors1[..., 0] * vectors2[..., 1]
                       - vectors1[..., 1] * vectors2[..., 0])
        return areas.min(axis=1)
