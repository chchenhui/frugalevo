annealed_tail_and_recombination

<DESCRIPTION>
Replace the fixed surrogate objective with an annealed low-tail bonus: early generations use the bonus to escape configurations with many nearly-degenerate triples, while late generations increasingly rank candidates by the actual max-min determinant. Track the incumbent using the true minimum area rather than the surrogate, since a configuration with a slightly lower tail average can still be the desired answer.

Add coordinate-wise recombination between independently selected elite parents. In barycentric representation, exchanging individual point locations preserves feasibility and is especially effective here because point labels are immaterial; it combines useful local point patterns discovered by separate elite configurations before mutation refines them.
</DESCRIPTION>

    def quality(configurations: np.ndarray, tail_weight: float) -> np.ndarray:
        areas = areas_of(configurations)
        ordered = np.partition(areas, 7, axis=1)[:, :8]
        # Early on, reward a broad healthy low tail.  This bonus is annealed
        # away so late selection is governed almost entirely by max-min area.
        return ordered[:, 0] + tail_weight * ordered.mean(axis=1)
