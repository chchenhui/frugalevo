<DESCRIPTION>
Replace the purely nonsmooth minimum-area DE objective with a lexicographic lower-tail objective. The true minimum remains the dominant term, while a very small secondary reward for the mean of the twelve smallest determinants encourages configurations with a broad, well-shaped active constraint set rather than a single fragile bottleneck. This is particularly useful before the oriented SLSQP maximin polish: DE can enter a stronger combinatorial basin, while SLSQP still restores the exact maximin solution. The reduced DE iteration budget offsets the slightly more elaborate objective and improves evaluation time.
</DESCRIPTION>

        a = q[triples[:, 0]]
        b = q[triples[:, 1]]
        c = q[triples[:, 2]]
        return float(np.min(np.abs(
            (b[:, 0] - a[:, 0]) * (c[:, 1] - a[:, 1])
            - (b[:, 1] - a[:, 1]) * (c[:, 0] - a[:, 0])
        )))

    def lower_tail_score(q: np.ndarray) -> float:
        """
        Lexicographic surrogate for global exploration.

        The minimum determinant is the primary quantity.  The deliberately
        tiny second term only breaks practically equal minimum-area ties in
        favor of configurations whose other near-active triples are also
        large.  Such basins are substantially more amenable to the subsequent
        exact oriented maximin polish than isolated raw-minimum plateaus.
        """
        a = q[triples[:, 0]]
        b = q[triples[:, 1]]
        c = q[triples[:, 2]]
        areas = np.abs(
            (b[:, 0] - a[:, 0]) * (c[:, 1] - a[:, 1])
            - (b[:, 1] - a[:, 1]) * (c[:, 0] - a[:, 0])
        )
        smallest = np.partition(areas, 11)[:12]
        return float(np.min(smallest) + 1.0e-4 * np.mean(smallest))
