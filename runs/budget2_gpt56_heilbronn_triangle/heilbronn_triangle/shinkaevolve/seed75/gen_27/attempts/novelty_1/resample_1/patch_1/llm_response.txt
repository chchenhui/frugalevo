<DESCRIPTION>
Add coordinated active-triple ascent proposals to the differential-evolution population. For each state, the twelve smallest determinants supply signed analytic gradients for every participating free point; their weighted aggregate directly increases the restrictive triangles rather than relying only on random affine DE directions. These proposals are increasingly emphasized late in the search, when identifying and resolving the active constraint set matters most.

Also include the historically best raw-minimum state in the local SLSQP finalist set. The population is selected using a soft lower-tail score, so its final members need not include the best exact maximin state encountered during the evolutionary phase.
</DESCRIPTION>

            # Directly ascend the restrictive determinants for part of the
            # batch.  A raw DE difference is often poorly aligned with the
            # small set of triangles currently limiting a near-optimal
            # configuration.  For each of the twelve smallest triangles,
            # accumulate the analytic gradient of its absolute determinant at
            # each free vertex.  This is a coordinated move: all points in
            # active triples can move together rather than one point being
            # changed in isolation.
            guided = rng.random(pop_size) < (0.16 + 0.22 * ratio)
            if np.any(guided):
                p = np.empty((pop_size, n, 2), dtype=float)
                p[:, :3] = fixed
                p[:, 3:] = population
                lo = np.min(areas, axis=1)
                near = np.argpartition(areas, 12, axis=1)[:, :12]
                gradient = np.zeros_like(population)
                rows = np.arange(pop_size)

                for rank in range(12):
                    ids = near[:, rank]
                    ia, ib, ic = triples[ids, 0], triples[ids, 1], triples[ids, 2]
                    aa, bb, cc = p[rows, ia], p[rows, ib], p[rows, ic]
                    determinant = (
                        (bb[:, 0] - aa[:, 0]) * (cc[:, 1] - aa[:, 1])
                        - (bb[:, 1] - aa[:, 1]) * (cc[:, 0] - aa[:, 0])
                    )
                    # Nearby active constraints receive most of the force,
                    # while retaining several constraints prevents cycling.
                    weight = np.exp(
                        -(areas[rows, ids] - lo) / (3.0 * temperature)
                    ) * np.where(determinant >= 0.0, 1.0, -1.0)

                    derivatives = (
                        np.column_stack((bb[:, 1] - cc[:, 1],
                                         cc[:, 0] - bb[:, 0])),
                        np.column_stack((cc[:, 1] - aa[:, 1],
                                         aa[:, 0] - cc[:, 0])),
                        np.column_stack((aa[:, 1] - bb[:, 1],
                                         bb[:, 0] - aa[:, 0])),
                    )
                    for point_ids, derivative in zip((ia, ib, ic), derivatives):
                        movable = point_ids >= 3
                        if np.any(movable):
                            gradient[

                            ] += weight[movable, None] * derivative[movable]

                scale = np.max(np.linalg.norm(gradient, axis=2), axis=1)
