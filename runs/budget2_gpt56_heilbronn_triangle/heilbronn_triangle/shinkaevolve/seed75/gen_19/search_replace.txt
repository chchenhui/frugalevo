<DESCRIPTION>
Replace the final single-proposal hill climb with batched active-set repair. Near strong Heilbronn configurations, the limiting determinants usually share vertices, so independently perturbing one point rarely improves the strict minimum. This refinement explicitly identifies points participating in the smallest triples and perturbs them jointly, while allowing controlled lower-tail balancing early in the search. It retains the best strictly feasible candidate throughout and remains deterministic under the existing fixed seed.

        # Batched active-set refinement.  At good configurations the limiting
        # triples are coupled, so move their participating points together
        # rather than relying only on isolated one-point perturbations.
        current = best.copy()
        current_value = best_minimum
        current_fitness = float(evaluate(current[None, :, :])[1][0])
        elite = current.copy()
        elite_value = current_value

        refinement_rounds = 900
        batch_size = 32
        for step in range(refinement_rounds):
            progress = step / max(1, refinement_rounds - 1)
            scale = 0.024 * (1.0 - progress) ** 1.35 + 0.00015

            current_areas = areas_batch(current[None, :, :])[0]
            active_count = 12 if progress < 0.68 else 20
            active_ids = np.argpartition(current_areas, active_count - 1)[:active_count]
            active_points = np.unique(triples[active_ids].ravel())
            active_mask = np.zeros(n, dtype=bool)
            active_mask[active_points] = True
            active_size = int(np.sum(active_mask))

            proposals = np.repeat(current[None, :, :], batch_size, axis=0)

            # Some isolated moves address a single poorly placed vertex.
            for q in range(8):
                point_id = int(rng.choice(active_points))
                proposals[q, point_id] += rng.normal(0.0, scale, size=2)

            # Joint repairs give all vertices in the active constraints a
            # coherent displacement plus independent local freedom.
            for q in range(8, batch_size):
                common = rng.normal(0.0, scale * 0.42, size=2)
                local_scale = scale * (0.28 + 0.57 * rng.random())
                proposals[q, active_mask] += common
                proposals[q, active_mask] += rng.normal(
                    0.0, local_scale, size=(active_size, 2)
                )
                if q % 4 == 0:
                    proposals[q] += rng.normal(0.0, scale * 0.09, size=(n, 2))

            proposals = project_to_simplex(proposals)
            candidate_minimum, candidate_fitness = evaluate(proposals)

            candidate = int(np.argmax(candidate_minimum))
            if candidate_minimum[candidate] > elite_value:
                elite_value = float(candidate_minimum[candidate])
                elite = proposals[candidate].copy()

            # Early balancing can escape a layout with one accidental small
            # determinant; the allowable loss vanishes toward the end.
            tolerance = 0.0015 * (1.0 - progress) ** 2
            admissible = candidate_minimum >= current_value - tolerance
            if np.any(admissible):
                adjusted = candidate_fitness.copy()
                adjusted[~admissible] = -np.inf
                chosen = int(np.argmax(adjusted))
                chosen_value = float(candidate_minimum[chosen])
                chosen_fitness = float(candidate_fitness[chosen])
                if (
                    chosen_value > current_value + 1.0e-12
                    or chosen_fitness > current_fitness + 0.00014 * (1.0 - progress)
                ):

                    current_value = chosen_value
                    current_fitness = chosen_fitness
