<DESCRIPTION>
The optimum for the triangular Heilbronn problem can require free points on the boundary. The current positive simplex margin excludes such arrangements and also moves any boundary solution returned by SLSQP back into the interior. Removing that artificial margin enlarges the feasible set without compromising validity.

Additionally, the directed stochastic phase explores several distinct orientation chambers, but only the single best raw layout is passed to the orientation-fixed SLSQP maximin polish. Keep each restart's best-ever layout in a small archive and polish the four strongest archive members. This is particularly valuable because SLSQP can substantially improve a chamber that is slightly weaker before polishing but has a more favorable active-constraint structure.
</DESCRIPTION>
