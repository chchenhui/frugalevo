snake_packing_swap_refinement

</NAME>
<DESCRIPTION>
The current `balanced_packing` uses a purely static snake (boustrophedon) assignment of sorted items to packs. While fast and decent, it ignores the actual accumulated pack loads. I propose adding a vectorized local-search refinement pass after the snake assignment: repeatedly identify (per layer, fully vectorized with gathers/scatters) the most-loaded pack and the least-loaded pack, take the *lightest* item from the heavy pack and the *heaviest* item from the light pack, and swap their (pack, rank) assignments when the swap provably shrinks the max-min load spread (condition: `w_heavy > w_light` and `spread > 2*(w_heavy - w_light)`). Each swap keeps every pack's cardinality intact (required by the algorithm's contract of exactly n/m objects per pack) and preserves the bijection between (pack, rank) slots, so downstream `inverse()` mappings still work.

This hill-climbing refinement directly reduces the per-GPU load spread (improving `balancedness_score_gpu`) while remaining fully vectorized across all layers, so the runtime overhead is a handful of small tensor ops per iteration (bounded, e.g., 64 iterations) — keeping `times_algorithm` low since the algorithm time is dominated by the replication loop. No other function signatures or outputs change.

    # Local-search refinement: swap the lightest item of the most-loaded pack
    # with the heaviest item of the least-loaded pack while it reduces the
    # max-min load spread. Fully vectorized over all layers.
    if num_packs > 1:
        w = weight.float()
        ar = torch.arange(num_layers, device=weight.device)
        inf = float("inf")
        for _ in range(64):
            loads = torch.zeros(num_layers,
                                num_packs,
                                dtype=w.dtype,
                                device=w.device)
            loads.scatter_add_(-1, pack_index, w)
            heavy = loads.argmax(-1, keepdim=True)
            light = loads.argmin(-1, keepdim=True)
            in_heavy = pack_index == heavy
            in_light = pack_index == light
            # lightest item inside the heavy pack
            hi = torch.where(in_heavy, w,
                             torch.full_like(w, inf)).argmin(-1)
            # heaviest item inside the light pack
            lo = torch.where(in_light, w,
                             torch.full_like(w, -inf)).argmax(-1)
            w_hi = w[ar, hi]
            w_lo = w[ar, lo]
            spread = (loads.gather(1, heavy).squeeze(1) -
                      loads.gather(1, light).squeeze(1))
            do_swap = ((w_hi > w_lo) & (spread > 2 * (w_hi - w_lo)) &
                       (heavy != light).squeeze(1))
            if not do_swap.any():
                break
            idx = ar[do_swap]
            a = hi[do_swap]
            b = lo[do_swap]
            pi_a = pack_index[idx, a].clone()
            ri_a = rank_in_pack[idx, a].clone()
            pack_index[idx, a] = pack_index[idx, b]
            rank_in_pack[idx, a] = rank_in_pack[idx, b]
            pack_index[idx, b] = pi_a
            rank_in_pack[idx, b] = ri_a
