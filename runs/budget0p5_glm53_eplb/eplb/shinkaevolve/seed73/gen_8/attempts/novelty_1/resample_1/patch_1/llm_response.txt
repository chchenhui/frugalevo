<DESCRIPTION>
The current GPU-level assignment relies purely on the greedy LPT-style `balanced_packing`, which gives no post-hoc refinement (balancedness_score_gpu is only 0.66). The makespan of a bin-packing solution can typically be improved substantially with a cheap local search: after the greedy assignment, repeatedly identify the most-loaded and least-loaded GPU within each (layer, node) and swap the pair of experts between them that most reduces the load gap while preserving the fixed per-GPU slot count (each GPU must keep exactly `phy_experts_per_gpu` experts, so swaps are the valid move). The search is bounded (a few iterations per row, each O(num_packs * slots²)) and operates on Python lists, so it adds negligible runtime compared to the greedy pass while directly minimizing the max-GPU-load objective that the balancedness score measures. The refined `pack_index`/`rank_in_pack` are then fed into the existing `phy2pphy` computation, so downstream logic is unchanged.

    tokens_per_phy = (tokens_per_mlog / mlogcnt).gather(-1, phy2mlog)
    pack_index, rank_in_pack = balanced_packing(tokens_per_phy,
                                                num_gpus // num_nodes)
    # Local search refinement: swap experts between the most-loaded and
    # least-loaded GPUs to reduce the max load while keeping the number of
    # experts per GPU fixed.
    num_packs = num_gpus // num_nodes
    if num_packs > 1 and phy_experts_per_gpu > 1:
        pi = pack_index.tolist()
        ri = rank_in_pack.tolist()
        tw = tokens_per_phy.tolist()
        for r in range(len(tw)):
            row_w = tw[r]
            pack_load = [0.0] * num_packs
            slot_of = [[-1] * phy_experts_per_gpu for _ in range(num_packs)]
            for j, p in enumerate(pi[r]):
                slot_of[p][ri[r][j]] = j
                pack_load[p] += row_w[j]
            for _ in range(8):
                order = sorted(range(num_packs), key=pack_load.__getitem__)
                hi, lo = order[-1], order[0]
                gap = pack_load[hi] - pack_load[lo]
                if gap <= 1e-9:
                    break
                best = None
                best_gain = gap
                for a in range(phy_experts_per_gpu):
                    ja = slot_of[hi][a]
                    wa = row_w[ja]
                    for b in range(phy_experts_per_gpu):
                        jb = slot_of[lo][b]
                        d = wa - row_w[jb]
                        if 0 < d < best_gain:
                            best_gain = d
                            best = (ja, jb, a, b)
                if best is None:
                    break
                ja, jb, a, b = best
                # swap the two experts between the two GPUs
                pi[r][ja], pi[r][jb] = lo, hi
                ri[r][ja], ri[r][jb] = b, a
                slot_of[hi][a], slot_of[lo][b] = jb, ja
                delta = best_gain
                pack_load[hi] -= delta
                pack_load[lo] += delta
        pack_index = torch.tensor(pi, dtype=torch.int64)
        rank_in_pack = torch.tensor(ri, dtype=torch.int64)
    phy2pphy = pack_index * phy_experts_per_gpu + rank_in_pack
