<DESCRIPTION>
All prior variants plateau at balancedness_score_gpu = 0.66, and the speed score is already ~0, so we have time budget to spend. The current LPT greedy is a good constructive heuristic, but LPT alone leaves a residual spread between the most- and least-loaded packs. I add a deterministic post-packing local-search refinement pass to `_LptPacker.pack`: after the greedy assignment, repeatedly locate the max-load and min-load packs, and search all pairwise item swaps between them, picking the swap whose gain best bisects the load spread (maximizing `min(gain, spread - gain)`). This monotonically shrinks the spread and terminates quickly (bounded rounds, packs are small). Since the same packer is used for both Step 1 (groups→nodes) and Step 3 (physical experts→GPUs), both stages benefit, and the final GPU load balance should improve past the 0.66 plateau. Ranks are rewritten from the pack lists after refinement so they remain a valid 0..cap-1 enumeration per pack. The added cost is modest Python work over small pack lists, which the near-zero speed score budget easily absorbs.

        for r in range(num_rows):
            row_idx = indices[r]
            row_w = weights[r]
            pack_load = [0.0] * num_packs
            pack_count = [0] * num_packs
            pack_items = [[] for _ in range(num_packs)]
            heap = [(0.0, p) for p in range(num_packs)]
            heapq.heapify(heap)
            pi_row = pack_index[r]
            ri_row = rank_in_pack[r]
            for item in row_idx:
                load, pack = heapq.heappop(heap)
                pi_row[item] = pack
                ri_row[item] = pack_count[pack]
                pack_count[pack] += 1
                load += row_w[item]
                pack_load[pack] = load
                pack_items[pack].append((item, row_w[item]))
                if pack_count[pack] < cap:
                    heapq.heappush(heap, (load, pack))

            # Local-search refinement: swap items between the most- and
            # least-loaded packs to shrink the load spread. Deterministic,
            # monotone, and terminates in a bounded number of rounds.
            for _ in range(4 * num_packs):
                maxp = max(range(num_packs), key=pack_load.__getitem__)
                minp = min(range(num_packs), key=pack_load.__getitem__)
                spread = pack_load[maxp] - pack_load[minp]
                if spread <= 1e-12:
                    break
                best = None
                best_score = 0.0
                for ia in range(len(pack_items[maxp])):
                    a, wa = pack_items[maxp][ia]
                    for ib in range(len(pack_items[minp])):
                        b, wb = pack_items[minp][ib]
                        gain = wa - wb
                        if gain <= 0.0:
                            continue
                        # prefer swaps that bisect the spread
                        score = min(gain, spread - gain)
                        if score > best_score:
                            best_score = score
                            best = (ia, ib, gain)
                if best is None:
                    break
                ia, ib, gain = best
                a, wa = pack_items[maxp][ia]
                b, wb = pack_items[minp][ib]
                pack_items[maxp][ia] = (b, wb)
                pack_items[minp][ib] = (a, wa)
                pack_load[maxp] -= gain
                pack_load[minp] += gain

            # Write back final assignment (ranks from list order)
            for p in range(num_packs):
                for k, (item, _) in enumerate(pack_items[p]):
                    pi_row[item] = p
                    ri_row[item] = k
        return pack_index, rank_in_pack
