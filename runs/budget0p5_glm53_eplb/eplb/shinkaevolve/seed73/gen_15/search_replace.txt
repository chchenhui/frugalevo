<DESCRIPTION>
Replace the pure snake (serpentine) LPT heuristic in `balanced_packing` with a balanced-pair "greedy matching" variant, as recommended. Items are sorted descending, then the k-th heaviest item is matched with the k-th lightest item (pair id = min(pos, n-1-pos)). Pairs are then distributed to packs round-robin with alternating (snake) direction per pair block, and the rank within the pack records whether the item was the heavy or light member of its pair. This guarantees each pack receives one heavy and one light item per pair block (heavier improvement over the item-level snake, which can put two mid-heavy items in the same pack when groups_per_pack > 2), while keeping the construction fully tensorized and loop-free via `scatter_` on the sort indices. This targets improved GPU balancedness while preserving the vectorized speed of the current implementation.</DESCRIPTION>

    # Vectorized balanced-pair (greedy matching) LPT packing:
    # sort items descending, then match the k-th heaviest item with the
    # k-th lightest item (pair id = min(pos, n-1-pos)). Distribute pairs
    # round-robin over packs with alternating (snake) direction per pair
    # block so every pack gets one heavy and one light item per block.
    indices = weight.float().sort(-1, descending=True).indices
    pos = torch.arange(num_groups, dtype=torch.int64, device=weight.device)
    pair = torch.minimum(pos, num_groups - 1 - pos)
    # side 0: heavy member of the pair, side 1: light member
    side = (pos > (num_groups - 1) // 2).to(torch.int64)
    # each pair block holds num_packs pairs; direction alternates per block
    block = pair // num_packs
    offset = pair % num_packs
    offset = torch.where(block % 2 == 0, offset, num_packs - 1 - offset)
    pack_sorted = offset
    rank_sorted = block * 2 + side
    pack_index = torch.empty(
        weight.shape, dtype=torch.int64, device=weight.device)
    rank_in_pack = torch.empty_like(pack_index)
    pack_index.scatter_(1, indices,
                        pack_sorted.expand(weight.shape))
    rank_in_pack.scatter_(1, indices, rank_sorted.expand(weight.shape))
    return pack_index, rank_in_pack
