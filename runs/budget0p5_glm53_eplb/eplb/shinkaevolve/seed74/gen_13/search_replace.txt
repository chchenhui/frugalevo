<DESCRIPTION>
The main bottleneck is `balanced_packing`: it runs a Python double loop (num_layers × num_items) with per-item `min(...)` scans and tensor iteration, which is extremely slow (speed_score 0.00). I replace it with a "round-based greedy" heuristic that is mathematically equivalent in spirit to LPT but fully vectorized across all layers:

- Sort each layer's items by descending weight once.
- Process items in rounds of `num_packs` (each pack must receive exactly `groups_per_pack` items, so there are exactly `groups_per_pack` rounds).
- In each round, take the `num_packs` heaviest remaining items (already sorted) and assign the heaviest to the currently lightest pack, second heaviest to second lightest, etc. Each round is a single argsort over pack weights plus a couple of scatter/gather ops, all executed for every layer at once on the tensor.

This reduces the Python loop from O(num_layers × num_items) iterations (each doing an O(num_packs) Python `min`) to O(groups_per_pack) fully vectorized torch iterations, typically a 1-2 order of magnitude speedup, while preserving near-LPT balancedness (pairing heavy items with light packs each round).
</DESCRIPTION>

    pack_weights = torch.zeros(num_layers,

                            fill_value=-1,
                            dtype=torch.int64,
                            device=weight.device)
    rank_in_pack = torch.full_like(pack_index, fill_value=-1)
    rounds = torch.arange(num_packs, dtype=torch.int64,
                         device=weight.device)
    rounds = rounds.expand(num_layers, -1)
    # Each round assigns the `num_packs` heaviest remaining items:
    # the heaviest item goes to the currently lightest pack, etc.
    for r in range(groups_per_pack):
        items = sorted_idx[:, r * num_packs:(r + 1) * num_packs]
        # Packs sorted by ascending current weight; the j-th heaviest item
        # of this round goes to packs_sorted[:, j].
        packs_sorted = pack_weights.argsort(-1, stable=True)

        rank_in_pack.scatter_(1, items, rounds)

                                  weight.gather(1, items))
