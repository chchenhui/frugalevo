<DESCRIPTION>
The current snake (boustrophedon) packing is very fast but produces substantially worse pack balance than the classic greedy longest-processing-time (LPT) assignment, which is reflected in the low GPU/expert balancedness scores. The prior program used true greedy assignment but with a doubly-nested Python loop (one iteration per layer per group), making it too slow. Here we restore the greedy "assign the next heaviest item to the least-loaded pack that still has capacity" policy, but vectorize the layer dimension: we only loop over the sorted item positions (num_groups iterations), and each iteration uses a handful of small tensor ops across all rows simultaneously. This recovers greedy-level balance (better balancedness scores) at a fraction of the original Python-loop cost, improving the combined score.

    # Greedy LPT assignment (next heaviest item -> least loaded pack that
    # still has capacity), vectorized across the layer dimension so the
    # Python loop only runs once per item position instead of once per
    # (layer, item) pair.
    w = weight.float()
    indices = w.sort(-1, descending=True).indices  # [X, n]

    pack_weights = torch.zeros(num_layers,
                               num_packs,
                               dtype=w.dtype,
                               device=w.device)
    pack_items = torch.zeros(num_layers,
                            num_packs,
                            dtype=torch.int64,
                            device=w.device)
    pack_index = torch.empty(num_layers,
                             num_groups,
                             dtype=torch.int64,
                             device=w.device)
    rank_in_pack = torch.empty_like(pack_index)

    inf = float("inf")
    ones = None
    for j in range(num_groups):
        col = indices[:, j:j + 1]  # [X, 1] next heaviest item per row
        # Packs that can still accept an item
        eligible = pack_items < groups_per_pack
        # Pick the least-loaded eligible pack per row
        cand = torch.where(eligible, pack_weights,
                           torch.full_like(pack_weights, inf))
        pack = cand.argmin(-1, keepdim=True)  # [X, 1]
        item_rank = pack_items.gather(1, pack)
        pack_index.scatter_(1, col, pack)
        rank_in_pack.scatter_(1, col, item_rank)
        pack_weights.scatter_add_(1, pack, w.gather(1, col))
        if ones is None or ones.shape[0] != num_layers:
            ones = torch.ones(num_layers,
                              1,
                              dtype=torch.int64,
                              device=w.device)
        pack_items.scatter_add_(1, pack, ones)
    return pack_index, rank_in_pack
