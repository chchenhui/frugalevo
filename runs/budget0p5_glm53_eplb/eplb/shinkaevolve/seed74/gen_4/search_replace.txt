<DESCRIPTION>
The dominant cost of the current algorithm is `balanced_packing`: it runs a pure-Python double loop (num_layers × num_groups iterations) with a `min()` generator per item, plus a `.cpu()` sync and per-item Python indexing. Since the greedy least-loaded-pack assignment is sequential only within a single layer's item sequence, we can vectorize across all layers: process items in sorted order step-by-step, but for every step compute the pack selection for ALL layers at once with tensor ops (masked argmin over pack weights, scatter_add updates). This reduces Python iterations from L×G to G, removing the per-item Python overhead entirely and avoiding repeated syncs. The resulting assignment is identical to the original greedy (argmin with +inf masking on full packs breaks ties toward the lowest pack index, same as Python's `min`). Sorting stays on CPU but is done once with `argsort` on the whole tensor instead of per-layer `.cpu()` round-trips in a loop. This substantially cuts algorithm execution time (speed_score is currently 0.00, times_algorithm 0.55), while producing the same (or better) balancedness since the greedy semantics are preserved.

    pack_weights = weight.new_zeros((num_layers, num_packs),
                                    dtype=torch.float32)
    pack_items = torch.zeros((num_layers, num_packs),
                             dtype=torch.int64,
                             device=weight.device)

                                    dtype=torch.int64,
                                    device=weight.device)
    rank_sorted = torch.empty_like(pack_index_sorted)

    for t in range(num_groups):
