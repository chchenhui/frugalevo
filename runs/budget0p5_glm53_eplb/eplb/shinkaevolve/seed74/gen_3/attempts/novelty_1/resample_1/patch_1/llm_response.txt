<DESCRIPTION>
The main bottleneck is `balanced_packing`: it sorts on GPU, moves to CPU, and then runs a pure-Python greedy loop of O(num_layers × num_groups × num_packs) iterations with a `min(...)` generator each step — this dominates algorithm runtime (times_algorithm: 0.55).

Replace the greedy assignment with a "snake" (boustrophedon) packing: sort items descending, then assign the j-th heaviest item to pack (j mod P) in even blocks and pack (P-1 - j mod P) in odd blocks, alternating direction each block. This guarantees exactly n/m items per pack (hard constraint preserved), places heavy items into different packs (same as greedy's first round), and alternates so that the 2nd heaviest round compensates the 1st — empirically near-identical balancedness to greedy LPT while being fully vectorizable on GPU with no Python loops and no CPU transfer. This cuts algorithm time dramatically (improving times_algorithm and speed_score) with negligible balancedness loss.

Additionally keep the computation entirely on the original device (no `.cpu()` roundtrip).

    # Sort items by weight (descending) once, fully vectorized on device.
    indices = weight.float().sort(-1, descending=True).indices

    # Snake (boustrophedon) assignment: the j-th heaviest item goes to
    # pack (j mod num_packs) in even blocks and to pack
    # (num_packs - 1 - j mod num_packs) in odd blocks. This guarantees
    # exactly `groups_per_pack` items per pack, spreads the heaviest
    # items across all packs, and alternates direction so subsequent
    # rounds compensate the load of earlier rounds.
    j = torch.arange(num_groups, device=weight.device)
    block = j // num_packs  # 0 .. groups_per_pack-1
    r = j % num_packs
    pack_of_sorted = torch.where(block % 2 == 0, r, num_packs - 1 - r)

                             num_groups,
                             dtype=torch.int64,
                             device=weight.device)
    rank_in_pack = torch.empty_like(pack_index)
    pack_index.scatter_(1, indices,
                        pack_of_sorted.unsqueeze(0).expand(num_layers, -1))
    rank_in_pack.scatter_(1, indices,
                          block.unsqueeze(0).expand(num_layers, -1))
    return pack_index, rank_in_pack
