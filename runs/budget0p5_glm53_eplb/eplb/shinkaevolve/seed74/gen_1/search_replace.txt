<DESCRIPTION>
The main bottleneck is `balanced_packing`: it runs a pure-Python double loop over every layer and every expert group, doing per-item greedy bin selection. This makes the algorithm's own runtime dominate (speed_score 0.00).

Instead, replace the per-layer greedy with a fully vectorized "snake" (serpentine) packing: sort each layer's weights in descending order, cut the sorted list into `num_packs` consecutive chunks of `groups_per_pack` items, and assign chunk 0 to packs in increasing order, chunk 1 in decreasing order, alternating. This is a classic, near-optimal heuristic for balanced partitioning of sorted weights: large items are spread first, and the alternating direction cancels the residual imbalance between consecutive chunks. It guarantees exactly `groups_per_pack` items per pack (same feasibility as before) while producing the same style of near-balanced sums.

The whole computation becomes a handful of tensor ops (`sort`, `scatter_`) executed once for all layers simultaneously, eliminating both Python loops entirely. This should massively reduce execution time while keeping (and typically slightly improving) balance, since greedy LPT-style per-item placement and snake assignment of sorted items are of comparable quality.

Note the return tensors now live on `weight.device` (same as before, since inputs are CPU here), and rank_in_pack semantics (position within the pack) are preserved, so the hierarchical rebalancer downstream is unaffected.

    # Vectorized "snake" packing: sort weights in descending order, split
    # into num_packs consecutive chunks of groups_per_pack items, and
    # assign alternating chunks in forward/reverse pack order. This
    # spreads the heaviest items first and cancels residual imbalance
    # between consecutive chunks, all with a handful of tensor ops.
    device = weight.device
    sorted_idx = weight.float().sort(-1, descending=True).indices.to(
        device=torch.int64, dtype=torch.int64)
    pos = torch.arange(num_groups, dtype=torch.int64, device=device)
    chunk = torch.div(pos, groups_per_pack, rounding_mode="floor")
    offset = pos - chunk * groups_per_pack
    even_chunk = (chunk % 2) == 0
    pack_of_pos = torch.where(even_chunk, offset, num_packs - 1 - offset)
    pack_index = torch.empty(num_layers,
                             num_groups,
                             dtype=torch.int64,
                             device=device)
    pack_index.scatter_(-1, sorted_idx,
                        pack_of_pos.view(1, -1).expand(num_layers, -1))
    rank_in_pack = torch.empty_like(pack_index)
    rank_in_pack.scatter_(-1, sorted_idx,
                          offset.view(1, -1).expand(num_layers, -1))
    return pack_index, rank_in_pack
