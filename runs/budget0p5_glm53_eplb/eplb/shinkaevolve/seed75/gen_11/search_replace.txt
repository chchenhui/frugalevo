<DESCRIPTION>
The greedy LPT packing in `balanced_packing` is fast but leaves a residual load spread between the heaviest and lightest packs, which caps both the GPU-load balancedness (0.66) and the per-expert balancedness (0.25). Since the algorithm runtime is currently negligible (times_algorithm ≈ 0.01) while speed_score is dominated by inference time (i.e., by the quality of the placement), we can afford a cheap local-search refinement phase. After the greedy assignment, for each layer we repeatedly identify the heaviest and lightest packs and swap the largest-weight item in the heavy pack with the smallest-weight item in the light pack whenever the swap provably reduces the spread (weight difference exceeds half the spread). This preserves all invariants (each pack still holds exactly n/m items, ranks remain a valid permutation) so downstream code is unaffected, while monotonically shrinking the max–min pack load gap — directly improving GPU load balance and, through it, inference-time balance. The refinement converges quickly (a few swaps per layer) so the added runtime is negligible.
