<DESCRIPTION>
Add a greedy local-search refinement pass after Step 3 of the hierarchical algorithm. After `balanced_packing` assigns physical experts to GPUs, per-GPU loads may still be unbalanced (GPU balancedness is only 0.66). Since each GPU holds a fixed number of physical experts, we can swap experts between the most-loaded and least-loaded GPU within each node (keeping pack sizes constant), choosing the pair whose weight difference best halves the load gap. This is fully vectorized across all (layer, node) rows, iterated at most 20 times, and stops early when no swap reduces the global max load. It reuses the existing `pack_index`/`rank_in_pack` plumbing so the downstream `phy2pphy` construction is unchanged. This should substantially improve GPU balancedness at negligible runtime cost (a few vectorized ops per iteration, versus the expensive Python loops in `balanced_packing`).

    num_rows = tokens_per_phy.size(0)
    row_idx = torch.arange(num_rows, dtype=torch.int64)

        min_pack = loads.argmin(-1)
