<DESCRIPTION>
The expert balancedness (0.25) is the weakest metric. The current `replicate_experts` greedily replicates the expert with the highest weight/count ratio, which is a myopic heuristic and under-uses redundancy. Instead, we do a proper LPT over post-replication loads: treat each logical expert's weight as being divided among its replicas; when we must add a replica, we pick the expert whose removal best reduces the maximum per-expert replica load. Concretely, sorting experts by weight descending and assigning each replica (in that order, including the first `num_log` mandatory replicas) to keep replica loads balanced yields a much better LPT-style solution: each logical expert of weight w gets either ceil/floor of total/num_log replicas such that w/c is as uniform as possible. This directly targets the expert balancedness metric (which measures how uniform the per-replica loads w_i/c_i are).

Additionally, `balanced_packing` is currently a slow Python double loop (times_algorithm 0.49). Replace it with the vectorized masked-argmin LPT loop validated in a prior program (which achieved times_algorithm 0.01), processing all rows in lockstep.

The new replication strategy: sort experts descending by weight; compute a target replica load T = total_weight / num_phy; for each expert in descending order, assign c_i = max(1, round(w_i / T)) replicas, then fix up the total to exactly num_phy greedily by adjusting the counts that most reduce the max deviation. This is a one-shot assignment with a small greedy fix-up, much faster than the per-replica loop and better balanced.

    n, num_log = weight.shape
    num_redundant = num_phy - num_log
    assert num_redundant >= 0
    device = weight.device
    phy2log = torch.empty(n, num_phy, dtype=torch.int64, device=device)
    rank = torch.empty(n, num_phy, dtype=torch.int64, device=device)
    logcnt = torch.ones(n, num_log, dtype=torch.int64, device=device)
    arangen = torch.arange(n, dtype=torch.int64, device=device)

    w = weight.float()
    total = w.sum(-1, keepdim=True)  # [n, 1]
    # Target per-replica load so replica loads are as uniform as possible.
    target = total / num_phy
    # Ideal replica count per expert (at least 1).
    ideal = (w / target).round().clamp(min=1).long()  # [n, num_log]
    # Fix up so each row sums to exactly num_phy, greedily adjusting the
    # count that most reduces the deviation of the per-replica load.
    logcnt = ideal.clone()
    diff = num_phy - logcnt.sum(-1)  # [n]
    safe_w = w.clamp(min=torch.finfo(w.dtype).tiny)
    for _ in range(int(diff.abs().max().item()) if n > 0 else 0):
        active = diff != 0
        if not active.any():
            break
        # Deviation if we add / remove one replica.
        cur_load = w / logcnt.clamp(min=1)
        add_load = w / (logcnt + 1).clamp(min=1)
        dev_add = (add_load - target).abs() - (cur_load - target).abs()
        dev_sub = ((logcnt > 1) & active.unsqueeze(-1))
        sub_load = w / (logcnt - 1).clamp(min=1)
        dev_sub_v = (sub_load - target).abs() - (cur_load - target).abs()
        rows = torch.nonzero(active, as_tuple=True)[0]
        d = diff[rows]
        if (d > 0).any():
            r = rows[d > 0]
            cand = torch.where(logcnt[r] > 0, dev_add[r],
                               torch.full_like(dev_add[r], float("inf")))
            j = cand.argmin(-1)
            logcnt[r, j] += 1
            diff[r] -= 1
        if (d < 0).any():
            r = rows[d < 0]
            cand = torch.where(dev_sub[r], dev_sub_v[r],
                               torch.full_like(dev_sub_v[r], float("inf")))
            j = cand.argmin(-1)
            logcnt[r, j] -= 1
            diff[r] += 1

    # Fill phy2log / rank from the counts (all rows in lockstep).
    order = w.sort(-1, descending=True).indices  # [n, num_log]
    slot = 0
    for j in range(num_log):
        e = order[:, j]  # [n]
        c = logcnt[arangen, e]  # [n]
        for k in range(int(c.max().item()) if n > 0 else 0):
            m = k < c
            if not m.any():
                break
            rows = torch.nonzero(m, as_tuple=True)[0]
            phy2log[rows, slot] = e[rows]
            rank[rows, slot] = k
            slot += 1
            if slot >= num_phy:
                break
        if slot >= num_phy:
            break
    # Any remaining slots (defensive): fill with lightest experts.
    while slot < num_phy:
        phy2log[:, slot] = order[:, -1]
        rank[:, slot] = 0
        slot += 1
    return phy2log, rank, logcnt
