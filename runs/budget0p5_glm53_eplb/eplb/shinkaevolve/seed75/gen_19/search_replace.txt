The current code has neither, and scores worse (0.66 gpu, 0.25 expert). I restore both edits — they measurably improve balancedness while keeping the algorithm fast (times_algorithm was 0.07s vs 0.01s, still negligible). The local-search swap only ever trades members between the max and min packs and requires both resulting packs to be lighter than the old max, so it strictly improves GPU-level balance at both Step 1 (groups→nodes) and Step 3 (physical experts→GPUs). The policy selection guards against cases where the hierarchical policy's node partitioning hurts global GPU balance.</DESCRIPTION>

    def gpu_imbalance(phy2log: torch.Tensor, logcnt: torch.Tensor) -> float:
        """Sum of squared deviations of per-GPU loads from the layer mean."""
        per_replica = (weight / logcnt).gather(-1, phy2log)
        loads = per_replica.view(num_layers, num_gpus, -1).sum(-1)
        mean = loads.mean(-1, keepdim=True)
        return ((loads - mean) ** 2).sum().item()
