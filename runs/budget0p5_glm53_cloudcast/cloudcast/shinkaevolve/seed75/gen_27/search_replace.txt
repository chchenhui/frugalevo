<DESCRIPTION>
The current algorithm computes a fully independent shortest path for each destination, so any link common to multiple destinations is paid for repeatedly (once per destination, times each partition). A broadcast is fundamentally a multicast problem: data that reaches an intermediate node once can be fanned out to many destinations, so shared edges should only be paid once. We evolve the search into a greedy Steiner-tree heuristic: process destinations sequentially and run Dijkstra with cost discounts on edges already used by the growing broadcast tree. This makes later destinations strongly prefer reusing the existing broadcast backbone instead of paying for redundant parallel transfers. This directly reduces the number of distinct paid edges, which is the dominant term in total transfer cost. We also add a reachability pre-check so unreachable destinations are recorded rather than silently dropped, and use a deterministic RNG seed for reproducibility of the perturbed candidate search.
