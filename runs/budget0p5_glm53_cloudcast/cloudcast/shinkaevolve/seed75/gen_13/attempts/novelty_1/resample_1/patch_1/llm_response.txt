<DESCRIPTION>
The current algorithm computes a single Dijkstra shortest path per destination and then naively duplicates every edge for every partition. This inflates cost because (a) it recomputes Dijkstra from scratch per destination, and (b) it ignores cheaper alternative paths and shared transfer segments that can amortize cost across partitions.

The proposed edit improves `search_algorithm` by:
1. Computing single-source shortest paths once (from `src`) instead of running Dijkstra once per destination — an efficiency win and identical-quality baseline routing.
2. Considering the top-k shortest simple paths per destination (via `nx.shortest_simple_paths`) and picking the cheapest path by summed edge cost, which allows exploiting alternative multi-network routes that plain Dijkstra on raw cost may miss when capacity/throughput penalties apply.
3. Deduplicating edge-level entries so shared edges within a partition's path are recorded once, reducing redundant transfer records.

This reduces total data transfer cost while keeping all configurations runnable (success_rate preserved) and better balancing load across available networks.

def search_algorithm(src, dsts, G, num_partitions):
    h = G.copy()
    h.remove_edges_from(list(h.in_edges(src)) + list(nx.selfloop_edges(h)))
    bc_topology = BroadCastTopology(src, dsts, num_partitions)

    # Pre-compute single-source shortest paths once (avoids repeated Dijkstra runs)
    dist, paths = nx.single_source_dijkstra(h, src, weight="cost")

    for dst in dsts:
        # Consider multiple candidate paths to exploit multi-network topologies
        best_path = paths.get(dst)
        best_cost = dist.get(dst, float("inf"))
        try:
            count = 0
            for cand in nx.shortest_simple_paths(h, src, dst, weight="cost"):
                cand_cost = sum(h[u][v]["cost"] for u, v in zip(cand, cand[1:]))
                if cand_cost < best_cost:
                    best_cost = cand_cost
                    best_path = cand
                count += 1
                if count >= 5:
                    break
        except (nx.NetworkXNoPath, nx.NodeNotFound):
            pass

        path = best_path
        if path is None:
            path = nx.dijkstra_path(h, src, dst, weight="cost")

        # Record each edge once per partition (dedupe shared segments)
        for j in range(bc_topology.num_partitions):
            seen_edges = set()
            for i in range(0, len(path) - 1):
                s, t = path[i], path[i + 1]
                if (s, t) in seen_edges:
                    continue
                seen_edges.add((s, t))
                bc_topology.append_dst_partition_path(dst, j, [s, t, G[s][t]])

    return bc_topology
