<DESCRIPTION>
Sort destinations by ascending true Dijkstra cost from src before constructing the shared multicast tree. This ensures the backbone forms along the cheapest central paths first, and expensive/far destinations hook onto the already-cheap tree rather than locking in an expensive first backbone. The tree builder already attaches each subsequent destination to the existing tree, so processing order directly affects tree quality. Cost sanitization is also added to avoid None-weight crashes.

def search_algorithm(src, dsts, G, num_partitions):
    h = prepare_graph(G, src)
    bc_topology = BroadCastTopology(src, dsts, num_partitions)

    # Backfill missing costs so pathfinding never fails on None weights
    # while still strongly avoiding unknown-cost links.
    for u, v, data in h.edges(data=True):
        if data.get("cost") is None:
            data["cost"] = 1e6

    # Process destinations cheapest-first (true Dijkstra cost from src) so
    # the shared backbone forms from the cheapest central paths; expensive
    # far destinations then hook onto that cheap tree.

        try:
            _, dist = nx.single_source_dijkstra(h, src, d, weight="cost")
            return dist.get(d, float("inf"))
