backfill_none_cost_penalty</NAME>
<DESCRIPTION>
Backfill `cost=None` edges with a large finite penalty (1e6) in the sanitized internal graph used by routing. This makes shortest-path computation deterministic and safe: previously, Dijkstra's behavior on None weights was undefined (it happened to work in some configs, crashed in others). With an explicit penalty, the router will strongly prefer edges with known real costs, and future heuristics can safely compare candidate path costs without None crashes. The sanitized graph `h` is internal only — the returned edge data still comes from the original graph `G`, so outputs are unchanged where costs already exist. I also fix the `_path_cost`/`edge_cost_fn` to use a safe accessor consistent with this.

    def __init__(self, G: nx.DiGraph, src: str, k: int = 3):
        # remove useless edges: into src and self loops
        h = G.copy()
        h.remove_edges_from(list(h.in_edges(src)) + list(nx.selfloop_edges(h)))
        # backfill missing costs with a large finite penalty so path scoring
        # is safe and deterministic; sanitized graph is internal only.
        for u, v, data in h.edges(data=True):
            if data.get("cost") is None:
                data["cost"] = 1e6
        self.h = h
