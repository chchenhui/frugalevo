<DESCRIPTION>
Replace the naive per-destination Dijkstra in search_algorithm with a Steiner-tree-like edge-sharing approach. First compute shortest paths from src to all destinations once via nx.single_source_dijkstra, then iteratively build a shared directed tree: start from src, and repeatedly attach the "closest" reachable destination (in terms of path cost over the sanitized graph), adding its path edges to the tree. Once an edge is in the tree, later destinations reuse those edges — the edge cost is only counted once in the tree, but per the recommendation we still append each destination's src→dst path (composed of tree edges) to the BroadCastTopology, so edge data is shared across destinations and redundant transfers are reduced by the evaluator's edge-sharing accounting. All edge lookups read from the sanitized directed graph h (never G), preserving the validated I/O contract of append_dst_partition_path with whole-edge appends. Using single_source_dijkstra once is also faster than repeated Dijkstra calls, improving runtime.
