<DESCRIPTION>
Replace independent per-destination shortest paths with a Steiner-tree-like shared backbone. We iteratively grow a shared directed tree from src using Dijkstra on the sanitized graph h, merging each destination's shortest path into the tree only once (edges already in the tree are reused for free). Then each destination's path is read from the tree. This shares edges across destinations, reducing total transfer cost while keeping the exact same output contract (per-dst, per-partition edge appends with [s, t, G[s][t]]). All edge data is read from G only for the final append, pathfinding on h only, matching the validated Gen 0 behavior.

    # Build a shared Steiner-ish tree: iteratively merge shortest paths into a
    # backbone so edges already paid for by one destination are free for the
    # next (edge-sharing across destinations reduces total cost).
    tree = nx.DiGraph()
    tree.add_node(src)
    parent = {src: None}
    remaining = sorted(set(dsts), key=lambda d: nx.dijkstra_path_length(h, src, d, weight="cost"))

    while remaining:
        # find the destination closest (by cost) to the current shared tree
        best_dst, best_dist, best_path = None, float("inf"), None
        for d in remaining:
            dist, path = nx.multi_source_dijkstra(h, list(tree.nodes), d, weight="cost")
            if dist < best_dist:
                best_dst, best_dist, best_path = d, dist, path
        if best_dst is None or best_path is None:
            raise nx.NetworkXNoPath(f"No path to {best_dst}")
        # merge best_path into the tree (skip edges already present)
        for i in range(len(best_path) - 1):
            s, t = best_path[i], best_path[i + 1]
            if not tree.has_edge(s, t):
                tree.add_edge(s, t, **h[s][t])
                parent[t] = s
        remaining.remove(best_dst)
