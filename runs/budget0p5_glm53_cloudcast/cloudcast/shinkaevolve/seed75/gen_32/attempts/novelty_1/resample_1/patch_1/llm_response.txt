<DESCRIPTION>
The current tree-building loop rebuilds `h.reverse(copy=True)` and re-runs Dijkstra for every remaining destination in every while-iteration, for every partition. The reversed graph never changes, so cache it once. Since the tree construction depends on nothing partition-dependent, the tree is identical across partitions — build it once and reuse the resulting `tree_parent` map for all `j`. Also cache the per-dst Dijkstra results since distances from a node in the reversed graph don't change during tree construction (paths are recorded, not mutated). This produces identical output paths while cutting runtime dramatically.
