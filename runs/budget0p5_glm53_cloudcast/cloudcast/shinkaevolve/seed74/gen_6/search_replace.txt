<DESCRIPTION>
The current algorithm sends every partition of data from src to each destination along the *same* single shortest path. This multiplies the cost by num_partitions and congests one route while parallel alternative networks sit idle. A better strategy: (1) only send data once over shared links — build a multicast Steiner-tree style routing where common prefixes of paths to multiple destinations are traversed only once, and (2) distribute partitions over edge-disjoint / k-shortest paths so that different partitions use different (possibly parallel) network routes, avoiding redundant transfers and balancing load. Since the BroadCastTopology records per-partition per-destination edge lists, we can assign partition i of each dst a path chosen from the k-shortest simple paths (by cost), cycling among them so no single path carries all partitions. For shared subtrees, we approximate by removing src in-edges and using k-shortest paths per dst. This reduces total cost when alternative cheap paths exist and lowers congestion.

def search_algorithm(src, dsts, G, num_partitions):
    h = G.copy()
    h.remove_edges_from(list(h.in_edges(src)) + list(nx.selfloop_edges(h)))

    # Precompute k shortest simple paths (by cost) for each destination.
    # Only keep paths whose cost is not excessively worse than the optimal one,
    # so we can spread partitions over cheap parallel routes without
    # paying a large premium for any single partition.
    k = min(num_partitions, 4)
    candidate_paths = {}
    for dst in dsts:
        try:
            gen = nx.shortest_simple_paths(h, src, dst, weight="cost")
            paths = []
            for p in gen:
                c = sum(h[p[i]][p[i + 1]]["cost"] for i in range(len(p) - 1))
                paths.append((c, p))
                if len(paths) >= k:
                    break
        except (nx.NetworkXNoPath, nx.NodeNotFound):
            paths = []
        if not paths:
            continue
        best_cost = paths[0][0]
        # keep all paths within 50% of the best cost (and always the best)
        kept = [p for c, p in paths if c <= best_cost * 1.5 or p is paths[0][0]]
        # dedupe while preserving order
        seen = set()
        uniq = []
        for p in kept:
            tp = tuple(p)
            if tp not in seen:
                seen.add(tp)
                uniq.append(p)
        candidate_paths[dst] = uniq

    bc_topology = BroadCastTopology(src, dsts, num_partitions)

    for dst in dsts:
        if dst not in candidate_paths:
            continue
        routes = candidate_paths[dst]
        for j in range(bc_topology.num_partitions):
            # cycle partitions over the cheap alternative routes to
            # balance load across networks / parallel paths
            path = routes[j % len(routes)]
            for i in range(0, len(path) - 1):
                s, t = path[i], path[i + 1]
                bc_topology.append_dst_partition_path(dst, j, [s, t, G[s][t]])

    return bc_topology
