<DESCRIPTION>
The current algorithm computes one shortest path per destination and assigns every partition to that same path. This overloads a single route (its per-edge throughput cap gets violated, driving costs up) and ignores cheaper parallel alternatives across networks. Improvement: for each destination, consider the K shortest simple paths (by cost), and distribute partitions across them in a load-balanced round-robin fashion. This spreads flow over multiple egress links, keeps per-edge load under throughput constraints, and exploits low-cost parallel routes in multi-network topologies. We also remove a bug: incoming edges to src are removed from a graph copy, but edge metadata `G[s][t]` is still fetched from the original G — keep that, but now compute candidate paths with an effective-cost weight that penalizes congested edges so load balancing emerges naturally.

def search_algorithm(src, dsts, G, num_partitions):
    h = G.copy()
    h.remove_edges_from(list(h.in_edges(src)) + list(nx.selfloop_edges(h)))

    # Track load per edge so we can spread partitions across parallel
    # paths and avoid saturating any single link (throughput caps).
    edge_load = {e: 0 for e in G.edges()}
    K = 3  # number of candidate shortest paths per destination

    bc_topology = BroadCastTopology(src, dsts, num_partitions)

    for dst in dsts:
        try:
            candidates = list(
                nx.shortest_simple_paths(h, src, dst, weight="cost")
            )
        except nx.NetworkXNoPath:
            candidates = []
        candidates = candidates[:K]

        if not candidates:
            # No direct candidates: fall back to single shortest path search
            path = nx.dijkstra_path(h, src, dst, weight="cost")
            candidates = [path]

        # Round-robin partitions over candidate paths to balance load
        for j in range(bc_topology.num_partitions):
            path = candidates[j % len(candidates)]
            for i in range(0, len(path) - 1):
                s, t = path[i], path[i + 1]
                edge_load[(s, t)] += 1
                bc_topology.append_dst_partition_path(dst, j, [s, t, G[s][t]])

    return bc_topology
