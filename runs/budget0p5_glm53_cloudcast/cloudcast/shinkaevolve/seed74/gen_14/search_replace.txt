<DESCRIPTION>
Invert the per-edge load penalty into a per-partition reuse reward. For each destination, process partitions in order and prefer candidate paths whose edges have already been used by earlier partitions (or by previously processed destinations) — if cost is charged per unique edge or aggregate flows get discounted, reusing edges lowers total cost. Destinations are processed in decreasing shortest-path cost order so expensive destinations first establish the shared backbone that cheaper destinations can then piggyback on. Keeps the `[s, t, G[s][t]]` append format untouched.
