shared_edge_reuse_tiebreaker
</NAME>
<DESCRIPTION>
Add a global shared-edge tracker and a two-level candidate selection: among candidates with nearly-equal cost, prefer paths that reuse edges already selected for other destinations (maximizing shared multicast-style transfer segments) and have fewer hops (fewer paid edges). This reduces redundant transfers across destinations while keeping the bounded K_PATHS enumeration and the congestion-aware per-partition spreading. Reuse is applied via a small bonus that only breaks near-ties, so strictly cheaper paths still win.
</DESCRIPTION>

            c += CONGESTION_WEIGHT * edge_load.get((path[i], path[i + 1]), 0)

    def reuse_count(path):
        return sum(1 for i in range(len(path) - 1)
                   if (path[i], path[i + 1]) in shared_edges)

    def select_best(cands, edge_load):
        """Pick best candidate: lowest cost; break near-ties by
        (max shared-edge reuse, then fewest hops)."""
        scored = []
        for p in cands:
            c = path_cost(p, edge_load)
            # apply a small reuse bonus so shared edges win near-ties only
            c -= REUSE_BONUS * reuse_count(p)
            scored.append((c, -reuse_count(p), len(p), p))
        scored.sort(key=lambda x: (x[0], x[1], x[2]))
        # among candidates within TIE_EPSILON of the best cost, prefer reuse/hops
        best_c = scored[0][0]
        tied = [s for s in scored if s[0] <= best_c + TIE_EPSILON]
        tied.sort(key=lambda x: (x[1], x[2]))
        return tied[0][3]
