<DESCRIPTION>
The baseline assigns every partition the same single Dijkstra path, which both wastes cheaper parallel routes and concentrates load on a single network link. A better broadcast strategy: for each destination, compute the k-shortest simple paths (by cost). Distribute partitions across these candidate paths so that cheaper paths serve more partitions while more expensive alternates absorb the remaining partitions. This exploits multi-network topologies (parallel paths), reduces redundant transfer volume on costly links, and balances load. We also cache candidate paths per destination to avoid recomputation overhead, and gracefully fall back to a single path when fewer alternatives exist.

    for dst in dsts:
        try:
            candidates = list(
                nx.shortest_simple_paths(h, src, dst, weight="cost")
            )
        except nx.NetworkXNoPath:
            candidates = []
        # keep a bounded set of cheapest path candidates
        max_candidates = min(len(candidates), max(2, num_partitions))
        candidates = candidates[:max_candidates]

        if not candidates:
            continue

        # assign partitions to paths: weight cheaper paths more heavily.
        # assign ~half of partitions to cheapest path, spread the rest
        weight = 2 ** (max_candidates - 1)
        weights = [weight]
        for _ in range(1, max_candidates):
            weight //= 2
            weights.append(max(weight, 1))

        # normalize weights so they cover all partitions
        total = sum(weights)
        assignment = []
        for idx, w in enumerate(weights):
            count = max(1, round(num_partitions * w / total))
            assignment.extend([idx] * count)
        # trim/pad to exactly num_partitions
        assignment = assignment[:num_partitions]
        while len(assignment) < num_partitions:
            assignment.append(0)

            path = candidates[assignment[j]]

                bc_topology.append_dst_partition_path(dst, j, [s, t, G[s][t]])

    return bc_topology
