<DESCRIPTION>
The current algorithm sends every partition of every destination along the exact same single Dijkstra path, which overloads that route's throughput budget and ignores cheaper alternate routes. Instead, for each destination we enumerate the k cheapest simple paths (via `nx.shortest_simple_paths` ordered by cost) and assign each partition to a different candidate path. This (1) spreads the transfer load across multiple parallel network routes so per-edge throughput limits are respected instead of being oversubscribed, and (2) allows some partitions to exploit alternate low-cost multi-network paths. If fewer than `num_partitions` simple paths exist, partitions wrap around over the available paths, preserving the original shortest-path behavior as a fallback.

    for dst in dsts:
        # Enumerate candidate simple paths ordered by cost and split
        # partitions across them: this balances load across networks and
        # exploits parallel low-cost routes instead of oversubscribing
        # a single shortest path for all partitions.
        try:
            path_gen = nx.shortest_simple_paths(h, src, dst, weight="cost")
            candidate_paths = []
            seen_costs = set()
            for path in path_gen:
                cost_key = tuple(path)
                if cost_key in seen_costs:
                    continue
                seen_costs.add(cost_key)
                candidate_paths.append(path)
                if len(candidate_paths) >= bc_topology.num_partitions:
                    break
        except (nx.NetworkXNoPath, nx.NodeNotFound, StopIteration):
            candidate_paths = []

        if not candidate_paths:
            candidate_paths = [nx.dijkstra_path(h, src, dst, weight="cost")]
