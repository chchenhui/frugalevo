<DESCRIPTION>
Replace the single Dijkstra path per destination with a bounded k-shortest-path search (k=4) using `islice` over `nx.shortest_simple_paths` with weight="cost". For each destination, evaluate up to 4 simple paths and pick the cheapest one. This can find cheaper routes than single-source Dijkstra when the Dijkstra-optimal path to one destination conflicts with shared trunk usage for others. Using `islice` (never `list(...)`) bounds memory/time; fall back to plain Dijkstra if the generator fails (e.g., disconnected pairs), preserving the 100% success rate.

    from itertools import islice

    for dst in dsts:
        # Bounded k-shortest-path candidate selection: evaluate a few
        # simple paths per destination and pick the cheapest, without
        # materializing the full path enumeration into a list.
        path = None
        try:
            best_cost = None
            candidates = islice(
                nx.shortest_simple_paths(h, src, dst, weight="cost"), 4
            )
            for cand in candidates:
                c = sum(
                    h[cand[i]][cand[i + 1]].get("cost") or 0
                    for i in range(len(cand) - 1)
                )
                if best_cost is None or c < best_cost:
                    best_cost = c
                    path = cand
        except (nx.NetworkXNoPath, nx.NetworkXError):
            path = None

        if path is None:
            # Fallback to plain Dijkstra for robustness
            path = nx.dijkstra_path(h, src, dst, weight="cost")

        for i in range(0, len(path) - 1):
            s, t = path[i], path[i + 1]

                bc_topology.append_dst_partition_path(dst, j, [s, t, G[s][t]])
