# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- **The current best Robust Adaptive Local-Trend Filter remains the strongest evaluated balance at 0.55 combined score and 0.49 composite.** Its pipeline—per-window median/MAD clipping, one exponentially weighted endpoint regression, then a simple alpha-beta state update with direct proposed-step reversal suppression—achieved the best reported directional stability among high-quality filters: **102.6 slope changes**, **81.2 false reversals**, and **0.16 smoothness**, while retaining **0.89 correlation**, **0.72 responsiveness**, **0.39 lag error**, and **0.01 s** runtime.

- **Robust local measurement construction before sequential tracking is consistently beneficial.** The current best clips each window to `median ± 3.5 × 1.4826 × MAD` before fitting the trend. Generation 41’s Robust Adaptive Alpha-Beta Trend Filter used the same broad pattern of MAD clipping plus recency-weighted regressions and achieved a competitive **0.54 combined score**. Although it had lower correlation (**0.86**) and more directional activity (**96.2 slope changes**, **76.6 false reversals**), it confirms that robust preprocessing paired with a lightweight tracker is substantially more stable than tracker-heavy consensus designs.

- **Causal endpoint regression continues to be the reliable low-lag measurement mechanism.** The current best’s coordinate system makes the regression intercept estimate the newest sample, avoiding the phase delay of a window mean. Newer endpoint-regression systems also achieved strong alignment: Generation 45 reached **0.93 correlation**, **0.30 lag error**, and **0.77 responsiveness**; Generation 46 reached **0.92 correlation**, **0.26 lag**, and **0.79 responsiveness**. These results reinforce that newest-endpoint evaluation preserves trend timing effectively.

- **Direct suppression of small output steps against current momentum is more effective than hysteresis labels alone.** The current best freezes a candidate before state commitment when its proposed step is opposite the velocity and below a noise/momentum-scaled band. Its **81.2 false reversals** are lower than all newly listed filters, including Generation 44’s output-direction hysteresis (**87.6**), Generation 41’s confirmation logic (**76.6**, but with weaker overall tracking), Generation 49’s reversal persistence (**108.4**), and Generation 51’s hysteresis confirmation (**122.4**). The best filter’s joint state/output gate preserved its higher combined score despite not maximizing raw correlation.

## Ineffective Approaches

- **Kalman-predictive and consensus-heavy architectures repeatedly traded directional stability for raw tracking metrics.** Generation 46’s Adaptive Kalman-Robust Trend Filter delivered excellent raw metrics—**0.92 correlation**, **0.79 responsiveness**, **0.26 lag**, and **0.52 noise reduction**—but scored only **0.53 combined** because smoothness fell to **0.08**, with **234.8 slope changes** and **185.4 false reversals**. Generation 43 showed the same failure mode: **0.92 correlation**, **0.77 responsiveness**, and **0.30 lag**, but only **0.08 smoothness**, **242.4 slope changes**, and **191.2 false reversals**.

- **Multiscale regression blending did not improve stability relative to the best program’s single robust measurement.** Generation 40 used three exponentially weighted causal regressions and confidence blending, but obtained only **0.52 combined**, **0.10 smoothness**, **186.4 slope changes**, and **148.6 false reversals**. Generation 47’s multiscale trend controller similarly achieved strong correlation (**0.93**) and low lag (**0.32**), but had **211.2 slope changes** and **167.4 false reversals**. Multiple local slope estimates and adaptive fusion appear to expose rather than cancel short-term disagreement.

- **Complex hysteresis layers did not reliably suppress jitter when the upstream tracker remained reactive.** Generation 42 combined robust fitting, acceleration limiting, deadbands, and hysteretic reversal confirmation, yet retained **150.4 slope changes**, **120 false reversals**, and **0.12 smoothness** at **0.52 combined**. Generation 45 added persistence-based reversal hysteresis after Kalman, regression, consensus, and alpha-beta stages, but still recorded **159 slope changes** and **125.4 false reversals**. This is consistent with prior evidence that post hoc direction confirmation cannot fully stabilize a candidate signal that has already been made highly reactive by predictive fusion.

- **Higher correlation and noise reduction did not necessarily translate to a higher combined score.** Generation 51 achieved **0.93 correlation**, **0.56 noise reduction**, **0.29 lag**, and **0.77 responsiveness**, all better than the current best’s respective **0.89**, **0.39**, **0.39**, and **0.72**. Yet it scored **0.54**, below the best’s **0.55**, because its smoothness was only **0.11**, with **155.6 slope changes** and **122.4 false reversals**. The evaluation clearly penalizes residual output-direction chatter enough to outweigh selected accuracy gains.

## Implementation Insights

- **The current best efficiently separates vectorized robust estimation from sequential state control.** `sliding_window_view` creates all trailing windows, and median, MAD, clipping, and weighted least-squares projections are computed in batch. Only the alpha-beta-like level/velocity update is sequential. This design reaches **0.01 s** and efficiency **1.00**, matching or exceeding more elaborate alternatives such as Generation 45 (**0.02 s**), Generation 51 (**0.04 s**), Generation 42 (**0.14 s**), and Generation 46 (**0.22 s**).

- **The current best’s one-scale regression is structurally simpler and directionally steadier than multiscale fusion.** It uses `t = arange(W) - (W - 1)`, so the fitted intercept is the endpoint estimate, with exponential recency weights from `exp(-3)` to `1`. The same fit provides both `measurements` and `local_slopes`, avoiding inconsistencies between separately blended local models. By comparison, Generation 40 and Generation 47 derive confidence and trend decisions from three scales, and both had substantially more slope changes than the best (**186.4** and **211.2** versus **102.6**).

- **Its adaptive gain is tied to local trend evidence, not solely prediction residual size.** The best filter uses `abs(local_slope) / (abs(local_slope) + local_noise)` to set alpha between **0.42 and 0.72**. Therefore, noisy flat regions receive lower measurement influence while strong slope evidence receives faster adaptation. This supports its useful responsiveness (**0.72**) without reaching the directional instability of adaptive Kalman/consensus filters such as Generation 43 and 46.

- **The effective stabilization point is before committing the output state.** In the best implementation, the test is performed on `step = candidate - level`; if that step opposes established velocity and is smaller than `0.16 * local_noise + 0.08 * abs(velocity)`, both the candidate and step are frozen. Velocity is then updated from the accepted step only. This differs materially from Generation 44’s output-only directional hysteresis and Generation 45’s persistence-based reversal logic, which retained more false reversals despite similarly robust or predictive measurement stages.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Use post-fit residual MAD for tracking confidence and reversal thresholds, while retaining window MAD for outlier clipping.** After fitting the clipped endpoint regression, compute `residuals = clipped - (measurements[:, None] + local_slopes[:, None] * t)` and `residual_noise = 1.4826 * median(abs(residuals - median(residuals)))`. Replace `local_noise` in `slope_evidence` and `reversal_band` with this residual scale, so clean coherent ramps are not incorrectly treated as noisy merely because the window spans a large trend.

2. **Add a lightweight pending-reversal state that confirms only suppressed countertrend moves.** When `step * velocity < 0` and the step is below the reversal band, record the proposed sign and measurement strength rather than simply discarding it; allow reversal on the next sample only if both the new local slope and candidate step retain that sign and exceed a stronger residual-noise-scaled threshold. This extends the successful pre-commitment suppression mechanism without adding the broadly reactive hysteresis layers that performed poorly in more complex filters.

3. **Quantize the adaptive alpha into hysteretic confidence modes instead of changing it continuously every sample.** For example, use a flat/noisy mode with `alpha≈0.42–0.48`, a transition mode near `0.55`, and a trend mode near `0.68–0.72`; require two consecutive high-confidence windows to enter trend mode and three low-confidence windows to leave it. The current slope-based alpha is already effective, but stabilizing gain changes should reduce gain-induced directional chatter while preserving high responsiveness during persistent trends.

4. **Make velocity updates confidence-aware and acceleration-limited using the existing robust local slope.** Form a target such as `target_velocity = w * step + (1 - w) * local_slopes[i]`, where `w` is larger in low-confidence or high-residual-noise windows, then clip `target_velocity - velocity` to a residual-noise-scaled acceleration cap before applying the existing smoothing. This preserves the current filter’s efficient single-scale measurement design while allowing sustained, clean trends to propagate more faithfully without adopting unstable Kalman-style predictive fusion.

5. **Test a conservative dual-profile endpoint fit only for persistent clean trends, not general multiscale blending.** Precompute the existing `exp(-3, 0)` regression plus a slightly more endpoint-focused profile such as `exp(-4.5, 0)`, and blend modestly toward the more recent estimate only after several high-confidence, same-direction slope windows. Endpoint regression is strongly supported for low lag, while restricting the second profile to stable conditions avoids the disagreement-driven slope changes seen in broad multiscale consensus architectures.
