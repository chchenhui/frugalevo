# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- **The current best Robust Adaptive Local-Trend Filter remains the best overall balance at 0.55 combined / 0.49 composite.** Its single robust endpoint measurement plus lightweight alpha-beta state tracker achieved **0.89 correlation**, **0.39 lag error**, **0.72 responsiveness**, and, most importantly, comparatively strong directional stability: **102.6 slope changes**, **81.2 false reversals**, and **0.16 smoothness**. None of Generations 48–59 exceeded this combined score.

- **Robust causal local-linear endpoint regression consistently supports low-lag tracking.** The current best evaluates a recency-weighted fit at the newest window sample using `t = arange(W) - (W - 1)`, so the intercept is endpoint-aligned rather than delayed like a moving average. This pattern also underlies Generation 52 and Generation 56’s adaptive alpha-beta filters, both reaching **0.54 combined**, with **0.88–0.89 correlation**, **0.38 lag**, and **0.72–0.73 responsiveness**.

- **MAD-based clipping before trend estimation is a reliable component of high-scoring filters.** The current best clips each trailing window to median ± `3.5 × 1.4826 × MAD`, then estimates both level and slope from the same cleaned local fit. Generations 52, 53, 56, 57, and 58 also used MAD-oriented clipping and retained strong accuracy/lag characteristics; for example, Generation 57 achieved **0.92 correlation**, **0.33 lag**, and **0.46 noise reduction**, while Generation 58 achieved **0.90 correlation** and **0.40 lag**.

- **Trend-evidence-based gain adaptation is more successful than purely residual-driven reactivity.** In the current best, alpha varies from **0.42 to 0.72** according to `abs(local_slope) / (abs(local_slope) + local_noise)`. This makes flat/noisy regions less measurement-reactive while retaining responsiveness when local slope evidence is strong. Generation 52’s mode-based alpha-beta gains and Generation 56’s residual-confidence gating produced competitive **0.54** scores, supporting adaptive tracking gains as a productive pattern when paired with robust local measurement construction.

## Ineffective Approaches

- **Kalman-heavy predictive trackers continued to produce excellent raw alignment but poor directional stability.** Generation 50’s Robust Adaptive Kalman Trend Filter reached **0.92 correlation**, **0.32 lag**, and **0.76 responsiveness**, but had only **0.09 smoothness**, with **211 slope changes** and **165.4 false reversals**, resulting in **0.51 combined**. Generation 57 and Generation 59 showed the same pattern: both had **0.92 correlation** and approximately **0.33 lag**, but only **0.12–0.13 smoothness** and **111.8–143 slope changes**.

- **Multiscale endpoint-regression fusion did not improve over the current best’s single-scale fit.** Generation 53 combined slow, medium, and recent regressions and reached **0.53 combined**, but incurred **129.2 slope changes**, **105.8 false reversals**, and **0.13 smoothness**. Generation 54 likewise used short/medium/long endpoint regressions and a three-mode state machine, but had **152.8 slope changes**, **122.2 false reversals**, and **0.12 smoothness**. Their additional slope estimates and confidence fusion appear to introduce disagreement-driven output activity rather than suppress it.

- **Post-hoc hysteresis labels and multi-window confirmation were insufficient when upstream candidates remained reactive.** Generation 48 used adaptive hysteresis ratcheting and two-pass robust regressions but still had **84.6 slope changes** and **67.2 false reversals**, alongside weak **0.18 noise reduction** and **0.19 smoothness**. More complex variants generally worsened directional counts: Generation 54 had **122.2 false reversals**, Generation 57 had **111.8**, and Generation 59 had **108.4**. The evaluation results indicate that state-machine confirmation alone does not consistently stabilize a rapidly changing candidate trajectory.

- **Predictive trend preservation without adequate noise suppression can sacrifice both lag and stability.** Generation 55’s predictive tracker with pending-turn confirmation recorded the lowest listed false reversals among the new programs at **40.6**, but had weak overall tracking: **0.77 correlation**, **0.74 lag error**, **0.57 responsiveness**, and only **0.01 noise reduction**, for **0.52 combined**. This shows that aggressively preserving or waiting through directional changes can reduce reversal counts while impairing alignment and noise performance.

## Implementation Insights

- **The current best efficiently separates batch local estimation from sequential state control.** `sliding_window_view` exposes causal windows, while medians, MADs, clipping, and weighted-regression projections are vectorized across all windows. Only the level/velocity update is sequential. This implementation reached **0.01 s** with an **efficiency score of 1.00**, matching the best efficiency of Generation 52 and Generation 56 and outperforming more elaborate pipelines that took **0.02 s** or more without exceeding its total score.

- **Using one coherent regression for both endpoint level and slope avoids multiscale fusion inconsistency.** The current best computes `measurements` and `local_slopes` from the same weighted least-squares matrix and same clipped window. In contrast, Generation 53, Generation 54, Generation 57, and Generation 59 fuse multiple horizon-specific levels/slopes with confidence rules. Despite higher correlation in some cases, these systems had substantially more output-direction activity: **129.2–152.8 slope changes** for Generations 53–54 and **137.6–143** for Generations 57–59, versus the current best’s **102.6**.

- **The current best gates the proposed level transition before updating velocity.** It computes `step = candidate - level`; if that step opposes velocity and is below `0.16 * local_noise + 0.08 * abs(velocity)`, it freezes both the candidate and step before the velocity update. This directly couples reversal suppression to the actual committed output movement. Its **81.2 false reversals** and **0.16 smoothness** compare favorably with Generation 56’s confirmation-based alpha-beta design (**103.2 false reversals**, **0.14 smoothness**) and Generation 58’s consensus/persistence design (**89.6**, **0.15**).

- **Adaptive alpha-beta tracking remains effective when bounded by robust local evidence.** The current best updates velocity as `0.72 * velocity + 0.28 * step`, preserving trend inertia without the stronger reactive dynamics visible in adaptive Kalman filters. Generation 52 and Generation 56 validate the general alpha-beta pattern with **0.54 combined** scores, but their more elaborate gain modes, innovation gates, and directional confirmations did not improve smoothness above **0.14–0.16** or reduce directional activity below the current best’s balance.

- **The current best’s 0.55 combined score remains unmatched by all newly evaluated filters.** The nearest results were Generation 52 and Generation 56 at **0.54**, followed by Generations 53, 57, and 59 at **0.53**. Generations 48, 50, 54, 55, and 58 remained at **0.51–0.52**. # META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Replace window MAD with post-fit residual MAD for confidence and reversal scaling.** Keep the existing window MAD for the initial median-based clipping, but after the clipped weighted fit compute residuals against `measurements[:, None] + local_slopes[:, None] * t` and derive a robust residual scale. Use this residual noise in `slope_evidence` and `reversal_band`, since a clean steep ramp should have low residual noise even when its raw window MAD is large.

2. **Add a one-sample pending reversal confirmation only when the current countertrend step is suppressed.** Instead of permanently freezing every small opposing step, store its direction when `step * velocity < 0` and it falls inside the reversal band; commit a reversal only if the next candidate step and local slope agree in sign and exceed a stronger residual-scaled threshold. This directly extends the current best pre-commit suppression mechanism while avoiding the broadly reactive multi-state hysteresis systems that increased slope changes.

3. **Convert the continuous alpha calculation into a small hysteretic gain-mode controller.** Retain the successful slope-evidence idea, but define, for example, low-confidence `alpha=0.44`, neutral `alpha=0.56`, and confirmed-trend `alpha=0.70` modes; require two consecutive high-evidence same-sign slopes to enter trend mode and several low-evidence samples to leave it. This should reduce sample-to-sample gain jitter and associated directional chatter while preserving the current filter’s strong responsiveness on sustained trends.

4. **Make the velocity update explicitly slope-aware and acceleration-limited.** Form `target_velocity` as a confidence-weighted combination of the committed `step` and `local_slopes[i]`, such as `target_velocity = w * step + (1 - w) * local_slopes[i]`, with more reliance on the regression slope during clean, high-confidence trends. Before the existing velocity smoothing, clip `target_velocity - velocity` to a cap proportional to residual noise plus a small fraction of `abs(velocity)`; this can improve persistent-trend tracking without adopting unstable Kalman-style prediction.

5. **Evaluate a conditional, endpoint-focused second regression profile only during confirmed clean trends.** Vectorize a second robust fit using somewhat stronger recency weights, such as `np.exp(np.linspace(-4.5, 0, window_size))`, but blend it modestly with the current `exp(-3, 0)` measurement only after multiple same-direction high-confidence local slopes. This preserves the current best’s coherent single-scale behavior in noisy or transitional regions while testing whether clean sustained movements can receive lower-lag endpoint measurements without the instability seen in unrestricted multiscale fusion.
