<DESCRIPTION>
Replace the leaky countertrend response with a one-window pending-reversal gate. The current `0.15 * step` behavior still emits many small opposing output steps, which can be counted as slope changes or false reversals. The new state records the first suppressed opposing move and releases a reversal only when the immediately following candidate step and independent local-regression slope agree in direction and exceed a volatility-scaled confirmation threshold. This preserves a genuine turn with only one-sample confirmation latency while keeping isolated noise from perturbing the output direction.
</DESCRIPTION>
