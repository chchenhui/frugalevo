<DESCRIPTION>
Introduce a persistent trend/flat controller around the reported output rather than allowing the Kalman level estimate to directly determine every emitted increment. Trend entry requires sustained normalized slope evidence, while trend exit uses a lower threshold and longer confirmation. This hysteresis prevents gain and direction behavior from changing rapidly near the noise floor.

In flat mode, the output uses a lower tracking gain and stronger velocity damping to reduce noise-driven slope changes. In trend mode, it uses a higher gain and faster velocity adaptation to retain low lag during genuine movement. Reversal confirmation is retained, but uses the controller state and innovation-scaled thresholds so real turns can still pass promptly after repeated evidence.
</DESCRIPTION>

            if emitted_level is None:
                emitted_level = level
            else:
                # Normalized Kalman velocity is a robust trend-strength measure:
                # enter trend mode only after repeated strong evidence, but do not
                # leave it until the weaker exit threshold persists.
                slope_strength = abs(slope) / (measurement_std + 1e-12)
                if not trend_mode:
                    trend_evidence = trend_evidence + 1 if slope_strength >= 0.10 else 0
                    if trend_evidence >= 2:
                        trend_mode = True
                        trend_evidence = 0
                        flat_evidence = 0
                else:
                    flat_evidence = flat_evidence + 1 if slope_strength <= 0.045 else 0
                    if flat_evidence >= 3:
                        trend_mode = False
                        flat_evidence = 0
                        trend_evidence = 0

                proposed_delta = level - emitted_level
                reversal_band = max(
                    (0.075 if trend_mode else 0.14) * measurement_std,
                    0.16 * abs(trend_velocity),
                )
                is_opposing = (
                    abs(trend_velocity) > 1e-10
                    and proposed_delta * trend_velocity < 0.0
                )

                # A direction change needs repeated evidence unless it is clearly
                # larger than the local innovation noise.  During flat periods,
                # require one additional confirmation to reject alternating jitter.
                accepted_delta = proposed_delta
                if is_opposing:
                    supported = abs(proposed_delta) >= 0.45 * reversal_band
                    opposing_evidence = opposing_evidence + 1 if supported else 0
                    required_evidence = 2 if trend_mode else 3
                    strong_reversal = abs(proposed_delta) >= 3.0 * reversal_band
                    if opposing_evidence < required_evidence and not strong_reversal:
                        accepted_delta = 0.0
                    else:
                        opposing_evidence = 0
                else:
                    opposing_evidence = 0

                # Flat mode deliberately follows more slowly and damps velocity;
                # trend mode remains responsive and uses a quicker velocity update.
                tracking_gain = 0.82 if trend_mode else 0.46
                emitted_level += tracking_gain * accepted_delta
                emitted_delta = tracking_gain * accepted_delta
                if abs(emitted_delta) > 0.015 * measurement_std:
                    velocity_gain = 0.48 if trend_mode else 0.20
                    trend_velocity = (
                        emitted_delta if abs(trend_velocity) <= 1e-10
                        else (1.0 - velocity_gain) * trend_velocity
                        + velocity_gain * emitted_delta
                    )
                else:
                    trend_velocity *= 0.72 if trend_mode else 0.50
