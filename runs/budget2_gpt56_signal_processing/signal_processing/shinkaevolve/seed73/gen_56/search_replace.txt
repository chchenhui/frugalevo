<DESCRIPTION>
Estimate noise after the clipped weighted linear fit using residual MAD, rather than using the raw window MAD for trend confidence. Raw window spread grows naturally across coherent ramps and oscillations, causing genuine slopes to be classified as uncertain. The post-fit residual scale measures only deviations from the local trajectory, so it improves responsiveness and trend tracking without weakening the existing window-MAD outlier clipping.

Also apply the existing reversal band to the countertrend hold condition. The current branch suppresses every unconfirmed countertrend step, even when its magnitude is large enough to represent a real reversal; `reversal_band` is calculated but unused. Restricting suppression to weak countertrend moves retains false-reversal protection while releasing substantial turns promptly.
</DESCRIPTION>

    # Window MAD remains appropriate for clipping outliers, but it includes
    # valid ramp amplitude.  Residual MAD instead measures noise around the
    # fitted local trajectory and is therefore the correct scale for deciding
    # whether a slope or prospective reversal is credible.
    fitted_windows = (
        measurements[:, None] + local_slopes[:, None] * t[None, :]
    )
    fit_residuals = clipped - fitted_windows
    residual_medians = np.median(fit_residuals, axis=1)
    fit_noise = np.maximum(
        1.4826 * np.median(
            np.abs(fit_residuals - residual_medians[:, None]),
            axis=1,
