<DESCRIPTION>
Add a short causal robust local-linear regression over the sliding context. Samples are clipped using the raw window MAD before fitting, so isolated spikes cannot set the local direction. The fitted residual MAD is then kept separate from raw variability: coherent ramps and curves have large raw spread but small residual noise, allowing the filter to respond promptly to genuine trends, while noisy windows receive stronger reversal suppression. The regression slope is also used as explicit trend evidence for consensus weighting, alpha scheduling, acceleration limiting, and velocity deadband sizing.
</DESCRIPTION>
