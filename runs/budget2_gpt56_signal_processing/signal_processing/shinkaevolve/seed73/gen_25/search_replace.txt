<DESCRIPTION>
Replace the current reversal counter with direction-aware, volatility-gated evidence. The existing logic only accumulates evidence when the Kalman velocity has already changed sign, which can keep genuine turns frozen because the output hold itself delays the velocity update. The revised gate retains one-sample suppression for noise rejection, but releases a reversal after two consecutive, sufficiently large opposite candidate steps even while the Kalman velocity is still transitioning. Large Kalman-supported turns continue to bypass confirmation. This should reduce lag and average error while retaining the current strong reduction in slope changes and false reversals.
</DESCRIPTION>
