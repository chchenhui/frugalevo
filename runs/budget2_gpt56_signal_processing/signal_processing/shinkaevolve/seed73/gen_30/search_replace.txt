<DESCRIPTION>
Replace the single exponential local reference with a confidence-weighted blend of three causal endpoint regressions. Gentle regression dominates flat or noise-dominated windows to reduce slope changes, while increasingly recent regression dominates when fitted slope is large relative to residual noise, reducing endpoint lag during coherent trends. The existing Kalman and reversal hysteresis stages remain intact, so this adds a stable multi-scale measurement consensus rather than introducing another reactive tracker.

        # window exists.  Thereafter blend gentle, medium, and steep endpoint
        # fits according to slope-to-residual confidence.  This prevents a
        # fixed recency decay from either lagging every turn or following every
        # noisy oscillation.
        window_level = decay * window_level + (1.0 - decay) * sample
        if index >= window_size - 1:
            local_index = index - window_size + 1
            medium_slope = endpoint_slopes[1, local_index]
            fit_noise = endpoint_noise[local_index]
            trend_confidence = abs(medium_slope) / (
                abs(medium_slope) + 1.5 * fit_noise
            )
            gentle_weight = (1.0 - trend_confidence) ** 2
            medium_weight = 2.0 * trend_confidence * (1.0 - trend_confidence)
