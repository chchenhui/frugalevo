<DESCRIPTION>
Add a lightweight directional hysteresis gate to the predictive consensus stage. The current alpha-beta update remains highly responsive, but its reported level can still alternate direction whenever short-lived innovations pull the target across the prediction. This edit requires two samples of consistent opposite-direction evidence before publishing a reversal, while allowing large, Kalman-supported turns to pass immediately. Holding the reported level during unconfirmed turns eliminates noise-induced sign changes without adding a fixed moving-average delay. The tracker itself continues updating during the hold, so genuine trend changes are released with minimal latency.
</DESCRIPTION>

        previous_consensus = consensus_level
        predicted_consensus = consensus_level + consensus_velocity
        residual = target - predicted_consensus
        alpha = 0.70 + 0.16 * min(1.0, disagreement / (2.5 * scale + 1e-12))
        candidate_level = predicted_consensus + alpha * residual
        step = candidate_level - previous_consensus

        # A reversal must have persistent local support.  A sufficiently large
        # Kalman-supported step bypasses the confirmation delay so sharp real
        # turns retain the low-lag behavior of the predictive filter.
        prior_direction = np.sign(previous_step)
        step_direction = np.sign(step)
        is_opposing = (
            prior_direction != 0.0 and step_direction == -prior_direction
        )
        supports_turn = (
            np.sign(velocity) == step_direction
            and abs(velocity) >= 0.035 * scale
        )
        decisive_turn = abs(step) >= 0.32 * scale and supports_turn

        if is_opposing and not decisive_turn:
            reversal_evidence = reversal_evidence + 1 if supports_turn else 0
            if reversal_evidence < 2:
                consensus_level = previous_consensus
                step = 0.0
            else:
                consensus_level = candidate_level
                reversal_evidence = 0

                reversal_evidence = 0
