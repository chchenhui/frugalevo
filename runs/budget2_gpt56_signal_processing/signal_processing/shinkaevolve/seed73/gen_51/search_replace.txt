<DESCRIPTION>
Fuse the accepted consensus motion with a robust short-horizon local slope when updating predictive velocity. The current velocity target depends heavily on the Kalman velocity, which can remain reactive to innovation noise even when the output reversal gate has held the consensus level. A median of recent first differences supplies a cheap robust local slope estimate that better represents sustained motion.

The fusion gives the accepted output step greater weight in flat or noise-dominated regions, preventing a noisy slope estimate from restarting motion after a held reversal. When the robust local slope is strong and agrees with the Kalman slope, it receives more weight, preserving propagation through genuine trends and reducing lag. The existing residual-scaled acceleration cap remains in place to prevent abrupt velocity changes.
</DESCRIPTION>

        # Blend accepted output motion with a robust local slope rather than
        # allowing the innovation-reactive Kalman velocity to dominate the
        # predictive state.  Median first differences reject isolated spikes.
        slope_span = min(window_size, 7)
        recent_differences = np.diff(x[max(0, index - slope_span + 1):index + 1])
        local_slope = (
            float(np.median(recent_differences))
            if recent_differences.size
            else 0.0
        )
        local_strength = abs(local_slope) / (0.12 * scale + 1e-12)
        slope_agreement = local_slope * velocity > 0.0
        trend_confidence = (
            local_strength / (1.0 + local_strength)
            if slope_agreement
            else 0.0
        )

        # In flat/noisy conditions the accepted step is safer; on a coherent
        # trend the local robust slope improves sustained low-lag propagation.
        step_weight = 0.78 - 0.43 * trend_confidence
        velocity_target = step_weight * step + (1.0 - step_weight) * local_slope
        acceleration_limit = 0.10 * scale + 0.025 * abs(velocity)
        velocity_change = np.clip(
            velocity_target - consensus_velocity,
            -acceleration_limit,
            acceleration_limit,
        )
