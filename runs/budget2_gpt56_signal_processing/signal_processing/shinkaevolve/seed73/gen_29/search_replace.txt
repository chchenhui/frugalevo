<DESCRIPTION>
Add a small causal multi-scale endpoint-regression ensemble. The existing regression uses one fixed recency decay, which creates an unavoidable compromise: a gentle profile is stable but late during a coherent move, while a steep profile is responsive but can react to endpoint noise. The edit reuses the robust residual weights from the existing IRLS fit to compute gentle, current, and steep endpoint fits with only two additional 2x2 solves.

The pipeline blends these profiles based on local trend-to-noise ratio and agreement between their slopes. In flat or ambiguous windows it retains substantial gentle/current influence, reducing spurious directional changes. When all scales independently support the same trend, it progressively favors the steep causal endpoint fit, reducing lag without relying on a single reactive estimate. The downstream reversal guard remains intact as a final protection against unsupported turns.
</DESCRIPTION>
