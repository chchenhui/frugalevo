<DESCRIPTION>
Strengthen the reported-output reversal gate using signed, innovation-normalized evidence rather than treating every candidate displacement as equally valid evidence. A genuine reversal should have the candidate displacement and the clipped Kalman innovation pointing in the same direction across several causal updates. Noise-induced reversals frequently produce weak or inconsistent innovations, so they no longer accumulate confirmation score merely because the internally predicted state moved slightly across the reported level.

The gate retains an immediate-turn path for unusually large coherent moves to preserve responsiveness, while ordinary turns require three qualifying samples and cumulative normalized innovation evidence. This directly targets the remaining false reversals and excess slope changes without changing the endpoint estimator or Kalman state model.
</DESCRIPTION>
