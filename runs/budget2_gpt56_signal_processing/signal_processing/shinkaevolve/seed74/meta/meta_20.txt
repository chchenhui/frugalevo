# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- **The current best, Robust Adaptive Local-Trend Filter (Generation 2), remains the strongest overall design at combined score 0.54.** Its combination of endpoint-aligned exponentially weighted local-linear regression, one-pass Huber residual reweighting, and constrained alpha-beta state tracking produced the best reported stability: **79.8 slope changes, 66 false reversals, and smoothness 0.20**. It accepts moderate lag error (0.42) and correlation (0.84) in exchange for substantially fewer spurious directional changes than the more reactive alternatives.

- **Endpoint-aligned local regression is consistently effective for preserving responsiveness without moving-average lag.** The current best fits `time = np.arange(1 - window_size, 1)` and uses the fitted intercept as the current endpoint estimate. Related endpoint-fit designs also performed well: Generation 14’s Robust Endpoint Trend Signal Filter scored 0.52, and Generation 19’s endpoint-aligned adaptive tracker reached **0.53**, the best result among the newly evaluated programs. These results reinforce that estimating the newest sample directly is preferable to outputting a window mean.

- **Robust local observation estimation plus restrained temporal tracking is more successful than tracker-only adaptation.** The current best’s Huber-refined regression supplies both a robust endpoint `observation` and local `slope`; the alpha-beta-like state then enforces continuity. Generation 16’s robust causal endpoint filter similarly combined robust weighted regression, bounded correction, predictive smoothing, and reversal confirmation, achieving score 0.52 with reduced instability relative to highly reactive trackers (**148.8 slope changes, 115.2 false reversals**).

- **Conservative stabilization is associated with better smoothness among causal low-lag filters.** Generation 19’s retuned robust tracker had relatively low slope changes (120.2) and false reversals (97.8), yielding smoothness 0.14 and score 0.53. Generation 14 had 119/98 with smoothness 0.14. While neither exceeded the current best’s 0.20 smoothness, both support the earlier evidence that more restrained trend-state behavior is preferable to highly adaptive slope switching.

## Ineffective Approaches

- **Highly reactive alpha-beta and local-polynomial designs achieved strong correlation and lag metrics but failed on stability.** Generation 9 scored 0.52 with correlation 0.93, responsiveness 0.78, lag error 0.28, and 48% noise reduction, yet had only **0.06 smoothness**, with **290.8 slope changes and 231 false reversals**. Generation 18 showed the same pattern: 0.93 correlation and 0.28 lag error, but 300.6 slope changes, 238 false reversals, and 0.06 smoothness. Strong endpoint prediction alone therefore did not produce a high composite outcome.

- **Multiscale endpoint LOESS/regression increased responsiveness but did not sufficiently stabilize direction estimates.** Generation 11’s robust multiscale causal LOESS reached responsiveness 0.85 and lag error 0.18, but its permissive blending/hysteresis led to 316.4 slope changes and 254.6 false reversals. Generation 12’s multiscale robust trend filter behaved similarly, with 313.2 slope changes and 250.2 false reversals. Both remained at score 0.51 and smoothness 0.06 despite robust regression and directional hysteresis.

- **Adaptive Kalman-style tracking remained overly sensitive to local variation.** Generation 15’s robust adaptive Kalman trend filter was exceptionally fast (0.01 s), with 0.89 correlation, 0.27 lag error, and 0.78 responsiveness, but achieved only score 0.49. Its adaptive covariance, maneuver detection, and clipped innovations still yielded 234.8 slope changes and 187 false reversals, with smoothness 0.08 and low noise reduction (0.21). Generation 17’s median-conditioned Kalman variant improved stability somewhat but remained below the best, at score 0.50 and smoothness 0.12.

- **Reversal confirmation alone was insufficient when the velocity update remained aggressive.** Several new programs used two- or three-sample confirmation gates—Generation 9, 13, 14, 16, and 18—but still retained 98 to 300.6 slope changes. The contrast with the current best indicates that confirmation must operate alongside constrained velocity propagation and a meaningful noise-scaled deadband; otherwise, local fitted slopes or innovations continue to inject jitter into the state.

## Implementation Insights

- **The current best’s endpoint-coordinate choice directly supports low-delay estimates.** By defining the trailing-window time axis as `[-(window_size-1), ..., 0]`, its fitted intercept estimates the newest point rather than the average time within the window. Exponential weights `exp(time / (0.35 * window_size))` further emphasize recent samples. This produces an observation model that is causal and responsive while avoiding the intrinsic endpoint bias of the basic moving-average path.

- **The current best uses a computationally economical robust-regression structure.** It performs an initial weighted linear fit, estimates residual scale using MAD, and then makes only **one Huber reweighting pass** with weights bounded by `2.5 * scale / abs(residual)`. This was sufficient to achieve full efficiency at **0.05 s**, while suppressing isolated spikes before they affect the predictive level and velocity states. In comparison, Generation 12 used three Huber-style IRLS iterations and remained efficient, but its more elaborate multiscale slope blending still did not improve stability.

- **Separating robust measurement construction from temporal state smoothing is a key strength of the best program.** The robust regression yields `observation` and `slope`; state propagation then uses `prediction = level + velocity`, a bounded gain in `[0.12, 0.78]`, and a blended velocity update. This creates a distinction between local evidence and accepted temporal movement. The newer alpha-beta trackers often contained similar ingredients—MAD scaling, innovation clipping, adaptive gains—but their high reversal counts indicate their state updates passed too much short-scale variability into velocity.

- **The current best’s specific deadband behavior is more selective than the newer reversal gates.** Its rule only nulls a sign flip when the candidate velocity is below `0.20 * scale`, preserving larger sustained turns while rejecting weak noise-driven reversals. This mechanism, together with `0.72 * velocity + 0.28 * slope + 0.18 * gain * innovation`, corresponds to the lowest reported false-reversal count among the high-performing causal predictors: **66**, versus 97.8 in Generation 19, 98 in Generation 14, 115.2 in Generation 16, and over 230 in Generations 9, 11, 12, and 18.

## Performance Analysis

- **The new evaluations did not surpass the current best’s 0.54 combined score.** Generation 19 came closest at **0.53**, while Generations 9, 13, 14, 16, and 18 clustered at 0.52; Generations 11 and 12 reached 0.51; Generation 17 reached 0.50; and Generation 15 reached 0.49. This preserves the earlier conclusion that the current best occupies the strongest overall balance between responsiveness and directional stability.

- **The current best’s advantage is primarily smoothness and reversal control, not raw correlation or lag.** Its correlation (0.84), responsiveness (0.70), and lag error (0.42) are weaker than Generation 9’s 0.93/0.78/0.28 and Generation 11’s 0.90/0.85/0.18. However, the current best’s **smoothness score of 0.20** is notably higher than the new designs’ 0.06–0.14 range, and its 66 false reversals are substantially lower than every reported new program.

- **Generation 19 demonstrates the closest alternative balance but still falls short of the best program’s stabilization.** It delivered score 0.53, smoothness 0.14, 120.2 slope changes, and 97.8 false reversals. Relative to the current best, it improved nominal correlation (0.88 versus 0.84) and lag error (0.39 versus 0.42), but incurred roughly **51% more slope changes** and **48% more false reversals**. The evaluator therefore appears to value the best program’s more stable temporal behavior enough to offset its lower raw tracking metrics.

- **Noise reduction does not track composite success by itself.** Generation 9 achieved the strongest listed noise reduction among the new programs (0.48) but only scored 0.52 because its output derivative remained highly unstable. Conversely, the current best’s noise reduction is only 0.30, but its smoothness 0.20 and low reversal counts produced the top score. Across the evaluated programs, the highest combined outcomes come from balancing noise suppression with stable trend direction rather than maximizing noise reduction, correlation, or minimum lag independently.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Add a two-stage reversal gate to the existing MAD-scaled deadband rather than changing the core tracker.** When `velocity * proposed_velocity < 0`, retain the prior velocity direction until the opposing candidate exceeds `0.20 * scale` for two consecutive windows; allow an immediate reversal only for a clearly strong candidate, such as `abs(proposed_velocity) > 0.45 * scale`. This directly extends the best program’s already successful deadband mechanism and targets its remaining 79.8 slope changes without adopting the overly reactive behavior seen in prior confirmation-only designs.

2. **Make the velocity update confidence-adaptive using regression agreement and slope strength.** Compute a second robust slope over a recent trailing subwindow, for example the newest 8–10 samples, and reduce the `0.28 * slope` contribution when full-window and recent-window slopes disagree in sign or differ substantially in magnitude; in that case increase velocity persistence above `0.72`. Endpoint regression is proven effective, while Generation 19’s near-best result suggests modestly better raw tracking is possible, but high gains should be reserved for coherent multi-horizon evidence to avoid extra false reversals.

3. **Use innovation-consistency gating to cap measurement gain during isolated endpoint disturbances.** Before applying `gain`, compare the innovation sign with both the robust fitted slope and prior velocity; if the innovation opposes both or is a large residual relative to `scale`, cap gain around `0.35–0.50` instead of permitting `0.78`. This preserves the current endpoint-aligned robust observation model but prevents a single late-window anomaly from moving the level state sharply enough to induce a future velocity reversal.

4. **Test a slightly broader exponential regression kernel jointly with a lower maximum gain.** Sweep recency constants around `window_size * 0.35`, especially `0.40` and `0.45`, while lowering the gain ceiling from `0.78` to approximately `0.65–0.72`; retain the same one-pass Huber regression and endpoint intercept. The current filter wins through stability rather than raw lag, so a small reduction in newest-sample dominance may improve smoothness and reversal control while retaining the low-delay advantage of endpoint fitting.

5. **Introduce asymmetric robust weighting for newest samples that contradict an established trend.** Keep the initial Huber threshold at `2.5 * scale` generally, but for the newest 2–4 points whose residual direction conflicts with both the initial regression slope and current velocity, use a tighter threshold such as `1.5–2.0 * scale`. This is a lightweight extension of the current best’s economical one-pass robust fit and should specifically protect the endpoint observation—the most influential input to the tracker—from isolated spikes without suppressing sustained turns.
