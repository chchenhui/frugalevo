# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- **The current best, Robust Adaptive Local-Trend Filter (Generation 2), achieved the top combined score of 0.54 by combining robust endpoint trend estimation with predictive state tracking.** Its exponentially weighted local linear regression is explicitly fit at the newest window sample, avoiding the intrinsic delay of a centered/window-average estimate. The one-pass Huber reweighting limits the influence of isolated spikes before the alpha-beta-like level/velocity update. This yielded efficient execution (0.05 s), good correlation (0.84), responsiveness (0.70), and moderate lag error (0.42).

- **Endpoint-aligned local linear fitting is consistently stronger than plain moving averages for responsiveness.** Generation 5’s Robust Adaptive Trend Signal Filter used an exponentially weighted robust endpoint fit plus an adaptive tracker and scored 0.53; Generation 6’s Robust Endpoint Trend Tracker used the same endpoint-aligned principle and scored 0.54. These results support the current best’s design choice: estimate the value at `time = 0` using a local slope/intercept, rather than outputting a window mean.

- **Robust innovation/outlier handling preserves high correlation without large computational cost.** The current best’s Huber residual reweighting, local MAD scale, and bounded adaptive gain avoid allowing single samples to dominate local trend estimates. Related robust mechanisms also helped Generation 1’s Kalman filter reach correlation 0.92 and responsiveness 0.84, and Generation 7’s MAD-clipped alpha-beta tracker reach correlation 0.93 with lag error 0.28.

- **Velocity deadbands and reversal logic materially reduced directional instability relative to more reactive trackers.** The current best had 79.8 slope changes and 66.0 false reversals, much lower than the pure/adaptive Kalman-style designs: Generation 4 had 438.4 slope changes and 359.8 false reversals, while Generation 3 had 284 and 225. Although the current best is not fully smooth, its noise-scaled velocity deadband is associated with the best observed stability among the high-responsiveness predictive designs.

## Ineffective Approaches

- **Aggressive low-lag Kalman prediction without enough temporal stabilization performed poorly on noise suppression and smoothness.** Generation 4’s Robust Adaptive Trend Kalman Filter obtained zero lag error and perfect responsiveness, but noise reduction was only 0.01, smoothness was 0.04, and the combined score fell to 0.46. Its slope-based prediction and adaptive measurement behavior made it highly reactive rather than selectively trend-preserving.

- **Innovation-dependent gain adaptation alone did not suppress false reversals.** Generation 3 and Generation 7 used robust MAD clipping, adaptive alpha-beta gains, slope deadbands, and/or reversal hysteresis, yet both remained at combined score 0.52 with smoothness 0.07 and roughly 284 slope changes and 225–227 false reversals. These mechanisms preserved correlation near 0.92–0.93 and low lag, but their tracker updates still passed too much local variation into the velocity state.

- **Median conditioning plus Kalman tracking reduced instability somewhat but did not match the current best’s local-fit/deadband balance.** Generation 8 added a causal three-sample median conditioner, Huber innovation treatment, velocity damping, and reversal hysteresis. It reduced slope changes to 160 and false reversals to 126.4 versus highly reactive Kalman variants, but its 0.51 score and 0.11 smoothness remained below the current best’s 0.54 score, 79.8 slope changes, and 0.20 smoothness.

- **Plain moving-average behavior is inherently limited for the evaluated endpoint-aligned task.** The baseline uses an unweighted window mean, which smooths but represents the whole historical window rather than the current endpoint. The successful enhanced implementations consistently replace this with causal endpoint regression or predictive tracking because average-based smoothing introduces lag and loses responsiveness on non-stationary trends.

## Implementation Insights

- **The current best’s time coordinate is a concrete low-lag implementation detail:** `time = np.arange(1 - window_size, 1)`. With the current sample assigned time zero, the fitted intercept, `observation = value_mean - slope * time_mean`, directly estimates the endpoint. Exponential weights, `exp(time / (0.35 * window_size))`, additionally prioritize recent samples. This is a more targeted observation model than a moving average and explains the favorable responsiveness/efficiency balance.

- **The one-pass Huber local-regression refinement is computationally lightweight and targeted.** The code first estimates slope/intercept, derives residuals, estimates scale by MAD, then applies `min(1, 2.5 * scale / abs(residual))` weights for a second fit. Unlike iterative robust regression, this keeps runtime at 0.05 s and efficiency at 1.00 while suppressing isolated observation spikes that would otherwise affect endpoint slope estimates.

- **The current best separates local observation estimation from temporal continuity.** The robust weighted regression produces `observation` and `slope`; then the alpha-beta-style state uses `prediction = level + velocity`, a bounded gain of 0.12–0.78, and blended velocity update. This hybrid structure differs from Generation 0’s direct exponentially weighted moving average, which reached only 0.50 combined score and had 223.4 slope changes/175.4 false reversals, showing that recency weighting alone was insufficient.

- **Noise-adaptive reversal suppression is one of the current best’s clearest differentiators.** Its reversal condition compares the candidate velocity to a MAD-scaled deadband: a sign change is removed only when `abs(proposed_velocity) < 0.20 * scale`. This retains substantial trends while blocking weak noise-driven direction changes. The resulting 66 false reversals is lower than Generation 5’s 76.2, Generation 6’s 95, Generation 8’s 126.4, and all Kalman/alpha-beta variants with more aggressive adaptation.

## Performance Analysis

- **The best combined-score range is narrow, but the current best occupies the leading stability position.** Generation 2 and Generation 6 both scored 0.54, with Generation 5 at 0.53 and several variants at 0.51–0.52. The current best is especially notable because its smoothness score of 0.20 is the highest reported, versus 0.18 for Generation 5, 0.15 for Generation 6, 0.11 for Generation 8, and 0.04–0.09 for the more reactive Kalman/alpha-beta variants.

- **Higher correlation and lower lag did not automatically produce a higher combined score.** Generation 1 achieved 0.92 correlation, 0.84 responsiveness, and 0.19 lag error, but scored 0.52 because smoothness was only 0.06 with 323 slope changes and 259.4 false reversals. Likewise, Generation 7 had 0.93 correlation and 0.28 lag error but scored 0.52 due to very weak smoothness and excessive directional changes. The evaluation therefore penalizes reactive tracking strongly enough that raw predictive accuracy cannot compensate.

- **The current best accepts moderate lag and lower correlation in exchange for substantially improved stability.** Its correlation of 0.84 and lag error of 0.42 are weaker than several Kalman and alpha-beta alternatives, but its 79.8 slope changes and 66 false reversals are dramatically lower. This balance corresponds to the top combined score, indicating that robust local fitting plus constrained velocity tracking is better aligned with the composite objective than minimizing lag alone.

- **Noise reduction remains a shared weakness across the strongest local-trend methods.** The current best has noise reduction of 0.30, nearly matching Generation 5 (0.31), Generation 6 (0.35), and Generation 8 (0.30), but below the more reactive Generation 1 (0.49) and Generation 7 (0.48). However, those higher noise-reduction designs still had smoothness near 0.06–0.07 and much higher reversal counts, demonstrating that their apparent noise reduction did not translate into stable local derivative behavior under the evaluator.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Tune the endpoint-regression recency scale and tracker gains jointly rather than replacing the hybrid design.** Try a small parameter sweep around the current exponential decay `0.35 * window_size`, such as `0.25`, `0.30`, `0.40`, and `0.50`, while modestly reducing the maximum measurement gain from `0.78` toward `0.65–0.72`. The endpoint fit is the strongest low-lag component, but slightly less aggressive recency weighting and gain capping may improve the current 0.20 smoothness score without reverting to moving-average lag.

2. **Add persistence-based reversal confirmation on top of the existing MAD-scaled velocity deadband.** When a proposed velocity changes sign, retain the old direction unless the new signed slope/velocity exceeds the deadband for two consecutive windows, or exceeds a larger immediate threshold such as `0.4–0.5 * scale`. The current deadband already produces the lowest observed false reversals (66), so confirmation logic is a targeted way to reduce the remaining 79.8 slope changes while preserving responsiveness to sustained reversals.

3. **Make Huber robustness asymmetric in time by applying stronger outlier suppression to the newest few samples only when they conflict with the fitted trend.** Preserve the current one-pass weighted fit, but for recent residuals that are large and opposite to the initial slope direction, use a somewhat tighter clipping multiplier (for example `1.5–2.0 * scale` versus the current `2.5 * scale`). This extends the proven lightweight robust-regression mechanism and specifically protects the endpoint estimate from isolated late-window spikes, which are disproportionately likely to create false directional changes.

4. **Replace the fixed velocity blend with confidence-adaptive velocity damping.** Keep the level update structure, but reduce the slope contribution in `proposed_velocity` when local slope confidence is weak—for example, scale the `0.28 * slope` term by `abs(slope) / (abs(slope) + c * scale)` and increase persistence from the previous velocity in noisy regions. This directly addresses the historical failure mode of adaptive alpha-beta/Kalman variants: their velocity states passed too much local variation despite having good correlation and lag.

5. **Use a robust short-horizon trend-consistency statistic to gate high gains.** Compute slopes from both the full weighted window and a recent subwindow (such as the newest 6–10 samples); allow gains near the upper bound only when their signs agree and their magnitudes are comparable, otherwise cap the gain around `0.35–0.50`. This preserves fast response during coherent trend changes while preventing the high-gain tracker behavior that prior reactive Kalman-style variants showed to be harmful for smoothness and false reversals.
