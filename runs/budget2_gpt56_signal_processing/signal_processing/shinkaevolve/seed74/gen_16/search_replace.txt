persistent_reversal_gate
</NAME>

<DESCRIPTION>
Add a causal persistence gate to the predictive continuity stage. The robust local fit already supplies a MAD-derived residual scale, but the output can still reverse direction when a single noisy window shifts the candidate estimate across the previous trajectory. The new gate only intervenes when a proposed output velocity opposes the established direction: a normal reversal must persist for two consecutive windows, while a large movement (at least 0.45 times the local robust scale) is accepted immediately. Holding one ambiguous sample avoids noise-induced directional flips with only a one-sample bounded delay for genuine sustained turns. The accepted velocity, rather than the raw candidate velocity, updates the predictor state so rejected reversals cannot contaminate later predictions.
</DESCRIPTION>
