<DESCRIPTION>
Add a velocity-coherent innovation gate before the Kalman measurement update. The current filter is highly responsive but produces many slope changes and false reversals because small measurement innovations opposing the predicted velocity can immediately pull the position estimate backward. The gate attenuates only sub-threshold opposing innovations, while innovations large enough to represent a genuine turn remain substantially available to the adaptive maneuver logic. This should improve smoothness and false-reversal penalties without materially increasing lag on confirmed direction changes.
</DESCRIPTION>
