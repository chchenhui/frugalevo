bounded_reversal_catchup
</NAME>

<DESCRIPTION>
Add a short bounded catch-up mode when the persistent direction gate confirms a genuine reversal. The current presentation layer switches directly from `max` to `min` (or vice versa), which can expose a large jump from the internally tracked level and harm smoothness. Conversely, retaining the old level too long creates the measured post-turn lag.

The new state releases the reported level toward the already-adapted internal level over three samples, with each movement capped relative to the robust noise scale. The final monotonic constraint is retained, so the output remains direction-safe and resistant to false reversals. This targets the weak lag/accuracy metrics without removing the source of the strong smoothness and false-reversal scores.
</DESCRIPTION>
