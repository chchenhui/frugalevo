</NAME>

<DESCRIPTION>
Add a causal output hysteresis stage to the existing robust level-and-trend Kalman estimator. The filter state remains responsive, but the emitted value now requires short confirmation before accepting a change opposite to the established output direction. The adaptive deadband is derived from the current robust measurement-noise estimate, so it scales with volatility rather than using a fixed threshold.

This directly targets the largest weak metrics: noise-driven slope changes and false reversals. Continuing trends are emitted immediately, while genuine reversals are delayed by at most one additional processed sample after exceeding the noise floor. This preserves low phase delay and tracking accuracy substantially better than increasing the Kalman smoothing globally.
</DESCRIPTION>
