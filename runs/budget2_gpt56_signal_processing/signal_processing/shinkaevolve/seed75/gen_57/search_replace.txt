<DESCRIPTION>
Strengthen the output reversal gate by requiring weak opposing output motion to agree with a consensus of the filtered slope and recent level increment. The existing gate can accumulate displacement from noisy endpoint oscillations even when the estimator has not actually established a new directional trend. This edit makes pending evidence decay when support disappears, uses only directionally consistent incremental displacement as evidence, and retains a fast path for decisive turns. It should reduce false reversals and slope changes while keeping genuine, high-energy corners responsive.
</DESCRIPTION>
