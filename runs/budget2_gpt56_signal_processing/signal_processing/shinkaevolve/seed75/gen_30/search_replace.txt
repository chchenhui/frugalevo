<DESCRIPTION>
Bound the innovation-driven process-noise schedule and reduce its sensitivity. The existing squared-innovation coefficient allows isolated measurement noise to sharply increase Kalman gain, which can create false directional reversals. A conservative baseline preserves responsiveness to real non-stationary motion, while clipping the acceleration variance prevents one noisy sample from destabilizing the level/slope model. This directly targets slope changes and false reversals without adding window latency.
</DESCRIPTION>
