<DESCRIPTION>
Strengthen the output reversal gate using graded multi-scale model confirmation. The current implementation only delays opposite increments smaller than the reversal band, so moderately large noise-driven endpoint movements can immediately flip direction. This edit gates every opposing movement unless it has strong fast/slow slope consensus, or exceptionally strong fast consensus, while retaining a two-sample accumulated-displacement fallback for genuine turns whose slow model has not yet rotated. This should substantially reduce slope changes and false reversals while limiting added turn lag.
</DESCRIPTION>
