<DESCRIPTION>
Add an adaptive output-direction hysteresis stage after the alpha-beta estimate. The tracker continues to update its internal level and slope on every sample, preserving responsiveness to genuine transitions, but suppresses a single small output movement that opposes the established direction. A direction reversal is accepted immediately when its magnitude exceeds the local volatility-scaled threshold, or after two consecutive opposing estimates confirm it. This specifically targets noise-induced slope changes and false reversals while imposing at most a one-sample confirmation delay for weak genuine turning points.
</DESCRIPTION>

        # Small bounded prediction compensates for causal filter delay.
        # Limiting lead prevents excessive overshoot near reversals.
        lead_limit = max(1.5 * self.noise_scale, 1e-6)
        lead = np.clip(self.prediction_lead * self.slope, -lead_limit, lead_limit)
        candidate = self.level + lead

        # Suppress isolated, sub-noise directional changes at the output.
        # Large moves pass immediately; smaller opposing moves require a
        # second consecutive confirmation, reducing false reversals without
        # freezing the adaptive state during a genuine trend transition.
        delta = candidate - self.last_output
        direction = np.sign(delta)
        reversal_band = max(0.18 * self.noise_scale, 1e-6)

        if direction == 0.0:
            return self.last_output

        if self.output_direction == 0.0 or direction == self.output_direction:
            self.output_direction = direction
            self.pending_direction = 0.0
            self.pending_reversal_count = 0
            self.last_output = candidate
        elif abs(delta) >= reversal_band:
            self.output_direction = direction
            self.pending_direction = 0.0
            self.pending_reversal_count = 0
            self.last_output = candidate
        else:
            if direction == self.pending_direction:
                self.pending_reversal_count += 1
            else:
                self.pending_direction = direction
                self.pending_reversal_count = 1

            if self.pending_reversal_count >= 2:
                self.output_direction = direction
                self.pending_direction = 0.0
                self.pending_reversal_count = 0
                self.last_output = candidate

        return self.last_output
