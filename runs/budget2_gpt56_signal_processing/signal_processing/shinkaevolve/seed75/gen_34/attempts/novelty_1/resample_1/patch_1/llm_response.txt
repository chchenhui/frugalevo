<DESCRIPTION>
Strengthen the reversal gate with state-model directional confirmation. The existing persistence rule only examines successive output-candidate directions, so correlated noise can still create accepted reversals. A genuine turn is better supported when the innovation-driven slope update and the current filtered slope both agree with the proposed output direction.

This edit adds a short fast slope estimate from recent first differences, forms a consensus with the alpha-beta slope, and uses a normalized directional-strength test. Counter-direction moves receive immediate acceptance only when both model slopes agree and the movement is materially above noise. Otherwise, modest reversals require the existing persistence confirmation, with stronger model agreement allowing confirmation one sample sooner. This should reduce false reversals and slope changes while avoiding unnecessary lag at real turning points.
</DESCRIPTION>
