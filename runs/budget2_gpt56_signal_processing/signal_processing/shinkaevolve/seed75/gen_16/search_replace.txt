<DESCRIPTION>
Replace the output-level reversal gate with a slope-specific bounded correction. The previous gate directly overwrote level estimates whenever a small directional change occurred, which reduces reversals but can create plateaus and delay genuine turns. Instead, retain the Kalman level update for responsive causal tracking while clipping only abrupt innovation-driven changes to the slope state. The adaptive bound is tied to the local innovation scale and existing predicted slope, so normal trend evolution remains responsive while isolated noise impulses cannot produce large slope reversals.
</DESCRIPTION>
