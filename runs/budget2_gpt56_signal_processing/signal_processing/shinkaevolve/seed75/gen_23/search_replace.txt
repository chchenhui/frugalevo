Replace the subtractive covariance update with the numerically robust Joseph form. The current `P - KHP` expression can gradually lose positive-semidefiniteness through floating-point cancellation, particularly when adaptive measurement/process variances produce aggressive gains. Joseph form preserves covariance consistency, while explicit symmetry restoration, variance floors, and cross-covariance bounding prevent invalid covariance states. This permits stable adaptive tracking without spurious gain excursions that can cause false slope reversals.

        # Joseph-form covariance update avoids the cancellation in P - KHP.
        # It preserves positive semidefiniteness under adaptive gain and noise
        # scheduling, preventing numerical covariance collapse from causing
        # unstable slope updates or noise-induced reversals.
        correction = np.eye(2)
        correction[:, 0] -= gain
        covariance = (
            correction @ predicted_covariance @ correction.T
            + measurement_var * np.outer(gain, gain)
        )
        covariance = 0.5 * (covariance + covariance.T)
        covariance[0, 0] = max(covariance[0, 0], 1e-12)
        covariance[1, 1] = max(covariance[1, 1], 1e-12)
