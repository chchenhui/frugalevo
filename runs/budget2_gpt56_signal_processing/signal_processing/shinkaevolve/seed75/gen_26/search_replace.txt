<DESCRIPTION>
Replace the subtractive covariance update with the numerically stable Joseph form. The current update can gradually lose covariance symmetry or positive-semidefiniteness under adaptive process noise and clipped innovations, producing erratic Kalman gains that manifest as noise-driven slope changes. The Joseph update preserves covariance structure, explicitly symmetrizes the result, and applies small variance floors. This makes the adaptive tracker more stable during volatile regime changes while retaining its current low-lag state prediction and responsiveness.
</DESCRIPTION>

        # Joseph-form covariance update is more stable than the subtractive
        # form when gains and process noise adapt rapidly.  It preserves a
        # symmetric positive-semidefinite covariance and prevents numerical
        # gain jitter from becoming spurious output reversals.
        innovation_projection = np.eye(2) - np.outer(gain, observation)

            innovation_projection @ predicted_covariance @ innovation_projection.T
            + measurement_variance * np.outer(gain, gain)
        )
        covariance = 0.5 * (covariance + covariance.T)
        covariance[0, 0] = max(covariance[0, 0], 1e-12)
