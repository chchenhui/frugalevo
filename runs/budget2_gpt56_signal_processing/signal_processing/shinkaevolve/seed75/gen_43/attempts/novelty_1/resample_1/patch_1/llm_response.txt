continuous_slope_coherence

<DESCRIPTION>
Introduce a slow, exponentially averaged slope as a stable trend reference and use continuous signed slope coherence to modulate the fast Kalman correction. When the instantaneous Kalman slope agrees with the established trend, nearly all of the responsive correction is retained. When it opposes the established trend, the correction is smoothly reduced rather than accepted or rejected by a binary rule. This avoids abrupt switching behavior and prevents isolated innovation-driven slope flips from producing false reversals, while sustained reversals remain trackable as the slow slope adapts. The existing small-increment deadband remains as a final safeguard.
</DESCRIPTION>

        candidate_state = predicted_state + gain * innovation
        covariance = predicted_covariance - np.outer(gain, predicted_covariance[0])

        # Use signed agreement between the responsive and slow trend slopes
        # as a continuous confidence measure.  Opposing slopes are common at
        # a real turn, but are also where one-sample noise most often creates
        # false reversals; therefore their measurement correction is tempered
        # rather than abruptly disabled.
        fast_slope = candidate_state[1]
        slope_alignment = (fast_slope * slow_slope) / (
            abs(fast_slope) * abs(slow_slope) + 1e-12
        )
        coherence = np.clip(slope_alignment, 0.0, 1.0)
        fast_weight = 0.50 + 0.45 * coherence
        candidate_state = predicted_state + fast_weight * (
            candidate_state - predicted_state
        )

        # Reject only small opposite increments.  This is a directional
        # deadband, not a level deadband, so genuine trends remain trackable.
        increment = candidate_state[0] - state[0]
        reversal_threshold = 0.18 * noise_scale
        if (
            previous_increment * increment < 0.0
            and abs(increment) < reversal_threshold
        ):
            candidate_state[0] = state[0]
            candidate_state[1] *= 0.35
            increment = 0.0

        state = candidate_state
        previous_increment = 0.75 * previous_increment + 0.25 * increment
        # Adapt slowly enough to reject impulses, but quickly enough that a
        # sustained genuine reversal regains full fast-model weighting.
        slow_slope = 0.90 * slow_slope + 0.10 * increment
