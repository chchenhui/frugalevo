<DESCRIPTION>
Replace the single-sample reversal suppression with a causal confirmation gate. The current gate can accept alternating medium-sized Kalman updates immediately, which still creates false reversals in volatile regions. The proposed edit keeps a pending opposite-direction displacement: a reversal is accepted when it is either clearly large relative to the adaptive noise scale or persists for two samples. This is a low-latency Schmitt-trigger/debounce mechanism. It reduces slope changes and false trend changes while allowing strong genuine turns through without an added confirmation delay. The gate operates only on the reported trajectory and retains the Kalman state as the underlying predictor, avoiding the prior inconsistency caused by overwriting the Kalman level and slope after suppressing an output step.
</DESCRIPTION>
