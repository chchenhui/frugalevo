<DESCRIPTION>
Strengthen the output-only reversal gate without changing the responsive alpha-beta core. The existing counter requires only sample count after a candidate crosses the small band; it can therefore accept repeated weak noise excursions. This edit adds a volatility-normalized excursion requirement, raises the immediate-turn threshold, and removes the unconfirmed large-delta bypass. A genuine turn can still pass rapidly when the dual-scale slope model agrees, while weak counter-moves need both persistence and sufficient displacement. This should reduce false reversals and slope changes with only limited additional lag.
</DESCRIPTION>
