<DESCRIPTION>
Seed the nonlinear solver with deterministic unequal radii correlated with the finite-row topology.  Corner-adjacent circles receive a modest radius advantage, while circles in the densest six-circle rows receive a slight penalty.  This breaks the artificial equal-radius basin before contacts are established and better reflects the boundary defects expected in strong finite square packings.  The radii remain deliberately small relative to initial separations, so all starts are feasible without requiring an unreliable repair before optimization.
</DESCRIPTION>

    # Do not begin every circle with an interchangeable radius.  In a finite
    # hexagonal patch, corners can often grow into useful boundary defects,
    # whereas the middle of a six-circle row is initially more constrained.
    # This small, topology-aware bias helps select unequal contact graphs
    # before the uniform sum-of-radii objective takes over.
    wall = np.minimum.reduce((
        centers[:, 0], centers[:, 1],
        1.0 - centers[:, 0], 1.0 - centers[:, 1],
    ))
    near_vertical_wall = np.clip((0.24 - np.minimum(
        centers[:, 0], 1.0 - centers[:, 0]
    )) / 0.24, 0.0, 1.0)
    near_horizontal_wall = np.clip((0.24 - np.minimum(
        centers[:, 1], 1.0 - centers[:, 1]
    )) / 0.24, 0.0, 1.0)
    corner_bonus = near_vertical_wall * near_horizontal_wall

    dense_row_penalty = np.empty(N_CIRCLES)
    cursor = 0
    for count in row_sizes:
        dense_row_penalty[cursor:cursor + count] = 0.0014 if count >= 6 else 0.0
        cursor += count

    radii = (
        0.0118
        + 0.0021 * corner_bonus
        - dense_row_penalty
        + rng.uniform(-0.0007, 0.0007, N_CIRCLES)
    )
    radii = np.clip(radii, 0.008, 0.015)
    return np.concatenate((centers.ravel(), radii))
