<DESCRIPTION>
Replace the expensive reflection-heavy 40-start search with a more geometrically diverse 12-start portfolio. The prior reflections mostly duplicate the same contact graph, while asymmetric five-row layouts move the six-circle layers relative to square boundaries and can produce genuinely different wall/diagonal tangency structures. Each of six distinct layouts contributes one equal-radius continuation start and one row-sheared direct unequal-radius start. This both emphasizes promising asymmetric hexagonal-layer arrangements and substantially reduces runtime, leaving the final polishing pass to refine the strongest basin.

        # unequal-radius starts: one inherited from a dense common-radius
        # packing and one with a small row shear that can enter a different
        # diagonal contact graph.
        for layout in layouts:
            base = layered_seed(layout, 0.18)
            sheared = base.copy()
            first = 0
            for row, count in enumerate(layout):
                # A nonalternating magnitude prevents the direct start from
                # being locked into the same symmetric basin as the common
                # radius continuation.
                offset = (0.011 if row % 2 else -0.009)
                if row == len(layout) - 1:
                    offset *= 1.45
                sheared[first:first + count, 0] += offset
                first += count
