<DESCRIPTION>
Replace the single five-row seed with a compact portfolio of structurally different 26-circle layered seeds.  The existing `(5,5,6,5,5)` arrangement is retained, while asymmetric placements of the four- and six-circle rows are added.  In a square, boundary circles have substantially different contact opportunities from bulk circles, so moving the denser rows away from the center can reach unequal-radius contact graphs inaccessible from a merely jittered copy of the symmetric seed.

The initial radius remains safely feasible for every candidate.  This adds only a few SLSQP starts, is deterministic, and lets the existing continuation stage further improve whichever topology produces the best local packing.

    n = 26

    def layered_seed(rows):
        """A square-adapted, approximately triangular seed for one row topology."""
        seed = []
        for row, count in enumerate(rows):
            # Different row populations naturally give the required horizontal
            # stagger.  The common vertical spacing leaves a feasible initial
            # radius while allowing SLSQP to form unequal boundary contacts.
            xs = np.linspace(1.0 / (count + 1), count / (count + 1), count)
            y = 0.10 + 0.20 * row
            seed.extend((x, y) for x in xs)
        return np.asarray(seed, dtype=float)
