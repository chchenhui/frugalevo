<DESCRIPTION>
Supply exact derivatives for both the linear radius objective and every geometric inequality. Pair-separation derivatives are particularly important here: numerical differentiation repeatedly evaluates all 325 pair constraints for each of 78 variables, whereas the analytic Jacobian provides the local contact geometry directly. This should make SLSQP converge more accurately and reliably within the same time budget.

Use the resulting lower optimization cost for additional asymmetric perturbation starts. The existing row population pattern is a useful boundary-aware topology, but small independent perturbations can select different contact graphs and escape its symmetric local optima. Candidate validation and conservative final scaling are retained unchanged.

        jac[k, 2 * n + k] = -1.0
        jac[n + k, 2 * k] = -1.0
        jac[n + k, 2 * n + k] = -1.0
        jac[2 * n + k, 2 * k + 1] = 1.0
        jac[2 * n + k, 2 * n + k] = -1.0
        jac[3 * n + k, 2 * k + 1] = -1.0

        rows = 4 * n + np.arange(len(ii))
