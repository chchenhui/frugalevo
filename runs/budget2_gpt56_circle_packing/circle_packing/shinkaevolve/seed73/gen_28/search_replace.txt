<DESCRIPTION>
Add deterministic geometric variants to every row-layout seed before nonlinear optimization.  The existing random jitter breaks some symmetry, but the row patterns still tend to enter a small number of contact graphs.  Reflecting the indexed configuration can lead SLSQP through a different active-set trajectory, while a small alternating row displacement more directly encourages triangular-lattice contacts and asymmetric boundary defects.  The displacement is far smaller than the initial clearance implied by the low starting radii, so every generated seed remains safely feasible.  This increases basin coverage without changing the public interface or the final feasibility certification.
</DESCRIPTION>

    rng = np.random.default_rng(seed)
    centers = _row_layout(row_sizes, phase)

    # boundary configurations instead of repeatedly converging to a grid.
    jitter = rng.normal(0.0, 0.017, centers.shape)

    centers = np.clip(centers, 0.045, 0.955)

def _geometric_variants(initial, row_sizes):
    """
    Produce deterministic alternatives with the same generous initial radii.

    A reflected indexing and alternating lateral row shifts are geometrically
    innocuous at small radius, but often select different boundary contact
    graphs during constrained optimization.
    """
    centers = initial[:2 * N_CIRCLES].reshape(N_CIRCLES, 2)
    radii = initial[2 * N_CIRCLES:]
    variants = [initial]

    reflected = centers.copy()
    reflected[:, 0] = 1.0 - reflected[:, 0]
    variants.append(np.concatenate((reflected.ravel(), radii.copy())))

    staggered = centers.copy()
    begin = 0
    for row, count in enumerate(row_sizes):
        # Opposite motions of neighboring rows promote diagonal contacts.
        shift = 0.011 if row % 2 else -0.011
        staggered[begin:begin + count, 0] += shift
        begin += count
    staggered = np.clip(staggered, 0.035, 0.965)
    variants.append(np.concatenate((staggered.ravel(), radii.copy())))

    return variants
