<DESCRIPTION>
Add a low-cost deterministic contact-escape stage after the existing elite polishing. The highest-scoring jammed arrangements can be trapped by a rigid contact graph even when a nearby unequal-radius arrangement is better. This refinement slightly deflates each of the two best certified candidates, perturbs only circles with substantial clearance from every wall, and reruns short high-accuracy SLSQP solves. Restricting motion to interior circles preserves the useful square-adapted boundary layer while allowing alternative bulk tangencies and asymmetric radius allocations to emerge. Every result is still ranked by the existing common-scale certification procedure.

    # Contact-escape refinement: a fully jammed solution often has a nearly
    # optimal boundary layer but can be held below a better solution by a
    # rigid interior contact graph.  Make only tiny, deterministic interior
    # displacements after a modest deflation, then let the exact constrained
    # solve regrow unequal radii.  This is deliberately focused on the best
    # basins rather than adding another expensive broad topology search.
    escape_rng = np.random.default_rng(904211)
    escape_bases = polished[:min(2, len(polished))]
    for base_rank, (_, base) in enumerate(escape_bases):
        for attempt in range(3):
            trial = base.copy()
            c, r = unpack(trial)
            wall_distance = np.minimum.reduce((
                c[:, 0], c[:, 1], 1.0 - c[:, 0], 1.0 - c[:, 1]
            ))
            # Keep wall-supported circles fixed: their contact structure is
            # particularly valuable in a finite square.
            movable = wall_distance > (r + 0.018)

            direction = escape_rng.normal(0.0, 1.0, (n, 2))
            direction /= np.maximum(
                np.linalg.norm(direction, axis=1, keepdims=True), 1.0e-15
            )
            magnitude = 0.0011 + 0.00045 * attempt + 0.0002 * base_rank
            c[movable] += magnitude * direction[movable]
            c[:] = np.clip(c, 0.001, 0.999)

            # The 0.4 percent release is enough to escape active contacts
            # without destroying the successful local geometry.
            r *= 0.996
            trial = np.concatenate((c.ravel(), r))

            result = minimize(
                objective,
                trial,
                jac=objective_jac,
                method="SLSQP",
                bounds=bounds,
                constraints=con,
                options={"maxiter": 1250, "ftol": 3.0e-13, "disp": False},
            )
            if np.all(np.isfinite(result.x)):
                polished.append((certified_value(result.x), result.x.copy()))

    polished.sort(key=lambda item: item[0], reverse=True)
    _, best = polished[0]
    centers, radii = certify(best)
    return centers, radii, float(np.sum(radii))
