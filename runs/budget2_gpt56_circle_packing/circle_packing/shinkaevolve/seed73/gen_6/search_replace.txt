<DESCRIPTION>
Replace the single local SLSQP run with a deterministic multistart search around the staggered hexagonal seed. The current seed is retained because it is already a good feasible packing, but several small, reproducible perturbations break row and reflection symmetries. This is important for variable-radius square packings: boundary circles often benefit from asymmetric radius and position adjustments, and a single symmetric local search can become trapped near a lower-sum contact graph.

All starts remain comfortably inside the square and use small initially feasible radii. The best feasible result is retained. A slightly more conservative final radius shrink ensures that numerical constraint tolerances cannot create microscopic overlaps in the returned packing.
</DESCRIPTION>

        # those asymmetric boundary/contact patterns while retaining a modest
        # and predictable running time.
        rng = np.random.default_rng(260319)

            perturbed_centers = centers0 + rng.uniform(-0.012, 0.012, centers0.shape)
            perturbed_radii = rng.uniform(0.025, 0.040, n)
            starts.append(np.concatenate((perturbed_centers.ravel(), perturbed_radii)))
