<DESCRIPTION>
Replace the clipped concentric-ring construction with a staggered five-row, near-hexagonal seed and a deterministic constrained local optimization over both center coordinates and radii. The seed has 26 distinct circles arranged in rows of 5, 6, 5, 5, and 5 circles, avoiding the severe degeneracies introduced by clipping the old outer ring.

The SLSQP model maximizes the sum of all radii subject directly to every border and pairwise non-overlap constraint. This permits boundary circles, interior circles, and transition rows to acquire different radii, which is important for a finite square where a perfectly uniform hexagonal lattice is not generally optimal. A final uniform feasibility scaling recomputes all limiting constraints after optimization, making the returned construction robust against small floating-point constraint violations from the optimizer.

    # A staggered lattice is a much better finite-square starting point than
    # concentric rings.  The central row has six circles; the other rows have
    # five, giving exactly 26 circles while retaining hexagonal neighbours.
    row_sizes = (5, 6, 5, 5, 5)
    seed_centers = []
    for row, count in enumerate(row_sizes):
        y = (row + 0.5) / len(row_sizes)
        for col in range(count):
            seed_centers.append(((col + 0.5) / count, y))
    seed_centers = np.asarray(seed_centers, dtype=float)
    n = len(seed_centers)

    # Optimize centers and radii simultaneously.  In contrast to successively
    # shrinking radii, these are the actual geometric packing constraints.
    ii, jj = np.triu_indices(n, 1)

    def inequalities(z):
        points = z[:2 * n].reshape(n, 2)
        rs = z[2 * n:]
        dx = points[ii, 0] - points[jj, 0]
        dy = points[ii, 1] - points[jj, 1]
        separations = np.sqrt(dx * dx + dy * dy) - rs[ii] - rs[jj]
        return np.concatenate((
            points[:, 0] - rs,
            points[:, 1] - rs,
            1.0 - points[:, 0] - rs,
            1.0 - points[:, 1] - rs,
            separations,
        ))

    initial_radii = np.full(n, 0.035)
    initial = np.concatenate((seed_centers.ravel(), initial_radii))

    try:
        from scipy.optimize import minimize

        result = minimize(
            lambda z: -np.sum(z[2 * n:]),
            initial,
            method="SLSQP",
            bounds=[(0.0, 1.0)] * (2 * n) + [(1e-6, 0.5)] * n,
            constraints={"type": "ineq", "fun": inequalities},
            options={"maxiter": 1800, "ftol": 1e-11, "disp": False},
        )
        candidate = result.x if np.all(np.isfinite(result.x)) else initial
    except Exception:
        # The seed itself is feasible, so this also provides a safe fallback
        # on installations without SciPy.
        candidate = initial

    centers = np.clip(candidate[:2 * n].reshape(n, 2), 0.0, 1.0)
    radii = np.maximum(candidate[2 * n:], 0.0)

    # SLSQP normally satisfies constraints to much better precision than this,
    # but scale once more to guarantee strict validity after floating point
    # rounding and any bound clipping above.
    border_limits = np.minimum.reduce((
        centers[:, 0], centers[:, 1],
        1.0 - centers[:, 0], 1.0 - centers[:, 1],
    ))
    scale = np.min(border_limits / np.maximum(radii, 1e-15))
    dx = centers[ii, 0] - centers[jj, 0]
    dy = centers[ii, 1] - centers[jj, 1]
    distances = np.sqrt(dx * dx + dy * dy)
    pair_scale = distances / np.maximum(radii[ii] + radii[jj], 1e-15)
    scale = min(1.0, scale, np.min(pair_scale)) * (1.0 - 1e-10)
    radii *= max(0.0, scale)

    return centers, radii, float(np.sum(radii))
