<DESCRIPTION>
Replace finite-difference constraint derivatives and the narrowly focused perturbed-grid portfolio with analytic derivatives plus a compact set of staggered row seeds.  Alternating five/six-circle layers approximate the triangular-lattice interior while moving the short-row defect among layers changes the boundary contact graph.  This directly explores the unequal-radius configurations that are unavailable from a nearly square 5-by-5 scaffold.  The analytic Jacobian both improves SLSQP convergence and leaves enough runtime for several distinct topologies.

    def layered_seed(counts, phase):
        """Boundary-aware triangular-lattice seed with a controlled defect."""
        points = []
        rows = len(counts)
        for row, count in enumerate(counts):
            y = 0.085 + 0.83 * row / (rows - 1)
            inset = 0.082 if count >= 6 else (0.098 if count == 5 else 0.17)
            xs = np.linspace(inset, 1.0 - inset, count)
            for col, x in enumerate(xs):
                # Tiny deterministic asymmetry prevents an artificial symmetric
                # stationary point without materially changing the topology.
                points.append((
                    np.clip(x + 0.008 * np.sin(2.17 * (row + 1) *
                                                (col + 1) + phase), .04, .96),
                    np.clip(y + 0.006 * np.cos(1.43 * (row + 2) *
                                                (col + 1) + phase), .04, .96),
                ))
        return np.asarray(points, dtype=float)
