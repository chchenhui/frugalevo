<DESCRIPTION>
Replace the global-radius scaling certification with a fixed-center linear program.  For any candidate center configuration, the radii subproblem is linear: each radius is capped by its nearest wall, and every pair imposes `r_i + r_j <= distance(i,j)`.  The existing common scaling discards uneven-radius improvements whenever one nearly active constraint has optimizer roundoff.  Solving this small 26-variable LP recovers the best feasible unequal radii for the optimized centers, especially improving boundary-layer configurations.  A small margin makes the returned packing strictly valid.

def _optimal_radii(centers):
    """Maximize feasible radii for fixed centers using the exact LP subproblem."""
    centers = np.asarray(centers, dtype=float)
    n = len(centers)
    wall = np.minimum.reduce((
        centers[:, 0], centers[:, 1],
        1.0 - centers[:, 0], 1.0 - centers[:, 1],
    ))
    wall = np.maximum(wall, 0.0)
    ii, jj = np.triu_indices(n, 1)
    distances = np.linalg.norm(centers[ii] - centers[jj], axis=1)

    try:
        from scipy.optimize import linprog

        pair_matrix = np.zeros((len(ii), n), dtype=float)
        rows = np.arange(len(ii))
        pair_matrix[rows, ii] = 1.0
        pair_matrix[rows, jj] = 1.0
        margin = 1.0 - 2.0e-9
        result = linprog(
            -np.ones(n),
            A_ub=pair_matrix,
            b_ub=distances * margin,
            bounds=[(0.0, float(value * margin)) for value in wall],
            method="highs",
        )
        if result.success:
            return result.x
    except Exception:
        pass

    # The existing projection remains a robust dependency-free fallback.
    return _safe_radii(centers, wall)[1]
