<DESCRIPTION>
Replace the single five-row seed with several related staggered row profiles.  Unequal-radius optima are sensitive to the boundary contact graph: moving the six-circle row between vertical layers, or using a six-row truncated triangular lattice, changes which circles can profitably touch walls and which interior contacts become active.  The existing deterministic phase perturbations are retained for each profile.

Initialize each optimization with radii derived from each center's local geometric clearance rather than a uniform radius.  This gives SLSQP useful scale variation between boundary and interior circles while maintaining a strictly feasible initial configuration.  The number of starts remains modest (20), well within the timeout given the current sub-second four-start runtime.
</DESCRIPTION>

    def make_seed(row_sizes):
        """Staggered lattice seed for one candidate boundary contact graph."""
        rows = len(row_sizes)
        points = []
        for row, count in enumerate(row_sizes):
            # Six-row layouts need a slightly tighter vertical lattice.
            y = 0.105 + 0.79 * row / max(1, rows - 1)
            if count == 6:
                xs = np.linspace(0.075, 0.925, count)
            elif count == 5:
                xs = np.linspace(0.14, 0.86, count)
            else:

            # nonlinear optimizer selects its own final contact graph.
            shift = 0.018 if row % 2 else -0.018
