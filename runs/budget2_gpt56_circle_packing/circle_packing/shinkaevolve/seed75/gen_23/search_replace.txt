<DESCRIPTION>
Use the exact fixed-center linear program for radii during multistart optimization and when ranking final candidates. For a given center configuration, maximizing the sum of radii is a linear program with wall bounds and pairwise radius-sum constraints. The current code ranks the nonlinear solver's radius vector directly, even though it can leave avoidable slack or an inferior radius allocation at otherwise strong centers. Re-solving this LP both produces substantially better initial unequal radii and evaluates each discovered contact geometry at its true fixed-center optimum. A small common shrink preserves strict numerical feasibility for SLSQP initialization and final validation.
</DESCRIPTION>

    # have an excellent contact graph but non-optimal individual radii.
    pair_matrix = np.zeros((len(pairs), n))
    pair_matrix[np.arange(len(pairs)), pairs[:, 0]] = 1.0

    def optimal_radii(c):
        d = c[pairs[:, 0]] - c[pairs[:, 1]]
        distances = np.sqrt(np.einsum("ij,ij->i", d, d))
        wall_limits = np.minimum.reduce((
            c[:, 0], c[:, 1], 1.0 - c[:, 0], 1.0 - c[:, 1],
        ))
        solved = linprog(
            -np.ones(n), A_ub=pair_matrix, b_ub=distances,
            bounds=[(0.0, max(0.0, w)) for w in wall_limits],
            method="highs",
        )
        if solved.success:
            return solved.x
        return np.full(n, 1.e-8)
