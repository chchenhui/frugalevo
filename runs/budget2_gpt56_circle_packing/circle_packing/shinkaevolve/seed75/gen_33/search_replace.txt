<DESCRIPTION>
Use the first SLSQP pass primarily as a contact-graph/topology search, then perform a much tighter continuation pass only on the strongest fixed-center LP candidates.  The LP reallocation often changes which circles are active at contacts, so restarting nonlinear optimization from those improved unequal radii can unlock a small but meaningful increase in the total radius.  Restricting this expensive pass to the best four candidates keeps runtime comfortably below the evaluator limit while avoiding spending high-precision iterations on weak row topologies.
</DESCRIPTION>
