<DESCRIPTION>
For a fixed set of centers, the optimal radii are obtained from a linear program: each radius has a wall upper bound, and every pair contributes the linear inequality r_i + r_j <= distance(i,j). The nonlinear SLSQP stage can stop with a suboptimal radius allocation even when its centers are promising, especially in asymmetric defect layouts. Re-solving this small LP after every center optimization extracts the best feasible varying-radius allocation from that contact geometry. The existing common-scale polish is retained afterward to certify strict feasibility against numerical tolerances.
</DESCRIPTION>

    # At fixed centers, radius selection is a linear program.  This is more
    # effective than retaining SLSQP's last radius vector: a small disk can
    # sacrifice radius to release several neighbors in an asymmetric contact
    # graph, precisely the boundary effect sought by the multistart stage.
    pair_matrix = np.zeros((len(ii), n))
    pair_matrix[np.arange(len(ii)), ii] = 1.0
    pair_matrix[np.arange(len(ii)), jj] = 1.0

    def optimal_radii_for_centers(c, fallback):
        wall = np.minimum.reduce((
            c[:, 0], c[:, 1], 1.0 - c[:, 0], 1.0 - c[:, 1]
        ))
        distances = np.sqrt(np.sum((c[ii] - c[jj]) ** 2, axis=1))
        try:
            lp = linprog(
                -np.ones(n), A_ub=pair_matrix, b_ub=distances,
                bounds=[(0.0, max(0.0, float(bound))) for bound in wall],
                method="highs",
            )
            if lp.success:
                return lp.x
        except Exception:
            pass
        return fallback
