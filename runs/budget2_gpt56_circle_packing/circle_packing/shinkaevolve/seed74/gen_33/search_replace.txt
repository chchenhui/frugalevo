<DESCRIPTION>
Add several geometry-aware restart families rather than relying mostly on perturbations of the same square grid.  The original 5-by-5 grid plus an interstitial circle is retained, since it provides good boundary coverage, but alternate seeds receive a small staggered-row displacement and a vertical compression/expansion.  These are controlled deformations toward triangular/hexagonal contact graphs while preserving a sensible initial LP solution.  Additional deterministic seeds explore different interstices and boundary asymmetries; this is inexpensive relative to the 360-second limit and avoids the zero-probability requirement that one jitter land near the best asymmetric contact graph.
</DESCRIPTION>

    extra = gap_choices[seed % len(gap_choices)].copy()
    centers = np.vstack((grid, extra))

    # Besides a Cartesian seed, use gentle staggered-row seeds.  A full
    # triangular lattice does not fit 26 comparable circles against four
    # straight walls, but its interior contact directions are valuable and
    # SLSQP can subsequently choose the required unequal boundary circles.
    # The displacement is deliberately modest: all 25 base circles still
    # begin well separated and the LP gives the extra interstitial circle a
    # useful nonzero radius.
    if seed >= 16:
        row = np.repeat(np.arange(5), 5)
        phase = np.where(row % 2 == 0, -1.0, 1.0)
        amplitude = (0.018, 0.032, 0.046)[seed % 3]
        centers[:25, 0] += amplitude * phase
        centers[:25, 1] = 0.5 + (centers[:25, 1] - 0.5) * (
            (0.94, 0.97, 1.03)[seed % 3]
        )
        # Move the interstitial point consistently with the two adjacent
        # rows, breaking reflection symmetry in a reproducible manner.
        centers[25] += np.array([
            0.5 * amplitude * (-1 if (seed // 3) % 2 else 1),
            0.008 * ((seed % 4) - 1.5),
        ])

    if jitter > 0.0:
        centers += rng.normal(scale=jitter, size=centers.shape)
        centers = np.clip(centers, 0.025, 0.975)

    return centers
