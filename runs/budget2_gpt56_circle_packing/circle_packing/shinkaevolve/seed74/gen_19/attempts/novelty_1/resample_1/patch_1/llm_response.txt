<DESCRIPTION>
Add certified continuation restarts from the best layout found by the initial hexagonal-layer searches. Dense unequal circle packings often lie in narrow local basins: a moderate radius shrink creates contact slack, while small deterministic center perturbations allow SLSQP to change the active contact graph and recover a better unequal boundary arrangement. The continuation starts use several perturbation magnitudes and accept feasible iterates even when SLSQP reports a non-success line-search status, since the later global scaling step provides the final certificate.

    rng = np.random.default_rng(26031991)
    best = None

    def retain_if_feasible(result):
        """Keep numerical feasible points regardless of SLSQP exit status."""
        nonlocal best
        if (np.all(np.isfinite(result.x)) and
                np.min(inequalities(result.x)) >= -2e-7):
            if best is None or result.x[2 * n:].sum() > best[2 * n:].sum():
                best = result.x.copy()

    # Small reproducible perturbations let the optimizer discover unequal,
    # boundary-adapted arrangements without an expensive global search.
    for trial in range(6):
        centers0 = base.copy()
        if trial:
            centers0 += rng.normal(0.0, 0.018, centers0.shape)
            centers0 = np.clip(centers0, 0.06, 0.94)
        z0 = np.concatenate((centers0.ravel(), np.full(n, 0.025)))
        result = minimize(
            lambda z: -np.sum(z[2 * n:]),
            z0,
            method="SLSQP",
            bounds=bounds,
            constraints=constraint,
            options={"maxiter": 1400, "ftol": 1e-11, "disp": False},
        )
        retain_if_feasible(result)

    # contact graph.  Shrinking its radii first supplies enough slack for
