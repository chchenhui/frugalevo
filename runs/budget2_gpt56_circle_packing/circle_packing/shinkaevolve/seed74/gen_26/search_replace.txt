<DESCRIPTION>
Add a fixed-radius center-relaxation stage before the final joint polish.  The existing joint SLSQP solves can become locked into a locally rigid contact graph because every radius is already active.  Deflating the LP-optimal radii by a few percent creates geometric freedom; optimizing only centers with a short-range repulsive clearance energy then redistributes that freedom among near contacts and walls.  A subsequent full center/radius solve restores the radii and can exploit the changed contact graph.  Candidates are still scored by the exact fixed-center LP and undergo the existing final feasibility certification.
</DESCRIPTION>

    def relax_centers(seed_centers, fixed_radii, maxiter):
        """
        Rearrange centers at slightly deflated, fixed radii.

        The exponentially weighted energy only significantly penalizes close
        contacts and walls.  Thus it opens a locked contact graph without
        imposing a global lattice symmetry or sacrificing feasibility.
        """
        fixed_radii = feasible_rescale(seed_centers, fixed_radii)
        tau = 0.014

        def fixed_clearance(flat_centers):
            c = flat_centers.reshape(n, 2)
            delta = c[ii] - c[jj]
            distances = np.sqrt(np.einsum("ij,ij->i", delta, delta))
            return np.r_[
                c[:, 0] - fixed_radii,
                c[:, 1] - fixed_radii,
                1.0 - c[:, 0] - fixed_radii,
                1.0 - c[:, 1] - fixed_radii,
                distances - fixed_radii[ii] - fixed_radii[jj],
            ]

        def energy(flat_centers):
            slack = fixed_clearance(flat_centers)
            return float(np.sum(np.exp(-np.minimum(slack, 0.16) / tau)))

        result = minimize(
            energy,
            seed_centers.ravel(),
            method="SLSQP",
            bounds=[(0.0, 1.0)] * (2 * n),
            constraints={"type": "ineq", "fun": fixed_clearance},
            options={"maxiter": maxiter, "ftol": 2e-10, "disp": False},
        )
        if result.x is None or not np.all(np.isfinite(result.x)):
            return seed_centers
        if np.min(fixed_clearance(result.x)) < -2e-7:
            return seed_centers
        return result.x.reshape(n, 2)
