<DESCRIPTION>
Add a bounded 2-for-1 exchange neighborhood to the local search. A single relocation or 1-for-1 swap cannot resolve cases where an overloaded GPU needs to release two small models together, while the destination requires a larger model returned to remain memory feasible. The new search considers pairs from only the highest-pressure GPUs and limits examined models, preserving the current low runtime. Every candidate is checked against exact remaining GPU memory and accepted only when it strictly improves the existing lexicographic pressure score.
</DESCRIPTION>
