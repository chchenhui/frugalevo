pressure_guided_threshold_packing
</NAME>

<DESCRIPTION>
Add a third deterministic packing policy to threshold feasibility construction. Existing first-fit and best-fit policies only consider effective-size fragmentation. The new policy still enforces the effective-size capacity constraint required by the target KVPR, but selects among feasible GPUs by the projected actual maximum KVPR. This produces different feasible seeds that are more aligned with the real objective, allowing the existing move/swap refinement to start from stronger placements while retaining the robust fragmentation-oriented policies as fallbacks.
</DESCRIPTION>

            for mode in range(3):
                assignments = [-1] * model_count
                free = [float(GPU_MEM_SIZE)] * gpu_num
                loads = [0.0] * gpu_num
                remaining = [float(GPU_MEM_SIZE)] * gpu_num

                for model_id in order:
                    item = effective[model_id]
                    size = sizes[model_id]
                    weight = weights[model_id]
                    feasible = [
                        gpu for gpu in range(gpu_num)
                        if free[gpu] + EPS >= item
                    ]
                    if not feasible:
                        assignments = None
                        break

                    if mode == 1:
                        chosen = feasible[0]
                    elif mode == 2:
                        chosen = min(
