<DESCRIPTION>
Add a memory-aware two-for-one exchange repair between a bottleneck GPU and another GPU. Single-model relocations and one-for-one swaps can become trapped when freeing enough memory or transferring enough pressure requires moving two models together while receiving one differently sized model in return. This local search only accepts exchanges that strictly lower the actual global maximum KVPR, preserves memory feasibility, and is followed by the existing relocation repair.
</DESCRIPTION>
