<DESCRIPTION>
The current relocation repair cannot improve placements blocked by memory fragmentation: a bottleneck GPU may need to give up a model, but no target has enough free memory. Add a best-improving pairwise swap phase after relocations. Each swap is checked for memory feasibility and accepted only when it strictly reduces the actual global maximum KVPR. This retains the fast greedy construction and move repair while escaping an important class of local optima.
</DESCRIPTION>

                        )
                        target_remaining = (

                            - source_model.model_size

                        )

                            if target_remaining > 0

                        )

                                default=0.0,
