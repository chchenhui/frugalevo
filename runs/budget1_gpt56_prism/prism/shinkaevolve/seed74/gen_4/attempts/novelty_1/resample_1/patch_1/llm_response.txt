<DESCRIPTION>
Extend the local repair phase with pairwise model swaps. A relocation cannot improve a placement when every destination lacks enough free memory, even if exchanging a large low-pressure model for a smaller high-pressure model would significantly balance KVPR. The added swap search evaluates only memory-feasible exchanges and applies the best strictly improving action (move or swap), preserving memory feasibility while escaping relocation-only local minima.
</DESCRIPTION>
