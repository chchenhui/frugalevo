<DESCRIPTION>
A swap can reduce the bottleneck KVPR while also creating enough free memory for a beneficial one-way relocation that was impossible before the swap. The current code performs all relocations before swaps, then returns immediately after swap optimization. Add one final relocation pass after swaps so the algorithm can exploit the newly defragmented memory. Each accepted move still strictly decreases the global maximum KVPR and preserves memory feasibility.

    # Swaps can create free-memory layouts that enable relocations which were
    # infeasible before defragmentation.  Run the cheap improving-move repair
    # once more on the swapped placement.
    while True:
        current_max = max(ratio(gpu_id) for gpu_id in range(gpu_num))
        best_move = None
        best_max = current_max

        for source in range(gpu_num):
            if ratio(source) < current_max:
                continue
            for model in placement[source]:
                model_weight = weight(model)
                for target in range(gpu_num):
                    if target == source or model.model_size > remaining[target]:
                        continue

                    source_ratio = (
                        (load[source] - model_weight)
                        / (remaining[source] + model.model_size)
                    )
                    target_remaining = remaining[target] - model.model_size
                    target_ratio = (
                        float("inf") if target_remaining <= 0
                        else (load[target] + model_weight) / target_remaining
                    )
                    candidate_max = max(
                        source_ratio,
                        target_ratio,
                        max(
                            (ratio(gpu_id) for gpu_id in range(gpu_num)
                             if gpu_id != source and gpu_id != target),
                            default=0.0,
                        ),
                    )
                    if candidate_max < best_max - 1e-12:
                        best_max = candidate_max
                        best_move = (source, target, model, model_weight)

        if best_move is None:
            break

        source, target, model, model_weight = best_move
        placement[source].remove(model)
        placement[target].append(model)
        remaining[source] += model.model_size
        remaining[target] -= model.model_size
        load[source] -= model_weight
        load[target] += model_weight

    return placement
