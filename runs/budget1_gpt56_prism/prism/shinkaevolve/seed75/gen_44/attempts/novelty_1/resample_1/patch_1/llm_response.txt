<DESCRIPTION>
Add a bounded deterministic perturb-and-repolish phase after normal strict local search. The existing descent can stop at a local minimum where every direct move, swap, and chain is non-improving, despite a slightly worse intermediate placement enabling a better final arrangement. The new phase perturbs only models on a bottleneck GPU using a small number of capacity-safe relocations or swaps, reruns the existing strict improvement routine, and retains a candidate only if it improves the original placement. This preserves feasibility and never returns an inferior solution.

    def perturb_and_improve(state):
        """Escape strict local minima with a few bounded safe perturbations."""
        base_score = objective(state[1], state[2])
        best_state = state
        best_score = base_score
        eps = 1e-12

        if not state[0] or not any(state[0]):
            return state

        pressures = []
        for g in range(gpu_num):
            remaining = GPU_MEM_SIZE - state[1][g]
            pressures.append(
                state[2][g] / remaining if remaining > eps else float("inf")
            )
        bottleneck = max(range(gpu_num), key=lambda g: pressures[g])

        # Only allow small temporary degradation; polishing must beat base_score.
        limit = base_score * 1.08 + eps
        candidates = 0
        source_models = sorted(
            state[0][bottleneck],
            key=lambda i: (-weights[i], -sizes[i], i),

                    continue

                    [list(items) for items in state[0]],
                    list(state[1]),
                    list(state[2]),
                )

                trial[1][bottleneck] -= sizes[i]
                trial[2][bottleneck] -= weights[i]
                trial[1][dst] += sizes[i]
                trial[2][dst] += weights[i]
