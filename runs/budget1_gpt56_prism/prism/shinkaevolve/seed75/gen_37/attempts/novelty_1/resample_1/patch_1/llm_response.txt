<DESCRIPTION>
Add a bounded best-improvement local-search pass after threshold packing. The binary-search feasibility routine finds a strong packing, but its multidimensional best-fit choices can leave avoidable imbalance because it does not reconsider earlier assignments. Relocations and memory-feasible swaps are evaluated against the complete descending KVPR profile: the maximum KVPR remains the primary objective, while the profile deterministically breaks exact maximum-pressure ties. This can escape greedy packing artifacts without changing feasibility guarantees.

    placement = {gpu_id: list(placement[gpu_id]) for gpu_id in range(gpu_num)}

    def pressure_profile():
        values = []
        for gpu_id in range(gpu_num):
            if remaining[gpu_id] <= EPS:
                values.append(
                    float("inf") if loads[gpu_id] > EPS else 0.0
                )
            else:
                values.append(loads[gpu_id] / remaining[gpu_id])
        return tuple(sorted(values, reverse=True))
