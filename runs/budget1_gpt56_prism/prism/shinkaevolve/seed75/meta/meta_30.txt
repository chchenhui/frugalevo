# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- **The current best program, Multi-Start Greedy GPU Placement / Multi-Start KV-Pressure Placement (Generations 21, 22, and 29), reached the top observed score of 26.18 combined / 25.18 max_kvpr with 1.00 success.** Its core pattern is five deterministic greedy starts followed by strict local improvement. This slightly exceeds the prior best tier represented by Generations 11 and 19 at **26.11 / 25.11**, while maintaining full correctness.

- **Greedy assignment based on the resulting global bottleneck pressure is the strongest construction strategy.** The current code evaluates each candidate GPU by the maximum pressure across *all* GPUs after assignment:
  `maximum = max(new_pressure, existing pressures on other GPUs)`.
  This is more aligned with the evaluated max-KVPR objective than selecting only the locally least-loaded destination. Generation 21’s 26.18 result and Generation 22’s identical 26.18 result support this global-minimax construction rule.

- **Diversified deterministic orderings consistently improve robustness and quality over single-order greedy packing.** The current program uses five orders based on: pressure weight, model size, weight/size density, weight×size, and weight+size. This extends the earlier successful multi-start designs from Generations 11 and 19, which also used varied pressure/size-oriented orders and achieved 26.11. The variation helps avoid memory-fragmentation failures caused by one fixed ordering.

- **Bounded strict-improvement neighborhoods are effective when layered over a strong initialization.** The current program applies best-improving single moves, pairwise swaps, and two-step three-GPU chains, accepting an action only if it strictly lowers the maximum pressure. This produced 26.18, whereas simpler successful move/swap approaches reached slightly lower values: Generation 24 scored **25.80 / 24.80**, Generation 26 scored **25.67 / 24.67**, and Generations 20 and 28 scored **25.59 / 24.59**.

## Ineffective Approaches

- **Heuristic feasibility tests built around parametric binary search were not reliable enough.** Generation 25, Parametric KVPR Bin Packing, received **0.0** because its binary-search feasibility predicate relied on greedy bin packers. As the feedback notes, a greedy failure does not prove infeasibility; this can create false infeasibility conclusions or invalid handling paths despite otherwise reasonable move/swap refinement.

- **More elaborate local-search logic did not guarantee validation correctness.** Generation 23 used lexicographic profiles, relocations, swaps, and blocker-evacuation moves, but still failed validation and scored **0.0**. Its bounded search could become trapped in placements the evaluator rejected. This demonstrates that added neighborhood complexity is not useful if the construction/fallback behavior is less robust than the successful multi-start global-minimax approach.

- **Beam search was correct but did not outperform the simpler greedy multi-start family.** Generation 27’s width-12 beam search with one-for-two/two-for-one exchanges passed all tests but reached only **25.90 / 24.90** at **0.05** execution time. It was reliable, but it trailed the current best by **0.28 combined-score points** while taking the same measured time.

- **Prior failed exact-search-like methods remain a cautionary contrast.** As reflected in the previous insights, Generation 15’s bounded DFS/branch-and-bound scored **0.0** because node limits and state approximations could incorrectly classify feasible cases. The successful programs instead preserve correctness through direct capacity-safe construction and local transformations rather than using incomplete search as a feasibility oracle.

## Implementation Insights

- **The current best implementation maintains state directly in the quantities relevant to feasibility and objective quality.** It tracks `used[g]` and `load[g]`, derives residual memory as `80 - used[g]`, and evaluates pressure as `load[g] / remaining`. Every candidate move, swap, and chain temporarily updates these arrays, evaluates the true global objective, and restores state before deciding whether to retain the action. This direct state handling is consistent with the program’s **1.00 success rate**.

- **Capacity preservation is enforced at every transition.** Greedy placement rejects any destination where `used[g] + sizes[i] > 80`; swaps explicitly test both resulting GPU utilizations; chains test the intermediate replacement load on GPU `b` and the final load on GPU `c`. This differs from the failed parametric approach in Generation 25, where feasibility depended on a heuristic packing decision rather than on preserving a verified placement state.

- **Strict improvement prevents cycling and makes the 120-round local search bounded.** The current code stores the best candidate action in each round and accepts it only under `value + eps < best_value`. This best-improvement descent is more exhaustive than first-improvement logic while remaining controlled. Its measured runtime of **0.05** shows that evaluating moves, swaps, and chains across five starts was still inexpensive on the evaluator workloads.

- **The best program optimizes scalar maximum KVPR during both construction and refinement, not a full lexicographic profile.** Several correct competitors used descending lexicographic pressure vectors—Generation 24 at 25.80, Generation 26 at 25.67, and Generation 28 at 25.59—but none exceeded 26.18. The evidence indicates that, on these tests, stronger global-minimax greedy initialization mattered more than optimizing secondary pressure-profile tie-breakers.

## Performance Analysis

- **Generation 21/22/29 establish the highest reported evaluated tier at 26.18 combined score, 25.18 max_kvpr, and perfect success.** This improves on the previously highlighted Generation 19 and Generation 11 top tier of **26.11 combined / 25.11 max_kvpr** by **0.07 combined-score points**. Although small, the repeated 26.18 result across closely related multi-start local-search implementations strengthens the evidence for this family.

- **The score ordering among correct programs favors five-start greedy minimax construction over more expensive construction methods.** The beam-search program, Generation 27, achieved **25.90** with 0.05 runtime, while the current program achieved **26.18** at the same 0.05 runtime. Thus, beam breadth and exchange complexity did not translate into a better measured KVPR outcome.

- **Correct multi-start local search has a relatively narrow but meaningful quality range.** The correct programs span from **25.59** (Generations 20 and 28) through **25.67** (Generation 26), **25.80** (Generation 24), **25.90** (Generation 27), and finally **26.18** (Generations 21, 22, and 29). The highest results consistently combine five construction orders with moves and swaps; the current best additionally evaluates global maximum pressure directly and includes chains.

- **Execution time is not the primary differentiator within the successful family.** Generation 20 reached 25.59 with effectively 0.00 measured time; Generations 24, 26, 28, and 29 took about 0.01; Generations 21, 22, and 27 took 0.03–0.05. # META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:
