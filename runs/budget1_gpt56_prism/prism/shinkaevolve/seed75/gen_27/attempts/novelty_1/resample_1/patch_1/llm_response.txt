<DESCRIPTION>
Add the missing asymmetric exchange direction to local search: replacing one model on a bottleneck GPU with two models from another GPU. The current search supports two-for-one exchanges only, which can miss memory-constrained improvements where a high-pressure GPU must give up one large/high-load model while receiving two smaller models. This preserves the primary sorted KVPR-profile objective and checks both GPUs' memory feasibility before accepting only strict improvements.
</DESCRIPTION>
