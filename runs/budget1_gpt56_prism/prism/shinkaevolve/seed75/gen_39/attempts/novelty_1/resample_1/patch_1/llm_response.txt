<DESCRIPTION>
Add a capacity-safe one-for-two exchange to the polishing phase. Direct relocations and one-for-one swaps cannot escape configurations where a bottleneck GPU needs to give up one model while receiving two smaller models from a more spacious GPU. This exchange preserves the strict lexicographic KVPR descent rule already used by the code, so it cannot create cycles or retain a worse placement. The search is bounded to moderate input sizes to preserve the current low execution time.
