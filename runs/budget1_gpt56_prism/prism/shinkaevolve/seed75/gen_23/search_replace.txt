<DESCRIPTION>
The relocation loop currently records an improved profile but never records the corresponding move, so direct improving moves are never applied. Fixing this enables the existing local-search phase to reach substantially better placements.

Additionally, add a bounded deterministic two-step unlock search after swaps fail. It temporarily evacuates a small candidate model from a target GPU to create capacity, then moves a high-pressure model off one of the two most pressured GPUs into that target. Both intermediate and final placements remain memory-feasible; the intermediate pressure is bounded, and the final placement is accepted only when it strictly improves the KVPR profile. This repairs capacity-blocked hotspots without introducing broad expensive search.
</DESCRIPTION>
