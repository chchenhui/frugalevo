<DESCRIPTION>
Add a capacity-safe two-model relocation chain when neither a direct relocation nor a swap improves the placement. A common local optimum occurs when a high-pressure GPU needs to move a model to a nearly full target GPU, but that target must first send one of its models to a third GPU. This three-GPU operation changes the assignment more flexibly than a swap while retaining the strict lexicographic KVPR improvement requirement, so the maximum KVPR never increases. The search is bounded for large workloads to preserve the current lightweight runtime behavior.
</DESCRIPTION>
