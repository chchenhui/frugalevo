<DESCRIPTION>
Add a capacity-safe two-model relocation neighborhood before the more expensive chain search. A pair move can reduce the pressure of an overloaded GPU when neither individual model can be moved beneficially on its own, while avoiding the restrictive structure of a three-GPU chain. The move is accepted only under the existing strict lexicographic profile improvement rule, so the maximum KVPR never worsens. Restricting it to moderate model counts preserves the current lightweight runtime behavior.
</DESCRIPTION>
