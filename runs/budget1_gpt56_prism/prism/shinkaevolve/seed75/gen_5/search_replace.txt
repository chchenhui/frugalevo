<DESCRIPTION>
Add a two-model relocation neighborhood to the local search. Single-model moves can become trapped when neither individual move improves the lexicographic KVPR profile, while moving two models together does improve it. This commonly occurs when a pair is needed to rebalance request pressure or to make a meaningful reduction in a highly pressured GPU's numerator.

The search is limited to moderate model counts to preserve the lightweight runtime behavior. Like existing moves and swaps, a pair relocation is accepted only when it improves the full sorted KVPR profile, so it never worsens the maximum KVPR.
</DESCRIPTION>
