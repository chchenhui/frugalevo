<DESCRIPTION>
Expand the local-search source set from only exact maximum-KVPR GPUs to GPUs near the bottleneck, plus the highest-pressure populated GPUs when needed. A move from the single worst GPU can otherwise make a nearly saturated second GPU become the new maximum, preventing beneficial coordinated swaps or asymmetric exchanges. All candidate actions still require strict improvement of the full sorted KVPR profile, so the maximum KVPR cannot worsen and the lexicographic objective remains preserved.
</DESCRIPTION>

        pressures = [pressure(load[g], used[g]) for g in range(gpu_num)]
        bottleneck = max(pressures)

        # Include near-bottleneck GPUs as exchange sources.  Balancing only an
        # exact maximum can merely transfer the hotspot to the next GPU.
        tolerance = max(1e-12, abs(bottleneck) * 0.05)
        source_gpus = [
            g for g in range(gpu_num)
            if bins[g] and pressures[g] >= bottleneck - tolerance
        ]

        # Ensure small numerical gaps do not hide useful coordinated exchanges.
        minimum_sources = min(3, gpu_num)
        if len(source_gpus) < minimum_sources:
            ranked = sorted(
                (g for g in range(gpu_num) if bins[g]),
                key=lambda g: pressures[g],
                reverse=True,
            )
            for g in ranked:
                if g not in source_gpus:
                    source_gpus.append(g)
                if len(source_gpus) >= minimum_sources:
                    break
