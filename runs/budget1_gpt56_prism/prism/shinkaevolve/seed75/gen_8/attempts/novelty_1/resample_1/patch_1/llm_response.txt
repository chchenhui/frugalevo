<DESCRIPTION>
Add a feasible one-for-two model exchange to the local-search refinement. Single moves and one-for-one swaps can become trapped when a bottleneck GPU must give up a large model, but no individual destination model has the right memory size to exchange. A one-for-two exchange can simultaneously rebalance both KVPR load and memory headroom, allowing the algorithm to escape these packing-related local minima while retaining the same strictly improving lexicographic objective.
</DESCRIPTION>
