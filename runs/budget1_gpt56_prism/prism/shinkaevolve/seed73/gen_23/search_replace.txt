<DESCRIPTION>
Add a bounded reverse two-for-one exchange after relocations and one-for-one swaps stall. This operation replaces two models on a bottleneck GPU with one model from another GPU. It can reduce the bottleneck KVPR while simultaneously consolidating memory on the destination, solving placements blocked by fragmentation where neither a direct move nor a one-for-one swap is beneficial. Both post-exchange memory capacities are checked exactly, and the exchange is accepted only when it strictly improves the global maximum KVPR.
</DESCRIPTION>
