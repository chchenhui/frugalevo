<lemma>
three_gpu_relocation
</NAME>

<DESCRIPTION>
Add a targeted three-GPU ejection-chain neighborhood after direct moves, swaps, and one-for-two exchanges are exhausted. It moves a high-pressure model from a bottleneck GPU to a target GPU while first relocating one target model to a third GPU. This repairs capacity fragmentation that prevents a direct beneficial move, while limiting source candidates to the six most pressure-relevant models to preserve the current fast runtime. Every candidate is evaluated using the existing lexicographic KVPR vector and all memory constraints are checked before application.
</DESCRIPTION>
