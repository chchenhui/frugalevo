<DESCRIPTION>
Add several complementary initialization orders before the existing relocation/swap improvement phase. The local search can only improve the basin produced by greedy placement, so diversified feasible starting layouts are valuable. In particular, pressure-per-post-placement-capacity prioritizes models that become expensive when paired with other models, while demand-and-size orderings distinguish equally demanding models based on their memory impact. This keeps the algorithm simple and only adds a small number of greedy passes.

    orders = [
        # High-demand models should normally be balanced first.
        sorted(models, key=model_pressure, reverse=True),
        # Large models first improves the chance of preserving a feasible packing.
        sorted(models, key=lambda m: m.model_size, reverse=True),
        # A model which leaves little capacity is especially costly on a crowded GPU.
        sorted(
            models,
            key=lambda m: model_pressure(m) / max(1e-12, GPU_MEM_SIZE - m.model_size),
            reverse=True,
        ),
        # Resolve equal (or similar) demand in favor of the more restrictive model.
        sorted(
            models,
            key=lambda m: (model_pressure(m), m.model_size),
            reverse=True,
        ),
        # Conversely, prioritize memory-heavy models when their demand is comparable.
        sorted(
            models,
