<DESCRIPTION>
Add a pairwise model-swap local-search phase after the existing relocation optimization. Single-model moves can become trapped when the best balancing action requires exchanging a large memory model for a high-demand model. A feasible swap changes both GPU memory denominators and request-rate numerators simultaneously, allowing the algorithm to escape those local minima while accepting only swaps that strictly reduce the global maximum KVPR.
