<DESCRIPTION>
Add a targeted refinement pass when direct moves, swaps, and ejection chains cannot improve the placement. The remaining local optimum can be caused by a large high-demand model on a bottleneck GPU that cannot move alone, while replacing it with two smaller models from another GPU would balance both memory headroom and demand.

The new pass ranks models on bottleneck GPUs by a combined demand-and-size score, considers only the top few, and evaluates feasible one-for-two exchanges against high-impact counterpart models. This keeps compound-search runtime bounded while addressing capacity barriers that pairwise swaps cannot resolve. Candidate evaluation still uses the existing lexicographic KVPR objective and feasibility checker, so every accepted refinement strictly improves the placement.
</DESCRIPTION>
