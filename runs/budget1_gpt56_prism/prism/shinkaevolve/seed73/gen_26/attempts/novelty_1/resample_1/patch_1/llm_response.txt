<DESCRIPTION>
Add the complementary exchange neighborhood that replaces one model on a current bottleneck GPU with two models from another GPU. The existing exchange sends two bottleneck models to another GPU and receives one model; this new direction is useful when reducing the bottleneck’s load requires taking multiple low-pressure models in exchange for one high-pressure model. Every candidate uses exact post-exchange remaining-memory checks and is accepted only when it strictly improves the existing lexicographic KVPR vector, so it cannot worsen the maximum KVPR or create cycles.
</DESCRIPTION>
