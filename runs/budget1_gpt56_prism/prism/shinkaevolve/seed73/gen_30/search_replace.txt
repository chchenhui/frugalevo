ejection_chain_repair

<DESCRIPTION>
Add a bounded three-GPU ejection-chain neighborhood. When a high-pressure model cannot fit on a desirable target because of memory fragmentation, the algorithm can first eject one model from that target to a low-pressure third GPU, then move the bottleneck model into the newly available target space. The complete two-move action is evaluated atomically using the resulting KVPR profile, so it is accepted only when it improves the maximum-pressure objective. Candidate limits keep this repair operator inexpensive.
</DESCRIPTION>

        for source in gpu_order:
            source_models = sorted(

                reverse=True,

            for outgoing in source_models:
                outgoing_demand = demand(outgoing)

                for target in range(gpu_num):
                    if target == source:
                        continue

                    target_models = sorted(
                        placement[target],
                        key=lambda m: (demand(m), m.model_size),
                    )[:EJECTION_MODEL_LIMIT]

                    for ejected in target_models:
                        ejected_demand = demand(ejected)

                        # The target must gain enough room after its ejection.
