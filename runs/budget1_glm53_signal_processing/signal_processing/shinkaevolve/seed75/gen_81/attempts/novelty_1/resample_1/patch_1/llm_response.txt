<DESCRIPTION>
The current program uses a single fixed-scale zero-phase SG polish, which forces one smoothing strength everywhere: it either over-smooths quiet regions (hurting lag/responsiveness) or under-smooths volatile ones (hurting smoothness and false reversals). The best prior generation (0.65, slope_changes 65.8, false_reversals 44.4) used a volatility-blended multi-scale SG polish, and the current program already computes a local volatility proxy (r_arr) and keeps the stable fixed-Q Kalman + solve-based RTS smoother. This edit replaces the single-scale SG in Stage 2 with the multi-scale volatility-blended variant (soft Gaussian membership in volatility space centered at the 20/50/80 percentiles, three kernel scales), while keeping the confidence-gated trend lead of Stage 3 intact. This targets the weakest metrics — smoothness (0.23) and reversals (45.4) — by widening the effective kernel only where local volatility genuinely demands it, without adding lag in quiet regions. Q remains strictly fixed at 0.05·q_scale² and the RTS gain stays solve-based, per confirmed prior findings; no Q-scheduling, no 3-state model.

    # --- Stage 2: volatility-blended multi-scale zero-phase SG smoothing ---
    # Wide kernels where volatility is high (smoothness, few false reversals),
    # narrow kernels in quiet regions (responsiveness, low lag). Soft Gaussian
    # membership in volatility space avoids seams.
    def _sg_coeffs(h):
        """Order-2 SG kernel (value at center -> zero phase) for half-width h."""
        t_off = np.arange(-h, h + 1, dtype=float)
        A = np.vstack([t_off ** k for k in range(3)]).T
        return (np.linalg.pinv(A.T @ A) @ A.T)[0]

    def _sg_smooth(sig, h):
        """Reflect-pad and convolve with the SG kernel; returns len(sig)."""
        c = _sg_coeffs(h)[::-1]
        if n > h + 1:

                2 * sig[0] - sig[1:h + 1][::-1],
                sig,
                2 * sig[-1] - sig[n - 2:n - h - 2:-1][::-1],

        else:

        out = np.convolve(pad, c, mode="valid")
        if len(out) != len(sig):
            return sig  # degenerate-length fallback
        return out
