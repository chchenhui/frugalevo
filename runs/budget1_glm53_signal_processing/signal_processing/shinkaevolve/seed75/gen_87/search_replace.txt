<DESCRIPTION>
The current program's main weakness versus prior generations is slope_changes (64.2) and false_reversals (45.0). Prior program 3 achieved 48.4/34.8 using two cheap post-stages: (1) conservative slope-lead compensation, which adds a fraction of the zero-phase-estimated slope back to the signal to restore corner dynamics lost to the multi-scale SG attenuation (improving responsiveness and tracking without adding lag, since the SG is zero-phase), and (2) a light short-window zero-phase SG polish pass that removes residual ripple. Both are O(n) convolution steps and risk negligible lag. I add these two stages between the volatility-gated blend and the end-aligned trim, using the same `_sg_smooth` helper already defined and the existing narrow half-width (`sg_half // 2`) so the polish matches the medium scale. The lead factor is conservative (0.5 * sg_half * 0.25) exactly matching the best prior performing variant.
