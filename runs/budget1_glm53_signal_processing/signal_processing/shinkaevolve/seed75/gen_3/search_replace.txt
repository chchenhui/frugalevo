<DESCRIPTION>
Replace the exponentially weighted moving average with a two-stage approach: (1) a 1D constant-velocity Kalman filter with adaptive measurement noise estimated from local residual variance (noise-adaptive gain), and (2) a short zero-phase Savitzky-Golay pass to suppress residual slope reversals without adding lag (Savitzky-Golay with polyorder 2 preserves linear trends with no phase delay). The Kalman filter tracks the signal with minimal lag, its adaptive R reduces spurious reversals from noise spikes, and the SG polynomial fit preserves genuine dynamics. We keep the same output-length semantics (len(x) - window_size + 1) and the existing function signatures so `process_signal` and `run_signal_processing` remain unchanged. Moving-average baselines are kept as fallbacks for compatibility.

    x = np.asarray(x, dtype=float)
    output_length = len(x) - window_size + 1

    # --- Stage 1: adaptive constant-velocity Kalman filter (low lag, tracks trends) ---
    # Initial noise estimate from local high-frequency residuals (median abs diff)
    dx = np.diff(x)
    q_scale = np.median(np.abs(dx)) + 1e-12
    # Measurement noise R adapted per-step from local residual scale
    local_std = np.convolve(np.abs(dx), np.ones(3) / 3.0, mode="same")
    r_arr = np.concatenate([[q_scale], local_std]) + 1e-9

    # State: [level, slope]; simple constant-velocity model
    F = np.array([[1.0, 1.0], [0.0, 1.0]])
    H = np.array([[1.0, 0.0]])
    Q = np.eye(2) * (q_scale ** 2) * 0.05  # process noise (allows trend changes)
    P = np.eye(2) * (r_arr[0] ** 2)
    s = np.array([x[0], 0.0])

    n = len(x)
    kf_out = np.zeros(n)
    kf_out[0] = x[0]
    for i in range(1, n):
        # Predict
        s = F @ s
        P = F @ P @ F.T + Q
        # Adapt measurement noise to local volatility (robust to outliers)
        R = max(r_arr[i] ** 2, 1e-12)
        # Update
        S = H @ P @ H.T + R
        K = (P @ H.T) / S
        innov = x[i] - (H @ s)[0]
        # Robust gating: down-weight innovations beyond ~3 sigma
        Sv = float(S[0, 0]) if np.ndim(S) else float(S)
        if abs(innov) > 3.0 * np.sqrt(Sv):
            R = R * 9.0
            S = H @ P @ H.T + R
            K = (P @ H.T) / S
            innov = x[i] - (H @ s)[0]
        s = s + (K.flatten() * innov)
        P = P - K @ H @ P
        kf_out[i] = s[0]

    # --- Stage 2: zero-phase Savitzky-Golay smoothing (kills slope reversals, no lag) ---
    sg_half = max(1, window_size // 4)
    sg_len = 2 * sg_half + 1
    poly = min(2, sg_len - 1)
    # Convolve via simple polynomial-fitting kernel equivalent: use local quadratic fit
    # Build SG coefficients for polynomial order 2
    t_off = np.arange(-sg_half, sg_half + 1, dtype=float)
    A = np.vstack([t_off ** k for k in range(poly + 1)]).T
    ATA_inv = np.linalg.pinv(A.T @ A)
    coeffs = (ATA_inv @ A.T)[0]  # row for value at center -> zero-phase
    padded = np.concatenate([
        2 * kf_out[0] - kf_out[1 : sg_half + 1][::-1],
        kf_out,
        2 * kf_out[-1] - kf_out[-2 : -sg_half - 2 : -1][::-1] if n > sg_half + 1 else kf_out[-1:],
    ])
    smoothed = np.convolve(padded, coeffs[::-1], mode="valid")
    if len(smoothed) < n:
        smoothed = kf_out  # degenerate case fallback

    # --- Trim to sliding-window output length, aligning end (minimal lag) ---
    y = smoothed[-output_length:] if len(smoothed) >= output_length else kf_out[-output_length:]

    return y
