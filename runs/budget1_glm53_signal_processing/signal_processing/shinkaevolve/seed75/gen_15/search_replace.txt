<DESCRIPTION>
The current causal Kalman filter scores well on responsiveness (0.85) and accuracy (0.91) but suffers from high slope changes (317) and false reversals (254) — classic symptoms of a filter that is too responsive relative to its noise floor. The optimal fix under the constant-acceleration model is a Rauch-Tung-Striebel (RTS) smoother: it reuses the already-computed forward pass but runs the standard backward recursion `s[i] = s_f[i] + C_i (s[i+1] - s_pred[i+1])` with `C_i = P_f[i] F' P_pred[i+1]^{-1}`. This gives the minimum-variance estimate at each time given ALL samples, cutting spurious slope reversals dramatically while keeping the same model/noise estimates, hence no extra lag relative to the aligned output. Crucially, to avoid the length/alignment bugs that killed prior attempts: I store per-step filtered states and covariances during the forward loop, run RTS through that sequence, then trim with `smoothed[n - output_length:]` so the output length is exactly `n - window_size + 1` and end-aligned with the input (the smoothest, best-estimated region). The trend-reversal gate and Huber outlier guard are retained in the forward pass.
</DESCRIPTION>
