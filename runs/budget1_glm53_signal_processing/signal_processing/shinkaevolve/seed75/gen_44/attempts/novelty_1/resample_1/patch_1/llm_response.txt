<DESCRIPTION>
Apply a short Savitzky-Golay smoothing pass to the RTS-smoothed slope state (which is already heavily denoised, unlike prior failed lead attempts on noisy slopes), then add a small conservative slope-lead to the output level. This attacks lag error without amplifying noise-induced reversals: the lead is a fraction (0.2) of the smoothed slope scaled by the effective delay (window_size//2), and because the slope channel is SG-smoothed first, the injected lead is nearly noise-free, so false reversals should not increase.

    # --- Slope-lead compensation on a denoised slope channel ---
    # 1) One short Savitzky-Golay pass on the already RTS-smoothed slope.
    #    The slope state is far less noisy than raw data, so a light SG pass
    #    (window ~7, polyorder 2) removes residual jitter without adding lag.
    sg_half = max(2, min(4, window_size // 6))
    sg_win = 2 * sg_half + 1
    slope_state = smoothed[:, 1]
    if n >= sg_win:
        slope_s = _sg(slope_state, sg_win, 2, mode="interp")
    else:
        slope_s = slope_state
    # 2) Conservative lead: advance the level by a fraction of the effective
    #    group delay. Small factor (0.2) -> safe against spurious reversals.
    lead_gain = 0.2
    estimates = estimates + lead_gain * sg_half * slope_s
