slope_conditional_quiet_region_polish</NAME>
<DESCRIPTION>
Gens 82–85 established that extra unconditional SG passes cannot reduce the ~48 slope changes / ~35 false reversals — they attenuate corners and hurt lag. The residual reversals occur almost entirely in quiet (low-slope) regions where the output still dithers. So instead of widening any global pass, I add a *slope-magnitude-conditional* polish: compute the slope of the current output, and only where |slope| is below a volatility-scaled threshold (0.25 * q_scale, using the Kalman stage's robust diff-median), apply a very short zero-phase SG (half-width max(2, sg_half//3)). Where the slope is significant (genuine trends, transitions), the output is passed through untouched, preserving responsiveness. The blend is done via np.where with an explicitly length-checked branch (guarding against Gen 90's length-mismatch crash: if the short kernel cannot be applied to this length, skip the polish entirely). This attacks the slope-change and false-reversal bottlenecks without degrading lag_error or responsiveness, since quiet-region smoothing is zero-phase and short-windowed.

    # Residual slope reversals live almost exclusively in flat (low-slope)

    # np.where; genuine transitions keep their responsiveness untouched.
