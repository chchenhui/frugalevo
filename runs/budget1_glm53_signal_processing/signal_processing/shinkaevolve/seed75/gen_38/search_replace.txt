The best prior program (score 0.65) used the same adaptive constant-velocity Kalman prefilter followed by an RTS backward smoother before the SG stage. The current program lacks the RTS pass, showing worse lag error (0.29 vs 0.27), more slope changes (107 vs 65.8), and more false reversals (83 vs 44.4). Adding the standard RTS recursion over the stored [level, slope] states uses full forward+backward evidence to remove noise-induced wobble without adding lag. Keep the 2-state model (3-state variants with reversal gates demonstrably injected jitter). Store s_f, P_f, P_pred in the forward loop, then run the backward recursion and feed the smoothed level into the SG stage.
