<DESCRIPTION>
Replace the exponentially-weighted moving average with a zero-lag double-smoothing filter (DSSA / "zero-lag EMA" style error-correction). A single EMA introduces phase lag proportional to window length, hurting lag_error and responsiveness. The zero-lag technique runs two passes of EMA and adds back the estimated lag error (error = input - EMA of EMA, corrected output = 2*EMA1 - EMA2), which cancels most of the group delay while retaining strong noise attenuation. This simultaneously reduces lag_error (error correction term), slope changes and false reversals (smoother trend), while improving correlation since output tracks the clean signal phase-aligned. To keep output length consistent with the current API, the filter is applied on the full signal and the last output_length values are returned, aligned to the window end as before.

    # Zero-lag double-smoothed EMA: two EMA passes plus lag-error correction.
    # alpha chosen from window size so noise attenuation matches the old WMA.
    alpha = 2.0 / (window_size + 1.0)

    # First EMA pass
    ema1 = np.empty(len(x))
    ema1[0] = x[0]
    for i in range(1, len(x)):
        ema1[i] = ema1[i - 1] + alpha * (x[i] - ema1[i - 1])

    # Second EMA pass over the first EMA (double smoothing)
    ema2 = np.empty(len(x))
    ema2[0] = ema1[0]
    for i in range(1, len(x)):
        ema2[i] = ema2[i - 1] + alpha * (ema1[i] - ema2[i - 1])

    # Zero-lag correction: add back the lag error (input - double-smoothed)
    y_full = 2.0 * ema1 - ema2

    # Return the last output_length samples (phase-aligned with window end,
    # consistent with previous API where index i corresponds to window end)
    return y_full[-output_length:].copy()
