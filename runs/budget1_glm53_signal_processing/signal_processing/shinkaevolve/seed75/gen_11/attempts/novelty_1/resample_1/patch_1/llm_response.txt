<DESCRIPTION>
Replace the exponentially-weighted moving average with an adaptive Kalman filter with online trend (velocity) tracking. A constant-velocity Kalman model estimates both level and slope each step, so it anticipates trends instead of lagging behind them (reducing lag error), while the measurement-noise vs process-noise ratio (adapted from residual statistics) provides strong smoothing that suppresses spurious slope changes and false reversals. This directly targets all four objectives: slope change minimization, lag minimization, tracking accuracy, and false reversal penalty. The filter is O(1) per sample, keeping execution time low. We keep the same output length convention as before for compatibility, but align estimates with the end of each causal window so phase delay is minimal.

    """
    Enhanced version with trend preservation using weighted moving average.

    Args:
        x: Input signal (1D array of real-valued samples)
        window_size: Size of the sliding window

    Returns:
        y: Filtered output signal
    """
    if len(x) < window_size:
        raise ValueError(f"Input signal length ({len(x)}) must be >= window_size ({window_size})")

    output_length = len(x) - window_size + 1
    y = np.zeros(output_length)

    # Create weights that emphasize recent samples
    weights = np.exp(np.linspace(-2, 0, window_size))
    weights = weights / np.sum(weights)

    for i in range(output_length):
        window = x[i : i + window_size]

        # Weighted moving average with exponential weights
        y[i] = np.sum(window * weights)

    return y

def enhanced_filter_with_trend_preservation(x, window_size=20, process_noise=1e-3, measurement_noise=None):
    """
    Enhanced version with trend preservation using an adaptive constant-velocity
    Kalman filter. The state is [level, slope]; the filter predicts forward each
    step, so genuine trends are tracked with minimal lag while noise is suppressed.

    Args:
        x: Input signal (1D array of real-valued samples)
        window_size: Size of the sliding window
        process_noise: Process noise variance (higher = more responsive)
        measurement_noise: Measurement noise variance (estimated if None)

    Returns:
        y: Filtered output signal
    """
    x = np.asarray(x, dtype=float)
    n = len(x)
    if n < window_size:
        raise ValueError(f"Input signal length ({n}) must be >= window_size ({window_size})")

    # Estimate measurement noise from first differences (robust median-based)
    if measurement_noise is None:
        d = np.diff(x)
        measurement_noise = max(np.median(np.abs(d - np.median(d))) ** 2, 1e-6)

    q = process_noise * measurement_noise

    # State: [level, slope]
    state = np.array([x[0], 0.0])
    P = np.eye(2) * measurement_noise

    # Constant-velocity model
    F = np.array([[1.0, 1.0], [0.0, 1.0]])
    H = np.array([[1.0, 0.0]])
    Q = q * np.array([[0.25, 0.5], [0.5, 1.0]])  # discrete white-noise acceleration model
    R = np.array([[measurement_noise]])

    # Run Kalman filter causally over the full signal
    est = np.zeros(n)
    for k in range(n):
        # Predict
        state = F @ state
        P = F @ P @ F.T + Q
        # Update
        S = H @ P @ H.T + R  # innovation variance
        K = (P @ H.T) / S[0, 0]
        innov = x[k] - (H @ state)[0]
        state = state + (K.flatten() * innov)
        # Joseph-form covariance update for numerical stability
        IKH = np.eye(2) - K @ H
        P = IKH @ P @ IKH.T + K @ R @ K.T
        est[k] = state[0]

    # Output aligned with the previous convention (causal estimates)
    output_length = n - window_size + 1
    y = est[window_size - 1:]

    return y
