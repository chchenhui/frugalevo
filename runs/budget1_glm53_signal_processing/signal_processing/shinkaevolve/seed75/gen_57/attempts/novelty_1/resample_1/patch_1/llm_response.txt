The hybrid composition keeps the current Kalman+RTS adaptive-R 3σ-gated backbone (which delivered lag 0.27) and adds the missing pieces: (1) keep the percentile-blended multi-scale SG (already present), (2) add a slope-lead compensation term driven by the *RTS smoothed slope* (the optimal low-noise derivative estimate, far less noisy than finite differences, so it restores dynamics without re-creating spurious reversals), gated by a *smooth sigmoid* in |slope| space rather than a hard binary gate — the hard gate causes discontinuities at the threshold that themselves register as slope changes. The lead magnitude is a modest fraction of the SG half-window, applied only where the trend is statistically meaningful relative to local noise scale. This attacks lag_error (still 0.27) while the sigmoid gating + already-achieved noise reduction (0.82) protects smoothness and false reversals, aiming to break the 0.65 plateau on the composite.</DESCRIPTION>

    # --- Stage 3: sigmoid-gated slope-lead compensation on RTS smoothed slope ---
    # The RTS smoothed slope is the optimal low-noise derivative estimate;
    # using it (instead of a finite difference) injects minimal residual
    # noise into the lead term, restoring dynamics (lower lag error)
    # without re-creating spurious reversals. A *smooth* sigmoid gate in
    # |slope| space avoids the discontinuities a hard threshold would cause.
    slope = smoothed[:, 1].copy()
    # Light zero-phase polish of the slope to kill residual jitter
    h_sl = max(1, sg_half // 2)
    c_sl = _sg_coeffs(h_sl)[::-1]
    if n > h_sl + 1:
        pad_s = np.concatenate([
            2 * slope[0] - slope[1:h_sl + 1][::-1],
            slope,
            2 * slope[-1] - slope[n - 2:n - h_sl - 2:-1][::-1],
        ])
        slope_p = np.convolve(pad_s, c_sl, mode="valid")
        if len(slope_p) == n:
            slope = slope_p

    # Sigmoid gate: full lead only where |slope| clearly exceeds the local
    # noise scale; smooth transition prevents gate-induced slope changes.
    q_scale2 = np.median(np.abs(np.diff(x))) + 1e-12
    thresh = 0.5 * q_scale2
    gate = 1.0 / (1.0 + np.exp(-(np.abs(slope) - thresh) / max(thresh * 0.35, 1e-9)))
    lead = 0.25 * sg_half  # conservative fraction of SG half-window
    smoothed = smoothed[:, 0] + lead * gate * slope

    # --- Trim to sliding-window output length, end-aligned (minimal lag) ---
    y = smoothed[-output_length:]
    return y
