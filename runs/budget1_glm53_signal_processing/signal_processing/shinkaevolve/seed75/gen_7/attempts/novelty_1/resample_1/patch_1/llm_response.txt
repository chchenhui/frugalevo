<DESCRIPTION>
The current metrics show excellent accuracy (corr 0.95) but weak smoothness (0.16) and still many slope changes (107) and false reversals (83). The Kalman stage tracks well; the Savitzky-Golay stage is too short (window_size//4 ≈ 5 samples) to suppress residual noise. Two targeted changes: (1) widen the zero-phase SG window to window_size//2 with cubic polynomial, and apply a second light zero-phase pass — zero-phase convolution adds no lag, so lag_error should not increase; (2) add explicit trend (lag) compensation by adding the Kalman's slope estimate times the effective lookahead offset back onto the output, which offsets any amplitude/phase attenuation introduced by stronger smoothing while preserving trend tracking (reduces avg_error and lag_error). Combined this pushes slope_changes and false_reversals down substantially without sacrificing correlation.

    # --- Stage 2: stronger zero-phase Savitzky-Golay smoothing (kills slope reversals, no lag) ---
    sg_half = max(2, window_size // 2)
    sg_len = 2 * sg_half + 1
    poly = min(3, sg_len - 1)
    t_off = np.arange(-sg_half, sg_half + 1, dtype=float)
    A = np.vstack([t_off ** k for k in range(poly + 1)]).T
    ATA_inv = np.linalg.pinv(A.T @ A)
    coeffs = (ATA_inv @ A.T)[0]  # row for value at center -> zero-phase

    def _zero_phase_smooth(sig, half, kernel):
        m = len(sig)
        if m < 2 * half + 1:
            return sig.copy()
        left = 2 * sig[0] - sig[1 : half + 1][::-1]
        right = 2 * sig[-1] - sig[-2 : -half - 2 : -1][::-1]
        padded = np.concatenate([left, sig, right])
        out = np.convolve(padded, kernel, mode="valid")
        return out[:m] if len(out) >= m else sig.copy()

    smoothed = _zero_phase_smooth(kf_out, sg_half, coeffs)
    # Second light zero-phase pass (short window) to further suppress slope reversals
    h2 = max(1, sg_half // 2)
    t2 = np.arange(-h2, h2 + 1, dtype=float)
    A2 = np.vstack([t2 ** k for k in range(3)]).T
    c2 = (np.linalg.pinv(A2.T @ A2) @ A2.T)[0]
    smoothed = _zero_phase_smooth(smoothed, h2, c2)

    # --- Stage 3: trend (lag) compensation using Kalman slope estimate ---
    # Estimate local slope of the smoothed signal and push output forward by the
    # effective smoothing look-ahead to cancel residual group delay / attenuation.
    slope = np.gradient(smoothed)
    # slope of the Kalman level estimate (already available implicitly via gradient)
    # compensate by the SG half-window look-ahead (zero-phase => no delay, but the
    # double pass attenuates sharp corners; restore with a mild slope boost)
    lead = 0.5 * sg_half * 0.25  # conservative fraction of look-ahead
    smoothed = smoothed + lead * slope
