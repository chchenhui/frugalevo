<DESCRIPTION>
Two targeted improvements on top of the working Kalman+RTS core:

1) **Lag/lead compensation using the smoothed slope state.** The RTS smoother gives us not just a level estimate but a slope estimate `smoothed[:,1]` that is already optimally denoised. The remaining lag_error (0.26) and avg_error (0.29) come from the filter's effective group delay. Shifting each output forward by a fraction of `window_size` times the smoothed slope (a first-order Taylor lead) recovers responsiveness without adding noise, since the slope channel is heavily smoothed by both the Kalman model and the backward pass.

2) **Light Savitzky-Golay polish.** slope_changes (82) and false_reversals (60) are still the weakest metrics. A short (length 7, order 2) Savitzky-Golay pass over the already-smoothed estimates preserves quadratic trends exactly (so genuine turning points are untouched, order 2 reproduces local curvature) while averaging out residual high-frequency ripple in the level channel. The short window keeps added phase delay far below the window-size scale, and the end-aligned trim is computed after both stages so the output contract (length = n - window_size + 1, end-aligned) is rigorously preserved.

These two operations act on different artifacts (lag from delay, ripple-driven slope reversals), so their gains compound while neither re-introduces the other's problem.

    slopes = smoothed[:, 1]

    # --- Lag compensation (first-order lead using the smoothed slope) ---
    # The smoother's slope channel is optimally denoised; advancing the
    # estimate by lead * slope recovers responsiveness without amplifying
    # noise (in contrast to using raw differences).
    lead = max(1.0, window_size / 8.0)
    estimates = estimates + lead * slopes

    # --- Light Savitzky-Golay polish on the level channel ---
    # Order-2 SG reproduces local quadratic trends exactly (genuine turning
    # points preserved) while averaging residual high-frequency ripple that
    # drives spurious slope reversals. Short window -> negligible delay.
    sg_len = min(7, n if n % 2 == 1 else n - 1)
    if sg_len >= 5:
        half = sg_len // 2
        padded = np.concatenate((
            2 * estimates[0] - estimates[half:0:-1],
            estimates,
            2 * estimates[-1] - estimates[-2:-2 - half:-1],
        ))
        # fixed order-2 SG coefficients for window length 7 (central weights)
        if sg_len == 7:
            c = np.array([-2.0, 3.0, 6.0, 7.0, 6.0, 3.0, -2.0]) / 21.0
        else:  # sg_len == 5
            c = np.array([-3.0, 12.0, 17.0, 12.0, -3.0]) / 35.0
        estimates = np.convolve(padded, c, mode='valid')
