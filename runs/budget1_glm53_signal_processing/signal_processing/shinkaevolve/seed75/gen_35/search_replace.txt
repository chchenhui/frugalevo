<DESCRIPTION>
Prior programs show the 2-state [level, slope] Kalman with Q = 0.05·(median|diff|)² is a proven winner, and Gens 25/32 showed an RTS backward smoother pass reduces lag error (0.31 vs 0.35) and noise while matching correlation 0.94 — they lost only because of aggressive lead/hysteresis add-ons and the jitter-inducing 3-state model. This edit: (1) stores the filtered states and covariances (and predicted covariances) during the existing forward Kalman loop, (2) adds a standard RTS backward recursion on the [level, slope] state, and (3) feeds the smoothed level channel into the existing multi-scale SG stage, which stays unchanged. The RTS pass uses full forward+backward evidence, so it removes noise-induced wobble (fewer false reversals / slope changes) without adding lag the way a wider forward window would. We deliberately avoid slope-lead compensation, which hurt smoothness in Gens 25/26/28/32.</DESCRIPTION>
