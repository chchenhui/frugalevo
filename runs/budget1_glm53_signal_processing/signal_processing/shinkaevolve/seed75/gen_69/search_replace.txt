Compose the two 0.65-anchor lineages: (a) replace the single fixed-scale SG polish with a percentile-blended 3-scale SG kernel bank (half-widths [sg_half//2, sg_half, 3·sg_half/2]) with Gaussian weights centered at the 20/50/80th percentiles of local volatility, then (b) add a short fixed second SG cascade (h=window_size//8) that cascaded short kernels use to kill residual ripple causing spurious slope reversals, and (c) add a confidence-gated lead using the RTS slope channel, lightly polished and MAD-gated via tanh, so lag compensation applies only where the trend is statistically significant. This targets the untried Pareto point between the 0.65 anchors: keeping noise reduction 0.82 while pushing lag below 0.27 and false reversals below 45.

    # --- Stage 2: zero-phase Savitzky-Golay polish (kills slope reversals, no lag) ---
    def _sg_coeffs(h):
        """Order-2 SG kernel (value at center -> zero phase) for half-width h."""
        t_off = np.arange(-h, h + 1, dtype=float)
        A = np.vstack([t_off ** k for k in range(3)]).T
        return (np.linalg.pinv(A.T @ A) @ A.T)[0]

    def _sg_smooth(sig, h):
        """Reflect-pad and convolve with the SG kernel; returns len(sig)."""
        c = _sg_coeffs(h)[::-1]

                2 * sig[0] - sig[1:h + 1][::-1],
                sig,
