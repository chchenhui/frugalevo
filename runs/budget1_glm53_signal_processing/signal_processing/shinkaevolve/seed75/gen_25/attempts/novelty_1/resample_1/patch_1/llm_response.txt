<DESCRIPTION>
Two targeted improvements on top of the RTS-smoothed Kalman pipeline:

1. **Trend-compensation lead using the denoised slope state.** The current output `smoothed[:, 0]` still carries residual lag (lag_error 0.26). A pure lead-shift using `np.gradient(smoothed)` would re-inject high-frequency energy (prior experiments showed lead compensation raising false reversals). Instead, we use the RTS-smoothed slope state `smoothed[:, 1]` — it is already optimally denoised by the Kalman/RTS machinery — and advance the estimate by `lead = 0.35 * sg_half` samples: `y = level + lead * slope`. This is a first-order Taylor extrapolation of the smoothed trajectory, so it reduces lag without amplifying noise, improving lag_error, responsiveness, and avg_error while preserving the 0.97 correlation.

2. **Localized reversal-suppression hysteresis** (re-adding the pass from the 0.63-scoring generation, which was dropped): where the gradient sign flips within a few samples while |gradient| is small relative to its median magnitude (micro-oscillations), apply a tiny zero-phase order-2 Savitzky–Golay pass restricted to only those neighborhoods. This directly targets slope_changes (82.2) and false_reversals (60.4) without adding lag elsewhere, since flagged regions are tiny and the smoothing kernel is 5 taps.

Both changes are consistent: lead compensation is applied first (uses the denoised Kalman slope), then hysteresis cleans up any residual weak-gradient flips introduced or left over.

def _local_hysteresis(y, flip_span=3, k=0.5):
    """Suppress weak micro-oscillations: where the gradient sign flips
    within a few samples while |g| is small, apply a tiny zero-phase
    order-2 SG pass restricted to those neighborhoods only."""
    n = len(y)
    if n < 7:
        return y
    g = np.gradient(y)
    med_g = np.median(np.abs(g)) + 1e-12
    weak = np.abs(g) < k * med_g
    s = np.sign(g)
    flip = np.zeros(n, dtype=bool)
    for lag in range(1, flip_span + 1):
        if lag < n:
            flip[lag:] |= (s[lag:] * s[:-lag]) < 0
    flag = weak & flip
    if not np.any(flag):
        return y
    # dilate flags by a couple samples on each side
    dil = np.zeros(n, dtype=bool)
    r = 2
    idx = np.where(flag)[0]
    for i in idx:
        dil[max(0, i - r):min(n, i + r + 1)] = True
    out = y.copy()
    # fixed order-2 SG coefficients (window 5, zero-phase)
    c = np.array([-3.0, 12.0, 17.0, 12.0, -3.0]) / 35.0
    # process each flagged neighborhood
    i = 0
    while i < n:
        if dil[i]:
            j = i
            while j < n and dil[j]:
                j += 1
            lo = max(0, i - 2)
            hi = min(n, j + 2)
            seg = y[lo:hi]
            if len(seg) >= 5:
                padded = np.concatenate((
                    2 * seg[0] - seg[2:0:-1],
                    seg,
                    2 * seg[-1] - seg[-2:-4:-1],
                )) if len(seg) >= 4 else seg
                sm = np.convolve(padded, c, mode='valid')
                # map smoothed samples back onto the flagged core
                core_start = i - lo
                core_len = j - i
                avail = min(core_len, len(sm) - core_start)
                if avail > 0:
                    out[i:i + avail] = sm[core_start:core_start + avail]
            i = j
        else:
            i += 1
    return out
