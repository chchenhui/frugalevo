<DESCRIPTION>
The current best (0.65) already contains the forward Kalman + RTS smoother + single zero-phase SG pass, but lacks any lag-compensation stage. The prior experiments show the trend-lead stage is the main lever on lag_error/responsiveness, but earlier versions contaminated it by blending a numerical gradient (`np.gradient`) with the RTS slope channel — the numerical gradient reintroduces exactly the ripple the SG cascade just removed, hurting slope_changes/false_reversals. This edit adds the minimal confidence-gated trend lead driven by the *pure RTS slope channel* (`smoothed_states[:, 1]`), which is already optimally smoothed by the RTS backward pass. No gradient is computed at all. The gate uses fixed constants anchored to the already-computed robust volatility scale `q_scale` (center 0.25·q_scale, temperature 0.15·q_scale) and a small lead of 0.5·sg_half·0.25, so the lag compensation is only applied where the smoothed slope exceeds the noise floor. Everything else in the file is untouched, making the score delta attributable to this single change.
</DESCRIPTION>
