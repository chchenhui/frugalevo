slope_conditional_quiet_region_polish</NAME>
<DESCRIPTION>
Apply an unconditional small SG polish only in quiet regions (small slope magnitude), then a localized slope-magnitude-conditional smoothing pass using the existing hysteresis machinery with a stricter slope gate. The key idea: slope changes (79.6) and false reversals (58.4) come from residual dithering in flat regions where |slope| is small relative to a robust slope scale. Smooth only there with a small zero-phase order-2 SG kernel (window 5), blending via np.where, so genuine transitions keep their responsiveness. This avoids the failure mode of extra global SG passes (Gens 82-85) by conditioning on local slope magnitude rather than applying everywhere.

    # --- Localized reversal-suppression hysteresis ---
    estimates = _local_hysteresis(estimates)

    # --- Slope-conditional quiet-region polish ---
    # Smooth only where the RTS-smoothed slope is small (quiet regions where
    # dithering causes spurious slope sign flips), leaving genuine transitions
    # untouched to preserve responsiveness and minimize lag.
    if n >= 5:
        slope_rts = np.gradient(estimates)
        q = np.abs(slope_rts)
        q_scale = np.median(q) + 1e-12
        quiet = q < 0.25 * q_scale
        if np.any(quiet) and np.sum(quiet) >= 3:
            c = np.array([-3.0, 12.0, 17.0, 12.0, -3.0]) / 35.0
            padded = np.concatenate((
                2 * estimates[0] - estimates[2:0:-1],
                estimates,
                2 * estimates[-1] - estimates[-2:-4:-1],
            ))
            smoothed_all = np.convolve(padded, c, mode='valid')
            # guard length: convolve valid output length equals n
            if len(smoothed_all) == n:
                estimates = np.where(quiet, smoothed_all, estimates)

    output_length = n - window_size + 1
