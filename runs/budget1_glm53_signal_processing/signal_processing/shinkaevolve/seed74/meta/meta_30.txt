# Analysis of Program Evaluation Results

## Successful Algorithmic Patterns

- **The Kalman/RTS + zero-phase bidirectional one-pole architecture is now firmly established as the dominant family**: the current best (Gen 27 `iterated_rts_two_pass`, combined 0.72) extends Gen 24's single-pass RTS (0.67) by adding an **iterated second RTS pass with Q reduced 4×** (variational refinement), which cut false reversals from 26.6 → 14.2, slope changes from 36 → 20.4, and lifted smoothness 0.36 → 0.50 while keeping correlation high (0.89) and efficiency perfect (1.00, 0.05s).

- **Iterated/two-pass RTS refinement is the highest-leverage recent addition**: Gen 27 (second pass, Q/4) and Gen 30 (same, alpha 0.55–0.95) both improved over Gen 24's single pass, confirming that re-smoothing already-denoised output with tighter process noise sharpens the minimum-variance estimate without adding phase lag.

- **The best program's (Gen 27) key structural elements**: (1) full forward Kalman storing `xp/xf/Pp/Pf`, (2) true RTS recursion with `G = Pf[k]FᵀPp[k+1]⁻¹` and pinv fallback, (3) a complete second forward+RTS pass on the smoothed output with `q2 = 0.25·qa`, (4) bilateral one-pole with tanh-adaptive alpha clipped to [0.55, 0.95], (5) explicit output contract `y[window_size−1:]` with length assertion `n − window_size + 1`, and (6) all entry points (`adaptive_filter`, `enhanced_filter_with_trend_preservation`, `process_signal`) funneling through the same core — avoiding Gen 19's fatal wiring error.

# Actionable Recommendations for Future Program Mutations

1. **Extend the iterated RTS to a third pass with geometrically decaying Q (q3 = 0.0625·qa)**. Gen 27's second pass (Q/4) delivered the largest recent jump (+0.05 over Gen 24) by exploiting the already-denoised output's statistics. Add a third forward+RTS cycle gated by an internal convergence check — stop if `max|y_new − y_old| < 0.05·σ_r` or if correlation on a self-test drops below 0.88 — so segments that are already smooth don't degrade. Keep the slicing contract and entry-point wiring identical; this is the lowest-risk incremental extension of the proven winner.

2. **Make Q locally adaptive (per-step Q[k]) instead of one global `qa`**. Compute `mad2` over sliding blocks of length ≈ window_size with 50% overlap, linearly interpolate σ_acc(k) between block centers (with the same floor/cap logic applied per-sample), and use Q[k] at each prediction step in the forward pass (the RTS pass reuses stored `Pp`, no change needed). The 5 Hz component in the test signal needs larger Q than the slow trend segments; a single global Q forces one smoothness/responsiveness trade-off everywhere, which is why avg_error (0.39) lags. Apply the same local-Q refinement (scaled 0.25×) in the second pass.

3. **Lower the alpha floor to 0.40 in the bidirectional one-pole damper, with a lag-based guard**. Gens 30/31 feedback explicitly flags that the 0.55 floor leaves residual ripple (14–24 false reversals, smoothness capped ~0.50). Since the damper is zero-phase, reducing alpha does not add lag directly — but guard against over-smoothing by correlating the damper output against the pre-damper RTS output and backing off alpha (raise toward 0.85) if correlation falls below 0.97. Also consider a double application of the bilateral pass at moderate alpha (0.65) instead of one strong pass — cascade smoothing has a flatter group-delay profile near the test signal's dominant frequencies.

4. **Add EWMA innovation-based adaptive R in the forward passes only**: `R[k] = 0.5·σ_r² + 0.5·ewma_var` with `ewma_var = 0.9·ewma_var + 0.1·innov[k]²`. Gen 31 (0.69) validated the EWMA measurement-noise direction. Widening R during noisy bursts and tightening during clean segments directly targets noise_reduction (0.55, the weakest unsaturated metric) without adding any pipeline stage. Crucially, do NOT add trend-lean or signal-shaping terms to the state update — Gen 2 showed those poison output; keep `x_est = xp[k] + K·innov` and the symmetrized covariance update exactly as-is.

5. **Exploit the velocity state: replace the one-pole damper with an optional velocity-limited reconstruction or add mild cross-smoothing of xs[:,1]**. The RTS pass already estimates velocity at minimum variance, yet it's discarded. One cheap use: after smoothing, clamp per-step displacement of y to `2·|xs[:,1]| + 0.5·σ_r` — this directly suppresses false reversals (14.2) and slope changes (20.4) while provably preserving genuine trend segments (which have large |velocity|). Alternatively, apply the bidirectional one-pole to xs[:,1] as well and integrate the smoothed velocity as a consistency polish — but guard with a correlation check ≥0.95 against the position-only output, given that phase misalignment (Gen 25's −0.85) is the known failure mode of stacked post-processing.
