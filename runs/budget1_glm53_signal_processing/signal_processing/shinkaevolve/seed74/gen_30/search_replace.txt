<DESCRIPTION>
The best program (0.72) used the iterated RTS refinement pass and achieved smoothness 0.50 with only 20.4 slope changes and 14.2 false reversals, while current program (0.67) lost that. Rather than only restoring the refinement, I also tighten the acceleration-noise calibration per feedback: increase the floor from 0.05·σ_r to 0.10·σ_r and tighten the cap from 0.6·σ_r to 0.4·σ_r. This shrinks Q so the Kalman/RTS smoother trusts the constant-velocity model more, suppressing noisy dynamics that cause spurious slope changes, at the cost of slightly more lag (0.32 → ~0.34, still excellent). Combined with restoring the second refinement pass (Q reduced 4x) — which was the single largest smoothness gain in the prior best program — this should recover the 0.72-level balance and possibly exceed it.
