<DESCRIPTION>
The RTS smoother already produces a minimum-variance velocity estimate (xs[:,1]), but the current pipeline discards it and applies a one-pole position-only damper as the final polish. This edit replaces the unconstrained one-pole output with a velocity-limited reconstruction: after smoothing, each per-step displacement of the output is clamped to 2·|v̂| + 0.5·σ_r, where v̂ is the RTS velocity estimate at that step. Genuine trend segments carry large |v̂| and pass through untouched (preserving tracking accuracy and lag performance), while noise-driven spikes — which the smoother attributes near-zero velocity — are clamped, directly suppressing false reversals and spurious slope changes. This is O(n), adds no phase delay (it's a symmetric magnitude clamp, not a filter), and avoids the stacked-post-processing phase-misalignment failure mode since it uses the smoother's own velocity rather than integrating an independently smoothed velocity stream.
</DESCRIPTION>

        for i in range(1, n):
            max_step = 2.0 * abs(vel[i]) + 0.5 * sigma_r
