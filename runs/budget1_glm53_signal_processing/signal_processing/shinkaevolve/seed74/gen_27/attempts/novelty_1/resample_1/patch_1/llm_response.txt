<DESCRIPTION>
Apply a second forward Kalman + RTS pass on the first-pass smoothed output with Q scaled down ~4× (R kept at σ_r²). This is a variational refinement: the first-pass smoother output is a cleaner signal whose first-difference statistics better reflect true dynamics, so a second cycle with tighter process noise sharpens the minimum-variance estimate further without adding lag (output alignment/slicing unchanged). This continues the pattern that carried Gen 13→single RTS pass (0.53→0.67). The bilateral one-pole damper still runs after the final pass to remove residual ripple. Guard: keep pass 2 only if it does not over-smooth (correlation check is implicit via reduced-Q second pass being conservative).
