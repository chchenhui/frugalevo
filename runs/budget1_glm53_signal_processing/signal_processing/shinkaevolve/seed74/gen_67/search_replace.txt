<DESCRIPTION>
Add a guarded zero-phase curvature clamp as the missing complement to the velocity clamp. The current pipeline bounds per-step displacement but permits alternating ±limit steps (oscillation entirely within the displacement bound), which is exactly how ~20 slope changes survive. Clamping the second difference |y[k+1] − 2y[k] + y[k−1]| ≤ c·(robust d2 scale of the current output) in forward+backward sweeps directly bounds the derivative's oscillation rate without adding lag or shifting the level. A correlation guard (≥ 0.97, slack-doubling retry like the velocity clamp) prevents distortion of genuine fast dynamics. Genuine curvature of the smoothed signal is far larger than residual noise curvature, so c ≈ 1.5 passes real turns while killing residual ripple.

def _curvature_clamp(y, c, d2_scale):
    """
    Zero-phase curvature clamp: bound the second difference
    |y[k+1] - 2y[k] + y[k-1]| <= c * d2_scale in forward and backward
    sweeps. Complements the velocity clamp: the velocity clamp bounds
    displacement per step but still permits alternating +/- limit steps
    (oscillation within the displacement bound). Bounding curvature
    bounds the derivative's oscillation rate directly.
    """
    n = len(y)
    if n < 3 or d2_scale <= 0:
        return y.copy()
    out = y.copy()
    limit = c * d2_scale
    # Forward sweep
    for k in range(1, n - 1):
        d2 = out[k + 1] - 2.0 * out[k] + out[k - 1]
        if abs(d2) > limit:
            half = np.sign(d2) * (limit - d2) / 2.0
            out[k - 1] -= half
            out[k + 1] += half
    # Backward (mirrored) sweep to cancel directional bias
    for k in range(n - 2, 0, -1):
        d2 = out[k + 1] - 2.0 * out[k] + out[k - 1]
        if abs(d2) > limit:
            half = np.sign(d2) * (limit - d2) / 2.0
            out[k - 1] -= half
            out[k + 1] += half
    return out
