Replace the final adaptive bilateral one-pole damper with a fixed-λ Whittaker–Henderson smoother (second-order difference penalty) solved with a banded Cholesky solver in O(n). Evidence: Gen 40 scored 0.71 with the adaptive damper; a constant λ keeps the curvature penalty uniform over the signal (no noise leaking through where α relaxed), and the second-order penalty's flatter passband reduces residual ripple (slope changes, false reversals) without adding phase lag or the attenuation a stronger one-pole would bring. λ is scaled from existing residual MAD: λ = clip(25·(r_std/σ_r)², 1, 200). Applied to the full-length signal and sliced last, preserving the len(y) = n − window_size + 1 contract.

def _whittaker_polish(y, lam):
    """Whittaker–Henderson smoother with second-order difference penalty.

    Solves (I + lam * D2^T D2) z = y with a symmetric pentadiagonal banded
    Cholesky solver: O(n) time, O(n) memory. Preserves trends (constant
    and linear components pass through exactly) while penalizing residual
    curvature, giving zero-phase ripple suppression with a flatter
    passband than a one-pole damper of equal noise reduction.
    """
    n = len(y)
    if n < 4 or lam <= 0:
        return y.copy()
    # Assemble banded matrix A = I + lam * D^T D in LAPACK 'sym' band
    # storage: ab[u + i - j, j] = A[i, j], u = bandwidth = 2.
    ab = np.zeros((3, n))
    ab[2, :] = 1.0        # main diagonal (i == j)
    # d = second difference operator applied column-wise
    # D^T D is pentadiagonal with diagonals [1, -4, 6, -4, 1] (interior)
    ab[1, 1:] = -4.0 * lam   # superdiagonal 1
    ab[0, 2:] = 1.0 * lam    # superdiagonal 2
    # main diagonal corrections from D^T D
    main = np.full(n, 6.0 * lam)
    main[0] = 1.0 * lam
    main[1] = 5.0 * lam
    main[-1] = 1.0 * lam
    main[-2] = 5.0 * lam
    ab[2, :] += main
    try:
        from scipy.linalg import cholesky_banded, solveh_banded
        c = cholesky_banded(ab, lower=False)
        return solveh_banded(ab, y, lower=False)
    except Exception:
        pass
    # Fallback: dense solve for small n or missing scipy
    D = np.zeros((n - 2, n))
    for i in range(n - 2):
        D[i, i] = 1.0
        D[i, i + 1] = -2.0
        D[i, i + 2] = 1.0
    A = np.eye(n) + lam * (D.T @ D)
    return np.linalg.solve(A, y)
