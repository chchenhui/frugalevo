<DESCRIPTION>
The recommendation is to replace the current independent backward-pass "blend" smoothing with a true Rauch-Tung-Striebel (RTS) smoother. An independent backward Kalman filter double-counts measurement information and can produce inconsistent estimates; the RTS recursion is the exact minimum-variance fixed-interval smoother given the forward pass. The edit stores the forward filtered states (x_f), filtered covariances (P_f), predicted covariances (P_pred), and the transition matrix F for each step inside the window, then runs the proper backward recursion: G_k = P_f[k] F^T P_pred[k+1]^{-1}, x_s[k] = x_f[k] + G_k (x_s[k+1] - x_f_pred[k+1]). The smoothed result is sliced to the last (n - window_size + 1) valid samples to match the existing output-length contract, with an explicit length assertion to prevent the total-failure class of bugs seen in earlier generations. Cost remains O(n) per window, latency and phase behavior are unchanged, but noise-induced slope reversals should drop because the smoothed estimate is the exact minimum-variance solution rather than a heuristic blend.
