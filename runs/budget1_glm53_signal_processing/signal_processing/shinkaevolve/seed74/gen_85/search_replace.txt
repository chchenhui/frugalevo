<DESCRIPTION>
The recommendation identifies the one structural lever never tested: placing a bilateral one-pole damper *between* the two RTS passes rather than as terminal polish. Rationale: the Q/4 (locally adaptive) refinement pass re-sharpens genuine corners that the damper rounds — its Kalman gain responds to real dynamics — while removed ripple stays removed. This decouples smoothness from the accuracy guard that caps smoothness at 0.50. Additionally, the terminal Whittaker polish is gated on substantial residual ripple (r_std > 0.3·sigma_r): polishing a clean output only adds lag and risk of trend loss. Alpha for the inter-pass damper is set ~0.70 (within the recommended 0.65–0.75 band), tuned from the pass-1 residual ripple scale.
</DESCRIPTION>

def _bilateral_one_pole(x, alpha):
    """Forward then reversed one-pole smoothing — net zero phase delay."""
    y = np.empty_like(x)
    acc = x[0]
    y[0] = acc
    for i in range(1, len(x)):
        acc = alpha * x[i] + (1.0 - alpha) * acc
        y[i] = acc
    acc = y[-1]
    out = y.copy()
    for i in range(len(x) - 2, -1, -1):
        acc = alpha * y[i] + (1.0 - alpha) * acc
        out[i] = acc
    return out
