<DESCRIPTION>
The local block-MAD Q currently only affects the refinement pass; the first (noisy-input) pass still uses the global Q, so busy segments (5 Hz component) are over-smoothed before the adaptive pass can recover them — contributing to lag_error (0.34) and avg_error (0.39). I propose (1) computing the local block-MAD qseq on the rough moving-average trajectory before the first pass and blending it into the first-pass process noise (Q[k] = max(local, global)·Qbase), so busy segments get responsive tracking from the start; and (2) tightening the refinement pass scale from 0.25 to 0.15 to recover noise_reduction (which slipped to 0.55) since the first pass now carries the adaptivity. Block medians over the MA-smoothed input remain robust to transients, unlike recursive EWMA estimates.

    # --- Locally adaptive process noise via robust block-MAD statistics
    # (explicitly NOT recursive/EWMA), computed on the MA-roughened input.
    # Overlapping blocks of ~window_size (50% overlap); subtract the
    # propagated noise floor (sigma_r/sqrt(w))*sqrt(6), floor at 0.05*sigma_r,
    # cap at 1.5*sigma_r; linearly interpolate to per-sample q_k. Used in the
    # FIRST pass (max with global qa) so busy segments track responsively
    # from the start, and re-derived on y1 for the refinement pass. ---
    def _block_qseq(sig, w, sig_r):
        step = max(1, w // 2)
        vals, cens = [], []
        for start in range(0, max(1, len(sig) - w + 1), step):
            seg = sig[start:start + w]
            if seg.size < 3:
                continue
            d2s = seg[2:] - 2.0 * seg[1:-1] + seg[:-2]
            mad_b = np.median(np.abs(d2s - np.median(d2s))) / 0.6745
            noise_d2_b = (sig_r / np.sqrt(w)) * np.sqrt(6.0)
            var_b = mad_b * mad_b - noise_d2_b * noise_d2_b
            s_b = float(np.clip(np.sqrt(max(var_b, 0.0)), 0.05 * sig_r, 1.5 * sig_r))
            vals.append(s_b)
            cens.append(start + w // 2)
        if len(vals) >= 2:
            return np.interp(
                np.arange(len(sig), dtype=float),
                np.asarray(cens, dtype=float),
                np.asarray(vals, dtype=float),
            ) ** 2
        if len(vals) == 1:
            return np.full(len(sig), vals[0] ** 2)
        return np.full(len(sig), qa)
