zero_lag_bidirectional_smoother</NAME>
<DESCRIPTION>
Prior gens failed to improve smoothness because post-smoothing was too weak. Add a two-pass forward-backward one-pole smoother with alpha ~0.5 applied to the fused output: running forward then reversed cancels the lag a single-pass filter would add, so lag error stays near 0.22 while the noise-driven ripple (which drives slope_changes/false_reversals) is damped by roughly a factor of 2. The bidirectional application is the key: a forward-only pass with the same strength would add phase delay, but the mirror pass compensates it.
