The slope-change count (~20.4) and false reversals (~14.2) have never moved across the 0.72 family. The velocity clamp bounds |Δy| but still permits alternating +limit/−limit steps, which is precisely how residual slope flips survive all downstream damping. This edit adds a guarded zero-phase curvature (second-difference) clamp immediately after the velocity clamp, mirroring its proven slack-doubling retry pattern with a corr ≥ 0.97 guard. Alternating spurious direction reversals — the direct driver of the slope-change and false-reversal metrics — are flattened while genuine smooth turns (curvature within the robust scale) pass untouched. The 4-attempt slack-doubling guard protects tracking accuracy and lag, so correlation/accuracy metrics should not regress.</DESCRIPTION>

def _curvature_clamp(y, limit):
    """
    Zero-phase curvature clamp. Limits |y[k+1] - 2y[k] + y[k-1]| to `limit`
    in forward and backward (mirrored) sweeps, directly attacking
    alternating slope reversals that survive displacement clamping.
    """
    n = len(y)
    if n < 3:
        return y.copy()
    out = y.copy()
    # Forward sweep
    for k in range(1, n - 1):
        c2 = out[k + 1] - 2.0 * out[k] + out[k - 1]
        if abs(c2) > limit:
            out[k + 1] = 2.0 * out[k] - out[k - 1] + np.sign(c2) * limit
    # Backward (mirrored) sweep for zero phase
    for k in range(n - 3, -1, -1):
        c2 = out[k + 1] - 2.0 * out[k] + out[k - 1]
        if abs(c2) > limit:
            out[k - 1] = 2.0 * out[k] - out[k + 1] + np.sign(c2) * limit
    return out
