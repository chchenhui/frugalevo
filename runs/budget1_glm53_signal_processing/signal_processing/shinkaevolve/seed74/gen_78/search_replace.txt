<DESCRIPTION>
Following the recommendation: Gen 72's operating point (corr 0.96 / nr 0.75 / lag 0.30) is reachable with a responsive core, but it collapsed under false reversals without terminal suppression. The current program keeps the guarded damper stack, so we can safely interpolate the core toward that operating point: (1) raise the global sigma_acc cap from 0.4·σ_r to 0.85·σ_r so the Kalman process noise can track genuine dynamics instead of being choked; (2) cap the local block-MAD process-noise estimate at 0.85·σ_r (was 1.5·σ_r) so noisy blocks can't fully open the filter either; (3) add the recommended dynamic blend factor `clip(1.25 − 1.25·dyn_ratio, 0.10, 1.0)` where dyn_ratio is the median block acceleration over σ_r — quiet signals keep the conservative 0.25× second-pass Q scale, while genuinely dynamic signals scale the refinement Q up to ~1.15×, cutting lag error and raising correlation toward ~0.93. The zero-phase bilateral damper and its correlation guard are left fully intact (removing them historically exploded reversals to ~70), keeping false reversals near the current ~14–16 level.
