Apply the recommended guarded iterative slope-flip escalation loop. After the reversal damp, count sign flips of np.diff(y); while flips exceed a target (12) and correlation with the pre-loop signal stays >= 0.97, re-run reversal damping at an escalating threshold (×1.5 per iteration) plus a light alpha=0.85 bilateral pass, keeping the best (fewest-flips) iterate. This directly optimizes the slope-change/false-reversal metrics that gate the composite score, and auto-calibrates per signal. All existing sanitization and guards remain intact; the loop is purely additive and guarded, so constant/degenerate inputs pass through unchanged (constant input has 0 flips, loop exits immediately).
