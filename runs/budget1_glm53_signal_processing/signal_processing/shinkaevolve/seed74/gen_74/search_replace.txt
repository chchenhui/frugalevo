interpass_bilateral_damper</NAME>
<DESCRIPTION>
Move the zero-phase bilateral one-pole damper from a terminal role to an inter-pass role: apply it (alpha ≈ 0.7) to the pass-1 RTS output before the per-sample-Q refinement pass. The refinement pass then re-sharpens genuine corners that the damper rounds (the Kalman gain responds to real dynamics) while removed ripple stays removed — an interaction that can never occur when smoothing is only terminal. Prior generations showed terminal-only damper stacking caps out (Gen 42/45), so ordering is the one untested structural lever. Lag risk is guarded: the bilateral pass is zero-phase, and the Q/4 refinement restores responsiveness; additionally the terminal Whittaker polish is now gated on residual MAD > 0.3·sigma_r so we don't double-smooth and inflate lag_error beyond ~0.40.
</DESCRIPTION>

def _bilateral_one_pole(x, alpha):
    """Forward then reversed one-pole smoothing — net zero phase delay."""
    y = np.empty_like(x)
    acc = x[0]
    y[0] = acc
    for i in range(1, len(x)):
        acc = alpha * x[i] + (1.0 - alpha) * acc
        y[i] = acc
    acc = y[-1]
    out = y.copy()
    for i in range(len(x) - 2, -1, -1):
        acc = alpha * y[i] + (1.0 - alpha) * acc
        out[i] = acc
    return out
