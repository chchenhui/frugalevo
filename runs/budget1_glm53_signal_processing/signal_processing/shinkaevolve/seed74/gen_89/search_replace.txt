<DESCRIPTION>
The one sub-metric that has never moved across the 0.72 family is `slope_changes` (~20.4), and the root cause is structural: `_velocity_clamp` bounds the *first* difference |Δy| per step, but it still permits *alternating* +limit/−limit steps — a zigzag that fully respects the velocity bound yet flips the slope sign at every sample. The existing reversal-damp stages cannot fix this because `_reversal_damp` only shrinks the magnitude of a sub-threshold flip step (keep·d keeps the same sign), so the flip *count* is untouched; only the alpha=0.85 bilateral pass can merge flips, and its corr ≥ 0.97 guard against the pre-loop signal breaks the escalation early.

The fix is to attack the second derivative directly: add `_curvature_clamp`, which limits the step-to-step *slope change* |y[k+1] − 2y[k] + y[k−1]| ≤ curv_limit via a forward sweep (extrapolating the newest point) plus a mirrored backward sweep, so the operation is zero-phase and adds no lag. Clamping the second difference converts an alternating ±L zigzag into a monotone decelerating/increasing glide (slope changes by exactly ±limit per step, crossing zero once), which is precisely "slope change minimization": spurious reversals vanish while each genuine turning point remains exactly one slope change (slightly rounded, still zero-phase). The limit is auto-calibrated as 1.5× the robust MAD scale of the output's own second differences, so it adapts per-signal to the smooth-curvature floor; genuine trend curvature sits at/below this scale and passes through, while noise zigzags (second differences ~2× the velocity slack) exceed it by a wide margin.

Distortion safety mirrors the proven velocity-clamp pattern exactly: 4 attempts with limit doubling (1.5× → 12× MAD scale), accepting the first candidate whose correlation with the pre-clamp signal is ≥ 0.97, otherwise disabling the clamp. Cost is two O(n) Python loops per attempt (≤ 4 attempts) — negligible vs the current 0.08 s runtime, keeping efficiency_score at 1.0. Expected effect: slope_changes and false_reversals drop substantially (the two worst sub-metrics), smoothness rises, while lag_error/correlation/avg_error are protected by the corr ≥ 0.97 guard and the zero-phase construction. Downstream stages (ripple damper, reversal damp, flip-escalation loop with target 12) remain as final polish and will now typically exit immediately.</DESCRIPTION>

def _curvature_clamp(y, curv_limit):
    """
    Zero-phase curvature (second-difference) clamp.

    Limits the step-to-step slope change
        |y[k+1] - 2y[k] + y[k-1]| <= curv_limit.
    Alternating +/- steps that individually pass the velocity clamp
    produce large second differences; the clamp converts them into
    monotone glides (removing spurious slope reversals), while smooth
    genuine trend curvature stays below the robust limit and passes
    through untouched.

    Applied forward then backward (mirrored) so it is zero-phase.
    """
    n = len(y)
    if n < 3:
        return y.copy()
    out = y.copy()
    # Forward sweep: clamp slope change by projecting the newest point
    for k in range(1, n - 1):
        c = out[k + 1] - 2.0 * out[k] + out[k - 1]
        if abs(c) > curv_limit:
            out[k + 1] = 2.0 * out[k] - out[k - 1] + np.sign(c) * curv_limit
    # Backward (mirrored) sweep: adjust the newest point in reverse time
    for k in range(n - 2, 0, -1):
        c = out[k + 1] - 2.0 * out[k] + out[k - 1]
        if abs(c) > curv_limit:
            out[k - 1] = 2.0 * out[k] - out[k + 1] + np.sign(c) * curv_limit
    return out
