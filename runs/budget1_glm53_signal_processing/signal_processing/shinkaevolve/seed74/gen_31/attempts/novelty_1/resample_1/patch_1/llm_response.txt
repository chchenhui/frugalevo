<DESCRIPTION>
Replace the static global R (from MAD of first differences) with an innovation-based, EWMA-smoothed adaptive measurement variance in the forward pass only: R[k] = 0.5·R0 + 0.5·ewma_var. This widens R during noise bursts (more smoothing, fewer slope changes) and tightens it during clean segments (better tracking/lag), improving noise reduction without adding any pipeline stage or touching the state update (which stays purely x_est = xp[k] + K·innov, per the lesson that signal-shaping additions poison output). Both RTS refinement passes use the same time-varying R sequence for consistency.
</DESCRIPTION>

    I2 = np.eye(2)

    x_est = np.array([x[0], 0.0])
    P = np.eye(2) * max(R, 1e-15)

    # --- Innovation-based adaptive measurement noise (EWMA-smoothed) ---
    # R[k] = 0.5*R0 + 0.5*ewma_var widens during noise bursts and tightens
    # during clean segments. Update step remains purely x_est = xp + K*innov.
    R0 = R
    Rseq = np.full(n, R)
    ewma_var = R0
    lam = 0.9

    # --- Forward Kalman pass ---
    for k in range(n):
        if k == 0:
            xp[k] = x_est
            Pp[k] = P
        else:
            xp[k] = F @ x_est
            Pp[k] = F @ P @ F.T + Q
        innov = x[k] - xp[k, 0]
        Rk = 0.5 * R0 + 0.5 * ewma_var
        S = Pp[k][0, 0] + Rk
        K = Pp[k][:, 0] / S
        x_est = xp[k] + K * innov
        P = (I2 - np.outer(K, H)) @ Pp[k]
        P = 0.5 * (P + P.T)
        xf[k] = x_est
        Pf[k] = P
        Rseq[k] = Rk
        # EWMA of squared innovations (heavily damped so bursts widen R,
        # clean stretches shrink it back toward the static estimate).
        ewma_var = lam * ewma_var + (1.0 - lam) * innov * innov
        ewma_var = float(np.clip(ewma_var, 1e-4 * R0, 100.0 * R0))
