locally_adaptive_q_blocks
</NAME>
<DESCRIPTION>
Replace the globally-scalar process noise Q in the second (refinement) RTS pass with a locally adaptive, per-sample Q derived from block-MAD second differences of the first-pass smoothed output y1. Since y1 is already denoised, its second differences reflect genuine local dynamics (e.g., the 5 Hz component) that a global Q under-serves: busy segments get larger process noise (less lag, better tracking), quiet segments get tighter Q (more smoothing, fewer slope changes/false reversals). Blocks of length ≈ window_size with 50% overlap, noise floor (σ_r/√w)·√6 subtracted in quadrature, floored at 0.05σ_r and capped at 1.5σ_r, linearly interpolated per sample. The second pass uses 0.25·Q[k]. The third refinement pass is removed (it added execution time and did not help; the local-Q pass subsumes its purpose) while keeping the final zero-phase polish to avoid the jitter collapse seen in over-smoothed variants.

        centers = []
        sigmas = []

        noise_d2_floor = (sigma_r / np.sqrt(blk)) * np.sqrt(6.0)
