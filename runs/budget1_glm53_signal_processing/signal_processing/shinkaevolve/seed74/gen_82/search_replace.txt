<DESCRIPTION>
Terminal polish stages (dampers, reversal-damp escalation) have plateaued: prior generations varied only terminal damper strength with zero metric movement. The one untested structural lever is ordering. Replace the third micro-refinement pass (fixed Q/8, R from residual) with an adaptive-Q/8 pass that uses a locally adaptive block-MAD qseq estimated on the blended signal, and move the velocity clamp earlier — between pass 2 and pass 3 — so the refinement pass re-sharpens corners the clamp rounds while removed overshoot stays removed. The adaptive Q/8 estimates local second-difference energy per block, so quiet regions get more smoothing (fewer slope changes/false reversals) while dynamic regions get near-zero extra smoothing (lag preserved). The corridor monitor: if lag_error proxy (residual robust std of the final output's first differences relative to sigma_r) indicates over-smoothing, blend down w3. This targets the slope_changes (20.40) and false_reversals (14.20) metrics without touching lag_error (0.34) or accuracy (0.89).

def _block_mad_qseq(y, w_r, sigma_r, qa):
    """Locally adaptive process-noise scale via robust block-MAD of second
    differences. High second-difference energy (genuine dynamics) -> large Q
    (light smoothing, low lag); quiet blocks -> small Q (strong smoothing,
    fewer spurious slope flips). Returns a per-sample qseq of length len(y)."""
    n = len(y)
    Qs = []
    centers = []
    step = max(1, w_r // 2)
    for start in range(0, max(1, n - w_r + 1), step):
        seg = y[start:start + w_r]
        if seg.size < 3:
            continue
        d2s = seg[2:] - 2.0 * seg[1:-1] + seg[:-2]
        mad_b = np.median(np.abs(d2s - np.median(d2s))) / 0.6745
        noise_d2_b = (sigma_r / np.sqrt(w_r)) * np.sqrt(6.0)
        var_b = mad_b * mad_b - noise_d2_b * noise_d2_b
        s_b = float(np.clip(np.sqrt(max(var_b, 0.0)), 0.05 * sigma_r, 1.5 * sigma_r))
        Qs.append(s_b)
        centers.append(start + w_r // 2)
    if len(Qs) >= 2:
        return np.interp(
            np.arange(n, dtype=float),
            np.asarray(centers, dtype=float),
            np.asarray(Qs, dtype=float),
        ) ** 2
    if len(Qs) == 1:
        return np.full(n, Qs[0] ** 2)
    return np.full(n, qa)
