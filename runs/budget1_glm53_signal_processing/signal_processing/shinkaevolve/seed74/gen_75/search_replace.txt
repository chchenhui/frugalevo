Per the recommendation, interpolate the current responsive core toward Gen 72's high-tracking operating point while keeping the clamp structure intact. Two targeted changes: (1) raise the global sigma_acc cap from 0.6·σ_r to 0.85·σ_r (letting the Kalman/RTS trust genuine dynamics more, cutting lag), and (2) the current program has no blend-floor mechanism, so we add one post-refinement: a dynamics-aware blend of the refined pass with the first-pass output, w = clip(1.25 − 1.25·dyn_ratio, 0.10, 1.0). This blends toward the smoother first pass when the signal is quiet (noise suppression) and toward the responsive refined pass when dynamics are strong (lag reduction), targeting corr ~0.93 while the Whittaker polish continues to hold false reversals near 14. The sigma_acc cap is preserved in the refinement block as a per-sample cap of 1.5·σ_r, consistent with the raise.</DESCRIPTION>
