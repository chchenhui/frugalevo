<DESCRIPTION>
Following the recommendation: after the RTS pass, apply a bidirectional one-pole smoother with stronger (moderate) alpha on the full sequence, plus a short zero-phase Savitzky-Golay polish, then slice. Both are applied in forward-then-reversed / symmetric fashion, so added group delay cancels — directly attacking slope_changes (36) and false_reversals (26.6) while lag (0.32) has headroom. Alpha range shifted lower (0.5–0.65 per recommendation) and SG window sized as window_size//4, order 2, which suppresses residual ripple without flattening genuine trends.

    # --- Zero-phase Savitzky-Golay polish (order 2, short window) ---
    # Symmetric LS polynomial regression: no phase delay, removes the
    # last bit of jitter that drives spurious slope reversals.
    def _sg_polish(sig, window, order):
        half = window // 2
        tt = np.arange(-half, half + 1, dtype=float)
        V = np.vander(tt, order + 1, increasing=True)
        try:
            c, _, _, _ = np.linalg.lstsq(V, np.eye(window), rcond=None)
        except np.linalg.LinAlgError:
            return sig.copy()
        coeffs = c[:, 0][::-1]
        # mirror-pad edges to keep length
        if half > 0 and sig.size > half:
            pad_l = sig[half:0:-1] if sig.size > half else sig
            pad_r = sig[-2:-half - 2:-1] if sig.size > half + 1 else sig
            padded = np.concatenate([pad_l, sig, pad_r])
        else:
            padded = sig
        if padded.size < window:
            return sig.copy()
        return np.convolve(padded, coeffs, mode="valid")
