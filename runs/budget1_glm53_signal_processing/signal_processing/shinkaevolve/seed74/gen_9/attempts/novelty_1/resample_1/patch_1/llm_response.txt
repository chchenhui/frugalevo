The weakest metrics are smoothness (0.09), slope changes (198) and false reversals (156) — the filtered output still flips direction too often, while noise reduction (0.41) also lags. The current post-processing (fixed one-pole smoother + crude reversal damping) cannot jointly fix these: the fixed alpha either over-smooths (lag) or under-smooths (ripple).

A constant-velocity (local-linear) Kalman filter applied to the zero-lag endpoint estimates is the principled fix: it optimally fuses the noisy per-window endpoint estimates with a smoothness prior, and by adapting the measurement-noise covariance R from the robust residual scale (r_std) and the process-noise covariance Q from the local signal dynamics, it automatically becomes more smoothing when the signal is quiet (killing noise-driven slope flips) and more responsive when the signal is genuinely moving (keeping lag error small). The Kalman gain is the closed-form solution to the exact multi-objective trade-off we need: it minimizes expected deviation (lag/accuracy) while the implicit state model suppresses sub-noise reversals far more effectively than the heuristic damping loop, because the velocity state carries trend memory across samples.

This replaces both the one-pole smoother and the reversal-suppression hack with a single statistically-grounded recursion, keeping output contract identical.
