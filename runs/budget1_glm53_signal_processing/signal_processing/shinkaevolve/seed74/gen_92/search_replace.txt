<DESCRIPTION>
Replace the hard hold (keep=0.0) in the guarded reversal damping with a magnitude-proportional quadratic soft damp: out[k] = out[k-1] + d*(1 - (|d|/thresh)^2) for sub-threshold flips. The hard hold creates flat zero-step segments that inflate avg_error/lag while leaving residual flips from the mirrored backward sweep re-introducing what the forward sweep removed. The quadratic falloff pins tiny flips to (nearly) zero while passing near-threshold steps almost intact, so a single unguarded sweep pair suffices — no guard retry escalation (which previously halted smoothing too early at the 0.97 correlation check). Guard instead with a single hard abort: correlation against the original input slice must stay >= 0.93, otherwise revert to the pre-damp signal. All sanitization and the rest of the pipeline remain untouched.

def _reversal_damp(y, thresh, keep=0.0):
    """
    Eliminate sub-noise sign flips in the first difference. On a detected
    flip (sign change vs. prev step, magnitude below `thresh`), the line is
    HELD: out[k] = out[k-1] + keep*d with keep=0 gives a zero step, so the
    output difference sequence truly does not reverse. keep>0 is a softer
    partial-step fallback (used on guard retry). prev_d is taken from the
    PRE-damp difference so a zero step does not stall subsequent detection.
    Forward sweep plus mirrored backward sweep => zero phase.
    """
    n = len(y)
    if n < 3:
        return y
    out = y.copy()
    # Forward sweep
    prev_d = y[1] - y[0]  # reference from pre-damp differences
    for k in range(2, n):
        d = out[k] - out[k - 1]
        if prev_d * d < 0 and abs(d) < thresh:
            out[k] = out[k - 1] + keep * d
        prev_d = out[k] - out[k - 1] if keep > 0 else d
    # Backward (mirrored) sweep to cancel directional bias
    prev_d = y[-2] - y[-1]
    for k in range(n - 3, -1, -1):
        d = out[k] - out[k + 1]
        if prev_d * d < 0 and abs(d) < thresh:
            out[k] = out[k + 1] + keep * d
        prev_d = out[k] - out[k + 1] if keep > 0 else d
    return out

def _reversal_damp(y, thresh):
    """
    Magnitude-proportional quadratic soft damping of sub-threshold sign
    flips in the first difference. On a detected flip (sign change vs.
    prev step, |d| < thresh), the step is scaled by (1 - (|d|/thresh)^2):
    tiny noise flips -> ~0 (pinned), near-threshold steps -> pass nearly
    intact. Unlike a hard hold this leaves no flat zero-step segments
    (which inflate lag/avg_error), and the smooth falloff means a single
    forward + mirrored backward sweep pair suffices. prev_d is taken from
    the PRE-damp difference so damping cannot stall later detection.
    """
    n = len(y)
    if n < 3:
        return y
    out = y.copy()
    thresh2 = thresh * thresh if thresh > 0 else 1e-30
    # Forward sweep
    prev_d = y[1] - y[0]
    for k in range(2, n):
        d = out[k] - out[k - 1]
        if prev_d * d < 0 and abs(d) < thresh:
            out[k] = out[k - 1] + d * (1.0 - (d * d) / thresh2)
        prev_d = d
    # Backward (mirrored) sweep to cancel directional bias
    prev_d = y[-2] - y[-1]
    for k in range(n - 3, -1, -1):
        d = out[k] - out[k + 1]
        if prev_d * d < 0 and abs(d) < thresh:
            out[k] = out[k + 1] + d * (1.0 - (d * d) / thresh2)
        prev_d = d
    return out
