dual_median_snap_prefilter

<DESCRIPTION>
A fundamentally different architecture: instead of a single post-convolution noise gate, this design applies noise-scaled median snapping twice — once before and once after the exponential window convolution. The pre-convolution snap removes noise-sized steps from the raw signal so the windowed average operates on already-debiased data, compounding the smoothing effect on the output. The mechanism remains entirely in the level domain (no slope gating), which prior generations showed is strictly superior. By quantizing noise-sized deviations to the local median before averaging, the exponential convolution receives a cleaner input, reducing spurious slope changes at the output without adding lag, since median snapping is zero-phase and O(1) per sample with a small 5-tap window. This targets smoothness improvement while lag and tracking remain governed by the same window length, preserving responsiveness.

</DESCRIPTION>

# EVOLVE-BLOCK-START
import numpy as np

def _median_snap(x, noise_scale):
    """5-tap, noise-scaled median snap: quantize noise-sized deviations
    to the local median, leaving genuine trends intact. Zero phase."""
    y = x.copy()
    n = len(x)
    for i in range(2, n - 2):
        m = np.median(x[i - 2:i + 3])
        # snap only if deviation is noise-sized
        if abs(x[i] - m) <= noise_scale:
            y[i] = m
    return y

def filter_signal(x, window_length, noise_scale):
    """
    Inputs:
        x : 1D array, raw non-stationary signal
        window_length : int, exponential convolution window size
        noise_scale : float, estimated noise magnitude
    Output:
        x_smooth : filtered signal, same length as x
    """
    x = np.asarray(x, dtype=float)
    n = len(x)
    if n < 5:
        return x.copy()

    # First snap point: clean noise-sized steps BEFORE convolution
    x_pre = _median_snap(x, noise_scale)

    # Exponential convolution (zero-phase via forward+backward pass)
    alpha = 2.0 / (window_length + 1.0)
    fwd = x_pre.copy()
    for i in range(1, n):
        fwd[i] = alpha * fwd[i] + (1 - alpha) * fwd[i - 1]
    bwd = fwd.copy()
    for i in range(n - 2, -1, -1):
        bwd[i] = alpha * bwd[i] + (1 - alpha) * bwd[i + 1]

    # Second snap point: remove residual noise-sized steps AFTER convolution
    x_smooth = _median_snap(bwd, noise_scale)

    return x_smooth
# EVOLVE-BLOCK-END
