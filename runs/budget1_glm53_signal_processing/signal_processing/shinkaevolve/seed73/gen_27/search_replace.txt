<DESCRIPTION>
Add a second noise-scaled median snap applied to the raw input before the convolution-based weighted regression. The current algorithm only snaps the output after convolution; noise-sized sample-to-sample steps in the raw signal still leak through the window average. Applying a 5-tap median filter to the input (with noise-scale detection) removes impulse-like noise spikes before the window averaging, compounding the smoothing effect on the output (targeting smoothness, currently 0.08) at negligible computational cost since efficiency is saturated (1.00, 0.00s). This stays entirely in the level-domain, noise-scaled mechanism that the history shows beats slope-gating designs - no added slope machinery.
</DESCRIPTION>

    # --- Pre-convolution snap: 5-tap median on raw input, noise-scaled ---
    # Remove impulse-like, noise-sized steps from the raw signal before
    # window averaging so they cannot leak through the weighted regression.
    n = len(xf)
    if n >= 5:
        dx = np.diff(xf)
        sig_x = 1.4826 * np.median(np.abs(dx - np.median(dx))) + 1e-12
        # 5-tap running median of the input
        pad_l = np.concatenate((xf[:2][::-1], xf, xf[-2:][::-1]))
        stacked = np.stack([pad_l[0:n], pad_l[1:n+1], pad_l[2:n+2],
                           pad_l[3:n+3], pad_l[4:n+4]])

        # noise-sized (no genuine trend step is large enough to be caught).
