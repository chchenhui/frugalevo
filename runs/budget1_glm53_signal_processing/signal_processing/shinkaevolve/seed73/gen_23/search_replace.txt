<DESCRIPTION>
The current Kalman pipeline has excellent lag (0.23) and error (0.22) but terrible slope churn (slope_changes=304.8, false_reversals=247.0, smoothness=0.06) — the output level estimate is too noisy because the adaptive Q inflates readily. The efficiency headroom is large (0.02s execution, efficiency=1.0), so we can spend compute on output conditioning without hurting the score. I add a post-processing stage after the streaming loop: two passes of a symmetric zero-phase 3-tap binomial smoother [0.25, 0.5, 0.25] to cut residual jitter, followed by an inter-sample slope-consistency snap: where consecutive output changes are below ~0.5× the local slope-noise scale, replace the sample with a 5-tap running median. This eliminates noise-induced directional flips (small diffs) while leaving genuine, large trend changes untouched, directly attacking slope_changes and false_reversals without adding phase delay (all filters are symmetric/centered). Tracking accuracy is preserved because only statistically insignificant movements are snapped.

    # ---- Stage 2: streaming output for remaining samples ----
    n_out = len(x) - window_size + 1
    y = np.empty(n_out)
    for j in range(n_out):
        level, _ = kf.step(x[warmup + j])
        y[j] = level

    # ---- Stage 3: zero-phase post-conditioning ----
    # (a) Two passes of symmetric 3-tap binomial smoother [1/4, 1/2, 1/4]:
    #     cuts residual jitter with no phase delay.
    # (b) Slope-consistency snap: where consecutive changes are below
    #     0.5x the local slope-noise scale, replace with a 5-tap running
    #     median. Kills noise-induced directional flips while genuine,
    #     large trend changes pass through untouched.
    if n_out >= 5:
        for _ in range(2):
            sm = y.copy()
            sm[1:-1] = 0.25 * y[:-2] + 0.5 * y[1:-1] + 0.25 * y[2:]
            y = sm

        diffs = np.diff(y)
        gate = 0.5 * (np.std(diffs) + 1e-12)
        if n_out >= 5:
            stack = np.vstack([y[:-4], y[1:-3], y[2:-2], y[3:-1], y[4:]])
            runmed = np.median(stack, axis=0)
            # center positions 2 .. n_out-3 correspond to diffs[1:-1]
            small = np.abs(diffs[1:-1]) < gate
            y[2:-2] = np.where(small, runmed, y[2:-2])

    return y
