<DESCRIPTION>
The current filter achieves excellent lag error (0.19), average error (0.20), correlation (0.93) and noise reduction (0.59), but suffers from excessive slope churn (337 slope changes, 268 false reversals). Prior attempts at simple slope gates (Gen 5: 0.25σ, Gen 8: 0.5σ) failed because they were permissive, one-sided soft thresholds. The fix is a strict, two-sided hysteresis gate applied to the output level path as a final stage: estimate slope-noise σ robustly via the MAD of the raw slope sequence, require a sign change to exceed 1.2×σ in magnitude, AND require the new direction to persist for 2 consecutive windows before a reversal is accepted. Otherwise the gated slope keeps its previous direction (sign persistence with linear decay toward zero so plateaus remain flat). The level is then rebuilt by integrating the gated slopes but blended with the original lag-free level estimate (0.75 blend) so the excellent zero-lag property is largely preserved while spurious wiggles in the output — which directly drive slope_changes, false_reversals, and smoothness — are eliminated. Since the gate only acts on sign flips, genuine turns exceeding noise σ pass within 2 windows, adding at most a small, bounded delay on real reversals only.</DESCRIPTION>

    # --- Pass 3: two-sided hysteresis reversal gate ---
    # Robust slope-noise scale via MAD of the raw slope sequence.
    med_slope = np.median(raw_slopes)
    slope_sigma = 1.4826 * np.median(np.abs(raw_slopes - med_slope)) + 1e-12
    gate = 1.2 * slope_sigma
    persist_req = 2  # consecutive windows required to confirm a reversal

    gated = np.zeros(output_length)
    gated[0] = raw_slopes[0]
    direction = np.sign(raw_slopes[0]) if abs(raw_slopes[0]) > gate else 0.0
    pending_sign = 0.0
    pending_count = 0
    for i in range(1, output_length):
        s = raw_slopes[i]
        sgn = np.sign(s) if abs(s) > gate else 0.0
        if sgn != 0.0 and sgn != direction:
            # candidate reversal: require persistence
            if sgn == pending_sign:
                pending_count += 1
            else:
                pending_sign = sgn
                pending_count = 1
            if pending_count >= persist_req:
                direction = sgn
                pending_sign = 0.0
                pending_count = 0
        else:
            if sgn == 0.0:
                # sub-gate slope: decay toward zero, keep previous sign lock
                pending_sign = 0.0
                pending_count = 0
            else:
                pending_sign = 0.0
                pending_count = 0
        # Emit slope consistent with the locked direction
        if direction == 0.0:
            gated[i] = 0.0 if abs(s) <= gate else s
        elif np.sign(s) == direction:
            gated[i] = s
        else:
            # oppose locked direction: shrink magnitude, keep locked sign
            gated[i] = direction * min(abs(s), 0.1 * slope_sigma)

    # Rebuild level from gated slopes (monotone-consistent trend path)
    gated_level = np.zeros(output_length)
    gated_level[0] = y[0]
    for i in range(1, output_length):
        gated_level[i] = gated_level[i - 1] + gated[i]

    level_out = 0.75 * level_adj + 0.25 * gated_level
