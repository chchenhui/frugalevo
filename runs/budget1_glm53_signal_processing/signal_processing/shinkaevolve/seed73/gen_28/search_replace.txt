<DESCRIPTION>
The current best program achieves correlation 0.92 and noise_reduction 0.50, but smoothness (0.10) and false reversals (134.6) remain weak. The recommendation is to add a Savitzky-Golay (SG) second-order polynomial smoothing stage over the pass-1 output — with an enlarged SG window (2×window_size−1, kept odd) — to strongly attack the smoothness/false-reversal objectives, while steepening the exponential recency weighting in the linear-regression pass from exp(linspace(-2,0)) to exp(linspace(-1.5,0)) to compensate the added group delay of the wider SG kernel. An order-2 SG fit preserves local curvature (genuine trends) far better than a moving average of the same width, and evaluating the fit at the window's end point keeps phase delay near zero. The SG coefficients are precomputed once via a least-squares pseudo-inverse and applied as a single vectorized convolution with edge padding, so the added cost is negligible (efficiency is currently 1.00). The final output blends the SG-smoothed estimate with the recency-weighted regression estimate, trading a small amount of correlation headroom (0.92 vs 0.78 floor) for the binding smoothness and noise-reduction metrics. Note that slope extrapolation is deliberately avoided since it failed in prior generations; the recency-weighted convolution is the proven lag-compensation mechanism here.

    # A wider (2W-1, odd) SG window suppresses sub-noise churn without the
    # over-smoothing of a moving average: the local quadratic fit preserves
    # genuine curvature/trends. Coefficients are precomputed once.
    M = 2 * window_size - 1  # kept odd
    if len(y) >= M:
        tm = np.arange(M, dtype=float) - (M - 1)
        V = np.stack([np.ones(M), tm, tm * tm], axis=1)
        # Least-squares fit evaluated at t = 0 (last sample) -> zero phase delay
        c = np.linalg.pinv(V)[0, :]  # row giving fitted value at t = 0
