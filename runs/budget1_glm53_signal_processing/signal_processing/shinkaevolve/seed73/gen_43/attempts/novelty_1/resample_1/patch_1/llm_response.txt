<DESCRIPTION>
Replace the global MAD-of-diffs sigma in the slope-consistency pass with a locally adaptive, vectorized rolling robust sigma computed over ±25-sample blocks of x_smooth diffs via sliding_window_view. Noisy non-stationary segments get aggressive snapping (smaller local sigma → more median blending) while clean segments with genuine dynamics get a larger local sigma and keep their full response. This directly targets lag_error (0.41) and avg_error (0.51) without sacrificing the reversal/slope gains (30 slope changes). Since the diff series of x_smooth is short-window available, we pad edge blocks via reflection to keep lengths aligned. The blend is slightly increased (0.5 → 0.6) for snapped samples to strengthen noise suppression where local noise dominates, exploiting the responsiveness margin (0.71).</DESCRIPTION>

    # --- Inter-window slope-consistency pass with LOCALLY ADAPTIVE threshold ---
    # Instead of one global MAD-of-diffs sigma, compute a rolling robust sigma
    # over +-25-sample blocks of the x_smooth diffs (fully vectorized). Noisy
    # non-stationary segments then get aggressive snapping while clean segments
    # with genuine dynamics keep their full response, reducing lag error.
    d = np.diff(x_smooth)
    block = 51  # +/- 25 samples around each diff sample

    if len(d) >= block:
        swv = np.lib.stride_tricks.sliding_window_view(d, block)
        local_mad = np.median(np.abs(swv - np.median(swv, axis=1, keepdims=True)),
                              axis=1) / 0.6745
        # Reflect-pad the (block-1)/2 edge positions that lack a full block
        pad_len = (block - 1) // 2
        local_mad = np.concatenate([
            local_mad[:1] * np.ones(pad_len), local_mad, local_mad[-1:] * np.ones(pad_len)
        ])
    else:
        med_d = np.median(d)
        local_mad = np.full(len(d), np.median(np.abs(d - med_d)) / 0.6745)
    sigma_local = np.maximum(local_mad / np.sqrt(2.0), 1e-12)

    if len(y) >= 5:
        pad = np.pad(y, 2, mode="edge")
        med = np.array([
            np.median(pad[i:i + 5]) for i in range(len(y))
        ])

        steps = np.zeros_like(y)
        steps[1:] = np.abs(np.diff(y))
        steps[:-1] = np.maximum(steps[:-1], steps[1:])
        # Per-sample threshold from the local noise scale aligned with y
        thr = 0.5 * np.concatenate([sigma_local[:1], sigma_local])[:len(y)]
        small = steps < thr
        y = np.where(small, 0.4 * y + 0.6 * med, y)
