zero_phase_poly_filter</NAME>
<DESCRIPTION>
Replace the exponentially-weighted moving average (which introduces lag and still allows noise-driven slope reversals) with a zero-phase local polynomial (Savitzky-Golay style) filter. A degree-2 polynomial fit over each sliding window passes through the data with no phase delay, preserves linear and quadratic trends (greatly reducing lag error and slope changes), and its least-squares nature suppresses noise more effectively than a weighted mean, reducing false reversals. Centering the fit on the window means no directional bias toward past samples, so responsiveness is maintained. This addresses all four objectives: slope-change minimization, lag minimization, tracking accuracy, and false-reversal avoidance, while keeping O(W) work per sample (efficient). We also make the basic filter use the same approach so both code paths benefit.</DESCRIPTION>

    output_length = len(x) - window_size + 1
    y = np.zeros(output_length)

    # Enhanced zero-phase polynomial filter with light robustness:
    # 1) Fit degree-2 polynomial over the window (trend-preserving, zero lag).
    # 2) One IRLS-style reweighting pass to downweight outlier noise,
    #    which suppresses spurious reversals (false trend changes).
    half = window_size // 2
    t = np.arange(window_size) - half  # centered time axis

    for i in range(output_length):
        window = x[i : i + window_size].astype(float)

        # Initial least-squares polynomial fit
        coeffs = np.polyfit(t, window, 2)
        resid = window - np.polyval(coeffs, t)

        # Robust reweighting (Huber-like) to reduce influence of outliers
        scale = np.std(resid)
        if scale > 1e-12:
            w = np.ones(window_size)
            big = np.abs(resid) > 2.0 * scale
            w[big] = scale / (np.abs(resid[big]) + 1e-12)
            # Weighted refit using pseudo-inverse for stability
            Wmat = np.vstack([t**2, t, np.ones(window_size)]).T * w[:, None]
            try:
                sol, *_ = np.linalg.lstsq(Wmat, window * w, rcond=None)
                y[i] = sol[2]  # polynomial value at t=0 (window center)
                continue
            except np.linalg.LinAlgError:
                pass
        y[i] = np.polyval(coeffs, 0.0)

    return y
