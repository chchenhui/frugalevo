<DESCRIPTION>
Two targeted improvements to the enhanced filter:

1. **Lag compensation via slope forecasting.** The Holt smoother introduces a systematic phase delay (lag_error = 0.42 hurts responsiveness). Since the Kalman state already carries a slope estimate, we can explicitly compensate the group delay by extrapolating each sample forward by a small number of steps: y[i] = hs[i] + lag_k * slope[i]. This directly reduces lag error and average error without additional smoothing (which would destroy dynamics). The lag constant (2.0 samples) is small and safe — it shifts the smoother's phase forward without amplifying high-frequency noise, since the slope estimate itself is already Kalman-smoothed.

2. **Blend instead of full slope-reintegration in Stage 3.** Currently the output is *entirely* rebuilt by re-integrating the median-filtered slopes. Pure reintegration is an integrator: any small bias in the gated slope sequence accumulates as unbounded drift, decoupling the output from the actual signal levels (visible in avg_error = 0.47 and correlation dropping 0.84 → 0.83 despite fewer slope changes). A convex blend (0.7 of the level-anchored Holt output + 0.3 of the slope-reintegrated output) keeps most of the false-reversal suppression (slope_changes = 103, false_reversals = 85.4 are already much better than baseline) while eliminating the drift: the level-anchored component acts as an anchor/low-frequency corrector for the integrator. This trades a small amount of reversal suppression for a large gain in tracking accuracy and lag/avg error.

Both changes preserve the window-alignment contract (`y_full[window_size-1:]`) and all function signatures, so the rest of the program is untouched.</DESCRIPTION>
