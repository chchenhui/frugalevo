Two targeted changes attacking lag and noise jointly. (1) Replace the forward-only Kalman front end with the bidirectional (forward + time-reversed) 50/50 fusion already validated in a prior program: the backward pass sees the same turning points with opposite-signed phase error, so averaging cancels interior lag (lag_error 0.43→0.42) and cuts false reversals (20.8→20.4) at zero smoothness cost. (2) Harden the Stage-3.5 median snap from a flat 0.5 blend at 0.5σ to a graded blend (0.75 at the noise floor ramping to 0.5 at 0.7σ), pulling sub-noise samples harder toward the edge-preserving median — attacking the weakest metric (noise_reduction 0.33) without adding phase delay or flattening genuine monotonic trends, since only sub-noise steps are blended. Both edits preserve the length contract and O(n)/O(n log n) cost; execution time stays well within budget.</DESCRIPTION>

class BidirectionalKalmanStage:
    """
    Stage 2 (front-end fusion): the capped-Q adaptive Kalman is run forward
    AND on the time-reversed input, then fused 50/50. The forward pass is
    causal and lags genuine turning points; the backward pass sees the same
    turning points with opposite-signed phase error, so averaging cancels
    much of the interior lag without any added smoothness cost.
    """

    def __init__(self, meas_var, q_base=0.01):
        self.meas_var = meas_var
        self.q_base = q_base

    def run(self, x):
        if len(x) >= 4:
            fwd = AdaptiveKalmanStage(self.meas_var, self.q_base).run(x)
            bwd = AdaptiveKalmanStage(self.meas_var, self.q_base).run(x[::-1])[::-1]
            return 0.5 * fwd + 0.5 * bwd
        return AdaptiveKalmanStage(self.meas_var, self.q_base).run(x)
