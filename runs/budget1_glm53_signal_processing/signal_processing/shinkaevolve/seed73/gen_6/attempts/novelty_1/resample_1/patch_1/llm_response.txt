<DESCRIPTION>
The current enhanced filter is a plain exponentially-weighted moving average. A weighted moving average is biased whenever the signal has a slope: it lags behind trends, which hurts lag_error, accuracy, and tracking. A better approach is a *weighted local linear (degree-1) regression* over each window, evaluated at the most recent sample (the window end). This is zero-lag with respect to linear trends: fitting y ≈ a·t + b over the window and evaluating at the last sample removes the systematic trend-induced bias of a moving average, while the exponential weights still emphasize recent samples for adaptivity to non-stationarity. Additionally, a single Huber-style robust reweighting pass downweights outlier samples within the window, suppressing noise spikes that cause spurious directional reversals (improving slope_changes and false_reversals). Solving the 2-parameter weighted least squares in closed form is cheap (O(W) per window), preserving the excellent efficiency score. To avoid amplifying noise when the residual scale is tiny or the system is ill-conditioned, we fall back gracefully to the weighted mean.

    y = np.zeros(output_length)

    # Exponential weights emphasizing recent samples (adaptive to non-stationarity)
    weights = np.exp(np.linspace(-2, 0, window_size))
    weights = weights / np.sum(weights)
    # Time axis anchored so the last sample in the window is t = 0:
    # evaluating the fitted line at t=0 gives zero trend-lag output.
    t = np.arange(window_size) - (window_size - 1)

    # Precompute weighted-normal-equation components that don't change
    Sw = np.sum(weights)
    St = np.sum(weights * t)
    Stt = np.sum(weights * t * t)
    denom = Sw * Stt - St * St

    for i in range(output_length):
        window = x[i : i + window_size].astype(float)

        # --- Pass 1: weighted local linear regression, evaluated at window end ---
        Sx = np.sum(weights * window)
        Stx = np.sum(weights * t * window)
        if denom > 1e-12:
            slope = (Sw * Stx - St * Sx) / denom
            intercept = (Stt * Sx - St * Stx) / denom
            fit = slope * t + intercept
        else:
            fit = np.full(window_size, Sx / Sw)
            slope = 0.0
            intercept = fit[0]
        y0 = intercept  # fitted value at t = 0 (most recent sample)

        # --- Pass 2: Huber-style robust reweighting to suppress outliers ---
        resid = window - fit
        scale = np.std(resid)
        if scale > 1e-12:
            rw = weights.copy()
            big = np.abs(resid) > 2.0 * scale
            rw[big] *= scale / (np.abs(resid[big]) + 1e-12)
            Sw2 = np.sum(rw)
            St2 = np.sum(rw * t)
            Stt2 = np.sum(rw * t * t)
            den2 = Sw2 * Stt2 - St2 * St2
            if den2 > 1e-12:
                Sx2 = np.sum(rw * window)
                Stx2 = np.sum(rw * t * window)

                y[i] = (Stt2 * Sx2 - St2 * Stx2) / den2  # value at t = 0
            else:
                y[i] = Sx2 / Sw2
        else:
            y[i] = y0

    return y
