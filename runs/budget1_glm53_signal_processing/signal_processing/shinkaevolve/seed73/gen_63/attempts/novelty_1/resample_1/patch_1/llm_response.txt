<DESCRIPTION>
Co-mutate the effective smoothing extent and recency tilt as a matched pair, per the recommendation: widen the regression window from W to 2W+7 (buying noise-reduction/smoothness headroom that cut false reversals in Gen 42) while steepening the exponential recency tilt to e^-1.2 spacing per sample so the fit's effective center of mass stays anchored near the window end, recovering the lag that naive widening would cost. The wider window is used only for the local regression; the output-length contract is preserved by evaluating each fit at the most recent sample and slicing. To keep efficiency at 1.00, the per-window Huber reweighting is applied in a single vectorized MAD pass over a strided view instead of the previous multi-solve IRLS loop with a Python inner loop. The final regression value is computed by a fixed pre-factored normal-equation solve of the weight matrix (weights are constant across windows), reducing the per-window cost to a few dot products. This jointly targets slope_changes/false_reversals (wider support + steeper tilt) and lag_error (tilt compensates), while keeping correlation intact since the quadratic fit evaluated at t=0 remains zero-phase.

    # reversals); the matched e^-1.2 per-step recency tilt keeps the fit's
    # effective center of mass near the window END, so the widened support
    # does not reintroduce lag. Fit is still evaluated at t=0 (last sample),
    # preserving zero-phase output.

        M = n  # graceful degradation on short signals
    if M < 4:

    weights = weights / np.sum(weights)

    St3 = np.dot(weights, t2 * t)

        A_inv = np.linalg.inv(A)
    except np.linalg.LinAlgError:

    wt2 = weights * t2
