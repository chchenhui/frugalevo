The current program's weakest metrics are smoothness (0.11) and slope_changes (162.8), while noise_reduction is already good (0.57) thanks to the robust Huber quadratic. Gen 3 showed that an adaptive constant-velocity Kalman pre-filter dramatically reduces slope changes (41.2) and boosts smoothness (0.33), because the Kalman state models slope and collapses its process noise when innovations are noise-consistent — noise can no longer flip the estimated trend. The edit: (1) insert an innovation-adaptive constant-velocity Kalman filter as a pre-smoothing stage over the raw signal, feeding its output into the existing robust weighted quadratic window fit; (2) use a MAD-based residual scale in the Huber pass instead of std (std is corrupted by the very outliers we want to suppress); (3) widen the post-smoothing kernel to a 5-tap binomial pass with edge-preserving handling to further cut spurious reversals without meaningful phase delay. This hybrid exploits the Kalman's noise-adaptive smoothing and the quadratic fit's zero-lag extrapolation, targeting slope_changes, false_reversals, and smoothness while preserving the lag and accuracy gains.</DESCRIPTION>

def _adaptive_kalman_prefilter(x):
    """
    Constant-velocity (level + slope) Kalman filter with innovation-adaptive
    process noise. When the normalized innovation is consistent with
    measurement noise, Q shrinks (heavy smoothing, stable slope estimate);
    when it grows (genuine dynamics), Q expands so the filter tracks
    trend changes quickly (minimal lag).

    Returns the filtered level estimate, same length as x.
    """
    n = len(x)
    if n < 3:
        return np.asarray(x, dtype=float).copy()

    # Robust MAD-based measurement noise variance from first differences
    d = np.diff(x)
    med = np.median(d)
    mad = np.median(np.abs(d - med)) / 0.6745
    r = max((mad * mad) / 2.0, 1e-8)

    # State: [level, slope]
    xs = np.array([x[0], 0.0])
    P = np.eye(2) * max(r, 1e-6)
    I = np.eye(2)
    F = np.array([[1.0, 1.0], [0.0, 1.0]])
    H = np.array([[1.0, 0.0]])
    q_base = 1e-3 * r + 1e-9

    y = np.empty(n)
    for k in range(n):
        # Predict
        xs = F @ xs
        P = F @ P @ F.T

        innov = x[k] - xs[0]
        S = P[0, 0] + r
        nis = innov * innov / max(S, 1e-12)

        # Adapt process noise: small NIS -> smooth; large NIS -> responsive
        q_dyn = q_base * (1.0 + 2.0 * min(nis, 25.0))
        P[0, 0] += q_dyn
        P[1, 1] += 0.25 * q_dyn

        # Update
        S = P[0, 0] + r
        K = P[:, 0] / S
        xs = xs + K * innov
        P = (I - np.outer(K, H[0])) @ P
        P += np.eye(2) * 1e-12

        y[k] = xs[0]
    return y
