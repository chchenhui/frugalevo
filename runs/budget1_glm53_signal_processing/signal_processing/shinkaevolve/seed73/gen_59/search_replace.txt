<DESCRIPTION>
The metrics show the dominant weaknesses are slope changes (108.20) and false reversals (85.20) with smoothness at only 0.16, while lag (0.33) and responsiveness (0.75) are already good. The current binomial post-smoother is linear, so isolated single-sample slope sign flips survive convolution. A non-linear fix is needed: apply a 5-tap median filter to the first difference (slope estimate) of the output, then integrate back. This kills isolated slope sign reversals (the classic "spurious flip" pattern) with a non-linear operator while leaving sustained, genuine trend reversals untouched — unlike stronger linear smoothing, which would add phase lag and hurt lag_error/tracking. Since median of the derivative only alters samples where the derivative is an isolated outlier, genuine dynamics pass through essentially unchanged, so accuracy and responsiveness are preserved. Implementation is O(n) and vectorized, keeping efficiency at 1.00. I apply it after the existing binomial pass, only when the output is long enough, and keep endpoints safe by padding with edge-replicated differences.

    # Non-linear slope stabilization: median-filter the first difference of
    # the output and re-integrate. Isolated single-sample slope sign flips
    # (the dominant source of spurious reversals) are removed by the median,
    # while sustained genuine trend changes pass through unchanged. This is
    # non-linear, so it removes reversals that linear smoothing cannot,
    # without adding phase delay.
    if output_length >= 6:
        dy = np.diff(y)
        # Edge-replicate the derivative so length is preserved exactly
        dy_pad = np.concatenate(([dy[0], dy[0]], dy, [dy[-1], dy[-1]]))
        dy_med = np.array([
            np.median(dy_pad[i : i + 5]) for i in range(len(dy))
        ])
        y = y[0] + np.concatenate(([0.0], np.cumsum(dy_med)))

    return y
