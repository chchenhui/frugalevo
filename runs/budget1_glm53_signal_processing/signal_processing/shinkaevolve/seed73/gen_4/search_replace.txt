<DESCRIPTION>
Replace the exponentially-weighted moving average with a two-stage hybrid: (1) a 1D Kalman filter with adaptive process noise (larger Q when innovation magnitude suggests genuine dynamics change, smaller Q when noise-dominated) to smooth noise with near-zero lag, followed by (2) a Savitzky-Golay smoothing filter that fits local low-order polynomials, preserving signal trends and slopes without the phase delay of MA filters. The Kalman stage makes the output statistically optimal for Gaussian noise; the SG stage suppresses slope changes and false reversals. The adaptive Q gate based on normalized innovation squared (NIS) keeps responsiveness during genuine trend changes while damping noise-induced reversals. Both filters are O(1)/O(window) per sample and causal alignment is maintained by the windowing convention already used.

    Args:
        x: Input signal (1D array of real-valued samples)
        window_size: Size of the sliding window

    Returns:
        y: Filtered output signal
    """

        raise ValueError(f"Input signal length ({len(x)}) must be >= window_size ({window_size})")

    output_length = len(x) - window_size + 1
    y = np.zeros(output_length)

    # Create weights that emphasize recent samples
    weights = np.exp(np.linspace(-2, 0, window_size))
    weights = weights / np.sum(weights)

    for i in range(output_length):

        # Weighted moving average with exponential weights

    return y

def _adaptive_kalman_filter(x, q_base=0.01, r_factor=1.0, forgetting=0.98):
    """
    1D Kalman filter with innovation-adaptive process noise.

    When the normalized innovation squared (NIS) indicates the prediction
    error is consistent with measurement noise, process noise stays small
    (heavy smoothing). When NIS is large (genuine dynamics change), process
    noise grows so the filter tracks the change quickly, minimizing lag.

    Args:
        x: Input signal (1D array)
        q_base: Baseline process noise variance
        r_factor: Scale factor for measurement noise estimate
        forgetting: Forgetting factor for online noise variance estimate

    Returns:
        Filtered signal (same length as x)
    """
    n = len(x)
    y = np.zeros(n)

    # Robust online estimate of measurement noise variance from first differences
    if n > 2:
        d = np.diff(x)
        med = np.median(d)
        mad = np.median(np.abs(d - med)) / 0.6745  # robust sigma of diff noise
        r = max((r_factor * mad * mad) / 2.0, 1e-8)  # var of diff = 2*var of noise
    else:
        r = max(r_factor * np.var(x), 1e-8)

    # State: [level, velocity]
    x_state = np.array([x[0], 0.0])
    P = np.eye(2) * r
    I = np.eye(2)
    H = np.array([[1.0, 0.0]])

    for k in range(n):
        # Predict
        F = np.array([[1.0, 1.0], [0.0, 1.0]])
        x_state = F @ x_state
        P = F @ P @ F.T

        # Innovation
        z = x[k]
        innov = z - x_state[0]
        S = P[0, 0] + r
        nis = innov * innov / S

        # Adapt process noise: small NIS -> smooth; large NIS -> responsive
        q_scale = q_base * (1.0 + 10.0 * min(nis, 50.0) / 10.0)
        Q = q_scale * np.array([[0.25, 0.5], [0.5, 1.0]])
        P = P + Q

        # Update
        S = P[0, 0] + r
        K = P[:, 0] / S
        x_state = x_state + K * innov
        P = (I - np.outer(K, H)) @ P

        y[k] = x_state[0]

    return y


def enhanced_filter_with_trend_preservation(x, window_size=20):
    """
    Enhanced version with trend preservation using an adaptive Kalman filter
    followed by Savitzky-Golay polynomial smoothing.

    Stage 1 (adaptive Kalman): statistically optimal noise reduction with
    near-zero lag and adaptive responsiveness to genuine dynamics changes.
    Stage 2 (Savitzky-Golay): fits local low-order polynomials, preserving
    trends and slopes, suppressing spurious slope reversals without adding
    the phase delay of moving-average filters.

    Args:
        x: Input signal (1D array of real-valued samples)
        window_size: Size of the sliding window

    Returns:
        y: Filtered output signal
    """
    if len(x) < window_size:
        raise ValueError(f"Input signal length ({len(x)}) must be >= window_size ({window_size})")

    # Stage 1: adaptive Kalman filtering
    x_kalman = _adaptive_kalman_filter(np.asarray(x, dtype=float))

    # Stage 2: Savitzky-Golay polynomial smoothing (trend-preserving)
    # Choose odd window and polynomial order 2-3 for slope preservation
    sg_window = window_size if window_size % 2 == 1 else window_size - 1
    sg_window = max(sg_window, 5)
    poly_order = min(3, sg_window - 1)

    from scipy.signal import savgol_filter

    x_smooth = savgol_filter(x_kalman, sg_window, poly_order)

    # Keep the same output convention as the sliding-window version
    output_length = len(x) - window_size + 1
    y = np.zeros(output_length)
    for i in range(output_length):
        window = x_smooth[i : i + window_size]
        # Slight emphasis on recent samples to reduce residual lag
        w = np.exp(np.linspace(-1.0, 0.0, window_size))
        w = w / np.sum(w)
        y[i] = np.sum(window * w)

    return y
