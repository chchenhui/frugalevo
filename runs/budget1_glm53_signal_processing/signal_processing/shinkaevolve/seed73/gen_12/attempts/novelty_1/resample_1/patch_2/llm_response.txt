zerophase_sg_trendgate</NAME>
<DESCRIPTION>
Replace the exponentially-weighted moving average with a zero-phase Savitzky-Golay (local quadratic polynomial) smoother, which preserves signal dynamics much better than an average, followed by a noise-scaled trend gate to suppress spurious reversals. The SG filter is applied forward and backward (and via reflection-padded convolution) to cancel phase delay, minimizing lag error. Slopes below a robust MAD-based noise threshold are zeroed and the level rebuilt, reducing slope changes and false reversals while preserving genuine trends. All operations are vectorized convolutions for O(n) runtime.
</DESCRIPTION>

    x = np.asarray(x, dtype=float)
    n = len(x)

    # --- Robust noise estimate from first differences (MAD-based) ---
    d = np.diff(x)
    sigma_noise = max(np.median(np.abs(d - np.median(d))) / (np.sqrt(2) * 0.6745), 1e-9)

    # --- Savitzky-Golay coefficients (local quadratic fit, zero-phase) ---
    w = window_size if window_size % 2 == 1 else window_size - 1
    if w < 3:
        w = 3
    half = (w - 1) // 2
    t = np.arange(-half, w - half, dtype=float)
    A = np.vander(t, 3, increasing=True)  # basis [1, t, t^2]
    sg = np.linalg.pinv(A)[0, :]  # smoothing weights (value at window center)

    def _sg_smooth(sig):
        # Reflection-padded convolution for clean edges
        pad = half
        if n > pad:
            sp = np.concatenate((sig[pad:0:-1], sig, sig[-2 : n - pad - 1]))
        else:
            sp = sig
        return np.convolve(sp, sg[::-1], mode="valid")[: len(sig)]

    # --- Zero-phase smoothing: forward pass then reverse pass cancels lag ---
    y_fwd = _sg_smooth(x)
    y_rev = _sg_smooth(y_fwd[::-1])[::-1]
    y_smooth = 0.5 * (y_fwd + y_rev)

    # --- Noise-scaled trend gating to suppress false reversals ---
    slope = np.gradient(y_smooth)
    thresh = 0.3 * sigma_noise
    slope_gated = np.where(np.abs(slope) < thresh, 0.0, slope)
    level_gated = np.zeros(n)
    level_gated[0] = y_smooth[0]
    level_gated[1:] = y_smooth[0] + np.cumsum(slope_gated[:-1])
    # Blend gated (reversal-free) path with smoother for tracking accuracy
    y_full = 0.5 * y_smooth + 0.5 * level_gated

    # --- Align to sliding-window output convention ---
    start = window_size // 2
    return y_full[start : start + output_length]
