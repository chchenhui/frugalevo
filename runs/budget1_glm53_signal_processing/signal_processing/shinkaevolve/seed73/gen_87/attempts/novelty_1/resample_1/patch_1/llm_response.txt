The best prior program (combined 0.68) had two features the current version dropped: (1) bidirectional adaptive Kalman filtering — fusing the forward pass 50/50 with a time-reversed pass cancels the causal phase error of the forward filter at zero smoothness cost, improving lag_error and responsiveness; and (2) the steeper exponential tilt (-1.5) on the output convolution weights, which held lag_error low with the wide SG window. The current program regressed both (lag_error 0.47, tilt -1.0). Restoring both matched changes recovers the validated 0.68 configuration and should also help slope_changes/false_reversals via the smoother interior estimate.</DESCRIPTION>
