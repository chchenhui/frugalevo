<DESCRIPTION>
The Kalman stage is the only causal (phase-lagging) element in the pipeline; the SG, median snap, and polish are all zero-phase. Prior-gen evidence (the crossover program) shows that fusing the forward capped-Q adaptive Kalman 50/50 with a time-reversed pass reduces slope_changes (23.2 vs 24.2), lag_error (0.42 vs 0.43), and false_reversals (20.4 vs 21.0) while leaving correlation/smoothness unchanged — the backward pass sees turning points with opposite-signed phase error, so averaging cancels interior lag at zero smoothness cost. I add a thin BidirectionalKalmanStage wrapper around the untouched, validated AdaptiveKalmanStage and swap it into the pipeline run(), keeping the graded median snap, recency convolution, hysteresis snap, and polish intact. Short-input guard (n < 4) falls back to the single forward pass, so n = window_size and n = window_size+1 edge cases remain safe.
</DESCRIPTION>

class BidirectionalKalmanStage:
    """
    Stage 2 (front-end fusion): the capped-Q adaptive Kalman is run forward
    AND on the time-reversed input, then fused 50/50. The forward pass is
    causal and lags genuine turning points; the backward pass sees the same
    turning points with opposite-signed phase error, so averaging cancels
    much of the interior lag without any added smoothness cost. Falls back
    to the plain forward pass for very short inputs.
    """

    def __init__(self, meas_var, q_base=0.01):
        self.meas_var = meas_var
        self.q_base = q_base

    def run(self, x):
        if len(x) >= 4:
            fwd = AdaptiveKalmanStage(self.meas_var, self.q_base).run(x)
            bwd = AdaptiveKalmanStage(self.meas_var, self.q_base).run(x[::-1])[::-1]
            return 0.5 * fwd + 0.5 * bwd
        return AdaptiveKalmanStage(self.meas_var, self.q_base).run(x)
