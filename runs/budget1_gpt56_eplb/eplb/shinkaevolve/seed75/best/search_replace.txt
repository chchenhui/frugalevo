<DESCRIPTION>
Replace scalar PyTorch operations in `balanced_packing` with CPU-native Python data structures after the required CPU transfer. The previous implementation repeatedly indexed and assigned individual tensor scalars inside nested Python loops, which incurs substantial dispatcher overhead.

The replacement uses a heap to select the least-loaded non-full pack in O(log(num_packs)) time, rather than scanning every pack for every item. It also adds a bounded two-pass local swap refinement for small packing problems. This preserves exact pack cardinality while reducing pairwise load differences when the greedy assignment has a beneficial exchange available. The refinement is intentionally capped at 64 items, covering common expert/GPU layouts without making large configurations quadratic.
</DESCRIPTION>

    # Packing is inherently sequential, so using tensor scalar operations in
    # the inner loop is significantly more expensive than operating on one
    # CPU copy of the loads.  The output has historically been CPU-resident in
    # this branch, including when the input was on an accelerator.
    cpu_weight = weight.detach().float().cpu()
    indices = cpu_weight.sort(-1, descending=True).indices.tolist()
    pack_index_rows: list[list[int]] = []
    rank_in_pack_rows: list[list[int]] = []

    for layer, order in enumerate(indices):
        row = cpu_weight[layer].tolist()
        pack_weights = [0.0] * num_packs
        members: list[list[int]] = [[] for _ in range(num_packs)]

        # Heap entries are removed permanently once a pack reaches its exact
        # cardinality limit.  Ties retain the lower pack index, matching the
        # deterministic behavior of the previous min() selection.
        available = [(0.0, pack) for pack in range(num_packs)]
        heapq.heapify(available)
        for group in order:
            load, pack = heapq.heappop(available)
            members[pack].append(group)
            load += row[group]
            pack_weights[pack] = load
            if len(members[pack]) < groups_per_pack:
                heapq.heappush(available, (load, pack))

        # Greedy LPT is fast but can leave an avoidable imbalance when equal
        # cardinality prevents moving an item.  For typical small expert/GPU
        # packings, test swaps and retain only those that reduce the pair's
        # absolute load gap.  The cap avoids quadratic work for large layouts.
        if num_groups <= 64 and num_packs > 1:
            for _ in range(2):
                changed = False
                for left in range(num_packs):
                    for right in range(left + 1, num_packs):
                        if pack_weights[left] >= pack_weights[right]:
                            high, low = left, right
                        else:
                            high, low = right, left
                        gap = pack_weights[high] - pack_weights[low]
                        best_gap = gap
                        best_swap: tuple[int, int] | None = None
                        for high_pos, high_group in enumerate(members[high]):
                            high_weight = row[high_group]
                            for low_pos, low_group in enumerate(members[low]):
                                new_gap = abs(
                                    gap - 2.0 *
                                    (high_weight - row[low_group]))
                                if new_gap < best_gap:
                                    best_gap = new_gap
                                    best_swap = (high_pos, low_pos)
                        if best_swap is not None:
                            high_pos, low_pos = best_swap
                            high_group = members[high][high_pos]
                            low_group = members[low][low_pos]
                            delta = row[high_group] - row[low_group]
                            members[high][high_pos] = low_group
                            members[low][low_pos] = high_group
                            pack_weights[high] -= delta
                            pack_weights[low] += delta
                            changed = True
                if not changed:
                    break

        pack_index_row = [-1] * num_groups
        rank_in_pack_row = [-1] * num_groups
        for pack, pack_members in enumerate(members):
            for rank, group in enumerate(pack_members):
                pack_index_row[group] = pack
                rank_in_pack_row[group] = rank
        pack_index_rows.append(pack_index_row)
        rank_in_pack_rows.append(rank_in_pack_row)

    rank_in_pack = torch.tensor(rank_in_pack_rows, dtype=torch.int64)
