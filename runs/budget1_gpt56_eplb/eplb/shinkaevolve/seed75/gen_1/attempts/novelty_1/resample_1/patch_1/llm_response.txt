<DESCRIPTION>
Replace the per-item linear scan over every pack with a min-heap of eligible packs. The previous implementation performs O(num_groups * num_packs) Python comparisons per layer, and repeatedly mixes Python integers with zero-dimensional Torch tensors. The heap implementation preserves the same greedy largest-processing-time assignment policy and capacity constraint, including deterministic pack-index tie breaking, while reducing assignment selection to O(log(num_packs)). It also materializes each layer’s weights as Python floats once, avoiding expensive scalar tensor operations in the inner loop. This reduces rearrangement latency without changing the placement heuristic or its load-balancing behavior.
</DESCRIPTION>
