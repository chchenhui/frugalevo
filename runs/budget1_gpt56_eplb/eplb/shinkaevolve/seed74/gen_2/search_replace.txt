<DESCRIPTION>
Replace the nested Python implementation of cardinality-constrained LPT packing with a batched tensor implementation across all MoE layers.

The existing policy already uses a strong greedy heuristic: process experts/groups in descending load order and place each into the currently least-loaded pack that still has capacity. However, it executes this independently for every layer using Python lists, Python `min`, generator expressions, and repeated scalar tensor accesses. This is particularly expensive because each scalar access creates substantial framework overhead.

The replacement preserves the same greedy packing policy and deterministic lowest-index tie breaking, but maintains pack loads and capacities as `[num_layers, num_packs]` tensors. Each sorted-item position is assigned for every layer at once using `masked_fill`, `min`, and `scatter` operations. Besides substantially reducing algorithm execution time, avoiding CPU-only state makes the helper usable efficiently if load metrics are retained on an accelerator in future callers.
</DESCRIPTION>

    # sorted position for every layer together, avoiding Python scalar tensor
    # accesses in the hot loop.
    packing_weight = weight.float()
    indices = packing_weight.sort(-1, descending=True).indices
    pack_index = torch.full_like(weight, -1, dtype=torch.int64)
    rank_in_pack = torch.full_like(pack_index, -1)

    pack_weights = torch.zeros((num_layers, num_packs),
                               dtype=packing_weight.dtype,
                               device=weight.device)
    pack_items = torch.zeros((num_layers, num_packs),
                             dtype=torch.int64,
                             device=weight.device)
    one = torch.ones((num_layers, 1), dtype=torch.int64, device=weight.device)

    for position in range(num_groups):
        group = indices[:, position]
        # torch.min resolves equal loads to the first pack, matching the
        # previous deterministic Python min behavior.
        eligible_weights = pack_weights.masked_fill(
            pack_items >= groups_per_pack, torch.inf)
        pack = eligible_weights.min(dim=-1).indices
        rank = pack_items.gather(1, pack.unsqueeze(1)).squeeze(1)

        pack_index.scatter_(1, group.unsqueeze(1), pack.unsqueeze(1))
        rank_in_pack.scatter_(1, group.unsqueeze(1), rank.unsqueeze(1))

        pack_weights.scatter_add_(1, pack.unsqueeze(1), item_weight)
        pack_items.scatter_add_(1, pack.unsqueeze(1), one)
