<DESCRIPTION>
Replace the Python-level per-layer/per-expert packing loop with a batched tensor implementation of the same capacity-constrained LPT greedy policy.

The previous implementation repeatedly converts tensor values into Python operations while selecting a pack for every group. This creates substantial interpreter overhead, particularly when there are many MoE layers, groups, or repeated balancing calls. The replacement processes all layers simultaneously for each sorted group position: it chooses the least-loaded non-full pack per layer, writes the selected pack/rank with scatter operations, and updates pack loads/counts with scatter_add.

This preserves the important balancing behavior: groups are processed in descending load order and each is assigned to the currently lightest eligible pack, while every pack receives exactly the required number of groups. It also avoids forced CPU index transfers, allowing the helper to remain efficient if called with tensors already on an accelerator.
</DESCRIPTION>
