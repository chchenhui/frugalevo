<DESCRIPTION>
Avoid recomputing the full `weight / logcnt` matrix for every added replica. The greedy replication policy only changes the per-replica load of the selected logical expert in each layer, so maintain that value incrementally. This preserves the exact expert selection and replica ranks of the existing algorithm while reducing replication from O(num_redundant * layers * num_logical_experts) division work to O(num_redundant * layers) updates plus the required reductions.
</DESCRIPTION>

all_pack_exchange_refinement
</NAME>

<DESCRIPTION>
The current refinement considers swaps only between the single heaviest and lightest packs. A cardinality-constrained packing can instead be improved by exchanging items between the heaviest pack and another moderately loaded pack, or between a non-extreme pair whose exchange reduces the global maximum. Evaluate the same one-swap neighborhood across all pack pairs and accept the best strict maximum-load improvement. This retains fixed physical-slot cardinality and permutation validity, while substantially improving the quality of the greedy LPT placement for GPU packing.
</DESCRIPTION>
