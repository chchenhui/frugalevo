<DESCRIPTION>
`balanced_packing` performs its greedy assignment in Python, but its current inner loop repeatedly indexes PyTorch scalar tensors and accumulates scalar tensors in a Python list. This creates substantial dispatcher and scalar-object overhead for every group assignment. Convert each sorted row and its weights to Python lists once, so the greedy LPT-with-capacity policy operates on native Python integers/floats while preserving the same ordering and assignment rule.

`replicate_experts` also allocates a fresh division result for every redundant replica. Reuse a preallocated floating-point score buffer with `torch.div(..., out=...)`. Replica selections remain strictly sequential, so the existing `argmax(weight / logcnt)` greedy behavior is unchanged after every count update.
</DESCRIPTION>
