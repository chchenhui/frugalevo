<DESCRIPTION>
Add a strictly gated identity-mapping fast path for the common degenerate case where no redundant replicas are requested and every logical expert has exactly equal recorded load within each layer. In this case, every valid placement with equal expert slots per GPU/node has identical load balance, so hierarchical group packing, sorting, heap scheduling, inverse permutations, and scatter construction are unnecessary. The returned identity layout preserves one replica per logical expert and gives every GPU the same number of equal-load experts. The equality gate is exact rather than heuristic, so skewed or merely near-uniform workloads retain the existing balancing behavior.
