<DESCRIPTION>
Improve the cardinality-preserving packing refinement without returning to the expensive exhaustive all-pack-pair search. The current refinement only exchanges an item between the heaviest and lightest packs. That misses valid improvements where moving an item to the lightest pack would make it the new bottleneck, while exchanging with a moderately loaded pack reduces the global maximum.

This change evaluates swaps from the current bottleneck pack with every other pack. It retains the low complexity of a targeted local search, preserves exact per-GPU capacity, and directly optimizes the maximum GPU load. It should improve GPU balancedness on skewed distributions while adding only a small bounded amount of work per packing row.
</DESCRIPTION>
