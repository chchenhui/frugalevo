<DESCRIPTION>
Replace the per-layer Python heap scheduler and exhaustive Python swap search with a batched tensorized cardinality-constrained LPT assignment. Each sorted item position is assigned simultaneously for all layers to the currently least-loaded non-full pack using a masked argmin. This preserves the greedy descending-weight and exact-capacity policy, including deterministic lowest-pack tie breaking, while eliminating `.tolist()`, `heapq`, Python list allocation, and per-layer scheduling loops. It also keeps the implementation device-agnostic, allowing callers to use accelerator tensors in the future without introducing CPU scalar synchronization.
</DESCRIPTION>

    rank_in_pack = torch.empty_like(pack_index)
    pack_load = torch.zeros(
        (num_layers, num_packs), dtype=weight.dtype, device=weight.device)
    pack_count = torch.zeros(
        (num_layers, num_packs), dtype=torch.int64, device=weight.device)
    one = torch.ones((num_layers, 1), dtype=torch.int64, device=weight.device)

    for position in range(num_groups):
        # masked_fill makes full packs ineligible. argmin selects the lowest
        # pack id for equal loads, matching the heap's deterministic ordering.
        eligible_load = pack_load.masked_fill(
