<DESCRIPTION>
Add a strictly gated identity-layout fast path when there is no replication and every logical expert in each layer has identical load. In this case every valid placement has the same expert and GPU load, so hierarchical group packing, inverse permutations, and greedy scheduling cannot improve balance. Constructing the canonical mapping directly eliminates the relatively expensive CPU scheduling path while preserving the required output layout. The gate is exact rather than heuristic, avoiding any balancedness regression on skewed or merely near-uniform workloads.
