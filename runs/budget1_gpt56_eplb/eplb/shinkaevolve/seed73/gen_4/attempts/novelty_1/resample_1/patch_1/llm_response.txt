<DESCRIPTION>
Replace the quadratic Python scan used to select the least-loaded non-full pack with a capacity-aware min-heap. This preserves the LPT-style greedy construction while reducing selection cost from O(num_groups * num_packs) to O(num_groups * log(num_packs)) per layer.

After the greedy placement, perform one strictly improving swap between the heaviest and lightest packs. The swap preserves the exact item count in every pack and is accepted only when it reduces the maximum pack load, so it cannot degrade the packing objective. This inexpensive local-search step addresses common greedy-LPT placement errors and improves GPU/node load balance without an expensive global combinatorial search.
</DESCRIPTION>

    # balancing on CPU, and Python heap operations require scalar weights.
    cpu_weight = weight.float().cpu()
    indices = cpu_weight.sort(-1, descending=True).indices
    pack_index = torch.full_like(weight,
                                 fill_value=-1,
                                 dtype=torch.int64,
                                 device="cpu")
    rank_in_pack = torch.full_like(pack_index, fill_value=-1)
    for i in range(num_layers):
        values = cpu_weight[i].tolist()
        pack_weights = [0.0] * num_packs
        pack_items = [0] * num_packs
        members: list[list[tuple[int, int, float]]] = [
            [] for _ in range(num_packs)
        ]

        # Entries are removed once a pack reaches its cardinality limit.
        available = [(0.0, pack) for pack in range(num_packs)]
        heapq.heapify(available)
        for group in indices[i].tolist():
            _, pack = heapq.heappop(available)
            rank = pack_items[pack]
            group_weight = values[group]
            pack_index[i, group] = pack
            rank_in_pack[i, group] = rank
            members[pack].append((group, rank, group_weight))
            pack_weights[pack] += group_weight
            pack_items[pack] += 1
            if pack_items[pack] < groups_per_pack:
                heapq.heappush(available, (pack_weights[pack], pack))

        # A greedy cardinality-constrained LPT packing can leave a beneficial
        # exchange between its extremes. Test that small neighborhood once and
        # accept only a strict reduction of the maximum pack load.
        if num_packs > 1:
            heavy = max(range(num_packs), key=pack_weights.__getitem__)
            light = min(range(num_packs), key=pack_weights.__getitem__)

            other_max = max(

                 if p != heavy and p != light),
                default=float("-inf"),

            best_max = current_max
            best_swap = None
            for heavy_group, heavy_rank, heavy_weight in members[heavy]:

                    new_light = pack_weights[light] - light_weight + heavy_weight
                    candidate_max = max(other_max, new_heavy, new_light)
                    if candidate_max < best_max:
