hull_biased_seeding
</NAME>

<DESCRIPTION>
Add a deterministic hull-anchored portion to the initial population. The normalized objective strongly rewards configurations whose convex hull retains nearly unit area, but purely jittered or uniform starts usually begin with a substantially smaller hull and the differential-evolution objective is based on unnormalized triangle area. Seeding candidates with the four square corners guarantees a unit-area convex hull from the outset, while the remaining nine points retain stratified diversity. These candidates expose high-hull-area basins without forcing all population members into a fixed-corner model.
</DESCRIPTION>

    # A minority of independent starts maintains global diversity.
    population[-population_size // 4:] = rng.random(
        (population_size // 4, n, 2)
    )

    # Hull-anchored starts are especially valuable for the normalized metric:
    # their hull already has unit area, so raw-area improvements correspond
    # directly to normalized improvements.  The free points remain stratified
    # rather than forming a rigid lattice.
    anchored_count = population_size // 5
    corners = np.array(
        [[0.0, 0.0], [1.0, 0.0], [1.0, 1.0], [0.0, 1.0]], dtype=float
    )
    for m in range(anchored_count):
        chosen = rng.permutation(16)[:9]
        jitter = rng.uniform(0.16, 0.84, size=(9, 2))
        population[m, :4] = corners
        population[m, 4:] = (cells[chosen] + jitter) / 4.0
