<DESCRIPTION>
Add a deterministic coordinate-pattern refinement after the stochastic polish. The maximin objective is piecewise linear in each point position between changes of the active limiting triangle, so testing the six barycentric tangent directions for every free point is substantially more reliable than relying only on random final perturbations. All moves preserve barycentric sum before projection, retain strict containment in the fixed equilateral hull, and are accepted only on a true minimum-determinant improvement. The coarse-to-fine schedule can resolve residual active-set defects while adding only small batched evaluations.

    for step_size in (0.012, 0.005, 0.002, 0.0008, 0.00025):
