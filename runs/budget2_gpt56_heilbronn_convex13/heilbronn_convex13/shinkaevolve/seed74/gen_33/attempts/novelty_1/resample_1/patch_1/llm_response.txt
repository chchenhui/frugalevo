<DESCRIPTION>
Fix a correctness issue in the annealing loop: the previous code could update `best_points` using a rejected proposal after restoring `points`, causing `best_minimum` and the returned configuration to become inconsistent. This can prevent the final strict polishing stage from accepting valid improvements because it compares against an unattainable recorded score.

Additionally, bias a portion of annealing proposals toward points participating in the current low-area active set and introduce occasional coupled two-point moves. Heilbronn optima are usually controlled by networks of simultaneously tight triangles, so moving only uniformly selected individual points makes it difficult to escape arrangements where two active constraints must be relieved together. The exact primary minimum remains the criterion for global-best preservation.
</DESCRIPTION>
