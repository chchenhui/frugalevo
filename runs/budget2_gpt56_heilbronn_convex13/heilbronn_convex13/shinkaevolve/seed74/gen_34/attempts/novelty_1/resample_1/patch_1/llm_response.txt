<DESCRIPTION>
Canonicalize the unordered nine free points by spatial order throughout the evolutionary phase. Triangle quality is invariant under permutations of point labels, but differential evolution and coordinate-wise crossover are not: without a canonical representation, two geometrically similar layouts can have unrelated point indices, causing donor differences and crossover to combine incompatible locations. Sorting free points into a deterministic y-then-x order makes corresponding genes represent similar spatial roles, improving the usefulness of current-to-elite DE while retaining the same feasible search space and deterministic behavior.
</DESCRIPTION>

def _canonical_free(points: np.ndarray) -> np.ndarray:
    """
    Give geometrically unordered free points a common deterministic encoding.

    Point permutations do not change any triangle area, whereas DE arithmetic
    between differently permuted layouts is destructive.  The y-major key
    groups points into comparable horizontal roles, with x breaking ties.
    """
    free = points[..., 4:, :]
    key = free[..., 1] * 2.0 + free[..., 0]
    order = np.argsort(key, axis=-1, kind="stable")
    return np.take_along_axis(
        free, np.expand_dims(order, axis=-1), axis=-2
    )
