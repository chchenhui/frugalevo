<DESCRIPTION>
Introduce geometry-aware displacement directions for active bottleneck triangles, rather than relying exclusively on isotropic Gaussian moves.  For a selected low-area triangle, the signed-area gradient moves a chosen vertex directly away from its opposite edge, which is the locally optimal first-order direction for increasing that triangle's area.  Random directional mixing preserves the ability to negotiate competing constraints.

Add a deterministic final strict-maximin polishing phase.  The annealing objective deliberately uses a lower-tail surrogate and can retain a point set whose tail is better while its strict minimum is not fully refined.  A final phase accepting only non-decreasing reported minimum area aligns the last search stage exactly with the evaluator metric.
</DESCRIPTION>

    def area_gradient(p: np.ndarray, triangle: np.ndarray,
                      vertex: int) -> np.ndarray:
        """Unit direction which increases this triangle's signed area."""
        a, b, c = triangle
        signed = ((p[b, 0] - p[a, 0]) * (p[c, 1] - p[a, 1])
                  - (p[b, 1] - p[a, 1]) * (p[c, 0] - p[a, 0]))
        sign = 1.0 if signed >= 0.0 else -1.0
        if vertex == a:
            edge = p[c] - p[b]
        elif vertex == b:
            edge = p[a] - p[c]
        else:
            edge = p[b] - p[a]
        direction = sign * np.array((-edge[1], edge[0]))
        norm = float(np.hypot(direction[0], direction[1]))
        return direction / norm if norm > 1.0e-14 else np.zeros(2)
