<DESCRIPTION>
Diversify the successful centre-plus-four-rings prior without abandoning its useful threefold structure. The existing restarts differ only by small radial and phase noise, so they tend to enter the same hull/sign basin. This edit cycles among: the original symmetric rings, a mildly elliptical affine embedding, and independently perturbed angular/radial ring roles. The latter permits radial exchanges between nearby rings and changes hull/interior combinatorics before annealing. Survivor selection is also made family-diverse: the best trajectory from each prior family is guaranteed a long refinement budget, while the final survivor remains the strongest remaining candidate by measured primary objective.
</DESCRIPTION>

    # restarts repeatedly discover the same oriented-matroid basin.  Cycle
    # through controlled variants which retain its useful threefold density.
    base_radii = np.array([0.31, 0.55, 0.79, 1.00])
    base_phases = np.array([0.03, 0.29, 0.57, 0.84])

    # Initial trials identify good determinant-orientation patterns.  Refining
    # only survivors avoids spending the full budget in poor maximin basins.
    survivors = []
    for restart in range(10):
        family = restart % 3
        points = np.zeros((n, 2), dtype=float)
        radii = base_radii + rng.normal(0.0, 0.035, 4)
        phases = base_phases + rng.normal(0.0, 0.045, 4)
