<DESCRIPTION>
Replace most unstructured exploratory starts with a center-plus-four-rings prior. Thirteen points naturally decompose as one central point and four three-point angular layers. This supplies the favorable threefold geometry commonly observed in strong Heilbronn configurations while independently perturbing ring phases, radii, and individual angles to avoid exact radial collinearities and to permit free hull evolution. One fully random exploratory start is retained to preserve access to unrelated basins, while the existing annealing and pattern search remain responsible for removing any imposed symmetry.

        if exploratory:
            if restart < 3:
                # A center plus four independently phased triples is a useful
                # Heilbronn prior: it starts near threefold balance without
                # imposing exact symmetry (which would create radial
                # collinearities through the central point).  The outer layer
                # is deliberately allowed to become the hull and subsequent
                # unconstrained moves may freely change that combinatorics.
                center = np.array([0.5, 0.5])
                radii = np.array([0.455, 0.348, 0.252, 0.145])
                radii += rng.normal(0.0, 0.018, size=4)
                phases = rng.uniform(0.0, 2.0 * np.pi, size=4)
                layers = [center]
                for radius, phase in zip(radii, phases):
                    angles = (phase + 2.0 * np.pi * np.arange(3) / 3.0 +
                              rng.normal(0.0, 0.045, size=3))
                    local_radii = radius + rng.normal(0.0, 0.010, size=3)
                    layers.append(center + np.column_stack((
                        local_radii * np.cos(angles),
                        local_radii * np.sin(angles),
                    )))
                current = np.vstack(layers)
                np.clip(current, 0.0, 1.0, out=current)

                # active-constraint pattern is superior.
