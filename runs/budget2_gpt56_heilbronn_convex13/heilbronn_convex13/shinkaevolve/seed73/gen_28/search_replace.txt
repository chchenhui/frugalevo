<DESCRIPTION>
Introduce geometry-aware coordinated proposals for a fraction of annealing iterations. Rather than relying solely on isotropic Gaussian perturbations, these moves select one of the currently smallest triangles and displace a chosen vertex along the signed normal direction that directly increases that triangle’s area. A second vertex receives a smaller tangential displacement. This preserves useful freedom to repair neighboring active constraints while allowing the search to cross bottlenecks that one-vertex moves frequently cannot escape. The proposal remains deterministic through the existing seeded generator and retains the original stochastic proposal mechanism for broad exploration.
</DESCRIPTION>

                    (pb[:, 0] - pa[:, 0]) * (pc[:, 1] - pa[:, 1]) -
                    (pb[:, 1] - pa[:, 1]) * (pc[:, 0] - pa[:, 0])
                )
                active = np.argpartition(double_areas, 17)[:18]
                triangle = triples[active[rng.integers(len(active))]]
                moved_position = int(rng.integers(3))
                moved = int(triangle[moved_position])
                other_position = (moved_position + int(rng.integers(1, 3))) % 3
                other = int(triangle[other_position])
                third = int(triangle[3 - moved_position - other_position])

                # Gradient of the signed doubled area with respect to `moved`.
                q = current[other]
                r = current[third]
                signed_area = ((q[0] - current[moved, 0]) *
                               (r[1] - current[moved, 1]) -
                               (q[1] - current[moved, 1]) *
                               (r[0] - current[moved, 0]))
                normal = np.array([q[1] - r[1], r[0] - q[0]])
