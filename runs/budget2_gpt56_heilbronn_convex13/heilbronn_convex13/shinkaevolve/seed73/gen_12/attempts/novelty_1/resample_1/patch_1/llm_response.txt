<DESCRIPTION>
Bias proposed mutations toward vertices involved in the currently smallest triangles. The minimum-area objective is controlled by a small active set of constraints; uniformly selecting a point wastes most iterations moving points that cannot improve the bottleneck. The added helper identifies vertices appearing in the 18 smallest triangles and assigns them higher sampling probability, while retaining a nonzero probability for every point to avoid premature trapping. This is especially useful during annealing, where repair moves should predominantly affect active near-degenerate triples.
</DESCRIPTION>

    def critical_vertex_weights(p: np.ndarray) -> np.ndarray:
        """Sampling weights concentrated on vertices of active small triangles."""
        a, b, c = p[triples[:, 0]], p[triples[:, 1]], p[triples[:, 2]]
        double_areas = np.abs(
            (b[:, 0] - a[:, 0]) * (c[:, 1] - a[:, 1]) -
            (b[:, 1] - a[:, 1]) * (c[:, 0] - a[:, 0])
        )
        active = triples[np.argpartition(double_areas, 17)[:18]].ravel()
        weights = np.bincount(active, minlength=n).astype(float)
        # Preserve occasional exploration of non-critical vertices.
        weights += 0.4
        return weights / weights.sum()

<NAME>
lexicographic_local_polish
</NAME>

<DESCRIPTION>
Replace the final purely random hill climb with a deterministic coordinate-pattern poll. For nonsmooth Heilbronn objectives, an improvement commonly requires moving a critical point in a particular geometric direction; random proposals leave many such directions untested. The eight-direction poll explicitly tests axial and diagonal displacements at a decreasing scale. It uses the existing lower-tail energy as a tie-breaker, so equal minimum-area moves are retained only when they improve the next active triangle constraints rather than drifting arbitrarily across a plateau.
</DESCRIPTION>
