# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- **The current best, Deterministic Annealed Heilbronn Point Search, combines a geometry-aware initialization with bottleneck-focused annealing effectively.** Its four perturbed three-point radial rings plus center create a broadly distributed, non-collinear starting configuration, while 82% of moves target a vertex from the currently minimum-area triple. This achieved the highest reported combined score, **0.76**, with normalized minimum area **0.02**.

- **Maintaining some stochastic mobility late in the run appears valuable.** The best program uses nonzero terminal proposal scale (`0.0025`) and temperature (`0.000015`), explicitly allowing active bottleneck triangles to change rather than freezing immediately. This aligns with its feedback that “nonzero cooling” helps exchange active bottlenecks. The related Deterministic Annealed Heilbronn Search (Generation 5) also used annealing plus a final metric-aligned phase and reached **0.68**, supporting the benefit of prolonged refinement.

- **Targeting worst or near-worst triangle constraints consistently beats unguided random placement.** The best program scored **0.76**; Simulated Annealing Triangle Point Packing using near-worst triples and a lower-tail surrogate scored **0.66**; Deterministic Simulated Annealing Triangle Search using active-constraint-focused moves scored **0.61**. All substantially outperform the initial seeded random placement’s **0.01** score and near-zero normalized minimum area.

- **Multi-start deterministic search is repeatedly associated with stronger outcomes.** The best program uses **10 seeded restarts**, compared with six restarts in several moderate performers: Annealed Critical-Triple Search (**0.50**), Annealed Critical-Triple Triangle Packing (**0.50**), and Simulated Annealing Triangle Point Packing (**0.66**). The larger restart count, together with a structured ring prior, appears to help avoid weak local configurations.

## Ineffective Approaches

- **Pure independent random placement was decisively ineffective.** Seeded Random 13-Point Placement achieved combined score **0.01** and normalized minimum triangle area **0.00**. It performed no optimization or triangle-area evaluation, so it had no mechanism to remove nearly collinear or otherwise degenerate triples.

- **Simplex-constrained soft-min search did not reliably produce strong configurations.** Deterministic Soft-Min Triangle Search (Generation 7) used active-triangle prioritization, coordinated moves, edge-aware probes, and reheating, yet reached only normalized minimum area **0.01** and combined score **0.36**. Despite sophisticated local-search machinery, its fixed-simplex formulation and soft-min-driven search found a comparatively weak final maximin arrangement.

- **Fixing three hull points to a reference triangle was not enough to match the best unconstrained convex-hull search.** Programs with fixed reference-triangle vertices generally clustered at normalized area **0.02** but lower combined scores: Annealed Critical-Triple Search (**0.50**), Annealed Critical-Triple Triangle Packing (**0.50**), Deterministic Annealed Triangle Point Search (**0.53**), and Deterministic Simulated Annealing Triangle Search (**0.61**). The current best’s unconstrained coordinates and hull-area normalization permit the hull itself to adapt.

- **More search work alone did not guarantee a better score.** Deterministic Simulated Annealing Triangle Search used eight restarts and **25,000 moves per restart**, but scored **0.61** with **11.20 s** runtime. The current best scored **0.76** in **19.95 s** with 10 × 12,000 iterations, indicating that structured initialization, hull-adaptive geometry, and acceptance behavior mattered more than simply maximizing move count.

## Implementation Insights

- **The current best directly optimizes the evaluation-relevant normalized quantity.** For every candidate, it computes all **286** triangle doubled areas, finds the minimum, computes convex-hull area via monotone chain, and returns `0.5 * min_double_area / hull_area`. This matches the reported normalized area rather than optimizing only raw triangle area in a fixed domain. Its score of **0.76** is the strongest evidence that hull-normalized evaluation is effective in this set.

- **The best implementation uses inexpensive vectorization where it matters most.** Triangle indexing is precomputed once, and each evaluation gathers the three point arrays and computes all determinants in NumPy. This follows the successful vectorized pattern also used by the **0.66** tail-objective search and **0.61** active-constraint annealer, making repeated full-triple assessment practical.

- **The move-selection mixture balances exploitation and exploration.** In the current best program, `0.82` probability is assigned to moving a point from the currently worst triple, while `0.18` selects an arbitrary point. This avoids exclusively modifying the currently active constraint, which can otherwise simply create a different weak triple or trap the search in a local bottleneck pattern. The feedback specifically credits targeted worst-triangle moves with helping exchange active bottlenecks.

- **The runtime cost is traceable to repeated global geometry recomputation.** The current best evaluates all triples and recomputes a monotone-chain hull for every proposal over **120,000 total annealing iterations**. This produced the best score but also one of the longest runtimes, **19.95 s**, nearly identical to Generation 5’s **19.34 s**, whose feedback similarly attributes cost to repeated triangle and hull evaluations.

## Performance Analysis

- **The current best establishes a clear top tier at combined score 0.76.** It exceeds the next-best Deterministic Batched Simplex Point Search at **0.74** and Deterministic Annealed Heilbronn Search at **0.68**. Although these leading programs all report normalized minimum area rounded to **0.02**, the combined-score differences indicate that unreported precision and/or runtime-sensitive scoring meaningfully separates solutions.

- **A normalized area displayed as 0.02 is necessary but not sufficient for a strong combined score.** Multiple programs reached the same displayed area but varied widely: **0.50** for Annealed Critical-Triple Search, **0.53** for Deterministic Annealed Triangle Point Search, **0.61** for Deterministic Simulated Annealing Triangle Search, **0.66** for tail-objective search, **0.68** for Generation 5, and **0.76** for the current best. Therefore, the rounded metric masks meaningful quality differences in the underlying minimum-area value and possibly the time component.

- **The best score was not the fastest among high-quality approaches.** Deterministic Batched Simplex Point Search reached **0.74** in **4.14 s**, far faster than the current best’s **19.95 s**, while only slightly lower in combined score. Conversely, the current best’s extra hull-adaptive evaluation and longer annealing achieved the maximum observed score. This indicates a quality/runtime tradeoff rather than a simple monotonic relation between runtime and score.

- **Search guidance quality correlates strongly with improvement over baseline.** The baseline random generator scored **0.01**; soft-min simplex search reached **0.36**; critical-triple annealers reached about **0.50–0.61**; lower-tail or more robust active-constraint strategies reached **0.66–0.68**; and the current program’s ring initialization, hull-normalized objective, targeted/random move mixture, and persistent cooling reached **0.76**.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Add a lower-tail secondary objective to the hull-normalized maximin score.** Keep the primary objective as `min_double_area / (2 * hull_area)`, but break close comparisons using the mean or weighted sum of the smallest 5–15 normalized triangle areas. This extends the best program’s active-bottleneck focus while incorporating the successful `0.66` tail-objective pattern, encouraging configurations that improve several near-active constraints rather than merely exchanging one worst triple for another.

2. **Use occasional coordinated moves of two points from the worst or near-worst constraints.** For example, on 10–20% of proposals, select two distinct vertices from the union of the worst 3–8 triangles and perturb both, using a smaller per-point scale than the existing single-point move. The current 82% worst-triple targeting is effective, but coordinated moves can escape local arrangements where moving any one bottleneck vertex alone simply activates a different nearly collinear triple.

3. **Broaden targeting from only the single worst triangle to a sampled active set.** Precompute all doubled areas during evaluation and, for targeted proposals, choose a triangle uniformly or area-weightedly among the lowest `k` triangles, with `k` varying from roughly 3 early in the run to 10–20 late in the run. This preserves the successful exploitation/exploration mixture while making the search more robust when multiple bottlenecks have nearly equal area, a situation the current nonzero terminal temperature is already designed to handle.

4. **Introduce deterministic local polishing after annealing, using accepted-coordinate probes on active vertices.** After each restart’s annealing phase, repeatedly test a small stencil of axis, diagonal, and radial perturbations for vertices appearing in the lowest-area triangles, accepting only score improvements and reducing the probe radius geometrically. This builds on the metric-aligned final refinement associated with the `0.68` annealed search, while retaining the current best program’s directly normalized hull-aware objective.

5. **Make restart allocation adaptive and seed stronger continuations from promising runs.** Run an initial batch of shorter ring-initialized anneals, retain the best few configurations by normalized score and lower-tail quality, then spend the remaining iteration budget on longer reheated refinements from those states with altered step schedules or ring-phase perturbations. This extends the demonstrated value of multi-start structured initialization, but avoids devoting equal full budgets to weak restarts and may improve quality without proportionally increasing the current roughly 20-second runtime.
