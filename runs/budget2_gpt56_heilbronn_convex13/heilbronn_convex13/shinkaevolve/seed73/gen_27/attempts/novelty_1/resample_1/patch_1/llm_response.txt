<DESCRIPTION>
Introduce two geometry-aware improvements without changing the fixed convex reference region or the deterministic search model.

First, add a signed-area gradient for a chosen point in a bottleneck triangle. Random isotropic moves spend most proposals changing triangle area inefficiently; moving a selected vertex along the normal to its opposite edge directly increases that triangle’s determinant. The proposal retains a random component, preserving the ability to resolve competing active constraints.

Second, use affine threefold-symmetric barycentric initializations on half of the restarts. The reference triangle admits the cyclic barycentric map `(x,y) -> (1-x-y,x)`, so a center point plus three three-point orbits gives exactly the ten non-corner points required. Such starts provide a much more balanced global distribution than purely random samples while subsequent unconstrained local moves can break symmetry if beneficial.

</DESCRIPTION>

    def area_gradient(
        p: np.ndarray, triangle_index: int, point_index: int
    ) -> np.ndarray:
        """Unit direction increasing the selected signed triangle area."""
        i, j, k = triples[triangle_index]
        signed = (
            (p[j, 0] - p[i, 0]) * (p[k, 1] - p[i, 1])
            - (p[j, 1] - p[i, 1]) * (p[k, 0] - p[i, 0])
        )
        sign = 1.0 if signed >= 0.0 else -1.0
        if point_index == i:
            u, v = p[j], p[k]
        elif point_index == j:
            u, v = p[k], p[i]
        else:
            u, v = p[i], p[j]
        edge = v - u
        direction = sign * np.array((-edge[1], edge[0]))
        norm = float(np.hypot(direction[0], direction[1]))
        return direction / norm if norm > 1.0e-14 else np.array((1.0, 0.0))
