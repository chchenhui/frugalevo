<DESCRIPTION>
Fix the convex hull to a reference triangle and constrain the remaining ten points to its interior. This removes hull-area recomputation and eliminates wasted search effort on affine-equivalent hull deformations; determinant magnitudes are then exactly the evaluator’s normalized triangle areas. The faster, geometrically normalized objective is paired with a deterministic final active-set stencil polish: it identifies vertices participating in the current lower-tail triangles and probes axis, diagonal, and radial perturbations while accepting only strict bottleneck improvements.

        """Twice-area monotone-chain hull, with a harmless zero-area guard."""
        ordered = p[np.lexsort((p[:, 1], p[:, 0]))]
        lower = []
        for q in ordered:
            while len(lower) >= 2:
                a, b = lower[-2], lower[-1]
                if (b[0] - a[0]) * (q[1] - a[1]) - (b[1] - a[1]) * (q[0] - a[0]) > 1e-12:
                    break
                lower.pop()
            lower.append(q)
        upper = []
        for q in ordered[::-1]:
            while len(upper) >= 2:
                a, b = upper[-2], upper[-1]
                if (b[0] - a[0]) * (q[1] - a[1]) - (b[1] - a[1]) * (q[0] - a[0]) > 1e-12:

                upper.pop()
            upper.append(q)

        if len(polygon) < 3:
            return 0.0
