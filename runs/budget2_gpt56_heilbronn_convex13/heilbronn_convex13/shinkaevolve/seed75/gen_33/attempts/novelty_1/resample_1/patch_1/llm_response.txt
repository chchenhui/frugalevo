<DESCRIPTION>
Diversify the deterministic restart portfolio without increasing the number of sweeps or proposals. The current sixteen restarts all begin in perturbations of one staggered-row arrangement, which can repeatedly enter the same maximin basin despite different random jitter. This edit cycles through four complementary ten-point seeds: the existing staggered pattern, a hexagonal-like pattern, an interleaved pattern, and a symmetry-broken high/low-row pattern. Each is lightly jittered and projected into the same fixed equilateral hull, preserving validity, determinism, and computational cost while improving the chance that the coordinate search reaches a stronger active-triangle combinatorial structure.
