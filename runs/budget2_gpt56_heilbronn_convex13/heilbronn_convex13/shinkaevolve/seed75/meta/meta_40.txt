# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- **The current best, Generation 35 `lexicographic_polish`, improves the established fixed-square soft-min pattern to the top observed score: 0.75 in 4.71 s.** Like earlier leaders, it fixes the four unit-square corners, making convex-hull area exactly one and eliminating any mismatch between raw and normalized minimum triangle area. Its ten seeded restarts, early annealed soft-min exploration, and late strict max-min polishing retain the successful Generation 26/27-style architecture while producing a modest but meaningful combined-score gain over the prior 0.74 ceiling.

- **Soft lower-tail search is effective when it is explicitly separated from strict final bottleneck optimization.** Generation 35 uses temperature-annealed soft-min scoring in its 520-sweep exploration phase, then switches to hard polishing that first maximizes the exact minimum triangle area and only then uses lower-tail sum and second-minimum comparisons. This is stronger than methods that allow a surrogate to dominate late decisions: the result is **0.75**, versus **0.65** for Generation 37’s more mixed stochastic/repair approach and **0.71** for Generation 32’s bottleneck-aware soft-min search.

- **Structured coordinate-level restarts remain more productive than population DE or more elaborate repair systems.** Generation 35’s ten restart coordinate search reached **0.75**, while Generation 31’s hybrid differential evolution plus incident-triangle polish reached only **0.49** despite being fast at **0.56 s**. Generation 38’s triangle-hull DE was similarly weak, at **0.33** and normalized area **0.01**. The evaluated results continue to favor repeated local basin search with exact geometric refinement over evolutionary population updates.

- **Multiscale directional polishing is consistently useful, but compact versions have the best efficiency-quality tradeoff.** Generation 35’s five polish scales, 48 circular directions, and two radii per direction improved on broad search without excessive runtime. It outperformed Generation 36’s active-triangle-normal version (**0.74**, **7.01 s**), Generation 24’s batched active-triangle method (**0.56**, **38.50 s**), and Generation 40’s active-normal/two-point repair search (**0.62**, **5.66 s**).

## Ineffective Approaches

- **Greater active-constraint and repair complexity did not translate into stronger configurations.** Generation 24 used active-triangle-guided batches, annealed acceptance, and multiscale polishing but scored only **0.56** while taking **38.50 s**. Generation 37 combined critical-triangle paired repairs with strict polishing and reached **0.65**. The results reinforce the earlier evidence that specialized repair mechanisms can add proposal cost without surpassing simpler coordinate soft-min search.

- **Differential evolution underperformed substantially in both square and triangular hull variants.** Generation 31’s elite-guided DE, donor mutation, crossover, and survivor polishing yielded **0.49**; Generation 38’s 48-member DE population with diversity injection achieved only **0.33** and a displayed normalized minimum area of **0.01**. Although fast, these methods appear less capable of resolving the dense nonsmooth set of active triangle constraints than coordinate-wise local optimization.

- **Successive halving and expanded seed budgets alone were not sufficient.** Generation 34 searched 16 jittered-grid seeds, retained six, and added coupled repairs and angular polishing, but attained only **0.40** at **4.76 s** with normalized minimum area **0.01**. Likewise, the triangle-hull Generation 33 used 16 restarts and 560 sweeps but obtained **0.74** only after **25.15 s**, below the current best’s **0.75** in **4.71 s**. More starts or longer trajectories did not reliably improve the final bottleneck.

- **Changing the fixed hull to a triangle has not improved the best observed result.** Generation 33’s equilateral-triangle formulation reached the prior **0.74** tier but required over five times the runtime of Generation 35. Generation 38’s right-triangle DE variant fell to **0.33**. Fixed hulls remain valuable for validity and normalization, but the square formulation has the stronger and more repeatable efficiency-quality record.

## Implementation Insights

- **Generation 35 efficiently exploits locality while preserving exact global candidate scoring.** For a proposed move of point `p`, `incident_areas` recomputes only triangles containing `p`; all nonincident triangle areas come from the cached global `areas` vector. It then reconstructs each candidate’s full 286-area spectrum for soft-min or lexicographic comparison. This avoids recomputing every triangle for each proposal while still ranking candidates against the true global constraint distribution.

- **The current program’s proposal set makes exploration non-destructive under its active objective.** Each coordinate update includes the current point as proposal zero. During the 520 exploration sweeps, the chosen candidate maximizes stable soft-min score among the current position, twelve random directional moves, and—early in the search—two global relocations. Thus, a coordinate update cannot worsen the current smooth exploration score. The early global proposals and use of lattice, staggered, and interleaved initial layouts specifically target the repeated horizontal/vertical near-collinear triples associated with grid basins.

- **The strict polish has a clear objective hierarchy aligned with evaluation.** Generation 35 computes candidate exact minima from both cached fixed triangles and recomputed incident triangles; it rejects candidates below the current true minimum. Among max-min plateaus, it compares the sum of the eight lowest areas, then the second-smallest area. This is a concrete refinement of the prior insight that tail shaping is useful as a tie-breaker but should not override the primary bottleneck objective.

- **Fixed corners provide both objective alignment and inexpensive feasibility control.** The fixed points `(0,0)`, `(1,0)`, `(1,1)`, and `(0,1)` ensure a unit-area convex hull regardless of interior-point movements. Clipping movable coordinates to `[0.035, 0.965]` keeps proposals safely interior. This same pattern underlies the better square programs—Generations 32, 35, 36, 37, and 40—but Generation 35 demonstrates that it is most effective when paired with moderate restart counts and strict lexicographic polishing.

## Performance Analysis

- **Generation 35 establishes the best reported combined score, improving the prior leading cluster from 0.74 to 0.75.** Its normalized minimum area is still displayed as **0.02**, as in Generations 32, 33, 36, 37, and 40, so the combined-score increase likely reflects unrounded geometric improvement within that displayed tier plus its competitive runtime. Its **4.71 s** evaluation is also substantially lower than Generation 24’s **38.50 s**, Generation 33’s **25.15 s**, Generation 32’s **8.98 s**, and Generation 36’s **7.01 s**.

- **Among the new fixed-square local-search variants, the current program has the strongest quality-efficiency balance.** Generation 36 is nearest in approach and result—active-triangle-normal proposals, ten restarts, 520 sweeps, strict multiscale polish—but scores **0.74** in **7.01 s**. Generation 35 reaches **0.75** in **4.71 s** using simpler random directional coordinate proposals, occasional early relocations, and a particularly explicit lexicographic final stage. Across both the previous and new evidence, the best outcomes come from maintaining a fixed unit hull, using diverse deterministic starts, caching incident-triangle updates, and subordinating lower-tail objectives to strict final max-min selection.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Make the final polish comparator fully lexicographic over a slightly richer lower tail.** Replace the current `(min, sum of 8 smallest, second-smallest)` selection with a stable tuple such as `(min, sum_smallest_8, second_smallest, sum_smallest_16)` and compare it with explicit tolerances only on the minimum. This directly extends Generation 35’s successful strict-primary / tail-secondary design, while giving plateau moves a more discriminating criterion without allowing a surrogate to reduce the true bottleneck.

2. **Add a small number of active-triangle normal directions only during the late exploration and polish stages.** For each movable point, identify its 2–3 smallest incident triangles, compute the normal to each triangle’s opposite edge, and append both normal signs at the current radius to the existing random or circular proposals. Keep this as a supplement rather than replacing the successful random-direction set: Generation 36 indicates such geometry-aware moves can be competitive, while Generation 35 shows that a compact proposal mechanism is preferable to elaborate active-constraint repair systems.

3. **Warm-start several later restarts from the best configuration discovered so far, with asymmetric multiscale perturbations.** After the first few independent lattice/staggered/interleaved runs, create 2–3 seeds by copying the current global best and perturbing all nine movable points with low-amplitude correlated shifts, row offsets, rotations around the square center, or sparse single-point displacements. This preserves Generation 35’s productive restart architecture but spends part of its restart budget refining promising high-quality basins rather than repeatedly rebuilding from broad grid-like starts.

4. **Use adaptive proposal radii tied to local active-triangle slack rather than only to the global sweep schedule.** For a point participating in several near-minimum triangles, test an additional smaller radius such as `min(step, 0.25 * local_slack_scale)` alongside the existing random radius distribution; for points absent from the lower tail, retain broader moves. The current annealing schedule is effective globally, but local radius adaptation should improve late precision around bottleneck constraints while maintaining the non-destructive soft-min coordinate updates that made Generation 35 robust.

5. **Introduce a rare, tightly bounded stall escape based on sequential two-point moves from the lower-tail conflict set.** If the exact best minimum has not improved for roughly 40–60 late sweeps, find the two movable points appearing most frequently in the smallest 6–10 triangles, generate a compact set of candidate moves for the first point, then optimize the second point conditionally using the normal/random proposal pool. Accept only a full-vector lexicographic improvement and invoke this once or twice per restart, preserving the proven coordinate-search core while offering a controlled way to escape configurations where multiple active triangles cannot be improved by one-point updates alone.
