strict_bottleneck_updates
</NAME>

<DESCRIPTION>
Make the true Heilbronn objective—the smallest of the 286 triangle areas—the primary acceptance criterion during the global coordinate search. The existing LogSumExp soft-min can select a candidate with a better average lower tail while sacrificing the actual smallest triangle, which is directly detrimental to the evaluated score. This edit first maximizes the exact candidate minimum area, then uses the soft bottleneck only to break numerically meaningful near-ties. This retains the useful global-shaping behavior of the smooth surrogate without permitting it to trade away the hard bottleneck.
</DESCRIPTION>

                # The evaluated objective is the strict smallest area.  Use it
                # as the dominant coordinate-selection criterion; otherwise a
                # soft-min improvement can silently reduce the true bottleneck.
                candidate_min = np.minimum(
                    np.min(local, axis=1),
                    np.min(fixed),
                )
                maximum_min = float(np.max(candidate_min))

                # Among essentially equal max-min alternatives, the smooth
                # lower-tail score encourages future improvements by enlarging
                # several currently tight triangles rather than just one.
                tied = candidate_min >= maximum_min - 2.0e-7
                scores = soft_bottleneck(all_values, temperature)
                scores[~tied] = -np.inf
                choice = int(np.argmax(scores))

<NAME>
denser_final_directions
</NAME>

<DESCRIPTION>
Increase angular resolution in the final strict max-min polish. Near a locally optimal Heilbronn configuration, the feasible improving motion for a point is often confined to a narrow cone determined by several active minimum-area triangles. Sampling 48 directions instead of 24 substantially improves the probability of finding that cone while affecting only the short final polishing phase.
</DESCRIPTION>
