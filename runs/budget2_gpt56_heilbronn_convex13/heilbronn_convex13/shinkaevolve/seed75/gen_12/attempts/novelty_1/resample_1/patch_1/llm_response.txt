<DESCRIPTION>
Replace the raw minimum-only annealing objective with a stable soft-min objective over all 286 normalized triangle determinants. A raw minimum has large flat plateaus: moves that improve the second-, third-, or tenth-smallest triangle receive no signal. The soft-min preserves emphasis on bottleneck triangles while rewarding improvements to the near-critical set, which is especially useful for the highly nonsmooth Heilbronn objective.

The search also chooses movable vertices from the endpoints of currently critical triangles most iterations. This concentrates local refinement on the triangles limiting the configuration, while periodic unrestricted moves preserve the ability to reorganize the full point set. The best configuration is still selected strictly by the true minimum triangle area, not the surrogate objective.

    def triangle_quality(p: np.ndarray) -> tuple[float, float, np.ndarray]:
        """Return true floor, a smooth bottleneck score, and critical triples."""
        a = p[triples[:, 0]]
        b = p[triples[:, 1]]
        c = p[triples[:, 2]]
        twice_areas = np.abs(
            (b[:, 0] - a[:, 0]) * (c[:, 1] - a[:, 1])
            - (b[:, 1] - a[:, 1]) * (c[:, 0] - a[:, 0])
        )
        floor = float(twice_areas.min())

        # Unlike the literal minimum, this gives useful improvement signal to
        # all triangles close to being limiting.  The subtraction is the
        # standard stable log-sum-exp implementation of a soft minimum.
        beta = 850.0
        soft_floor = floor - np.log(
            np.exp(-beta * (twice_areas - floor)).sum()
        ) / beta
        critical = np.argpartition(twice_areas, 18)[:18]
        # The outer triangle has determinant one, hence determinants are
        # precisely areas normalized by the fixed hull area.
        return floor, float(soft_floor), critical
