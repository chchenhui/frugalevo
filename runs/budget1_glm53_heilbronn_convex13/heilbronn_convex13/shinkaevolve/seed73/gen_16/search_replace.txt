<DESCRIPTION>
The soft-min subgradient ascent is poorly suited to this problem: the min-triangle objective is piecewise-linear and non-smooth, so gradient ascent stalls early (hence the very low min_area_normalized of 0.01). A direct discrete pattern search on the true objective (the exact minimum triangle area, computed vectorized over all 286 triples) is far more reliable for Heilbronn-type max-min problems. I add a post-processing refinement phase that, for every point, tries moves along 16 directions (k·π/16, k=0..15 — the recommended 22.5°-increment set), accepting a move only if the true global minimum triangle area strictly improves. This lets points slide off the symmetric rings into the irregular configurations characteristic of good Heilbronn placements, while remaining fully deterministic and cheap (286 triples × 13 points × 16 directions vectorized per sweep).

    # ---- Direct pattern-search refinement on the true min-triangle objective ----
    # 16 directions at 22.5-degree increments break the ring symmetry and let
    # points settle into irregular optimal placements.
    ang = np.arange(16) * np.pi / 16.0
    dirs = np.stack([np.cos(ang), np.sin(ang)], axis=1)  # (16,2)

    def min_area_val(p):
        return min_tri(p).min()

    cur_val = min_area_val(pts)
    step2 = 0.01 * R
    while step2 > 1e-5 * R:
        improved = False
        for i in range(n):
            # candidate moves for point i: (16,2)
            cand = np.repeat(pts[i][None, :], 16, axis=0) + step2 * dirs
            cand = clip(cand)
            # evaluate all candidates at once: 16 x 286 areas
            vals = np.empty(16)
            base = pts.copy()
            for d in range(16):
                base[i] = cand[d]
                vals[d] = min_tri(base).min()
            d = int(np.argmax(vals))
            if vals[d] > cur_val + 1e-15:
                pts[i] = cand[d]
                cur_val = vals[d]
                improved = True
        if not improved:
            step2 *= 0.5

    pts = clip(pts)

    # Validate: finite, distinct
    assert np.all(np.isfinite(pts))
    assert pts.shape == (13, 2)
    return pts
