<DESCRIPTION>
Two targeted improvements: (1) Add more diverse seeds — in particular boundary-of-triangle placements (vertices plus interior arc), since optimal 13-point Heilbronn configurations tend to place points on the convex hull vertices and edges of a triangle, and more random restarts increase basin coverage. (2) Add a final intensive fine-grained polish phase applied to the overall best configuration after basin hopping: a dedicated fine hill-climb (step sizes from 0.02 down to 5e-4, including diagonal coordinate moves) that can squeeze out the last area improvements on the smallest triangles. This complements the elite-ladder basin hopping without replacing it.

    # ---- final intensive fine-grained polish on the overall best
    def fine_polish(P: np.ndarray, steps_max: int = 60) -> np.ndarray:
        step = 0.02
        best = score(P)
        for _ in range(steps_max):
            improved = False
            # single-coordinate moves
            for i in range(len(P)):
                for j in range(2):
                    for d in (+1, -1):
                        Q = P.copy()
                        Q[i, j] += d * step
                        sc = score(Q)
                        if sc > best + 1e-12:
                            best = sc
                            P = Q
                            improved = True
            # diagonal moves (helps escape 45-degree ridge directions)
            for i in range(len(P)):

                        P = Q
                        improved = True
