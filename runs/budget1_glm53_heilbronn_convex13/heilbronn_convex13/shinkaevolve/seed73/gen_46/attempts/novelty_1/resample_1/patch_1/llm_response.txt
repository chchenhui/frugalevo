<DESCRIPTION>
The blended surrogate `score()` (0.6·min + 0.4·mean-of-smallest-5) optimizes a different quantity than the graded metric, which is the pure minimum triangle area. Near a plateau, surrogate-optimal points can be exact-poor. Two targeted changes: (1) after the surrogate `fine_polish`, run a final coordinate hill-climb directly on `true_score` so the last refinement pushes the actual graded objective; (2) since the true polish may move points, re-verify with `true_score` and accept on any non-negative improvement (ties accepted to allow lateral exploration of flat directions that may later yield gains via diagonal moves). This is cheap (286 triangles vectorized) and deterministic, directly targeting min_area_normalized rather than the proxy.</DESCRIPTION>

    # ---- final polish directly on the exact objective (min triangle area),
    # since the blended surrogate can plateau away from true optimum
    def exact_polish(P: np.ndarray, steps_max: int = 50) -> np.ndarray:
        step = 0.02
        best = true_score(P)
        for _ in range(steps_max):
            improved = False
            for i in range(len(P)):
                for j in range(2):
                    for d in (+1, -1):
                        Q = P.copy()
                        Q[i, j] += d * step
                        sc = true_score(Q)
                        if sc > best + 1e-12:
                            best = sc
                            P = Q
                            improved = True
            # diagonal moves escape ridge directions in the exact objective
            for i in range(len(P)):
                for dx, dy in ((1, 1), (1, -1), (-1, 1), (-1, -1)):
                    Q = P.copy()
                    Q[i, 0] += dx * step * 0.7
                    Q[i, 1] += dy * step * 0.7
                    sc = true_score(Q)
                    if sc > best + 1e-12:
                        best = sc
                        P = Q
                        improved = True
            if not improved:
                step *= 0.5
                if step < 5e-4:
                    break
        return P
