incremental_climb_and_widen_polish</NAME>
<DESCRIPTION>
The main runtime bottleneck is `_climb`: every candidate move recomputes all 286 triangle areas plus the hull. When moving a single point i, only the ~66 triangles containing i change. Maintaining a cached area array and recomputing only affected rows (while still recomputing the cheap 13-point hull exactly) makes each climb step ~4x faster, letting us widen Stage 2 polish from top-14 to top-20 and increase climb iterations substantially within the same wall-clock budget. This converts directly into higher min_area_normalized, per the recommendation from Gen 36's proven approach.

# Precomputed row indices per point: triangles containing point i
_ROWS = [np.where((_I == i) | (_J == i) | (_K == i))[0] for i in range(_N)]


def _all_areas(P):
    ax, ay = P[_I, 0], P[_I, 1]
    bx, by = P[_J, 0], P[_J, 1]
    cx, cy = P[_K, 0], P[_K, 1]
    return 0.5 * np.abs((bx - ax) * (cy - ay) - (cx - ax) * (by - ay))


def _climb(P, rng, iters, amp0=0.02, amp_hi=0.08):
    """Incremental stochastic hill climbing on the ratio; moving point i
    only recomputes the ~66 triangles containing i (cached areas array)."""
    P = P.copy()
    areas = _all_areas(P)
    ha = _hull_area(P)
    best = areas.min() / ha if ha > 1e-12 else 0.0
    best_P = P.copy()
    amp = amp0
    fails = 0
    for it in range(iters):
        i = int(rng.integers(_N))
        d = rng.normal(size=2) * amp
        old = P[i].copy()
        new = old + d
        if not (0.0 <= new[0] <= 1.0 and 0.0 <= new[1] <= 1.0):
            amp *= 0.98
            continue
        rows = _ROWS[i]
        saved = areas[rows].copy()
        P[i] = new
        ax, ay = P[_I[rows], 0], P[_I[rows], 1]
        bx, by = P[_J[rows], 0], P[_J[rows], 1]
        cx, cy = P[_K[rows], 0], P[_K[rows], 1]
        areas[rows] = 0.5 * np.abs((bx - ax) * (cy - ay) - (cx - ax) * (by - ay))
        ha = _hull_area(P)
        if ha > 1e-12:
            v = areas.min() / ha
            if v > best + 1e-14:
                best = v
                best_P = P.copy()
                fails = 0
                amp = min(amp * 1.03, amp_hi)
                continue
        P[i] = old
        areas[rows] = saved
        fails += 1
        if fails > 60:
            amp *= 0.85
            fails = 0
            if amp < 1e-4:
                break
    return best_P, best
