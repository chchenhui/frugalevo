<DESCRIPTION>
The current code optimizes the raw minimum triangle area while clipping points into a fixed unit-area hexagon. But the scoring metric is min_triangle_area / hull_area(points), where the hull is the convex hull of the 13 points themselves — not the hexagon. Two consequences:

1. The optimizer's objective (raw min area inside the hexagon) is misaligned with the true metric. Shrinking the hull (pulling points inward) reduces the denominator and can increase the normalized score even at constant raw min area. The optimizer should directly maximize min_area/hull_area.
2. A single global step size means one stuck point (e.g., a hull vertex that cannot move outward) throttles refinement for all points. The recommendation suggests per-point adaptive step sizes: halve only the failing point's step, and occasionally re-grow steps.

The edit replaces the hard-min optimizer with a ratio-based one that:
- uses the monotone-chain hull area as denominator (computed on the fly, cheap for 13 points),
- maintains a per-point step vector, halving only steps whose trials fail and multiplying successful steps by 1.3 (capped),
- tries both an objective-ascent move and a random perturbation per point per sweep,
- no longer forces points into the hexagon (only a mild centering/repulsion keeps the configuration non-degenerate); instead the hull of the points defines the region.

This directly targets combined_score = min_area/hull_area / 0.0309.

    def hull_area(p):
        order = np.lexsort((p[:, 1], p[:, 0]))
        hidx = []
        for chain_in in (order, order[::-1]):
            chain = []
            for i in chain_in:
                while len(chain) >= 2:
                    o, a = p[chain[-2]], p[chain[-1]]
                    if (a[0]-o[0])*(p[i,1]-o[1]) - (a[1]-o[1])*(p[i,0]-o[0]) <= 0:
                        chain.pop()
                    else:
                        break
                chain.append(i)
            hidx.extend(chain[:-1])
        hidx = sorted(set(hidx))
        V = p[hidx]
        m = len(hidx)
        s = 0.0
        for i in range(m):
            x1, y1 = V[i]
            x2, y2 = V[(i + 1) % m]
            s += x1 * y2 - x2 * y1
        return abs(s) * 0.5

    def score(p):
        ha = hull_area(p)
        if ha < 1e-12:
            return 0.0
        return min_tri(p).min() / ha

    def min_grad(p):
        # Ascent gradient of the smallest-triangle area wrt each point.
        areas = min_tri(p)
        order = np.argsort(areas)
        grads = np.zeros_like(p)
        for t in order[:12]:
            i, j, l = idx[t]
            a, b, c = p[i], p[j], p[l]
            s = (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])
            s = 1.0 if s >= 0 else -1.0
            grads[i] += 0.5 * s * np.array([c[1] - b[1], b[0] - c[0]])
            grads[j] += 0.5 * s * np.array([a[1] - c[1], c[0] - a[0]])
            grads[l] += 0.5 * s * np.array([b[1] - a[1], a[0] - b[0]])
        gn = np.linalg.norm(grads, axis=1, keepdims=True)
        gn[gn < 1e-12] = 1.0
        return grads / gn
