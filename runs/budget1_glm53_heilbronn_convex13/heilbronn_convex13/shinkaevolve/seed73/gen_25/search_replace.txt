<DESCRIPTION>
The best prior program (combined_score 0.80) used exact-ratio stochastic coordinate hill climbing with basin hopping, while the current gradient-only version scores 0.18. The softmin gradient ascent tends to stall in shallow basins because the smooth approximation of the min is a poor guide near the kinked true objective. The fix: (1) add a single-point-move stochastic hill climber on the exact ratio _ratio, with adaptive step size; (2) run it as a refinement stage after each gradient run and again as a long final polish on the global best (this combines the gradient's fast basin approach with the climber's exact objective); (3) add fully asymmetric random 13-point seeds passed through the same pipeline, per the recommendation to break the symmetry trap of the 3-fold parametrization. Determinism is preserved via fixed seeds.

def _climb(P, rng, iters=3000, amp0=0.04, amp_min=1e-4):
    """Stochastic single-point hill climbing on the exact ratio."""
    P = P.copy()
    best = _ratio(P)
    best_P = P.copy()
    amp = amp0
    fails = 0
    for it in range(iters):
        i = rng.integers(_N)
        d = rng.normal(size=2) * amp
        Q = P.copy()
        Q[i] = P[i] + d
        v = _ratio(Q)
        if v > best + 1e-14:
            best = v
            best_P = Q.copy()
            P = Q
            fails = 0
            amp = min(amp * 1.01, 0.15)
        else:
            fails += 1
            if fails > 80:
                amp *= 0.85
                fails = 0
                if amp < amp_min:
                    break
    return best_P, best
