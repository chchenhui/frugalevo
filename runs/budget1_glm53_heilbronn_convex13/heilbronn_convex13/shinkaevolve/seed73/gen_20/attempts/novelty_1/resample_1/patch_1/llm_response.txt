<DESCRIPTION>
The current program loses to the earlier vectorized soft-min gradient approach (0.70 vs 0.75) because its hill climbing is slow and gets stuck. The fix: (1) add a fast, fully vectorized soft-min gradient ascent optimizer (exact analytic gradient of a LogSumExp-smoothed minimum of all 286 triangle areas, with annealed sharpness) applied to every seed; (2) run the expensive exact hill-climb polish only on the top few candidates rather than every seed; (3) add a basin-hopping style deterministic perturbation-and-restart around the best solution, which directly attacks the local-optimum limitation. This keeps determinism (fixed seeds, fixed perturbations) while substantially improving the achieved minimum-triangle area and reducing runtime.

    def grad_ascent(P0: np.ndarray, iters: int = 300, lr0: float = 0.08) -> np.ndarray:
        """Fast vectorized soft-min gradient ascent on min triangle area.
        Exact analytic gradient of LogSumExp-smoothed min of |signed areas|,
        with annealed sharpness p: 30 -> 600."""
        P = P0.copy()
        for it in range(iters):
            A, B, C = P[I], P[J], P[K]
            S = 0.5 * ((B[:, 0] - A[:, 0]) * (C[:, 1] - A[:, 1])
                       - (B[:, 1] - A[:, 1]) * (C[:, 0] - A[:, 0]))
            a = np.abs(S)
            m = a.min()
            p = 30.0 + 2.0 * it
            w = np.exp(-p * (a - m))
            w /= w.sum()
            wt = w * np.sign(S)
            X, Y = P[:, 0], P[:, 1]
            gx = 0.5 * (np.bincount(I, wt * (Y[J] - Y[K]), minlength=n)
                        + np.bincount(J, wt * (Y[K] - Y[I]), minlength=n)
                        + np.bincount(K, wt * (Y[I] - Y[J]), minlength=n))
            gy = 0.5 * (np.bincount(I, wt * (X[K] - X[J]), minlength=n)
                        + np.bincount(J, wt * (X[I] - X[K]), minlength=n)
                        + np.bincount(K, wt * (X[J] - X[I]), minlength=n))
            G = np.column_stack([gx, gy])
            nrm = np.linalg.norm(G)
            if nrm < 1e-16:
                break

            P = P + (lr * G / nrm) * n
            P = np.clip(P, -1.5, 1.5)
        return P
