<DESCRIPTION>
Replace the soft-min gradient ascent + gentle hill-climb pipeline with a hard-min coordinate-descent optimizer applied directly to the true objective (min triangle area / hull area). Coordinate descent on the exact hard min has previously proven ~3.5x more effective than soft-min gradients because the LogSumExp smoothing wastes effort raising near-min triangles that never become the bottleneck. Additionally, add structurally diverse full-configuration seeds (two concentric rings 7+5+center, hexagonal lattice, golden-ratio-perturbed circle) so the optimizer can escape the 3-fold-symmetric basin — known Heilbronn-13 optima are irregular, so symmetry-constrained initialization likely limits the achievable score. Each seed is polished with hard-min descent and only kept if its final true score beats the running best. All randomness is seeded, so results stay deterministic. Vectorized triangle/hull computation keeps each objective evaluation cheap (~286 triangles), so the descent converges in well under a second per seed.

                         rounds: int = 40) -> np.ndarray:
        """Hard-min coordinate descent on the TRUE objective
        (min triangle area / hull area). Try per-coordinate moves at several
        step sizes each sweep; shrink step when no move improves."""
        P = P.copy()
        best = true_score(P)
        step = step0
        for _ in range(rounds):
            improved = False

        return P
