<DESCRIPTION>
The gradient ascent only optimizes a soft-min surrogate; the final score is the true hard min of triangle areas normalized by hull area. I add a deterministic hill-climb polishing stage that directly maximizes the true score, with **adaptive per-point step sizes** (per the recommendation): each point keeps its own step, halved when none of its trial moves improve, and occasionally regrown (×1.5, capped at 0.25) when a point has been skipped for many sweeps. This lets constrained points refine finely while hull points keep exploring, avoiding premature global step collapse. We polish only the top few gradient-optimized candidates to keep runtime bounded, then take the best true score across all candidates.

    def true_score(P: np.ndarray) -> float:
        a = np.abs(signed_areas(P))
        ha = _hull_area(P)
        return a.min() / ha if ha > 1e-12 else 0.0

    def polish(P: np.ndarray, sweeps: int = 60) -> np.ndarray:
        """Hill-climb on the TRUE min-area/hull-area score with adaptive
        per-point step sizes (halve on failure, regrow when skipped)."""
        P = P.copy()
        npts = len(P)
        step = np.full((npts, 2), 0.03)
        skip = np.zeros(npts)
        best = true_score(P)
        for sw in range(sweeps):
            improved_any = False
            for i in range(npts):
                pi_moved = False
                for j in range(2):
                    for d in (+1, -1):
                        Q = P.copy()
                        Q[i, j] += d * step[i, j]
                        Q[i, j] = np.clip(Q[i, j], -1.5, 1.5)
                        sc = true_score(Q)
                        if sc > best + 1e-14:
                            best = sc
                            P = Q
                            step[i, j] = min(step[i, j] * 1.3, 0.25)
                            pi_moved = True
                if not pi_moved:
                    step[i] *= 0.5
                    skip[i] += 1
                    if skip[i] >= 6 and step[i, 0] < 0.01:
                        step[i] = np.minimum(step[i] * 1.5, 0.25)
                        skip[i] = 0
                else:
                    skip[i] = 0
                improved_any = improved_any or pi_moved
            if step.max() < 1e-5:
                break
        return P
