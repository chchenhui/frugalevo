<DESCRIPTION>
The current program runs a single symmetric ring initialization, which gets trapped in a poor local optimum (0.49 vs 0.70 for the earlier free-hill-climbing approach). Two improvements: (1) run the gradient ascent + pattern search pipeline from multiple diverse seeds (different ring radii and jitter levels) and keep the best, and (2) select/score candidates using the *true* objective min_area / hull_area, including a hull-expansion move (scaling all points outward) inside the pattern search, since pushing points toward the hexagon boundary increases min triangle area while hull area stays capped at the hexagon area.

    def _hull_area(p):
        # convex hull area via monotone chain
        order = np.lexsort((p[:, 1], p[:, 0]))
        def cross(o, a, b):
            return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])
        def chain(sub):
            out = []
            for q in sub:
                while len(out) >= 2 and cross(out[-2], out[-1], q) <= 0:
                    out.pop()
                out.append(q)
            return out
        lower = chain(p[order])
        upper = chain(p[order[::-1]])
        h = lower[:-1] + upper[:-1]
        if len(h) < 3:
            return 1e-12
        s = 0.0
        for i in range(len(h)):
            x1, y1 = h[i]
            x2, y2 = h[(i + 1) % len(h)]
            s += x1 * y2 - x2 * y1
        return abs(s) / 2.0
