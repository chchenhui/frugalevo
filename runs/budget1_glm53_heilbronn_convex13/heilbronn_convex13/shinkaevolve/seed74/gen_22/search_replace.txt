<DESCRIPTION>
The current hill climbing only accepts moves that strictly increase the single global minimum area. This creates huge flat plateaus: moving one vertex of the argmin triangle usually doesn't help (another triangle becomes the min), so the search stalls at min_area_normalized ≈ 0.02. Following the recommendation, I modify `_polish` to (a) rank moves by a soft objective — the mean of the k smallest triangle areas — which gives targeted pressure to lift the whole bottom tail, and (b) re-check the true global minimum as the gate for committing a new best configuration. This escapes local traps where improving the bottom-k average is possible but the strict min stays flat, and then periodically locks in true min improvements. I also apply the same soft pressure inside `_anneal` by widening k_bot and biasing vertex selection toward the very worst triangles.

def _soft_score(pts, k=10):
    """Soft objective: mean of the k smallest triangle areas (pressure on bottom tail)."""
    ha = _hull_area(pts)
    if ha <= 1e-12:
        return 0.0
    areas = np.partition(_all_tri_areas(pts), k - 1)[:k]
    return areas.mean() / ha


def _polish(pts, iters=1500):
    """Greedy targeted refinement driven by the k smallest triangles.

    Accepts moves that increase the mean of the k smallest triangle areas
    (soft pressure that escapes flat minima), while tracking and returning
    the configuration with the best true global minimum encountered.
    """
    pts = pts.copy()
    ha = _hull_area(pts)
    best_true = _all_tri_areas(pts).min() / ha if ha > 1e-12 else 0.0
    best_true_pts = pts.copy()
    soft = _soft_score(pts)
    K = 12
    for it in range(iters):
        areas = _all_tri_areas(pts)
        order = np.argsort(areas)
        # target vertices from the K worst triangles
        verts = np.unique(_IDX[order[:K]].ravel())
        improved = False
        for vi in verts:
            for d in range(2):
                for sgn in (1, -1):
                    for step in (0.006, 0.002, 0.0005):
                        cand = pts.copy()
                        cand[vi, d] = np.clip(cand[vi, d] + sgn * step, 0.0, 1.0)
                        s = _soft_score(cand, K)
                        if s > soft + 1e-12:
                            pts, soft, improved = cand, s, True
                            # gate: keep the best true minimum seen so far
                            ha_c = _hull_area(cand)
                            if ha_c > 1e-12:
                                t = _all_tri_areas(cand).min() / ha_c
                                if t > best_true + 1e-13:
                                    best_true = t
                                    best_true_pts = cand.copy()
        if not improved:
            break
    return best_true_pts, best_true
