<DESCRIPTION>
Replace the naive random-point stub with a deterministic, efficient heuristic optimizer for the 13-point Heilbronn problem.

Reasoning:
1. **Anchored unit-area hull**: Points 0,1,2 are fixed at the vertices of a unit-area equilateral triangle, so the convex hull area is exactly 1 (normalized min-area equals raw min-area) and all points are trivially inside/on the convex hull after barycentric projection.
2. **Exact objective**: Minimum area over all C(13,3)=286 triples computed vectorized via numpy cross products.
3. **Fast local search**: Deterministic (seeded) batched hill-climb. Identify the worst triple, perturb one of its free points with K Gaussian candidates, project into the triangle, and recompute only the ~66 triples containing that point; the minimum over remaining triples is cached. Accept non-decreasing moves only.
4. **Annealing + restarts**: Perturbation scale anneals geometrically (coarse→fine); 5 seeded restarts plus a fine final refinement guard against poor local optima while keeping runtime a few seconds.
5. **Determinism & robustness**: Fixed seed, pure numpy, projection guarantees feasible duplicate-free output; returns list of 13 [x,y] pairs.
</DESCRIPTION>

import numpy as np
from itertools import combinations


def solve(n=13, seed=20240613):
    """Deterministic heuristic constructor for the 13-point Heilbronn problem.

    Anchors the convex hull as a unit-area equilateral triangle (vertices are
    points 0,1,2), then runs seeded annealing-style local search on the
    remaining interior points to maximize the minimum triangle area.
    Returns a list of n [x, y] pairs.
    """
    rng = np.random.default_rng(seed)
    npts = n

    # Unit-area equilateral triangle.
    side = 2.0 / (3.0 ** 0.25)          # (sqrt(3)/4) * side^2 = 1
    height = (np.sqrt(3.0) / 2.0) * side
    tri = np.array([[0.0, 0.0], [side, 0.0], [side / 2.0, height]])

    triples = np.array(list(combinations(range(npts), 3)), dtype=np.int64)
    rows_with = [np.where((triples == j).any(axis=1))[0] for j in range(3, npts)]
    rows_without = [np.where(~(triples == j).any(axis=1))[0] for j in range(3, npts)]

    t0, t1, t2 = triples[:, 0], triples[:, 1], triples[:, 2]

    def all_areas(P):
        d1x = P[t1, 0] - P[t0, 0]
        d1y = P[t1, 1] - P[t0, 1]
        d2x = P[t2, 0] - P[t0, 0]
        d2y = P[t2, 1] - P[t0, 1]
        return 0.5 * np.abs(d1x * d2y - d1y * d2x)

    # Barycentric projection back into the triangle.
    u = tri[0] - tri[2]
    v = tri[1] - tri[2]
    det = u[0] * v[1] - u[1] * v[0]

    def project(pts):
        q = pts - tri[2]
        w0 = (q[:, 0] * v[1] - q[:, 1] * v[0]) / det
        w1 = (u[0] * q[:, 1] - u[1] * q[:, 0]) / det
        w2 = 1.0 - w0 - w1
        W = np.clip(np.stack([w0, w1, w2], axis=1), 0.0, None)
        W /= W.sum(axis=1, keepdims=True)
        return W @ tri

    def local_search(P, steps, K=48, s0=0.12, s1=0.002):
        P = P.copy()
        areas = all_areas(P)
        cur = areas.min()
        for step in range(steps):
            sig = s0 * (s1 / s0) ** (step / max(steps - 1, 1))
            worst = int(np.argmin(areas))
            members = triples[worst]
            free_members = [int(p) for p in members if p >= 3]
            if free_members:
                j = int(free_members[rng.integers(0, len(free_members))])
            else:
                j = 3 + int(rng.integers(0, npts - 3))
            ridx = rows_with[j - 3]
            other = rows_without[j - 3]
            m_other = areas[other].min() if other.size else 0.0

            cand = project(P[j] + rng.normal(0.0, sig, size=(K, 2)))
            Aidx = triples[ridx]
            is_j = (Aidx == j)
            base = P[Aidx]
            coords = np.where(is_j[None, :, :, None], cand[:, None, None, :], base[None])
            d1 = coords[:, :, 1] - coords[:, :, 0]
            d2 = coords[:, :, 2] - coords[:, :, 0]
            ar = 0.5 * np.abs(d1[:, :, 0] * d2[:, :, 1] - d1[:, :, 1] * d2[:, :, 0])
            newmin = np.minimum(ar.min(axis=1), m_other)
            k = int(np.argmax(newmin))
            if newmin[k] >= cur:
                P[j] = cand[k]
                areas = all_areas(P)
                cur = areas.min()
        return P, cur

    best_P = None
    best_val = -1.0
    for _ in range(5):
        W = rng.random((npts - 3, 3)) + 0.02
        W /= W.sum(axis=1, keepdims=True)
        P = np.vstack([tri, W @ tri])
        P, val = local_search(P, 3500)
        if val > best_val:
            best_P, best_val = P, val

    best_P, best_val = local_search(best_P, 3000, s0=0.01, s1=0.0005)

    return [[float(x), float(y)] for x, y in best_P]
