<DESCRIPTION>
Implement a robust constructor for the n=13 Heilbronn triangle problem using a hybrid strategy: (1) generate diverse candidate configurations (3-fold symmetric boundary+interior arrangements, rotated ring configurations, and seeded random distributions), (2) apply deterministic hill-climbing local refinement with adaptive shrinking step sizes on the objective "smallest triangle area normalized by convex hull area", (3) return the best configuration found. The optimization uses vectorized triangle-area computation over all C(13,3)=286 triangles, projected back into the convex hull after perturbations. Multiple restarts with fixed seeds guarantee determinism while providing good coverage of configuration space. The normalization by hull area makes the score scale-invariant, matching the primary performance metric.

            try:

                return ConvexHull(pts).volume

                P = pts[np.argsort(pts[:, 0])]
                def cross(o, a, b):
                    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])
                lower = []
                for p in P:
                    while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
                        lower.pop()
                    lower.append(p)
                upper = []

                    s += x1*y2 - x2*y1
                return abs(s) / 2.0
