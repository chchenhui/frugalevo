<DESCRIPTION>
The key observation from the prior programs: all runs plateau at min_area ≈ 0.02 while the best program (score 0.71) used the largest time budget (7s). Random hill climbing with single-point perturbations is extremely inefficient in 26 dimensions. A much stronger approach is a smooth surrogate of the min-area objective optimized by Adam with exact analytical gradients: use a soft-min (negated LogSumExp) over the 286 triangle areas plus a term lifting the k smallest areas (so the bottom of the area distribution rises together rather than one triangle at a time), and a smooth surrogate for the hull area in the denominator. The full gradient of every triangle area w.r.t. all 13 points is computable in closed form and vectorized over all 286 triangles, so each Adam step costs only microseconds — thousands of steps per seed within a 7s budget. We keep a strict min-area evaluation for the true objective (tracking the best feasible configuration seen), add a final bottleneck-targeted polish, and enlarge the time budget to 7s since the 0.71-scoring program shows more time pays off. Seeds are diversified (rings, ellipses, 3-fold symmetric configurations known to be good for Heilbronn).

    # ---- Phase 1: Adam on smooth soft-min surrogate (exact gradients) ----
    def _softmin_grads(pts, tau=0.002, kk=10):
        """Smooth surrogate S = softmin(areas) + lam * mean of kk smallest
        (via soft weights), gradient w.r.t. all points. Exact chain rule."""
        p = pts[tri_idx]                       # (286,3,2)
        a = p[:, 0]; v1 = p[:, 1] - a; v2 = p[:, 2] - a
        cr = v1[:, 0]*v2[:, 1] - v1[:, 1]*v2[:, 0]  # signed cross (286,)
        areas = np.abs(cr) * 0.5
        # soft-min via negated LogSumExp on -areas/tau
        z = -areas / tau
        zm = z.max()
        w = np.exp(z - zm)
        smin = -tau * (zm + np.log(w.sum()))
        g_soft = w / w.sum()                   # weights on each triangle
        # soft "mean of kk smallest": weights from another softmax, sharper
        tau2 = 2.0 * np.sort(areas)[min(kk, len(areas)-1)] + 1e-12
        z2 = -areas / tau2
        zm2 = z2.max()
        w2 = np.exp(z2 - zm2)
        w2 = (w2 / w2.sum()) * kk              # sums to kk
        lam = 0.35
        gw = g_soft + lam * w2 / kk            # combined triangle weights
        # d area / d cross = sign(cr) * 0.5
        dcr = gw * np.sign(cr) * 0.5
        # accumulate gradient onto the three vertices of each triangle
        grad = np.zeros_like(pts)
        for c in range(3):
            # derivative of cross wrt vertex c
            # cr = (b-a) x (c-a); wrt a: v2-perp - v1-perp etc.
            if c == 0:
                gx = (v2[:, 1] - v1[:, 1])
                gy = (v1[:, 0] - v2[:, 0])
            elif c == 1:
                gx = -v2[:, 1]
                gy = v2[:, 0]
            else:
                gx = v1[:, 1]
                gy = -v1[:, 0]
            np.add.at(grad, tri_idx[:, c], np.column_stack(
                [dcr * gx, dcr * gy]))
        return smin, grad

    def _adam(pts0, deadline, lr=0.01, iters=4000):
        pts = pts0.copy()
        m = np.zeros_like(pts); v = np.zeros_like(pts)
        b1, b2, eps = 0.9, 0.999, 1e-8
        ha = _convex_hull_area(pts)
        step = 0
        while step < iters and time.time() < deadline:
            smin, g = _softmin_grads(pts)
            # normalize hull area to 1 periodically (scale-invariance):
            # maximize smin directly, rescale afterwards
            step += 1
            m = b1 * m + (1 - b1) * g
            v = b2 * v + (1 - b2) * g * g
            mh = m / (1 - b1 ** step)
            vh = v / (1 - b2 ** step)
            pts = pts + lr * mh / (np.sqrt(vh) + eps)
        # rescale to unit-ish hull and return
        ha = _convex_hull_area(pts)
        if ha > 1e-12:
            pts = pts / np.sqrt(ha)
        return pts
