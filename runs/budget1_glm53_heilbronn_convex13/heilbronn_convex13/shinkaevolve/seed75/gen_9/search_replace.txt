<DESCRIPTION>
The key weakness is the blind hill-climbing: it perturbs random points and immediately accepts any score increase, which gets stuck easily. Improvement strategy based on Heilbronn-specific geometric insight: the objective is governed by a few "bottleneck" triangles, so moves should target vertices of the currently-smallest triangles. I also improve seeds (12-gon + center, two-ring 7+6 configuration are classic boundary-heavy Heilbronn candidates), use simulated annealing with reheating to escape local optima, always track the global best, and use a scale-invariant step size (sigma scaled by hull diameter) so moves don't stall for small/large configurations. Targeted edits to the seed construction and the optimization loop.

def _score(pts, tri_idx):
    ha = _convex_hull_area(pts)
    if ha <= 1e-12:
        return 0.0
    return _min_triangle_area(pts, tri_idx) / ha


def _bottleneck_vertices(pts, tri_idx, k=3):
    """Indices of points participating in the k smallest triangles."""
    p = pts[tri_idx]
    a = p[:, 0]
    v1 = p[:, 1] - a
    v2 = p[:, 2] - a
    cr = np.abs(v1[:, 0]*v2[:, 1] - v1[:, 1]*v2[:, 0])
    order = np.argsort(cr)[:k]
    return np.unique(tri_idx[order])
