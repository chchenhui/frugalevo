<DESCRIPTION>
The best prior program (combined 0.71) used adaptive-sigma strict-improvement hill climbing with many structural seeds and a second restart phase, while Gen 8 showed bottleneck-triangle-targeted perturbations help escape local optima. The current program regressed (0.57) because its simulated annealing accepts downhill moves, wandering without accumulating improvement. This edit replaces the annealing inner loop with the proven strict-improvement hill climb (sigma grows on improvement, shrinks otherwise, terminates when sigma < 1e-5 so each seed converges quickly and time is saved), but targets the bottleneck-triangle vertices ~50% of moves. The freed time is spent on a second phase of restarts from perturbed best configurations, which is where the 0.71 program gained its edge. Strict-improvement acceptance plus adaptive sigma deterministically ratchets the score upward, and bottleneck targeting speeds convergence per seed so more restarts fit in the 3s budget.

    def _climb(pts, sc, sigma0, deadline):
        """Adaptive-sigma strict-improvement hill climb with
        bottleneck-triangle-targeted moves (~50% of proposals)."""
        sigma = sigma0
        while time.time() < deadline:
            improved = False
            for _ in range(200):
                cand = pts.copy()
                if rng.random() < 0.5:
                    # target a vertex of the current bottleneck triangle
                    tri = _smallest_tri_idx(pts)
                    i = int(rng.choice(tri))
                else:
                    i = int(rng.integers(n))
                cand[i] += rng.normal(0, sigma, 2)
                csc = _score(cand, tri_idx)
                if csc > sc + 1e-12:
                    pts, sc = cand, csc
                    improved = True
            if improved:
                sigma = min(sigma * 1.3, 0.3)
            else:
                sigma *= 0.6
            if sigma < 1e-5:
                break
        return pts, sc
