<DESCRIPTION>
The Adam/softmin approach scores 0.72, while pure hill-climbing scored 0.68. Each optimizer has complementary strengths: softmin-Adam makes coordinated global rearrangements (escaping poor basin shapes), while greedy bottleneck-pool hill-climbing makes sharp, exact max-min moves once near a local optimum (softmin with finite temperature plateaus before the true min is maximized). The edit:

1. Adds structured seeds on a parabola (a classical Heilbronn test curve where triangle areas factor into products of gaps — a good basin for max-min configurations) and a stretched lattice.
2. Adds a deterministic greedy refinement routine `_refine` that perturbs only vertices belonging to the currently-smallest triangles (bottleneck pool), with geometrically decaying step size — this performs exact max-min ascent, which softmin-Adam cannot fully achieve at finite temperature.
3. Rewrites Phase 2 as a hybrid loop: each iteration does a short Adam re-anneal (global reshaping) followed by a bottleneck hill-climb polish (local exact sharpening), keeping the best of both. Since the score is scale-invariant this reliably pushes the true minimum triangle up, and the final rescale to unit hull area is preserved.

def _refine(pts, rng, deadline, sigma0=0.02):
    """Greedy exact max-min ascent: perturb only vertices of the
    currently-tightest triangles, with geometric step decay."""
    pts = pts.copy()
    sc = _score(pts)
    sigma = sigma0
    while time.time() < deadline and sigma > 1e-6:
        pool = None
        for _ in range(250):
            cand = pts.copy()
            if pool is None:
                cr = np.abs(_cross_all(pts))
                idx = np.argpartition(cr, 8)[:8]
                pool = np.unique(TRI_IDX[idx])
            i = int(rng.choice(pool))
            cand[i] += rng.normal(0, sigma, 2)
            csc = _score(cand)
            if csc > sc + 1e-14:
                pts, sc = cand, csc
                pool = None
        sigma *= 0.82
    return pts, sc
