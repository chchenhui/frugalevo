<DESCRIPTION>
Add bottleneck-vertex-targeted perturbation to the fine-tuning hill climb: with ~50% probability, perturb a vertex of the current minimum-area triangle instead of a uniformly random subset. This focuses the search on the constraint that actually limits the score, helping escape local optima. We compute the argmin over the 286 vectorized triangle areas to identify the bottleneck vertices.

        sigma = 0.004
        while time.time() - t_start < time_limit and time.time() - t_seed < per_seed * 1.3 and sigma > 1e-5:
            improved = False
            for _ in range(60):
                cand = pts.copy()
                # bottleneck-vertex targeting: half the time perturb a vertex
                # of the current smallest-area triangle
                if rng.random() < 0.5:
                    p = cand[tri_idx]
                    a = p[:, 0]
                    v1 = p[:, 1] - a
                    v2 = p[:, 2] - a
                    areas = np.abs(v1[:, 0]*v2[:, 1] - v1[:, 1]*v2[:, 0])
                    btri = tri_idx[int(np.argmin(areas))]
                    nb = int(rng.integers(1, 4))
                    if nb == 3:
                        idxs = btri
                    else:
                        idxs = rng.choice(btri, size=nb, replace=False)
                else:
                    k = int(rng.integers(1, 4))
                    idxs = rng.choice(n, size=k, replace=False)
