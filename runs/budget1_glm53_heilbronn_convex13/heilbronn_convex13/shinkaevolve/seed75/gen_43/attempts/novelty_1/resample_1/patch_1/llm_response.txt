<DESCRIPTION>
All prior programs plateau at min_area_normalized ≈ 0.02 because the restart kicks perturb all 26 coordinates with small σ (0.05). Isotropic full-kicks average out: every triangle changes a little, so the incumbent's basin structure is largely preserved and the subsequent climb falls back into the same local optimum. The recommendation is to kick only 3–4 randomly chosen vertices with a larger σ (0.12–0.15), so a genuine basin transition occurs in one region of the configuration while the rest of the geometry stays fixed. Additionally, with ~20% probability, kick all 3 vertices of the current bottleneck triangle with correlated noise (same displacement added to each vertex — this rigidly translates the worst triangle relative to the rest, a move that single-vertex perturbations cannot explore, since translating one vertex of the bottleneck changes its area only quadratically in some directions). Acceptance stays strict on the best-seen score. I also raise the time budget to 4.5s (still under 7s used by better-scoring programs) and lengthen each restart's deadline so the larger kicks have room to be polished.
