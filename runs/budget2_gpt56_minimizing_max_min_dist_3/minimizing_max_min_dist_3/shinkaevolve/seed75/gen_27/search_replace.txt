<DESCRIPTION>
Add a deterministic derivative-free local search after the contact-force polishing. The exact minimum/maximum distance objective is nonsmooth: when a closest or diameter pair changes, its averaged contact-force direction can cease to be improving and the existing force loop stops. Single-point random-direction moves with exact-ratio acceptance can cross these contact-switch boundaries while preserving every accepted improvement. The step size contracts only after an unsuccessful sweep, providing a narrow final refinement without materially increasing runtime.
</DESCRIPTION>

        # The active-contact force can stall at a nonsmooth contact switch.
        # Use a small deterministic pattern search on individual points,
        # accepting only improvements of the true diameter-normalized ratio.
        # This also permits locally asymmetric adjustments that are obscured
        # when several nearly active contacts are averaged together.
        x = candidate.copy()
        move_size = 0.028
        for _ in range(18):
            improved = False
            for point in rng.permutation(n):
                direction = rng.normal(size=3)
                direction /= np.linalg.norm(direction)
                for sign in (1.0, -1.0):
                    trial = x.copy()
                    trial[point] += sign * move_size * direction
                    trial = normalize(trial)
                    trial_value = exact_ratio(trial)
                    if trial_value > candidate_value + 1e-13:
                        x = trial
                        candidate = trial.copy()
                        candidate_value = trial_value
                        improved = True
                        break
            if not improved:
                move_size *= 0.62
