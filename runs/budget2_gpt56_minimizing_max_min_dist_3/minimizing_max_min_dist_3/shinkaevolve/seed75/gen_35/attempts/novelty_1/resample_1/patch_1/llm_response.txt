<DESCRIPTION>
Retain useful geometry even when the first SLSQP call reaches its iteration limit, because its returned iterate can still have a better exact diameter ratio. Then rescale that iterate to an explicitly feasible diameter-one formulation and run a second, longer exact constrained solve. This implements an active-set tightening pass: the first solve discovers a contact graph, while the second starts with strict lower-bound slack near that graph and can move all contacts jointly without being limited by the original nearly-active initialization.
</DESCRIPTION>

        # SLSQP commonly reports an iteration-limit status after it has found
        # an excellent contact graph.  Its iterate is still meaningful for
        # the scale-invariant objective, so evaluate it independently of the
        # solver status and use it as the seed for a fresh feasible pass.
        solver_points = unpack(result.x)
        solver_q = distances_sq(solver_points)
        if np.all(np.isfinite(solver_points)) and float(np.max(solver_q)) > 1.0e-12:
            polished = normalize(solver_points)
            polished_value = ratio_sq(polished)
            if polished_value > best_value:
                best_value = polished_value
                best = polished

            # Reimpose diameter exactly one and make the lower-bound
            # constraint slightly slack.  This second solve is an
            # active-contact polishing pass rather than merely continuing
            # from a numerically tight, potentially stalled constraint set.
            solver_points /= np.sqrt(float(np.max(solver_q)))
            refined_ratio = ratio_sq(solver_points)
            refined_z0 = np.concatenate((
                solver_points[1:].ravel(),
                [0.999999 * refined_ratio],
            ))
            refined = minimize(
                lambda z: -z[-1],
                refined_z0,
                jac=lambda z: np.r_[np.zeros(3 * (n - 1)), -1.0],

                    "type": "ineq",
                    "fun": constraints,
                    "jac": constraints_jacobian,

                method="SLSQP",
                options={"maxiter": 1400, "ftol": 2.0e-14, "disp": False},
            )
