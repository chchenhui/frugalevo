<DESCRIPTION>
The best prior result used only translation and global-scale normalization rather than constraining every point to the unit sphere. A diameter-packing optimum is not generally cospherical, so the per-point projection removes useful radial degrees of freedom. This edit changes the existing normalization helper to center the configuration and fix only its RMS radius, while changing momentum/gradient projection to remove just translation and global scaling. The cube-axis seed is also rescaled so its axis vertices initially lie on the same radius as cube vertices.
</DESCRIPTION>

def _normalize_rows(points: np.ndarray) -> np.ndarray:
    """Remove translation and fix RMS radius without imposing cosphericity."""
    centered = points - np.mean(points, axis=0, keepdims=True)
    scale = np.sqrt(np.mean(np.sum(centered * centered, axis=1)))
    return centered / max(float(scale), 1e-12)
