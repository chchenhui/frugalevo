adaptive_contact_polish
</NAME>

<DESCRIPTION>
Add a second, contact-graph-aware polishing stage after each successful exact SLSQP solve. The first solve identifies the emergent minimum-distance and diameter contacts. A short regularized solve then reduces slack variation on those contacts while retaining every original feasibility constraint, followed by a final pure max-t solve. This can improve convergence in the degenerate active-set regime where many equivalent diameter/minimum constraints make a single linear-objective SLSQP pass terminate slightly short of the best feasible packing.
</DESCRIPTION>

            # second active-set pass substantially less sensitive to SLSQP's
            # choice among nearly dependent constraint gradients.
            y_contact = result.x.copy()
            q_contact = dist2(unpack(y_contact))
            t_contact = float(y_contact[-1])
            low_contact = q_contact <= 1.012 * max(t_contact, 1.0e-10)
            high_contact = q_contact >= 0.988

            if np.any(low_contact) and np.any(high_contact):
                low_count = float(np.count_nonzero(low_contact))
                high_count = float(np.count_nonzero(high_contact))

                def contact_objective(y: np.ndarray) -> float:
                    qy = dist2(unpack(y))
                    low_slack = qy[low_contact] - y[-1]
                    high_slack = 1.0 - qy[high_contact]
                    return float(
                        -y[-1]
                        + 0.25 * np.dot(low_slack, low_slack) / low_count
                        + 0.25 * np.dot(high_slack, high_slack) / high_count
                    )
