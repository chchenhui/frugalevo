<DESCRIPTION>
Add an exact-objective active-contact polishing phase after the smooth continuation. The smooth power objective is useful for entering a good basin, but at high powers it can still distribute force over pairs that are no longer limiting. The added phase explicitly identifies pairs close to the current minimum and maximum distances, pushes the former apart and pulls the latter together, and uses a deterministic multi-step accept-only line search evaluated with the true min/max ratio.

This preserves the best point encountered rather than assuming the final smooth iterate is best. The tolerance schedule starts with a small contact band to coordinate nearly active constraints and ends with a sharp band focused on the actual bottlenecks.
</DESCRIPTION>

        # The smooth objective locates a useful basin, but its force remains
        # spread over non-limiting pairs.  Finish with an accept-only descent
        # on the actual contact sets, retaining the best exact-ratio iterate.
        candidate = x.copy()
        candidate_value = exact_ratio(candidate)

        for tolerance, base_step, iterations in (
            (0.030, 0.030, 180),
            (0.015, 0.016, 240),
            (0.006, 0.008, 300),
        ):
            for _ in range(iterations):
                delta = x[iu] - x[ju]
                d2 = np.sum(delta * delta, axis=1)
                distances = np.sqrt(np.maximum(d2, 1e-15))
                dmin = distances.min()
                dmax = distances.max()

                # Average logarithmic forces over all nearly active contacts.
                # Closest pairs are expanded; diameter pairs are contracted.
                near_low = distances <= dmin * (1.0 + tolerance)
                near_high = distances >= dmax * (1.0 - tolerance)
                weights = np.zeros_like(distances)
                weights[near_low] = 1.0 / np.count_nonzero(near_low)
                weights[near_high] -= 1.0 / np.count_nonzero(near_high)
                pair_force = weights[:, None] * delta / d2[:, None]

                force = np.zeros_like(x)
                np.add.at(force, iu, pair_force)
                np.add.at(force, ju, -pair_force)
                force -= force.mean(axis=0, keepdims=True)
                fscale = np.sqrt(np.mean(np.sum(force * force, axis=1)))
                if fscale == 0.0:
                    break

                # The nonsmooth objective can reject a full force step near a
                # contact switch, so deterministically backtrack on its exact
                # value rather than allowing a polishing step to lose quality.
                accepted = False
                for multiplier in (1.0, 0.5, 0.25, 0.125):
                    trial = normalize(x + base_step * multiplier * force / fscale)
                    trial_value = exact_ratio(trial)
                    if trial_value > candidate_value + 1e-13:
                        x = trial
                        candidate = trial.copy()
                        candidate_value = trial_value
                        accepted = True
                        break
                if not accepted:
                    break

        if candidate_value > best_value:
            best_value = candidate_value
            best = candidate
