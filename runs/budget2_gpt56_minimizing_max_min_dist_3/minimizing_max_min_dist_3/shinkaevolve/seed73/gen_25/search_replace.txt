<DESCRIPTION>
Replace the final stochastic soft-force polishing with explicit contact-aware moves. The objective is nonsmooth: only shortest-pair and diameter-pair memberships matter locally. This edit forms separate near-minimum and near-maximum active sets, alternates a shortest-contact repulsion move with a diameter-contact contraction move, and retains small random perturbations solely for contact-graph exchanges. Every move remains subject to strict exact-ratio acceptance, so this cannot degrade the best retained configuration while providing more decisive local refinement than a single force whose competing contacts can cancel.
</DESCRIPTION>

        # Exact-objective accepted moves using explicitly separated contact
        # sets.  Near-shortest pairs are pushed apart and near-diameter pairs
        # are pulled together on alternating proposals; separating these moves
        # avoids cancellation when the two active graphs overlap at a vertex.
        for p0 in polished + [best]:
            p = p0.copy()
            current = ratio(p)
            scale = 1.8e-3

            for block in range(18):
                accepted = 0
                contact_width = 2.0e-3 * (0.72 ** block) + 2.0e-6

                for attempt in range(110):
                    q = dsq(p)
                    qlo, qhi = q.min(), q.max()
                    delta = p[iu] - p[ju]

                    short = q <= qlo * (1.0 + contact_width)
                    long = q >= qhi * (1.0 - contact_width)
                    force = np.zeros_like(p)

                    # Alternate pure active-set motions.  The inverse squared
                    # length factors make the displacement closer to a log
                    # distance ascent/descent direction.
                    if attempt % 3 == 0:
                        pair = delta[short] / q[short, None]
                        np.add.at(force, iu[short], pair)
                        np.add.at(force, ju[short], -pair)
                    elif attempt % 3 == 1:
                        pair = -delta[long] / q[long, None]
                        np.add.at(force, iu[long], pair)
                        np.add.at(force, ju[long], -pair)
