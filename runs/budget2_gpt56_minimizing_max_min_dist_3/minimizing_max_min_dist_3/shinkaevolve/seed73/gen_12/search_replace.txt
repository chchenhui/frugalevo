<DESCRIPTION>
Add a deterministic final polishing phase after the continuation-based Adam search. The existing objective is a smooth approximation and can leave a small gap to the true nonsmooth minimum-distance/diameter objective, especially when the identity of active closest or diameter pairs changes.

The new phase computes a much sharper log-distance softmin/softmax ascent direction, normalizes this direction to make step sizes scale-stable, and uses backtracking line search evaluated against the exact ratio. A candidate is retained only when its actual minimum-pairwise-distance divided by diameter improves, so this stage cannot reduce the best configuration found by the existing optimizer. Cycling sharpness parameters helps exchange active constraints rather than becoming locked to one particular soft approximation.
</DESCRIPTION>

    # Polish the best continuation result against the *exact* nonsmooth
    # objective.  Sharp soft extrema provide useful bundle-like directions,
    # while backtracking acceptance is based only on the true ratio.
    polished = best_points.copy()
    upper = np.triu_indices(n, 1)
    polish_ratio = best_ratio
    polish_eye = np.eye(n, dtype=bool)

    for iteration in range(1200):
        delta = polished[:, None, :] - polished[None, :, :]
        distance2 = np.sum(delta * delta, axis=2)
        distance2[polish_eye] = 1.0
        distance = np.sqrt(distance2)

        # Alternating sharpness permits active closest/farthest pairs to
        # exchange during the final minimax refinement.
        p = (70.0, 130.0, 240.0, 420.0)[iteration % 4]
        log_distance = np.log(distance)
        near_scores = -p * log_distance
        far_scores = p * log_distance
        near_scores[polish_eye] = -np.inf
        far_scores[polish_eye] = -np.inf

        near_scores -= np.max(near_scores)
        far_scores -= np.max(far_scores)
        near_weights = np.exp(near_scores)
        far_weights = np.exp(far_scores)
        near_weights /= np.sum(near_weights)
        far_weights /= np.sum(far_weights)

        coefficient = (near_weights - far_weights) / distance2
        coefficient[polish_eye] = 0.0
        direction = np.sum(coefficient[:, :, None] * delta, axis=1)
        direction -= direction.mean(axis=0, keepdims=True)

        direction_scale = np.sqrt(np.mean(np.sum(direction * direction, axis=1)))
        if direction_scale < 1e-14:
            continue
        direction /= direction_scale

        # Exact-ratio line search: retain only genuine improvements.
        step_size = 0.030
        for _ in range(7):
            candidate = polished + step_size * direction
            candidate -= candidate.mean(axis=0, keepdims=True)
            candidate /= np.sqrt(np.mean(np.sum(candidate * candidate, axis=1)))

            candidate_delta = candidate[:, None, :] - candidate[None, :, :]
            candidate_distance = np.sqrt(
                np.sum(candidate_delta * candidate_delta, axis=2)
            )
            candidate_ratio = (
                np.min(candidate_distance[upper]) / np.max(candidate_distance[upper])
            )
            if candidate_ratio > polish_ratio + 1e-13:
                polished = candidate
                polish_ratio = candidate_ratio
                break
            step_size *= 0.5

    return np.asarray(polished, dtype=float)
