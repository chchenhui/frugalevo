<DESCRIPTION>
Add a final deterministic constrained optimization pass specialized for the hard packing formulation.  Normalize the incumbent so its closest squared distance is one, then minimize an explicit diameter variable subject to every pairwise squared distance being at least one and at most that diameter.  This is the direct epigraph formulation of the evaluator objective, unlike the earlier softmin/softmax surrogate.

The analytic constraint Jacobian makes SLSQP practical despite the 91 pair constraints.  Two passes are used: the first permits a minute lower-bound relaxation to settle the active contact graph, while the second uses the exact lower bound and tighter termination.  The result is accepted only if it is numerically feasible and improves the exact ratio, retaining the robust stochastic incumbent otherwise.
</DESCRIPTION>

    # minimizing an epigraph variable D with 1 <= q_ij <= D for every pair.
    # This also resolves the small discrepancy between a finite-beta surrogate

        coordinates = state[:-1].reshape(n, d)
        delta = coordinates[iu] - coordinates[ju]
        q = np.einsum("ij,ij->i", delta, delta)
        return np.concatenate((q - lower, state[-1] - q))

    def diameter_constraint_jacobian(
        state: np.ndarray, lower: float
    ) -> np.ndarray:
        del lower
        coordinates = state[:-1].reshape(n, d)
        delta = coordinates[iu] - coordinates[ju]
        count = iu.size
        jacobian = np.zeros((2 * count, n * d + 1), dtype=np.float64)
        rows = np.arange(count)[:, None]
        axes = np.arange(d)[None, :]
        first_columns = d * iu[:, None] + axes
        second_columns = d * ju[:, None] + axes
        derivative = 2.0 * delta
        jacobian[rows, first_columns] = derivative
        jacobian[rows, second_columns] = -derivative
        jacobian[count + rows, first_columns] = -derivative
        jacobian[count + rows, second_columns] = derivative
        jacobian[count:, -1] = 1.0
        return jacobian
