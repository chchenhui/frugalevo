<DESCRIPTION>
Use the recommended feasibility-aware two-pass epigraph refinement. The first SLSQP pass has a minute lower-distance relaxation, which allows a nearly active contact graph to exchange constraints instead of being locked by floating-point-level violations. Its result is then rescaled so its true minimum squared distance is exactly one and used to initialize a tighter exact pass. Every returned intermediate configuration is evaluated using the evaluator’s actual hard squared ratio, so only a genuine improvement is retained.
</DESCRIPTION>
