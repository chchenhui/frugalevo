<DESCRIPTION>
Strengthen the exact diameter formulation with a feasibility-relaxed multi-pass SLSQP continuation. The first constrained solve identifies a contact graph; subsequent solves are reinitialized after exact minimum-distance rescaling and use progressively smaller lower-bound relaxation. This avoids SLSQP becoming prematurely stuck on tiny numerical lower-bound violations while preserving the scale-invariant ratio after each rescaling. Candidate solutions from every pass are evaluated with the true squared min/max ratio, so an imperfect solver termination cannot degrade the returned packing.
</DESCRIPTION>

        def constrained_polish(seed: np.ndarray, lower_slack: float = 0.0) -> np.ndarray:
            # A minute relaxation of the lower distance constraints is useful
            # after a contact graph has formed: it lets SLSQP exchange nearly
            # active contacts instead of treating roundoff-level violations as
            # an immovable active set.  The result is rescaled before the next
            # pass, so this does not alter the scale-free objective.
            seed = seed / np.sqrt(
                np.min(
                    np.einsum(
                        "pd,pd->p",
                        seed[pair_i] - seed[pair_j],
                        seed[pair_i] - seed[pair_j],
                    )
                )
            )
            lower_bound = 1.0 - lower_slack

                "pd,pd->p",
