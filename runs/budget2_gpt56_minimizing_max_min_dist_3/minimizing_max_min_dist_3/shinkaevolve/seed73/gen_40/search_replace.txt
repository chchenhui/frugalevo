<DESCRIPTION>
Replace the final isotropic random hill climb with an active-contact exact-ratio polish.  Near a diameter-packing optimum, only pairs close to the current minimum and maximum distances determine the nonsmooth objective.  The new stage explicitly forms separating forces from short contacts and contracting forces from long contacts, then selects pure or mixed projected moves based on contact-count imbalance.  Every move is still accepted only when the exact squared min/max ratio improves.  A small random tangent proposal remains available to escape contact-graph degeneracies, while adaptive contact width and proposal scale make the stage increasingly local after improvements stall.
</DESCRIPTION>

        # families rather than perturbing every coordinate independently.
        # A short-contact force separates its endpoints; a long-contact force
        # contracts them.  This is particularly effective when several nearly
        # tied contacts exchange roles at a nonsmooth optimum.
        current_ratio = exact_ratio(points)
        proposal_scale = 0.010
        contact_width = 0.010
        stalled_batches = 0
        for exact_step in range(650):
            delta = points[iu] - points[ju]
            dsq = np.einsum("ij,ij->i", delta, delta)
            dmin = dsq.min()
            dmax = dsq.max()
            short = dsq <= dmin * (1.0 + contact_width)
            long = dsq >= dmax * (1.0 - contact_width)

            short_force = np.zeros_like(points)
            long_force = np.zeros_like(points)
            short_pair_force = delta[short] / (dsq[short, None] + 1.0e-15)
            long_pair_force = -delta[long] / (dsq[long, None] + 1.0e-15)
            np.add.at(short_force, iu[short], short_pair_force)
            np.add.at(short_force, ju[short], -short_pair_force)
            np.add.at(long_force, iu[long], long_pair_force)
            np.add.at(long_force, ju[long], -long_pair_force)

            short_count = max(1, int(short.sum()))
            long_count = max(1, int(long.sum()))
            imbalance = short_count / long_count

            # When one family dominates, first address that limiting family.
            # Otherwise use a per-point normalized mixture so that vertices
            # incident to both families do not receive an excessive force.
            combined = short_force / short_count + long_force / long_count
