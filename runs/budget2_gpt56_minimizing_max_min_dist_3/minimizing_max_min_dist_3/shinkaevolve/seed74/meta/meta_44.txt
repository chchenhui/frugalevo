# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- **The current best program’s full-space smooth min/max continuation plus exact-ratio retention is a proven top-tier pattern.** The current program reaches `min_max_ratio = 0.24`, combined score `1.00`, in **2.60** time units by optimizing all 42 coordinates, increasing `beta` from `9` to `254` in broad search and from `260` to `1110` in polish, while selecting incumbents solely by the exact nonsmooth squared-distance ratio. This confirms the earlier result that smooth gradients are effective for locating contact structures, but exact-objective tracking is required to preserve true evaluator improvements.

- **Structured seed portfolios improve efficiency when followed by unrestricted refinement.** Generation 38 (*Layered Contact-Gradient Point Optimizer*) and Generation 41 (*Deterministic Multi-Stage Point Configuration Search*) both reached the same maximum `1.00` score and reported `0.24`, but in **1.82** and **1.83** units respectively—about 30% faster than the current best’s 2.60. Their layered hexagonal-ring/pole, cube-axis, antipodal, and related seeds appear to start closer to productive contact graphs than the current best’s 20 Gaussian starts, while their later optimization still permits full point-level adjustment.

- **Late active-contact polishing is consistently associated with crossing from the 0.22–0.23 tier to the 0.24 tier.** The current best uses four high-sharpness polishing attempts, including deterministic tangent-space perturbations around the best incumbent. Generation 38 similarly uses a high-sharpness final contact-graph polish, and Generation 41 uses rollback-based continuation followed by exact-ratio mutation hill climbing. All three obtain `1.00` / `0.24`, reinforcing that the final improvement is driven by resolving a small number of limiting shortest and longest pairs rather than by broad global search alone.

- **Active-contact methods can be efficient even without the full soft-objective machinery.** Generation 43 (*Rank-Based Contact Balancing Search*) uses ranked short-pair repulsion and long-pair attraction with structured seeds and obtains `0.22` / `0.90` in **1.60** units. This is lower quality than the exact-polished 0.24 solutions, but it shows sparse contact selection can produce a strong low-cost baseline. The main quality gain of the current best and Generations 38/41 is the more globally aligned soft min/max objective plus exact retention.

## Ineffective Approaches

- **Permanent low-dimensional geometric parameterization limits final quality unless symmetry is released.** Generation 42 begins from a favorable staggered-ring-plus-poles family and uses differential evolution, but reaches only `0.22`, combined score `0.93`, in **5.68** units. Although it eventually releases symmetry during its 42-coordinate polish, substantial effort is spent in a four-parameter evolutionary search. Relative to the current best’s direct full-space multistart continuation, the constrained/global-evolution phase adds runtime without reaching the 0.24 quality plateau.

- **Longer or more elaborate global search is not automatically beneficial.** Generation 42’s seeded differential evolution and 1,250-step local searches take more than twice the current best’s runtime yet score `0.93` rather than `1.00`. This is consistent with the prior evidence from slower 1.00 solutions: runtime grows when optimization budget is spread broadly, whereas the current best concentrates expensive sharp polishing only after a viable exact-ratio incumbent has been identified.

- **Rank-only contact balancing appears less evaluator-aligned than soft min/max ratio optimization.** Generation 43 efficiently reaches `0.22` / `0.90`, but does not match the 0.24 solutions. Its approach selects distance bands by rank and repels/attracts them, while the current best computes soft weights over all 91 distances and explicitly divides by soft minimum and soft maximum values. The latter more directly approximates ascent of the evaluator’s ratio and better handles transitions in which multiple pairs compete to become active contacts.

- **Structured initialization alone does not guarantee top quality.** Generation 42 has a strong geometric family and deterministic seeded regions, and Generation 43 has several structured seed types, but both stop at `0.22`. In contrast, Generations 38 and 41 combine geometry-aware starts with rollback, survivor selection, or exact-objective polishing. The differentiating factor is therefore not the presence of rings, poles, cube axes, or antipodal structures by itself, but the exact-managed unrestricted refinement after initialization.

## Implementation Insights

- **The current best’s gradient is tightly aligned with the measured objective.** For all 91 pairwise squared distances, `smooth_gradient` computes stable shifted exponentials for both a soft minimum and a soft maximum. Its coefficient
  `low_weights / soft_low - high_weights / soft_high`
  expands distances contributing to the minimum while shrinking distances contributing to the maximum. This is a stronger objective match than isolated nearest-neighbor repulsion, and its effectiveness is reflected in the current best’s `1.00` / `0.24` result.

- **Projection removes translation and scale from both state and search direction.** The current program normalizes after every update by centering the points and fixing RMS magnitude. It also projects the gradient by removing its mean and radial component. This prevents adaptive first and second moments from accumulating motion in invariance directions, leaving the optimizer focused on shape changes. The stable 2.60-unit result supports the prior conclusion that tangent-space projected updates are a key implementation detail in this problem.

- **Its rollback logic restores optimizer state, not just coordinates.** During high-beta polish, the current best tracks `local_best` using the exact ratio; after two checkpoint regressions, it restores `local_point`, clears momentum, damps the second-moment accumulator by `0.15`, and reduces step scale by `0.62`. This addresses the fact that a surrogate-gradient direction can become harmful when the active shortest or longest pair changes. Generation 38’s exact-ratio rollback and Generation 41’s rollback-based continuation independently support this design: both reached `1.00` in less time.

- **The newer fastest methods validate the current best’s architecture while refining its search allocation.** Generation 38’s targeted layered initialization, exact-objective incumbent tracking, geometry-aware restart perturbations, and contact polish closely mirror the current best’s broad-search-plus-polish structure. Generation 41 similarly uses structured seed screening, elite refinement, and deterministic exact-ratio hill climbing. Their faster runtimes suggest the major architectural ingredients of the current best are correct; their efficiency advantage comes primarily from better initial basin selection and more selective staging rather than from abandoning smooth continuation or exact polishing.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Replace most Gaussian starts with a compact deterministic structured portfolio, while retaining full 42-coordinate optimization immediately afterward.** Seed layered hexagonal-ring-plus-pole, staggered ring, cube/axis, antipodal, and slightly symmetry-broken variants; add tangent-space noise of roughly `0.02–0.05`, and keep only 6–10 random Gaussian starts for basin diversity. Generations 38 and 41 reached the same `0.24` tier about 30% faster, indicating that better contact-graph entry can reduce broad-search cost without sacrificing the current program’s unrestricted refinement.

2. **Convert the 20 × 1,500 uniform broad searches into a screen-and-survivor schedule.** Run all structured and random seeds for about `450–600` iterations using the existing `beta=9→~120` continuation, score every candidate with `exact_ratio_squared`, cluster or deduplicate near-identical candidates, then continue only the best 5–8 survivors for another `700–1,000` iterations toward `beta≈250–350`. This preserves the current best program’s exact incumbent selection and all-pair smooth objective, but reallocates computation toward promising basins as in the faster staged methods.

3. **Add a conservative exact active-contact gradient during high-beta polish, blended with the existing smooth gradient.** At each checkpoint or every few iterations, identify all pairs satisfying `dsq <= min_dsq * 1.01–1.02` and `dsq >= max_dsq * 0.98–0.99`; construct a ratio-gradient that expands active short pairs and contracts active long pairs, then use `grad = 0.80–0.90 * smooth_grad + 0.10–0.20 * active_grad` before the existing tangent-space projection. The smooth min/max continuation remains the main driver, while this explicitly targets the small active contact set responsible for the final `0.22→0.24` improvement.

4. **Make final polishing schedule-diverse rather than using four nearly identical `260→1110` trajectories.** Keep one current branch, but add a moderate branch such as `180→650` with somewhat larger learning rates, an aggressive sharp branch such as `450→1500` with smaller learning rates, and one branch initialized from a deterministic tangent perturbation of the best candidate rather than only Gaussian noise. The successful 0.24 methods use late exact-managed local search, but differing sharpness schedules can cross different nonsmooth contact transitions while exact-ratio retention protects the incumbent.

5. **Strengthen rollback after an exact-objective regression by resetting both adaptive moments and temporarily reducing sharpness.** When a checkpoint is meaningfully below `local_best`—for example, a relative drop exceeding `1e-4`—restore `local_point`, clear both `first` and `second`, reduce `step_scale`, and run the next `40–75` iterations at `beta *= 0.7–0.8` before returning to the nominal continuation. The existing rollback already contributes to top-tier performance; a brief beta retreat should make it less likely that momentum repeatedly forces the configuration through the same harmful active-contact transition.
