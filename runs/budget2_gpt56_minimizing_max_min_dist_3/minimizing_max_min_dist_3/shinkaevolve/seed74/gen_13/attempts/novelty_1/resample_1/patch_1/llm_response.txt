<DESCRIPTION>
Augment the existing random one-point perturbations with contact-force-biased proposals.  Near an optimal diameter packing, improvements are governed primarily by the shortest pairwise contacts.  For half of each batch, move the selected point away from nearby points using an inverse-fourth-power repulsive force, while retaining a small random component to break symmetric force cancellations.  The remaining proposals retain the original unbiased random moves, preserving exploration and avoiding reliance on the force heuristic alone.  All candidates continue through the existing centering and diameter normalization, so the optimization remains exactly aligned with the evaluator objective.

            candidates = np.repeat(current[None, :, :], batch_size, axis=0)
            moved = rng.integers(0, n, size=batch_size)

            # In addition to unbiased moves, try moves away from the active
            # near-contact constraints.  The inverse-fourth-power weighting
            # makes the shortest distances dominate without requiring an
            # explicit, discontinuous nearest-neighbour selection.
            offsets = current[moved, None, :] - current[None, :, :]
            separation_squared = np.sum(offsets * offsets, axis=-1)
            weights = 1.0 / (separation_squared + 1.0e-5) ** 2
            forces = np.sum(offsets * weights[:, :, None], axis=1)
            force_norms = np.linalg.norm(forces, axis=1, keepdims=True)
            force_directions = forces / np.maximum(force_norms, 1.0e-12)

            displacements = rng.normal(size=(batch_size, d)) * scale
            guided = np.arange(batch_size) < batch_size // 2
            displacements[guided] = (
                0.30 * displacements[guided]
                + 0.90 * scale * force_directions[guided]
            )
            candidates[np.arange(batch_size), moved] += displacements
